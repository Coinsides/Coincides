# 2026-09-12 Coincides:设计规划场——外观体系下半场、纸型自由化、导航窗格

> 背景:波次 B1a-B1d(皮引擎/板皮部件/纸型/材质追样)落库中,Henry 真机试用后连续四轮规划对谈(先不做,先商量)。

## 一、外观体系下半场(第一轮)

- **入口搬家**(Henry 拍):外观控制撤出 Settings,纸上「笔记外观」钮=快选条(预设小色卡)+详细编辑;Settings 瘦身为一行默认外观;
- **浮卡**(Henry 拍):详细编辑=非模态可拖浮卡,纸即预览(⛔另做预览);HQ 注:浮卡=钉住态第一个活原型(纯 UI 浮窗⛔入 placement);
- **色盘**(Henry 拍):hex 换三段式(精选色板+色轮+hex 高级保留);HQ 拆两题:皮 token 槽少是对的,真正要大池子的是**内容色**(标注/墨水/粉笔)→建**全局调色板资产**(命名色池,出厂 20-24+用户可添),所有取色处共享;字体池同理;
- **部件盘点**(Henry 拍方向):调研市面(Notion/OneNote/GoodNotes/Craft/Word)出《纸面部件注册表》:每件=可见性×样式变体×颜色(取 palette);纸底纹(横线/网格/点阵)入候选;逐步开放=逐件注册,⛔自由 CSS;
- **Agent 参与**(Henry 拍):深度定制主路=用户提需求→Agent 出 skin/部件配置提案→浮卡呈现→用户删改;浮卡数据形状=Agent 输出格式(人机同卡同旋钮)。

## 二、设计室与套装(第二轮)

## 三、墙触感、分隔线、标题页(第三轮)

- **墙触感**(Henry 提,HQ 定律获候认):**显示归皮,编辑归工具**——显示=--sk-wall-idle(B1d 已落);编辑=平时零命中(误触绝除),入显式工具态才可拖;HQ counter:并入 Layout 态(给排版工具态实职)⛔新钮,候 Henry 选;

- **标题页**(Henry 纠结,HQ 解案候认):Henry 直觉验证=标题现为裸 textarea 非 unit 公民;终局=**真封面页(第 0 页)+真相绑定块**(题名件/述名件,内容绑 notes.title/description——item_ref 同族机制,改它=改名),自由排版与真相不散同时成立,留英手册封面第一客户;排期随 V14 纸面工程线(与分页同批做页的家务);其前⛔中间态半自由,B1d 治比例撑颜值。

## 四、杂项批+纸型自由化+导航窗格(第四轮)

**杂项收账**:①暖纸桌面未铺满(棕外黑圈)=B1a 变量化射程边界,归 B1e 顺手修;②Settings 内容居中+Provider 收折叠项,归 B1e;③Project 卡面格式不统一/分隔线上下不一+project 内部(material/目标/卡片集)排版重设计→"HQ 先设计 Henry 挑错"模式,排 13.6 后;④**整体视觉大检**(Henry 立项):V14/15 完工后 HQ 全应用逐面走查出《视觉检查报告》,总体打补丁。

**纸型自由化**(Henry 裁向,HQ 认 B1c 交互失误):

- 建纸时选型撤销(外面选=生涩),纸型/尺寸调节迁**「笔记外观」浮卡+Layout 态**(看着纸选=WYSIWYG 定律);
- **每页可异形**(Gamma 感):笔记有默认纸型,任一页可单独覆写尺寸,新页回归默认——frame 几何本就逐帧存,机制便宜;
- **单位厘米/毫米⛔像素**(人类无像素概念;打印刻度 mm 映射现成);
- 预设扩常用族:A5/A4/A3/Letter/Legal(+Web 长页保留降级候评);
- Agent 生成⛔随心所欲页(笔记本要有笔记本的样子),异形=给人的选项;
- 排期:归 V14 纸面工程线(与分页/封面页同骨)。

**导航窗格**(Henry 拍照抄 Word):三页签=标题(树)/页面(单列缩略,复用 E4 渲染)/结果(纸内搜索);**标题的本体解**(HQ 案候认):heading=writing_role 新角色(heading_1/2/3,/h1+# 输入;⛔新块型⛔修宪;writing_role 枚举扩展=TextFlow 契约 amendment,F17 先例);agenda=heading 单元聚合投影(零新真相);小箭头折叠=toggle collapsed+按层级隐藏既有机制推广。

## 六、章节块(第五轮追谈,Henry 裁定合成)

Henry 对 heading 解案的关键补充:**块=章的领地**——自由写作/日记=无标题大块囊括所有;分章写作=新建块+戴标题,用户心智里"块内内容属于这个标题"(与 toggle 不同:toggle=行内口袋,章节块=一等公民房间)。

**合成模型(Henry 裁语义,HQ 机制)**:

- 机制层:heading 仍=writing_role 新角色(heading_1/2/3,契约 amendment 照走);
- 语义层:**块首行戴 heading→块升格为章,块内归属=实的块成员关系**(⛔Word 式推断归属);块间层级(H2 章挂最近 H1 下)才用推断——**实叶推枝**;
- 白送:拖把手=搬整章(现役块拖机制零改获新语义);块本体零新结构(是否为章由首行角色宣告,同一原语两种心智);
- 折叠章=块级折叠(部件注册表加行为);
- 细则待定(真机后裁):块中间的 heading 行=大字样式⛔立章(HQ 倾向:只有块首 heading 立章,agenda 只收块首)。

§五状态清单增补:章节块合成模型=**Henry 拍语义+HQ 机制候认细则**;导航窗格设计就绪,入批候拍。
