## 六、章节块(第五轮追谈,Henry 裁定合成)

Henry 对 heading 解案的关键补充:**块=章的领地**——自由写作/日记=无标题大块囊括所有;分章写作=新建块+戴标题,用户心智里"块内内容属于这个标题"(与 toggle 不同:toggle=行内口袋,章节块=一等公民房间)。

**合成模型(Henry 裁语义,HQ 机制)**:

- 机制层:heading 仍=writing_role 新角色(heading_1/2/3,契约 amendment 照走);
- 语义层:**块首行戴 heading→块升格为章,块内归属=实的块成员关系**(⛔Word 式推断归属);块间层级(H2 章挂最近 H1 下)才用推断——**实叶推枝**;
- 白送:拖把手=搬整章(现役块拖机制零改获新语义);块本体零新结构(是否为章由首行角色宣告,同一原语两种心智);
- 折叠章=块级折叠(部件注册表加行为);
- 细则待定(真机后裁):块中间的 heading 行=大字样式⛔立章(HQ 倾向:只有块首 heading 立章,agenda 只收块首)。

§五状态清单增补:章节块合成模型=**Henry 拍语义+HQ 机制候认细则**;导航窗格设计就绪,入批候拍。

## 十二、宪法的 domain 学:三不变量+仪式缩放(第十二轮,09-13)

Henry 点盲区:"用户文字永不直写"遇上"帮我润色这行字"——明示委托改自己的字,不就突破宪法?凡事都有 domain。

HQ 解(候 Henry 认):

1. **宪法禁的是"直"不是"改"**:委托授权做事,不授权跳过知情环节;真问题=一刀切重仪式在小 domain 里成官僚主义;
2. **三不变量**(=块终局档慢性病总药方"失手可见、可拒、可退"升格):任何 domain 里 Agent 动人的东西,可见/可拒/可退必须全真——不缩放;
3. **仪式四档按 domain 缩放**:润色一行=轻档**行内修订痕**(Word track changes 五百年答案:改动落文中带痕,勾=接受叉=还原);改一块几块=中档就地 diff 逐块采纳;整篇/批量=重档侧桌投影区分票;Agent 改自己造的=最轻档直落整批可撤;每档三不变量全真——轻档⛔是豁免,是宪法的紧凑形态;
4. **宪法解释学一句**:条文是原则,执行仪式随 domain 缩放,缩放的是重量,永不缩放的是可见可拒可退;"直写"定义收窄为**无痕静默替换**(唯一被永禁的东西);后逢违宪之争,先问三不变量再挑仪式档,⛔逐案立新法。
