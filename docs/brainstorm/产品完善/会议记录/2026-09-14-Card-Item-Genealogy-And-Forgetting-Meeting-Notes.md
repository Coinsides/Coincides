# 2026-09-14 Coincides:卡片五波谈——降采样、平级衍生、item 家谱与系统遗忘

> 参与:Henry(出题+逐波推进)/ Fable(品+总结+命名)。性质:认识论对谈,非工程排期;结论定调为**实验性草案**(Henry:"尽力而为")。蒸馏版见 `docs/agent-ops/design/item-genealogy-draft.md`。

## 波一 · 卡片=downsampling(Henry)

把一本书变成一摞卡=对知识体的降采样。原像比喻:照片竖切千条,按规则抽半,**保原序重排**——远观仍是原像,只是不清晰了。要点:

- 卡组不是一袋无序原子(Anki 观),是**一叠有座位的切片**;抽取规则(采样策略)是一等对象;
- Fable 补:学习发生在**插值**——答卡时脑补缺失邻条;采样过稀=aliasing(背两千卡不会一门课),过密=无压缩无插值劳动;知识有奈奎斯特率,卡密度应随信息密度;
- 复习一副卡组=低成本把整幅图重看一遍(模型保温),同 Henry 的 CS:GO 地图论(脑内常驻低清图,用时局部放大)。

Henry 元注:如何看待工具=对该技能本质认识的侧写;卡片是工具,学习是技能。**产品的卡片形态在教用户学习观**(工具有立场)。

## 波二 · 平级衍生物(Henry)

1.0 前只能抽 PDF,卡片是主体,被采样的全貌=原始文档;现在全貌可以是板/笔记/卡任何一种。**三者是平级的衍生物,共同母本=a set of 原始文档**(不是某一篇)。

- 板→笔记→卡是一条顺的操作流,但**顺序可乱**:对烂熟的题材(儿时读透的历史手册)直接要卡是正常需求——脑内模型已建成,可跳过施工期直接进维护期;
- 卡内容可比笔记**更唠叨也可更精简**——因为在学习中的地位不同;
- Fable 推论:三形态对应**脑内模型三个生命周期时刻**(板=施工中/笔记=成形后/卡=维护期),入口由脑走到哪决定;平级有信息论牙齿——若卡采样自笔记=对降采样信号再采样,一代代糊(复印件的复印件);平级=各形态保有对母本全清晰度的访问权;
- Henry 抛出:**衍生过程要有草稿,草稿是不是都该保存?**(Fable:该——草稿=衍生物的出生证:再衍生的配方/当时理解的标本/灵感生长处;出处文化从内容延伸到过程)。

## 波三 · 卡片=item(Henry)

卡片眼熟——像 item。item 产生于**打碎原始文档、重拼成引用源**的环节。

- Fable 合拢:照片比喻整段映到源管线——打碎=竖切,保序抽条=采样,重拼=引用源;**item=拿到身份证的切片**(身份+座位/出处锚);卡=切片摆出考官脸(正反面=面向检索练习的穿着);
- 合成卡(跨多切片的对比题)=在"拼"环节出生的多亲 item——Henry 原话本就含"打碎**再重拼**",同构不破反显韧性;
- 三波合图:**母本→打碎(采样)→切片得身份(item)→拼(不同拼法)→引用源/板/笔记/卡组**;三形态=同一批切片的三种拼法;卡组若按原序拼≈"考试用的引用源";
- 白捡:卡的出处锚不用设计,继承自 item。

## 波四 · 家谱失记(Henry 抛问,Fable 命名)

草稿问题暴露的真问题:**如何对待 item 的世代**。200 页课本→80 页笔记:大量引用源 item 未入笔记但参与了思考路径;入笔记的成为新 item(带花瓣);笔记再被引用再降采样→大量**同构 item**(好分类,与祖先直接对应,只略细节)+**异构 item**(双亲拼成)。积压不是病(买大硬盘),**干扰 Agent 思考是病**:做某主题笔记时,海量同代/跨代同构 item+局部相关异构 item 灌满检索面。

Fable 总结(Henry 认"顶得住"):

> **系统会诞生同一知识点的许多代降采样副本,但血缘在出生那一刻被丢掉了——积压的不是数据,是失记的家谱。**

- 同构 item 族=一个知识点的 **mipmap 链**(留在照片隐喻内):病不在链长,在每层被登记成独立新图;
- 失记态=RAG 近重复灾难(上下文灌满、同话五代各投一票、全清晰度祖先排第十六);登记态=收拢为**一个身份+一条分辨率阶梯**,Agent 按任务选层——冗余翻转为多分辨率访问能力;
- **去重是错误答案,归档是正确答案**(每层各有职守,谁也不删;"买大硬盘"直觉对得比字面深:什么都不删,一切只欠登记);
- 异构 item=join 不塌缩,血缘记双亲→局部重叠变精确("经由父 A 触及主题");
- 未入笔记的 120 页=草稿正身:**排除决策也是血缘数据**(下个 Agent 的采样策略先例);
- 铁律:**亲缘在出生时登记,不做事后 DNA 鉴定**(衍生瞬间免费确定;事后相似度重建又贵又错)。

## 波五 · 系统遗忘(Henry 抛,Fable 拧刀)

Henry:人记忆最大特点=遗忘;多份相似记忆融合成一份融合记忆(经验/总结),有扭曲风险(cognitive dissonance),融合记忆也在淡忘——但这恰是大脑能**放空**的基础(点连线、线连面)。RAG 的问题:**不允许遗忘**——每次检索把所有相似物全部看一遍再筛选排序打分,这是架构最大的问题。

Fable 位置:对,但病灶再挪半寸——**RAG 的病根不是"不许忘",是没有睡眠**:

- 人脑=写时/息时整合(睡眠把点连线连面,然后**扔点留面**),醒来工作集极小而够用——放空可能是因为整合提前付过账;
- RAG=把整合无限期推迟到每次读取瞬间,每读重付全部整合成本且随积压线性涨——"一个从不睡觉、靠翻全部日记过日子的人";
- 对回家谱学:**融合记忆=多亲合成 item(族顶层/schema 层);遗忘=低层沉降出默认检索面**(降权冷藏⛔删除,"忘出注意力,不忘出存在");放空=默认工作集只装每族顶层;
- **带收据的遗忘=系统超越大脑的唯一机会**:大脑融合毁原件,cognitive dissonance 无法自查;我们的融合留原件,schema 可疑时沿出处锚下潜对账——扭曲可审计。完整哲学形态:**硬盘不忘,注意力忘**;
- 现成心跳:**FSRS**——产品里已住着遗忘的数学模型(为人抗遗忘而设),反用即系统自身记忆的衰减调度。**人用系统对抗遗忘,系统向人学习遗忘**;
- 草案升格:家谱学(登记是骨)+睡眠学(遗忘是呼吸)——缺后者家谱是整洁的坟场,缺前者睡眠是毁原件的赌博;先骨后呼吸。

## 收尾定调(Henry 拍)

- 卡片没什么了不起,**就是一种展现形式**;
- **卡片也是 item,可被板和笔记引用**(卡=同构/异构 item 重灾区——唯一"全员衍生"的形态,登记态下恰是家谱树现成的探针层);
- Fable 补的三推论在案:卡上板=考试面空间化(采样空洞可见)/复习记录=模型清晰度回传(体检报告)/卡面亲笔措辞=人的字(Agent 改题面走提案);
- 整套定位=**实验性草案**(RAG 通病,尽力而为);工程排期另议。
