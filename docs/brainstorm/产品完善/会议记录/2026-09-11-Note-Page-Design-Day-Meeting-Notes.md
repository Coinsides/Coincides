# 2026-09-11 Coincides:笔记页设计日——样式方向、封面页与检索、Agent 改皮、组件交付

## 一、三案打样与择向

HQ 按 Henry 点单制作三方向完整静态打样(同一张笔记:纸面/表头/底部工具条/Note Actions 菜单):

- **C · 工作台**:蓝图网格台面、页边距墙线带刻度(72)、分舱仪表坞、命令面板式菜单,琥珀工作灯色。与认知工作台身份同频,红线=工程感⛔侵入纸内。

**通用处方(与方向无关,任何风格都需要)**:容器只许一层皮——浮层可有边框/阴影,条目永远是"行"不是"卡";分组用间距与发丝线,悬浮用极淡底色,危险项用颜色不用边框。此即现版 Note Actions"框框套框框"的病根与解药。

## 二、样式自设计:三层架构 + Agent 改皮

**三层结构(HQ 案,Henry 未逐条拍)**:

1. **版面层**(半数现物):纸型预设、页边距(=D1 的墙)、Typography(Font/Size/Line/Spacing 已在);
2. **皮层**(新,很小):约八个 token——桌面、纸、墨、弱墨、强调、批注金、发丝线、危险;三案=三组预设一键切,高级抽屉逐 token 微调。**纪律:给 token 不给 CSS**;
3. **部件层**(有限枚举):标题衬线/无衬线、菜单密度、把手样式等二三选一开关,⛔自由定制。

挂点三级:全局默认 → project 皮 → 单张纸覆写;留英手册=project 皮第一客户;打印/导出跟皮。落位=13.5 B1 版面模板+专场议程 6 皮挂点。

**Henry 补充(拍方向)**:这些样式大概率未来经 Agent 改——"帮我把这页背景换了/这个按钮样式改改/整体给我设计一版"。HQ 判定升级:**token 面 = Agent 的改装面**——①同门同钥自动满足(Agent 拧的旋钮=人拧的同一批,同路由);②皮域=错改零内容损失域(undo 即回),继板沙箱后 Agent 写权第二块理想试验田;③"整体让他设计"=Agent 产出 token 预设提案→人预览→人采纳,判断归人。登记进 V14 材料。

## 四、分页愿景(落 V14 纸面工程线)

Word 式自动分页+断块已拍入 V14(09-11 晨);本日 Henry 补:**页间空白可折叠**(Word "隐藏空白"式,页缝收成一线)。HQ 判定为点睛而非锦上添花:断块+折缝组合下,**折缝开启时分页世界呈现为连续长页**——"流式 vs 分页"两种世界观在一个开关里和解;显页缝=控制感/所见即打印,折缝=沉浸书写。已补进 V14 纸面工程线设计要点。

## 五、封面页(标题层升格为单独一层)

**核心合流(本日最重要判定)**:封面页的人面与机器面是同一份数据——人看是封面,Agent 看是**检索卡片**。

**封面账单**:

- 标题、description(现物,D2 已上纸);
- **标签**(唯一新真相):note 级,人/Agent 双出处(actor 记账),扁平⛔层级——检索锚非分类学;
- **来源账(上游)**:引用源(=原始文档的系统内投影,用户视角一码事)+引用的其他笔记——**块级出处的聚合投影,零新记账,永不漂移**;
- **去向账(下游,HQ 补)**:本纸的块被哪些板/内容组引用——影响力一目了然,亦是 Agent 召回权重信号;同为聚合投影;
- **浮窗⛔挤版**(Henry 拍):封面只放折叠条("来源 · 3 文档 2 笔记"),点开浮层看明细;与表头带高度有界同一不变式;
- **节制线(HQ)**:封面到"一排标签+一两条折叠账"为止;⋯菜单的 View info 弹窗将来收编进封面浮窗退役,合并不新增面。

**导出**(Henry 拍):封面页可选导出,默认不带(正文纯净);格式不循 APA——定位=学习调查整理空间非排版工具(Notion 同理,专业排版归 Word)。HQ 注:出处是结构化真相,将来要 APA 是"从真相生成格式"的一键活,账从未欠。

**演进路径(HQ 案,候拍)**:表头带(已上线)→ +元数据行(标签+来源/去向折叠条,13.5-13.6 中单,标签真相随行)→ 真封面页(第 0 页,与留英手册"封面成设计页"同批,皮系统之上)。

## 六、笔记检索:分层,不二选一

Henry 问:笔记内容检索系统 vs 依 item 检索,"从笔记定 item"还是"从 item 定笔记"?

**HQ 答(候拍)**:**item→笔记是主航道**——item 是蒸馏物(被判断过,信号密度高)、corpus 小、天然带出处锚(召回 item 顺出处直跳笔记块,引用连"哪一段"都是现成的)。笔记全文检索=补网(兜未蒸馏内容);**标签+题述=粗筛第一层,而封面页恰好把粗筛层做成了人可见的页面**。三层动线:标签/题述粗筛(scope 过滤)→ item 语义召回(12.9d embedding 地基)→ 出处回跳笔记块。此即 V14 记忆架构"资产层=检索唤醒"的具象化——不必新立"笔记检索系统"项,要立的只有:标签真相 + 把 item 检索接进 Agent 找笔记动线。

## 七、Staging 与组件交付(variable table 案例复裁)

**Henry 观察(拍)**:对 Mr Zero 说"做个暗色底 variable table,条件如此这般"而**未指明去处→交付默认落 Staging(装卸区)**——装卸区宪法条("交付一律先落装卸区,采纳归人")的日常形态,Staging 在组件交付场景找到正职。明说"直接放上去"=显式授权跳过采纳,仍整批一键可撤(机械闸不拔牙)。

**旧案"悬浮跟随按钮"复裁(HQ 案,候 Henry 认)**:把"住所"与"召唤方式"拆开——

- **本体必须有籍贯**:悬浮无家的工具=幽灵件(搜不到/出处断/导出丢/read_note 读不到);组件块住纸(V14 已裁,⛔Figma 化);
- **悬浮跟随=钉住态(pin),投影非住所**:落籍纸上的组件块可被"钉住"成跟随视口的浮窗,关闭零损失——"真相一份投影多张"本周第四次应用(板卡/跨页分片/封面页/钉住态);
- 完整动线:Mr Zero 造件→Staging→采纳落纸(出处随行)→钉住随用;
- 远景:钉住态与 V14 工作台标签条同族("在场"器官),钉住组件可停靠标签条。
