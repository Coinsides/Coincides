# 2026-07-04 Better Notebook：Source 重建 —— 现状 + 三层契约 + 可插拔设计（面向开源多语言）会议记录

> Henry × Claude。Henry 明说这块技术面不熟、要我多担待，所以本记录**刻意写成能一路读下来的大白话** —— 名词就地解释，先建心智再谈设计。承接 06-28「三层源重建愿景」+ 今天两轮代码 map 与工具调研。
> **主线**：Source 是"从用户上传的原始材料，到能做成笔记"之间的地基。今天把它啃透：现状多初级、该怎么设计、工具选谁、以及 Henry 新提的"要可插拔以适配开源后各国语言"。

## 一、先说清楚 Source 是什么、为什么现在啃它

**Source = 用户丢进来的原始材料（PDF、扫描件、照片、手写笔记、网页、docx…），到我们能拿它做笔记之间的那一整层地基。**

为什么是"总闸"：我们之前定了"目的层先做"（那半不碰 Source）。但另外那半 —— **AI 从源料装配出一篇笔记、笔记里每句能"跳回原文哪一处"（溯源/抗幻觉）、member 冻结一份"原文当时长啥样"的收据** —— 全压在 Source 上。Source 不立好，这半都无从谈起。

---

## 二、三层模型（先建立这个心智，后面全靠它）

把"原始材料 → 笔记"拆成**三层，别塌成一层**（这是 06-28 定的、也是全盘的骨架）：

```
① 原始字节        你上传的原件本身（PDF/照片），一个字节不改。= 证据根，永不动。
      ↓  用 OCR / VLM「读懂」它
② SourceArtifact  机器读懂后的「结构化版」：哪块是标题/段落/公式/表/图，
                  各在第几页什么位置，阅读顺序，公式转成 LaTeX，表转成结构。
                  —— 它「仍然是源」：忠实、可指、可浏览，但还不是你的笔记。
      ↓  按你的目的，挑精华、连关系（这一步"按需、按目的"，不是一上来全做）
③ 蒸馏内容        你的笔记 / ContentGroup：从 ② 里选出的重点 + 角色 + 关系。= 你的内容。
```

**名词就地解释（这几个词后面反复出现）：**
- **OCR**：让机器"认字"（把图片里的文字读出来）。
- **VLM**：视觉语言模型 —— 更聪明的一类，不只是认字，还能认"版面"（哪是标题、哪是表、哪是公式）。
- **bbox**：bounding box，一个"方框坐标"，标某块内容在页面上的位置（左上/右下角）。有了它才能在原件上高亮"就是这一块"。
- **LaTeX**：数学公式的文本写法（比如 `\frac{a}{b}` = a 分之 b）。把公式变成 LaTeX 才能干净地存和显示，而不是变成一张图或一堆乱码。
- **阅读序 (reading order)**：多栏排版时"该先读哪块后读哪块"的正确顺序。
- **锚 (anchor)**：笔记里某句 ↔ 源里某处的**双向链**。有锚 = 这句是"搬来的、可查、保真"；无锚 = "凭空生成的、要送审"。

**最容易踩的坑（06-28 反复强调）**：② 层的"块"和 ③ 层的"块"**同名但不在一层**。② 的块 = 源自己的可寻址区域（锚的**靶子**）；③ 的块 = 你蒸馏出的内容（锚的**发出端**）。**别把 ② 的块自动变成 ③ 的块。**

**一句话记住**：① 是原件、② 是"机器读懂的源"、③ 是"你的笔记"。②→③ 之间靠"锚"串起来。

## 三、现状：我们其实已经有一整套，但内核很初级（大白话版）

两轮代码 map（实读代码）的结论：**现有 Source = 一副装得很漂亮的骨架 + 一个很初级的内核。**

**装得漂亮的部分**：上传 → 解析 → 切块 → "快照" → 锚，这一整套表和管道**都有、都在用**，看着挺全。

**初级的内核（四个实锤，尽量说人话）**：
1. **解析只吐"一坨纯文字"**。不管你传 PDF 还是图，最后都压成一个大字符串。**没有块类型、没有坐标、公式和表格被压平甚至毁掉**（数学尤其惨 —— 扫描件用的 OCR 甚至被明确命令"只要文字、别的都别管"）。
2. **"快照"是假的**。它本该是"原件当时长啥样"的忠实拍照，实际却是**把已经压平的文字再重新分页拼一遍**（等于"复印件的复印件"），页码还是**编出来的**、而且**可变**（每次重生就覆盖）。→ 当不了"冻结收据"。这就是你说的"snapshot 做得不好"，坐实了。
3. **锚只能指到"整页"**。指不到"第几行/哪个区域"。所以"跳回源"只能翻到**一页文字**，高亮不了你要的那一句。这对"抗幻觉/溯源"是不够的。
4. **② 和 ③ 塌成了一层**（那个坑落成了 bug）：锚的靶子其实是用 ③ 那坨压平文字拼的，两层共用一个底料。

**好消息（这决定了不用推翻重来）**：那些"假保真"的表（快照、锚）**都是能重算的、没有不可替代的数据**；真正宝贵的东西（**原件字节、你手写的引用、策展过的库**）都在**稳的表**里。所以是 **"留骨架、换内核"**，不是推翻。

## 四、设计：契约优先 + 解析器可换（"契约"到底是什么）

**核心一招：先定死一个"输出的固定形状"（叫「契约」），app 只依赖这个形状；至于背后用哪个工具去填这个形状，随便换。**

打个比方：**先定「插座标准」，电器（解析工具）只要符合插座就能插进来。** 你换电器不用改墙里的线。

- **契约长啥样（大白话字段）**：每个"块"记 `{第几页, 方框坐标(bbox), 阅读第几, 类型(段/标题/表/图/公式…), 文字, 公式的 LaTeX, 表的结构, 置信度, 谁解析的}`。而且**不可变、带版本** —— 这样 member 的"原文快照收据"才有个稳定的东西可指（重新解析 = 出个新版本，不改旧收据）。
- **两道闸（双闸门）**：
  - **现在**：先把"插座"（契约）+ 表 + 解析器接口定好。**便宜、且解锁后面一切。**
  - **晚点**：再接真正强力的解析工具（要调研、要试）。
  - **今天那个糙解析，先当一个"能用但简陋"的默认插头顶着** —— 集成时**不破坏任何东西、零用户数据迁移**。
- **锚改指"块"而不是"页"**：把那些一直空着的坐标/偏移列**激活** → 锚到行/区域级 → "跳回源"能高亮真区域。有锚=可查、无锚=生成→标红送审。

## 五、可插拔 = 开源扩展点 + 多语言（Henry 今天的新想法）

**背景**：这产品要开源，用户母语未知。Henry 自己以中文为基准；英文天然兼容；但可能有以日/韩/小语种为基准的人来用。

**好消息：这正是上面"解析器可换"已经给的能力 —— 你今天等于独立想出了它的又一个理由，而且把这个接口的地位升级了。**

- **破一个框**：**不是"一种语言配一个解析器"**。现代解析器本就多语言（PaddleOCR-VL/MinerU 支持 109 种语言）—— 日/韩在默认工具上就能跑。可插拔真正解决的是：① 有人找到语言专精的更好工具想换；② 偏好/信任/合规（有人不想用某国实验室的工具）；③ 没显卡→换云；④ 未来出更好的。
- **对开源最关键**：这个"插座"变成**社区的扩展点** —— 一个日语贡献者可以加一个日语调优的插头，**碰都不用碰你的核心**。
- **优雅原则**：**你拥有「契约」+ 一个合理的「默认插头」；插座是给别人填的。你不用去追每一种语言，你只做那个接缝。**
- **让它真成立要注意**：
  1. **契约保持语言中立**（真正的多语言约束）：阅读序要能处理从右到左（阿拉伯语）/ 竖排（日语）；类型分类是语言无关的。**别把中文假设焊进契约。**
  2. **有个"后端注册表 + 选择开关"**：一个默认 + 可按文档/按用户覆盖；配置驱动 → "想换就换 = 改配置、不用重编译"。
  3. **每个插头声明自己会啥**（哪些语言、公式、表格、手写）→ app 据此挑或提示。
- **v1 别过度**：手动"默认 + 覆盖"就够；自动按语言选后端先不做。

## 六、工具选谁（为什么是 PaddleOCR-VL）

**这类工具干的事**：给它一页图，它还你结构化的块（带坐标、公式 LaTeX、表结构）—— 正好填我们的契约。

**选型结论（2026-07 联网查证，Henry 已拍）**：默认路径**全本地、全开源、全中文强**。
- **主（常驻）= PaddleOCR-VL 1.6**（百度，Apache-2.0 开源）：当前公开基准第一，公式/表格都最强，模型小（0.9B），**你的 4060 显卡跑得很稳**；中/英/日/韩都覆盖。
- **备（可换）= MinerU 2.5**（上海 AI Lab，开源）：中文同样强，手绘图处理最好；当交叉验证/难页备胎。
- **Mistral OCR 4**：闭源 + 云 → **移出默认路径**，只当"没显卡/最脏手写"时用户主动开的可选逃生口。
- **Docling 踢掉**（中文是实验性的）。
- 补充：更新了 06-28"MinerU 当默认"的旧判断 —— 当时靠的是那会儿的信息，现在 PaddleOCR-VL 反超了。

**Windows 上怎么跑**：这些好工具在 Windows 上是"Docker/WSL2 开个本地小服务"的形式，不是"pip 装完就能用"。你有 4060，本地跑没问题。

## 七、承重的产品启示：置信度 + 一键纠错（比"抽得准"更重要）

**手写中文是所有工具的命门（准确率 ~86%）—— 抽不干净是必然。**

所以关键认知：**Source 这块产品做得好不好，不取决于"抽得多准"，取决于"抽错了改得多快"。**
- 契约里每个块带**置信度**；低置信的**显式标出来** → 用户**一键纠错** → 改完就锚定（不回写源）。
- 这正好扣上两条我们已有的东西：**抗幻觉**（无锚/低置信 → 送审）+ **红线**（Agent 能改的，人 100% 能改）。

## 七.5、手绘图 / 图像处理（Henry 2026-07-04 · "猪 vs 绘画课"）

> Henry 提的一块：手绘图很棘手（复杂手绘图 / 设计草稿 / 没坐标系的手画数学图 / 普通涂鸦）。核心直觉：**不用重画，截图放在对应内容下就行；但要判断这图有没有价值。** 这几个直觉全对，而且"猪 vs 绘画课"正是钥匙。

- **不重画、直接截图 = 正确做法，不是妥协**。重画（矢量化/复现手绘）会失真、甚至"脑补"出错的干净版，而且**重画=一种解读**，违了 ②层"忠实"的职责。**截原始像素 = 忠实 + 安全。**（想要干净版 = ③层可选解读、锚回原截图，默认不做。）
- **它怎么做：先布局分析**。模型把一页切成块、贴标签（文字/标题/表/**图**）+ 方框坐标（bbox）；图块 → 按框截原始像素 → 存成图片资产 → 放回阅读序。**我们选的 PaddleOCR-VL / MinerU 本来就干这个**（自带"检测图区→截图→放回"；MinerU 还会细分图区类型）。
- **最关键 —— 价值不能焊在图上，它相对目的**（= 相对不焊的又一例）：同一只小猪，"学微积分"目的下=噪音丢掉，"复习我的画/绘画课"目的下=正文留下。所以：
  - **②抽取：忠实截下每一张图、不判价值（全留）** —— 图片便宜，且抽取时不知道未来哪个目的用它；当场删违"忠实源"、可能丢掉未来所需。
  - **③按目的蒸馏：这里才判哪张图进这篇笔记** —— 小猪排除在微积分笔记外、每张速写进绘画课笔记；是**提案、可一键改回**（"你漏了张图，加回来"）。
  - 一句话：**"截不截"在②（全截），"要不要"在③（按目的）。** （可选：②给每张图附一句"这是啥"的轻描述，帮③判留不留 —— 是"它是什么"不是"它有没有用"。）
- **输入五花八门（PDF/Word/HTML/纯图）+ "套娃"**：纯图/扫描 PDF = 整页图 → 直接布局分析；Word/HTML/原生 PDF = 结构化、图能直接抠+文字有结构；**但"有人把手写笔记拍成图塞进 Word/网页"= 那张图其实是一整页内容，要当页面图递归再做一次布局分析**。→ 规则：**先判源类型，再决定走哪条路**（= PI-048 的 source-type detection）。这些路由都藏在解析器接口后面，每种格式最后吐同一个契约（"图块"就是图块，不管来自 PDF 截图还是 HTML `<img>`）。

**收敛**：抽取(②) = 布局分析→图区截原始像素→存 `kind=figure` 块（bbox+图片资产+可选描述），忠实全留不重画不判价值；蒸馏(③/目的) = 按目的判哪张进笔记、锚回原图、提案可改；重画 = 极少数③层可选解读、默认不做。

## 八、它在整体里的位置（先后）

```
目的层（U1/U2：purpose-frame + 角色拆到边 + CG 加 type）  —— 先做，完全不碰 Source
   → Source 契约接缝（定 artifact/block 表 + 解析器接口 + 锚改指块 + 今天解析当默认插头）
        —— 这是"真快照 / 真锚 / 装配"的前置
      → member 快照补全 + 装配管线
   ‖ 真正强力的 PaddleOCR-VL 管线（本地小服务）另排 —— 建之前先拿 Henry 真实手写中文数学跑一次 spike
```
**目的层仍然第一、仍不被 Source 挡**；但"真锚定/真快照/装配"那半，前面要先立 Source 契约接缝。

## 九、待你拍 / 待细化（我们一起理这块）

1. 契约的"类型(kind)"分几类合适（工具吐的类目比我们想的粗，要不要轻量映射）。
2. bbox 坐标空间归一（不同工具坐标系不一样）—— 工程细节，可后置。
3. 可插拔的"选择开关"做到多细（就一个全局默认？还是 per-文档？）—— v1 我倾向"默认 + 覆盖"最小化。
4. 那个"一键纠错 UX"具体长啥样（低置信怎么显示、怎么改、改完怎么锚）—— 这块是产品重心，值得单独细聊。
5. Source 契约接缝**排在目的层之后紧跟**，还是与目的层并行？（看你想多快摸到"能跳回源"的手感。）
