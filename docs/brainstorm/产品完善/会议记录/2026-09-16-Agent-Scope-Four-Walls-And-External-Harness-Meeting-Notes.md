## 一 · 四堵墙(Henry 已拍:"是 OK 的,也就这么多了")

工具注册表式 Agent 的可达空间=既有原语的组合;四类需求结构性撞墙:

1. **表现力墙**:用户要新表现形式(时间轴/新卡面/小游戏),应用没有该原语则动词无用。Henry 早有测量仪:验收北极星的 Artifact 对照组(差距=表达力缺口清单);
2. **主动性墙**:每个动作 Agent 都会做,但「没人说话它也做」需要触发器/调度运行时——今天不存在;它是独立权力形态(规则在人睡时跑),需自己的门、注册表、总闸;
3. **外界墙**:每个外部连接(网页/视频字幕/发送分享)=一份代码,集合无界;
4. **智能墙**:失败不因缺工具而因模型不够聪明;任何权限治不了,归调教环。

越墙总原则(Fable 提,Henry 未反对):**把「改代码的事」降级成「改数据的事」**——可解释模板(墙一)、规则即数据+独立门(墙二)、连接器协议(墙三)。V2 现物种子:部件注册表/composition templates/皮肤套件/组件块第四族。

## 二 · 三层分权与挂靠(Henry 提案)
