# v2.x 产品与架构调研大纲

**创建日期**: 2026-05-21
**状态**: 进行中
**用途**: 作为 post-v2.1.1 调研清单，帮助校准 v2.2、v2.3、v2.4 以及后续模板引擎路线。

这份大纲不是 workflow 规则，也不是 release plan。它只是调研入口和进度清单。每完成一个方向，就在 `docs/brainstorm/` 下新增一份独立调研文件，并在这里打勾。

---

## 调研原则

- 研究目标是借鉴成熟产品/框架的架构能力，不是复制它们的产品身份。
- 每份调研都要回答三个问题：
  - 他们大概怎么做？
  - Coincides 应该学什么？
  - 对 roadmap 的影响是新增、修改，还是不动？
- 调研结论要服务 Coincides 的核心方向：
  - source-grounded learning workspace；
  - proposal-first AI；
  - Course Material Library；
  - NoteBlock / Projection；
  - 未来 Source Board / Learning Canvas。

---

## 调研清单

- [x] 1. Block 架构与模板/类型系统
  - 文件: `docs/brainstorm/v2.x-block-architecture-reference.md`
  - 重点: schema、block tree、service、view、template、object type。
  - 当前结论: 学 BlockSuite/AFFiNE 的架构分层，但不引入依赖；保留 Coincides 的 source evidence / learning role / proposal-first AI 核心。

- [x] 2. Document / Canvas 双模式切换
  - 目标文件: `docs/brainstorm/v2.x-document-canvas-mode-reference.md`
  - 重点: 文档视图、画布视图、同一数据多视图、切换体验、定位/同步、canvas 是否是 projection。
  - 当前结论: Document mode 是阅读和编辑顺序，Canvas mode 是空间理解和关系组织；两者共享学习对象，但不共享布局规则。
  - 影响版本: v2.3 Source Board / v2.4 Learning Canvas。

- [x] 3. Source Viewer / Source Board
  - 目标文件: `docs/brainstorm/v2.x-source-viewer-reference.md`
  - 重点: PDF/source snapshot、页码跳转、范围选择、引用锚点、source trust、源材料和笔记之间的来回跳转。
  - 当前结论: v2.3 应该做 Source Snapshot Viewer + Source Anchor + Scope Selection + Source Board seed，不做完整自由画布。
  - 影响版本: v2.3。

- [x] 4. Material Reconciliation
  - 目标文件: `docs/brainstorm/v2.x-material-reconciliation-reference.md`
  - 重点: 多批上传、重复材料、冲突、合并/拆分/恢复、canonical block、source evidence set。
  - 当前结论: Material Reconciliation 不只是去重，而是从来源碎片到可信知识对象的审阅式合并流程；v2.2 应该做 conservative proposal-first reconciliation。
  - 影响版本: v2.2。

- [x] 5. Learning-Specific Blocks
  - 目标文件: `docs/brainstorm/v2.x-learning-blocks-reference.md`
  - 重点: definition、theorem、proof、formula、example、exercise、answer、mistake、review card。
  - 当前结论: Learning-specific block 的核心不是多几个类型，而是同一个学习对象可以生成不同 projection；ReviewCard 应该是 NoteBlock 的 projection。
  - 影响版本: v2.2+ / template engine。

- [x] 6. Template Engine / Package Studio
  - 目标文件: `docs/brainstorm/v2.x-template-engine-reference.md`
  - 重点: 用户可编辑模板、模板字段、默认内容、可选字段、模板包、schema-first customization。
  - 当前结论: 第一阶段应开放 template variant、composition template 和 domain block set，不开放任意底层 system block type 或代码插件；模板变更也要 proposal-first。
  - 影响版本: v2.4.x 或 v2.5。

- [x] 7. AI Proposal UX
  - 目标文件: `docs/brainstorm/v2.x-ai-proposal-ux-reference.md`
  - 重点: AI 建议、review/apply、置信度、warnings、source grounding、用户授权边界。
  - 当前结论: AI UX 核心不是 Chat，而是 Proposal -> Review -> Apply -> Evidence -> Recovery。
  - 影响版本: v2.2-v2.4。

## 当前建议调研顺序

本轮调研清单已完成。下一步建议做总整理，再统一讨论 roadmap 调整和版本拆分。
