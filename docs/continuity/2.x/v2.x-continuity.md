# v2.x Continuity Register

**Created**: 2026-05-19
**Updated**: 2026-05-22
**Status**: Active

This file is the major-version continuity register for Coincides v2.x.

It is not a development log, changelog, roadmap, or replacement for version review files. It records only items that must survive from one v2.x minor version into later planning or implementation.

Use this file when a finding, decision, risk, or deferred item affects a future v2.x version but does not belong only to the current version's plan.

Long-lived items that affect multiple major versions, product principles, architecture direction, or repeated deferred work should also be promoted to `docs/continuity/Coincides-Continuity.md`.

---

## Continuity Rules

Each item must use these fields:

- **ID**
- **From**
- **Type**
- **Status**
- **Priority**
- **Suggested Version**
- **Owner**
- **Context**
- **Decision So Far**
- **Next Action**

Allowed statuses:

- `OPEN`
- `PROMOTED`
- `DEFERRED`
- `CLOSED`
- `SUPERSEDED`

Allowed item types:

- `UX_DEBT`
- `ENGINEERING_FOLLOWUP`
- `PRODUCT_DECISION`
- `KNOWN_RISK`
- `FUTURE_VERSION_CANDIDATE`
- `UNRESOLVED_QUESTION`
- `RELEASE_CARRYOVER`

Continuity items should be short and decision-oriented. Ordinary implementation activity belongs in the active version's review file. Final release summaries belong in the version changelog.

### V2X-008: Material Reconciliation shell must not be mistaken for real merge apply

- **ID**: `V2X-008`
- **From**: `docs/releases/v2.2.0-plan.md`
- **Type**: `ENGINEERING_FOLLOWUP`
- **Status**: `OPEN`
- **Priority**: High
- **Suggested Version**: v2.2.1 and v2.2.2
- **Owner**: Henry for product acceptance / Codex for implementation
- **Context**: v2.2.0 creates a review-only `material_reconciliation` proposal shell. It can group duplicate, overlap, same-concept evidence, and conflict candidates, but it intentionally does not persist EvidenceSets, merge source evidence, exclude material, resolve conflicts, or provide recovery/unmerge behavior.
- **Decision So Far**: v2.2.1 implemented EvidenceSet + Conservative Merge Apply. v2.2.2 added reversible exclusion, conflict review, and recovery event safety records without deleting, hiding, rewriting, or canonicalizing source/note content. v2.2.3 uses active exclusions and open conflicts as safety inputs for role-aware reconciliation hints.
- **Next Action**: Henry should run v2.2.x batch acceptance before this track moves toward stronger source inspection in v2.3.
