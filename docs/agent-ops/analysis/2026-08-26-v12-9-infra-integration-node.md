## 六、预置材料(2026-08-27,Henry 提前抛出的库治理之问;§四三反问的先行讨论,**届时重问,不许照抄**)

**Henry 的担忧(原话要义)**:AI 检索加入后源库数量级暴涨;大敞四开无分类 = 整理地狱;库内未过期的源被忽略、从网上重复引入,库被近似物无限填充;打散成 unit 后复用效率高,但整理效率跟不上。

**当日讨论方向(Fable,三病三药)**:
1. **重复填充 → 入库问询门(门口不是货架)**:Agent 引入新源必须附**查重申报收据**(内容指纹查逐字节重复 + 近似指纹查同源异版;查了什么/命中什么/为何仍引入);"找材料"类动词强制**库内优先**,外来物必须申报来源。无申报=引入不合法。
2. **整理地狱 → 不建文件夹,分类靠「出生语境 + 使用轨迹」自动生长**:每份源入库自带语境(课程/笔记/任务)=免费一级分类;视图(按课/按在用/按沉睡)是**读时投影**不落库;标签走**候选→人工确认**管线(复用关系候选机制)。architect-all 之忌适用于收纳本身。
3. **整理效率 → 只保工作集,不保全库整洁**:未被再用的源躺着成本为零;工作集由使用自动排序。同构:知识衰老板块「状态是读时投影」。

**收束句**:门口设卡,货架不设卡,人工只出现在标签确认一处;让库追着使用跑,不让人追着库跑。

**边界原则(Henry 2026-08-27 定,检索设计的总闸)**:「够不够」的判断归模型(以及用户的自然语言需求拆分),**我们不替模型考虑怎么变聪明——那是本末倒置**;我们提供的永远是:**若模型自问「够不够」,它总能以高效率检索到库里有什么**的机制。
Fable 补两刃:①机制标准除了快,还有**对「没有」诚实**——检索结果自带「我怎么找的」元数据(范围/匹配方式/置信度),让「没查到」从断言变成可评估的证据;不替它判断,但把判断所需证据递全(同溯源子句哲学)。②「不替模型想」≠「对 Agent 没规矩」——问询门/库内优先是**舞台管理不是演技指导**,保护的是库不是智能。
**尺子一句(将来砍伪需求用)**:凡「替模型想」的功能不做;凡「让模型看得见、查得快、查得诚实」的机制做。

**四层收拢(Henry × Fable 2026-08-27 第二轮,库治理模型完整形态)**:
1. **两层楼**:原始文档库=散沙层(导入零门槛零语义,只证存在);引用源=**被征用的证据**——东西不自己上二楼,被某 purpose/program 用到那一刻晋升,晋升事件自带语境。身份不是导入时发的,是使用时挣的(grow-by-use 第四应用面)。
2. **多重征用=简历不是问题**:源永远一份,多的是征用边(⛔ 不复制;形状同内容组一体多处安放);简历喂检索排序——自己用过且反复有用的排在陌生来源前。
3. **泛 program 判断=常设偏置 × 当下焦点**:program 名与描述是 prior(降权不出局,⛔ 不做过滤器);**笔尖就是查询语句**——此刻动作压过常设偏置;"对不上"须带检索自述证据才授权外采。
4. **概念重复不在文档层解决——它是知识层的原料**:文件级重复归查重门;同概念多定义=多份证据非冗余(⛔ 机器挑「最好的定义」=裁真相违宪)。金字塔收敛:概念=一个 Item(骨架现成),定义=名下多条带出处证据链;异名同义走**合并候选管线**(机械检测近似→人点头才合,机器永不自动合——同 noteBlocks 副本教训);**定义间差异本身是学习材料**(矛盾浮现机制跨来源适用)。
**收束**:散沙层允许重复,征用层记录简历,知识层负责收敛,收敛靠人点头;Agent 只递「这俩可能是一个概念」与「此刻哪份证据最相关」,永不裁「哪个定义对」。

**第三轮(Henry 2026-08-27):下拉选单——把「决定」换成「默认」,概念收敛的注意力解**:
- Henry 指出上一轮「合并候选靠人点头」在批量场景(整理清单遇几十上百近似定义)= dismiss 债务,不可行。**修正裁定:Fable 上轮把两个操作捆错了**——「选用哪个定义呈现」(可逆、可默认)≠「熔掉概念身份」(危险、其实可无限推迟)。
- **机制**:近名+近义定义聚成一个槽位,**置信度最高的直接呈现**(不问——可逆的事不配打断人);下拉展开=库内全部候选各带出处;三出口=选任一 / 自己写 / 叫 Agent 定制熔铸。
- ⭐ **合并是创作不是删除**:定制合并产出**新条目**,出生证含全部母本指针,母本零改动 ⇒ 系统中不存在「合错毁数据」。软聚类(同槽不熔身份)使显式身份合并永不必要。
- **追溯三层**:候选各带出处 / 选择本身是收据 / 熔铸件带母本链。
- **两护栏**:①下拉内置「这不是同类」一键踢出(显式拒绝判决,学习环合法食物);②选择只学相关性(此语境偏好 B),⛔ 不学成真理判决(A 是错的)——学相关性不学重要性,G5 原则跨域适用。

**第四轮(Henry 2026-08-27):AI 直接熔铸的合法性边界**:
- 场景:高智能模型判「库内任一定义都不合此刻需求,但综合可达,无需外采」⇒ **AI 直接铸合并件 C,不咨询用户**。
- **合法前提四条**(踩准=效率,踩偏=机器裁真相):①母本零改动;②C 标 AI 铸造(actor+任务语境;与用户自写件**同原语不同出处**——内容组双重身份的实现);③C 占默认位而默认位可逆;④**下拉选单本身=常设非阻塞咨询**,故无需时点性咨询——否决权铺在界面结构里,不必在特定时刻请求行使。
- **机制对笨模型同样安全**:差 C 被一次点击换掉并在排序沉底——模型愚蠢被机制封顶(舞台保证最坏情况,不赌演员水平)。
- **记录边界拧紧**:「为什么融合」不记(叙事没人读,真想知道叫 Agent 当场复述);「从哪融合」**必须结构化记**——母本指针是下拉聚合与逐级追溯的地基,两源拼接肉眼可辨、五源转述不可辨;**指针是数据不是推理,装修可省地基不能靠猜**。

**第五轮(Henry 2026-08-27):下拉选单升格为设计哲学「折叠的多样性」**:
- Henry 明确:下拉选单只是举例,不代表全部展现形式;它是一种设计哲学——所有同族展示形态皆可用(他举:特殊标识点开下拉/悬停气泡+滑动条)。
- **哲学一句**:面上只放一个(此刻最合身),全集一步之遥,来源随身,选择可逆。
- **形态例(各贴宿主语境)**:①角标+气泡(页面模式行文内,收起零占地)②复习卡「换个说法」轮换(多定义=现成变式练习材料)③画布牌堆(空间习语,边缘露角)④摊开对比(用户主动邀请的吵,唯一全亮形态)⑤对话引用票根(Agent 引用句尾的来源小票)。
- **五条不变式(合格判据,形态自由、不变式入宪)**:①默认不吵 ②全集一步可达 ③候选带出处 ④选择可逆留痕 ⑤有「这不是同类」退出口。形态归设计部(将来 open design 用武之地),不变式归宪法——「设计造壳、工程造插座」再现。

**第六轮(Henry 2026-08-27):「折叠的多样性」正式表述 + 设计选项如何交到用户手里**

> **「折叠的多样性」(canonical,Henry 授意 Fable 执笔)**
> **对象**:凡一处内容存在多个合法候选——定义、说法、来源、呈现形态、样式——既不逼用户选,也不全部铺开。
> **呈现**:默认位显示此刻最合身的一个;其余候选折叠在一步之遥的安静入口后(角标/手势/面板,⛔ 不闪不数不红点)。
> **用户四权**:换选任一 / 自造新候选 / 令 Agent 熔铸定制 / 把误入者踢出组。
> **系统四义务**:每候选带出处;每次换选留收据;默认可覆盖且覆盖可逆;未打开入口不产生任何债务。
> **自相似**:同一哲学作用于内容(选哪个定义)、形式(穿哪件壳)、样式(旋钮拧多少)——三层同构,这是它成为哲学而非控件的原因。

**设计选项交付路径(接组织总纲三条组件裁定,Henry 之惑的解)**:
1. **默认不选,场景替选**——「定义槽位」是插座(工程:数据契约/出处/收据);气泡/牌堆/轮换是壳(设计);每个宿主场景默认插自己的母语壳,开箱零配置。
2. **选中即旋钮**——样式选项不设集中设置页,长在组件身上:点选实例,出生证申报的旋钮当场浮出(已有 demo 实证)。
3. **换壳是一个旋钮**——兼容同一插座的壳共享食谱,换壳零损失(数据/出处/历史原样);新壳由设计部造、带出生证进组件库、声明兼容插座即自动进入换壳候选。用户全程不离开应用。
⭐ 换壳旋钮自身亦遵守折叠的多样性(默认壳在面上,其余一步之遥)。

**第七轮(Henry 2026-08-27):「抽成什么样子」——四步管线与选品考题**
- Henry 之问:PDF/Word/Excel 该抽成什么?中间到抵达 item 之间发生了什么?(提及微软 MarkItDown 类工具)
- **四步管线**:层0 原件(证据,永不动)→ **① 忠实转写**(带锚文本;⛔ 不是分析,是机器可读呈现)→ **② 结构切分**(可寻址碎片;打散在此,但还不是知识)→ **③ 语义识别**(机器猜想,候选身份;⚠️ 第八轮已纠:**不在晋升线上,是路边服务**,晋升不需要它)→ **④ 铸造**(被 purpose 征用那一刻才成 item,带完整出处链——征用即晋升)。
- **三判断**:①抽的产物**不是 markdown 是「带锚的转写」**——下拉出处/跳转现场/熔铸母本指针全骑在位置映射上,锚一丢追溯链永断 ⇒ 选品第一考题=「转完还回得去吗」(MarkItDown 的真实短板:给正文不给回程票);②**打散≠铸造**——碎片(有地址、可检索)与 item(被征用、有出处链)两种身份,⛔ 入库即全量铸 item=architect-all;③**快慢两档**:①②入库即做(检索依赖它,便宜),③④按需(贵,分析费只花在被用到的页上)。
- **选品格局=两类工具**:转写器(考题=锚保真;生来数字的 Office 天然有锚,Excel 格子即碎片;**扫描 PDF 是分水岭**,需带版面坐标的方案)+ 识别器(云端旗舰 VLM,08-07 已拍;考题=前五轮聊出的定义识别与出处携带)。
