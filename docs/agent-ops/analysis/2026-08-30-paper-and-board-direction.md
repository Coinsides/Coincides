# 纸与板 —— 笔记载体架构变更方向

## 〇 · 一句话

**一篇笔记 = 一叠有界的纸;无限画布从笔记内部搬出,独立成一等公民的「板」(黑板),承载笔记/item/组/text range 的投影与连线。纸负责"记",板负责"串"。**

现行"笔记 = 页框 + 环绕无限野地"系 Affine 移植件,今日识别为**供体排异**——当年学来的器官,身体认出不是自己的了。

## 一 · 双重嵌套模型

### 第二重 · 纸(有界画布黑板)—— 用户 99% 的主战场

- 一篇笔记的根容器 = **页框叠**(pageStack),⛔ 不再有环绕野地;
- **页内保留画布感**:块自由摆放、吸附开关、可调尺寸(A4 / A-任意 / 网页式)——只是**有界**;
- 有界的三重目的:①下次看"一眼望到头"(显示器物理:所有主屏横长竖窄,注定逐页阅读);②AI 逐页截图/逐页碎片,零横滑(与锚体系页基同构);③可导出可放映。

### 第一重 · 板(无限画布)—— 关系之家

- 真无限,因为它承载的是**多篇笔记之间的思路**(公安局线索黑板):整篇笔记、item、ContentGroup、text range 皆可上板,连线串思路;
- **铁律:拿出去 ≠ 挪出去**——上板的一切是**投影(引用)**,真相留在笔记;原文改,板上窗户跟着变。机关现成:`ContentMount`(投影模式/同步策略)+ `VisualConnector` + 锚体系(text range 的可存活地址——12.9 埋的地基在产品侧冒头:**锚不只给 AI 引用,也给用户上板**);
- 板上**不编辑文字**,只摆放/连线/画笔;想读,双击进纸的世界。

## 二 · 论证(七向同构,无一逆向)

1. **真相分离**(全项目唯一设计语法):纸=内容真相,板=关系真相;现行设计把两种真相塞一个面,正是"画布到底他娘的是干嘛的"之惑的病根;
2. **锚体系**:碎片流宪法整卷建立在页基锚上;有界页=天然地址单元,无限画布上的内容无地址;
3. **AI 读法**:纸=竖滚页序逐页读;板=读**摆放图**(结构数据,什么在哪谁连谁),根本不用截图——两面都从"AI 费劲"变"AI 顺撇";
4. **OD 管线**:OD 产物天然页尺寸;三层解剖(皮/纸/肉)落点即页模板,零返工;
5. **跑题分蘖论**(Henry):无限画布**制造**跑题蔓延(一锅粥);有界的纸产生**分蘖压力**(写满/跑题→抽出另立一篇),板负责合流——**有界逼你化整为零,黑板帮你零又成整**。学习工具该有的呼吸节奏;
6. **比例无解定理**(Henry 体感证据,2026-08-30 截图在案):画布里两把标尺打架——字号听屏幕阅读标尺(px),纸听物理页面标尺(A4 宽高);无限画布把缩放变成自由变量 ⇒ **不存在让两把标尺同时成立的缩放档位**(字舒服则纸出画;纸完整则字如蚁;导出全屏则正文大过标题)。调参不可救。文档编辑器(Word/Docs)全锁页面视口、画布工具(Miro/Figma)文字体验全稀烂,即此定理的行业验证。新架构 = 两把标尺各自回家:纸锁阅读标尺(缩放退化为"适合页宽/整页"档位,**所见即导出比例**);板保留自由缩放(板上无人读字);
7. **屏幕预算**:字可读的缩放下野地出画,野地可见的缩放下字不可读——一块屏喂不饱两个空间 ⇒ scratch workspace 是死区(唯一用户从不使用,实证)。

**Henry 判语(原文入档)**:"我们在工程上一切说得通,想的可厉害了。但问题就是实际应用的时候,用户的眼睛能看到的这些东西,他就是过不了关。"——体感证据与工程自洽同级,眼睛是终审。

## 三 · 重做小账(换宗主,不推倒)

- **保留原样**:页框模板体系(尺寸/边距/背景/排版 profile)、块几何、吸附机制、UX-4b 归属搬迁 cohort(板上"搬笔记连着搬便签"直接复用)、投影/mount/连接线机关;
- **白赚的简化**:inside/outside/crossing 三态跨界兼容语义大幅退役(野地没了,跨界失去对象)——4b 复杂度反向缩水;
- **新做件**:①板作为一等实体(数据模型/归属);②投影上板交互(笔记缩影/组/text range);③"抽成新笔记"分蘖动作;④页内搁置托盘(野地退役后草稿块新家);⑤纸视口的阅读标尺锁定(字号绑定纸的物理尺寸:A4 按 pt、网页式按 px)。

## 四 · 开口(设计日再答,今日不裁)

1. 板的归属层级:项目级?工作区级?还是板本身即 item(想建几块建几块)?——Fable 直觉后者;
2. 分蘖动作细节:抽出后原位留投影还是留链接;
3. 野地迁移:存量笔记散在画布上的块搬去哪(托盘?附录页?);
4. "允许溢出"改判:溢出不再进野地——页边搁置或页自动加高,需重新过堂;
5. 板要不要皮(OD 主题)——晚做,纯装饰层。

## 五 · 版本落位

- 本方向翻牌后即为**设计上游**:版面模板 schema、item 化重构(停车场 E)、L3 跨库语境(板面即语境集——用户把哪几篇摆一起,Mr. Zero 视野即哪几篇)、Agent-first Home 均对其对齐;
