# 纸的视口 —— 阅读标尺锁定方案(13.1 的图纸)

## 一 · 病与解(方向档第 6 论证的工程化)

病:画布把缩放变成自由变量,屏幕标尺(px 字号)与物理标尺(纸的尺寸)不存在同时成立的档位——比例病(一号证物:2026-08-30 Henry 截图,V2.BN12 笔记)。
解:**页面模式下取消自由缩放**,视口由"阅读档位"驱动;文字度量只听纸的物理标尺,⛔ 永不参与画布 zoom 运算。

## 二 · 两把标尺各自的家

1. **纸的物理标尺**:页尺寸以物理单位定义(A4=210×297mm ⇒ 96dpi 下 794×1123px——引擎 `createPageFramePrintProfile` 已如此建模,保留);
2. **阅读标尺 = 视口档位**(页面模式仅此三档 + 步进):
   - **适合页宽**(默认):页宽 → 视口宽减边距;
   - **适合整页**:整页入视口;
   - **100%(物理)**:1 css px = 1/96in,所见即导出比例;
   - 步进缩放(如 50%–200%,10% 级)保留给可访问性,⛔ 无级捏合取消;
3. 档位只作用于**整页的等比呈现**(纸和字一起缩放),⛔ 不改变纸内任何布局度量——这是与旧画布 zoom 的本质区别。

## 三 · 排版绑定(defaultTypographyToken 的升级)

- **纸族页**(A4/Letter/A-系):排版 profile 用 **pt 系**(正文 11pt≈14.67px、行高按 pt 推),绑定页物理尺寸;换纸型 ⇒ profile 等比跟随;
- **网页族页**(screen_note/custom-web):排版 profile 用 **px 系**(正文 16px 族),绑定页 px 宽;
- 机制沿用 `DocumentTypographyProfile` + `pageFrameTemplateToCssVars` 通道,新增的只是「profile 选择随 pageSize 族」与「度量与 viewport zoom 解耦」两条约束。

## 四 · 导出保真判据(未来工单的必红判据源)

- **K-比例**:同一页在 100% 档的屏幕光栅 与 导出 PDF 光栅,布局盒逐一对齐(容差=字体抗锯齿;⛔ 容忍任何盒位移/换行差);回归样本 = 一号证物笔记;
- **K-档位**:三档切换不改变任何块的 page_frame_local 几何(纯呈现变换);
- **K-解耦**:文本测量函数的输入里不出现 viewport.zoom(侦察其全部消费者后机械验证)。

## 五 · 拆单时的 K-0 侦察清单(留给委派层)

1. `CanvasViewport.zoom` 全部消费者(渲染/测量/命中判定各归哪类);
2. 文本测量(`averageCharWidthPx`/行高)与 zoom 的现有耦合点;
3. 导出管线的 scale 来源(是否已走 print profile);
4. page 模式与 canvas 模式的视口控制器分叉点(13.1 只动 page 模式,⛔ canvas 模式原样留给 13.2)。
