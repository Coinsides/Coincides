# Better Notebook「成熟」的定义（未来目标，可测）

> Henry 反复强调：重点不是**评判现状**，是**定义"未来 Better Notebook 怎样算成熟"**。本文给定义，现状只用来对账。

## 0. 这趟怎么来的 + 隔离纪律
- 真跑了一次：在 scratch DB（隔离）上 server 干净跑完 **41 个 migration（到 041：连接线 extension + 图片资产）**，应用活着、数据层健康。
- 已有一整套 dev 环境在跑（3001 server + 5173 vite，几乎肯定是 Codex 的）——**没碰**。我自己的 vite 落 5174，看完即杀。
- "建一篇真笔记"的写操作会落到共享在跑的 DB，**Codex session 内不写**；完整交互走查留到 canvas 收口、独立端口+独立 DB 干净隔离时做。

## 1. 成熟的本质：一个**采纳门槛**（没法作弊）
> **当 Henry 不再回头用 Notion / markdown 会议记录、而是自然伸手开 Coincides 干真活——那一刻就成熟了。**

功能清单能 100% 打勾、产品照样死；但"第一个真实用户离不开它"作弊不了（PRODUCT.md: *first real user is Henry; optimize for serious self-use*）。
- **可操作化**：真实旅程里**没有死路**。
- **地板 vs 天花板**：成熟 = 核心 loop **到地板** + 够愉悦，**不是**每个功能到天花板。所以它是**有界、够得着**的门槛，不是无限工程。
- roadmap 坐标：这是"**用户可靠**"那一档（工程可靠 → 用户可靠 → 人机协作可靠）。Agent 在它之后。

## 2. 真实旅程（测试集）
规范旅程（就用 `local-test-materials` 里的真料）：
> **把一份讲义 PDF + 一份公式/习题 PDF + 几篇网页文章，变成一篇能留下来、能分享的学习笔记/报告。**

七个阶段，成熟 = 每一段都不撞墙：
```
收集 → 写 → 组织 → 接地(溯源) → 空间排布 → 再入 → 导出
```

## 3. 每阶段的成熟标准（= 具体的"无死路"定义）+ roadmap 三桶对账
> 🟢到地板 / 🔧在飞 / 🟡在路上(roadmap 有) / 🔴要补但未明确排近线 / ⚪正确推迟(Agent 时代)

| 阶段 | 成熟地板（无死路 = 什么） | 现状·roadmap |
|---|---|---|
| **收集/导入** | 真人能把素材弄进来，且**作为源被留住**（有出处）；手动上传/粘贴通，内容进 TextFlow 或 Source | 🟡 SourceLibrary 页在；手动导入到地板是成熟要求；溯源地基(A9a)在路上；重 OCR 重建=⚪Phase G |
| **写** | 点→写、slash、结构化块（公式/定义/代码），像 Notion 不像后台 | 🟢 TextFlow 基本到地板（typography 已成熟） |
| **组织** | 手工把碎片收进 ContentGroup、归文件夹、refine 成 Petal，舒服 | 🟢 实体在(Rail/Gallery/Editor)；UX 还在成熟 |
| **接地/溯源** | 给一句话挂源、看出处、跳回原文——**纯手动也通、可审** | 🟡 源链原则已进 PRODUCT；手动引用地板是成熟要求；A9a 在路上 |
| **空间排布** | page-first 写 + 画布对象(图形/连接线/图片/表格) + **ContentGroup 投影上画布**；能手排一页报告，顺手 | 🔧 8.11(对象家族，040/041 刚落)→ 8.12(ContentGroup 投影)= canvas 收口。**当前主线** |
| **再入** | 几周后回到一篇笔记，快速定位、接着干 | 🟡 基础再入在；"找回思路/出处"的顺滑是边际；真痕迹层=⚪Agent 时代 |
| **导出** | **基础忠实导出**（正式页 → PDF / 可分享）。一个导不出的笔记本不算成品 | 🔴 现 export 只有分类器、无发射器(gap-hunt)；**基础人读导出是成熟硬要求**，需补；忠实双层导出(带 CG/Relation/源 sidecar)=⚪后话 |

## 4. 横切的成熟质感（不分阶段，但都得有）
- **可靠/可恢复**：不丢数据、undo 可靠、无声破坏性操作清零。(PRODUCT 9)
- **安静/愉悦**：工程元数据退幕后，像专注笔记本不像 demo。(PRODUCT 10 + brand)
- **无墙**：知识不困在项目里（拆墙；Fork 2）。
- **一致**：跨表面(Notes / ContentGroup / Source)概念一致、不打架。

## 5. 成熟闸门（何时能说"成熟了"）
- [ ] 七阶段每条**无死路**（到地板）。
- [ ] 四条横切质感都在。
- [ ] **采纳信号**：Henry 连续真用它干真活、且不想退回旧工具。
三者同时满足 → 成熟（= 跨过"用户可靠"）。

## 6. 现在与"成熟"之间，具体隔着什么
- 🔧 **canvas 收口(8.11→8.12)** = 排布阶段地板。在飞。
- 🟡 **拆墙(8.12 前) + Source 溯源地基(A9a)** = 收集/接地地板。roadmap 上排着。
- 🔴 **基础忠实导出** = 导出阶段地板。目前只有分类器、无发射器，且**没明确排进近线**——建议显式排一个版本，否则"导不出"会一直是死路。**这是对账里唯一一条"roadmap 没接好"的。**
- ⚪ 重 OCR 重建 / AI 组织·蒸馏 / 痕迹层 / GraphRAG = Agent 时代，**不在人类侧成熟范围**。
