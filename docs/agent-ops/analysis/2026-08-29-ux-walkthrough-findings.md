# 设计构想:Agent-first Home 与导航重构(Henry 口述,2026-08-29 凌晨)

**原话要点**(附 home/navigator 设计灵感截图):
1. **Home page 不显示 navigator bar**,取而代之显示「Projects」等**大按钮**。
2. **Agent 对话窗口放在 home page 最上**。用户可通过 agent 进行页面交互(如打开某一个笔记)。
3. **跳转页面后 agent 变悬浮窗**,可收起展开,按用户后续指令服务。
4. **并非每个操作都跳页**:如「让 agent 从别的笔记或源中寻找内容,加入当前笔记的布局排版」——就地执行,不跳转。
5. **形态约束**:当前是 Chrome 网页形式;**目标形态是独立可多窗口应用**(Tauri),网页限制让设计受阻。

**Fable 批判读法(讨论中)**:
- **形状先于能力警戒**:Agent-first home 的落地必须等 Agent 真能干活(12.9d 检索地基 + 13 Agent 消费面);设计现在定,入口后上。⛔ 一个不能兑现的对话框摆在最显眼处比没有更伤。
- **红线的反向应用**:Agent 能导航的,人类必须也能导航——大按钮保住了这条(Agent 不是唯一入口)。
- **焦点规则是真设计题**:「不是每个操作都跳页」需要一条原则:**用户明确要求去哪才跳;内容操作就地完成,结果非模态提示**(抢焦点 = 反「Word 的安静」)。

## §7 补三(2026-08-29 晨三,Henry 对「形状先于能力」的射程勘定 —— 法理级)

- **「形状先于能力”是服役律,不是设计律**:罪名只有一个——**冒充**(形状在服役场景声称自己是能力);设计过程「先有形再安能力」是造物天然顺序,组件库是**预备役**,形先于能是常态非病。
- **场所即申报**:组件躺在库里,位置本身就如实申报了「未接线」——不需逐件挂牌。
- **能力晚绑定**(进度条 0-100 vs 0-10000 案):能力实参不属于组件,属于服役现场——库件带**能力接口**(「我有范围,我吐一个值」),笔记入役时供给实参;实参烧死进库件才是 bug 之源。
- **三段律**:库中形先于能(常态)→ 入役晚绑定实参 → 服役后形能必配(违者即冒充)。

**口子 2 提案(组件改版追随策略,已全文陈述,待拍)**:
- 改动分两性:**A 换皮**(边框/行高/配色,不碰接口)vs **B 动接口**(加列/改值型/删行)。

## §7 补六:口子 2 合体定案候选(Henry 双库构想 × Fable 接口指纹,傍晚)

**Henry 构想(原话要旨)**:每组件带**样式库**(一次改样式存一条;**原型不动**,除非用户显式替换原型或 AI 默认选优)与**变体库**(功能增减,如三旋钮加可选名字框 = 变体,也可新建组件);样式与功能分开。

**Fable 合体(定案候选,待 Henry 点头)**:
1. **问题被溶解而非被解决**:双库**只增不改**——实例引用的东西永不在脚下变掉;「改一处炸十处」无从发生。与「原件永不修改」同语法:组件库 = 家族树(原型 + 皮变体 + 肉变体)。
2. **接口指纹当分拣帽**:保存时机器算接口签名——不变→样式库,变→变体库。⛔ 用户不需申报改动性质;「在皮的名义下夹带肉」被机器拒绝(指纹变则拒原地存,转存新变体)。
3. **两条边界规则**:样式条目可原地编辑且自动传播(皮安全);变体默认住家族,**显式提升**才独立成组件。
4. **实例引用形态**:(变体, 样式) 对 + 本笔记实参绑定;组件带默认样式指针(人/AI 可拨)。

## §7 补七:口子 2 最终三层模型(Henry 污染之问补完,傍晚二)

**Henry 之问**:一篇笔记同款组件调 30 次改 30 个颜色,若都进库 = 库变流水账;变体库的意义在**适用性与通用性**;局部小改该"哪儿都不存但每次打开都复原"。⇒ **自我修正**:上轮「每次改完样式就自动保存一条」作废。

**定案候选(三层)**:
1. **库层(精选集,只增不改)**:⛔ 只收显式「存下来」的;存时接口指纹分拣(皮→样式库/肉→变体库/提升→新组件);
2. **实例层(自由覆写,住笔记)**:随手改动只落本笔记本实例(存为对引用样式的 diff),随笔记持久复原,零库污染——**不具代表性的东西不配进库,但配被记住**;技术上照抄块布局持久化的现成形状,不难;
3. **提升通道**:实例覆写可随时「存为样式/存为变体/提升为组件」毕业进库——**毕业是荣誉不是义务**。

**层叠细则**:样式原地编辑传播时,实例覆写压顶部分⛔不被冲掉(覆写永远赢)。
