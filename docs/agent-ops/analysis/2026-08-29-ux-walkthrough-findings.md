## 9. API key 配置入口应在 Settings 统一,provider 需扩充

- **原话**:「不同 API key 的输入入口应该在 setting 里统一,provider 需要扩充,.env 文件不能成为成熟的用户端体验中用户主动保存 key 的方式,太过于麻烦。」

- **落点候选**:不插队 12.9c;归 12.9d(检索地基,Agent 门在彼)或 13 开场,与「Agent 怎么用库」一并设计。
