# 统一方向概念稿:长着投影的收据数据库

## 0. 存在理由(一页纸版)

**总账第 0 号加重版**:2026 夏期末季,产品主人在真实高压学习中对自建应用**零使用**——被自己用 Claude artifact 工作流搓出的 18 件 HTML 复习件完胜。差距是**结构性的**:不是旧表面打磨能追平,而是缺少"内容生而结构化、格式由默认值给、成品立即可用"的整条管线。

但同一个期末季也交付了答案:18 件复习件收敛出一套**组件语言**(九组件,共享同一 token 系),手写笔记标本验证了双层学习理论,make-or-buy 的边界摸清,外部候选查实归册。**本稿把这些装订成一个方向:真相层一寸不动,表层全面重划。**

三句钉语作纲:**智能会贬值,真相不会;智能是租的,手是自己的;手为什么长这个形状——那个"为什么",就是核。**

## 1. 本体论与定位

- **我们是一个长着投影的收据数据库**:五真相=表;收据(锚/出生证/判断快照)=带诚实降级的外键;新鲜度与 compiled scope=读时派生;阅读面/画布/HTML/vault=同一批行的四种视图;MCP 工具面=对外存储过程;驾驶舱=对自己跑的分析查询。(08-18 §十二)
- **定位:学习主力工具**——任意常见学习文档扔进来,对着软件学习(替代 Chrome 的真卖点:**Chrome 的高光死在原件里,我们的圈选活成收据**)。(08-18 §四)
- **与 artifact/Claude design 的区别**:它们的页是终点(孤儿成品),我们的页是投影(背后有真相层)——不是重做它们,是补上它们没有的那一半。(08-16 §八)
- **不可 fork 之核(资产专用性判据)**:①真相层的语法(可 fork schema,fork 不走判断史);②末端执行器(工具形状由笔记语义定);③学习理论本身(主人学习→反思→蒸馏→再用的闭环)。(08-16 §九)
- **对照钉句**:Obsidian 是文件系统上的笔记应用,我们是数据库上的学习系统。(08-18 §十二)

## 2. 架构总图:三层不绑架 + 外骨骼

```text
大脑(模型)     全租,前沿一档,provider 缝可换(08-07 云化拍定)
                约 18 个消费点挂 4-5 档位槽:推理/视觉/快速/嵌入/杂役(08-18 §十)
穿戴者(harness) 可换可多:管家=OpenClaw 改装(⚠️ 许可复核前置闸)、
                工程=Claude Code/Codex/OpenCode、产房=Open Design 驱动
                规矩:穿戴者只许点菜不许下厨(v2:沙盒厨房例外,见 §6)
外骨骼(应用)    唯一不换:真相层+末端执行器+守卫+收据
                纪律:外骨骼不为任何穿戴者整容(改锥形状由螺丝决定)
```

**零模型荣誉榜**(设计健康度另一半):客观判分/机械新鲜度/沉降/选区捕捉/锚定位/compiled scope——全机械零 token。

## 3. 万物之始:Source 统一门与三层梯子

- **三层梯子**:层0 原件观看(hash+blob 零成本进门;观看器全租)→ 层1 原件+锚(**区域锚不需解析,即可划红圈问 AI**)→ 层2 引用源(窄腰解析,AI 加工基座)。**解析按需,不入库即解析**(付费点后移至首次加工)。(08-18 §四)
- **窄腰**:任意格式(PDF/DOCX/扫描/图片/**外来 HTML**)→ 一个前端映射 → 类型化组件流+阅读序+源坐标。外来 JS 永不执行(导入侧)。
- **抽取矩阵(便宜机械道,已核验)**:pdf.js(坐标页码白送)/mammoth(DOCX)/SheetJS/JSZip——Node 原生零 sidecar,写进自有层0 schema;MarkItDown 仅预览件;Kreuzberg 挂 spike 前置。**锚模型格式原生**:PDF=页+bbox、DOCX=元素路径+偏移、XLSX=单元格地址——"多记坐标"按格式各记各的坐标系。(登记册三之二)
- **多记坐标 + 摘录副本**(已拍):锚 schema 是不可逆地基,解析是可重跑机器——投资优先级由此定。(07-20)
- **功课**:格式 ×(观看/锚/解析)能力矩阵,随施工计划出。

## 4. 表面重划(革新=搬家非拆迁,真相层零移动)

| 旧 canvas 引擎的幻想 | 新归属 |
|---|---|
| Figma 级自由空间编辑 | **释放**(减负:减"无尽"不减"画布") |
| 格式成熟感 | **排版预设+编译器**(好格式是默认给的,不是调出来的) |
| 交付分享 | HTML 投影三口味(§7) |
| 结构承载 | 组件语言(§5) |
| 日常书写 | **流式装配面(默认面)**——一维组件流,布局由流接管 |
| 空间整理/墙/全局 | 画布保留(摆) |
| 圈选/锚/划红圈 | 画布+层1 原件(圈) |

- **编辑形态:所见即将得**——编辑视图与导出成品共用组件渲染与 token;应用内打开的是"本人",导出的是"照片"。(08-16 §七)
- **【待拍-1】canvas 减负声明边界**:保留=写作顺手+装配+圈选锚+打散重排;释放=无尽打磨+Figma 级+炫技。(08-16 §四.6)
- **【待拍-2】page frame 退役**:Note=唯一文档单位;page frame 从内容容器退役为「导出取景框」;A4/分页降级为导出关切;"合集"需求归 Project/Purpose/墙。牵动 V8.8 机器,施工计划单列。(08-18 §六)
- **双 register 不变**:矿场(引用源,采收优先,修正显式)/花园(笔记,创作自由)——引用源页面永不长成第二个笔记编辑器。(07-20 §五)
- **诚实例外**:08-08 实测四条 🅰(焦点/死胡同/污染/所见与可编辑错位)住编辑机件深处,新流面仍坐同一 TextFlow 内核——**噪声随面死,机件随面活,只修活的**(建议 Codex 并案查 root cause)。(08-18 §十一)

## 5. 组件体系

- **组件语言 v0(九组件,自 18 件标本显影)**:目的声明头/导航层/骨架卡/公式卡三件套(eq+vars+Anchors)/折叠答案三段式(含个人层)/勘误卡/语义卡族/对照收据/统一 token。**=手写标本理论的实物化(1:1 映射)**;备考目的的默认模板。(08-16 §一)
- **【待拍-3】组件语言 v0 作为订单规格"备考"默认模板与增员轴优先候选**(折叠问答/公式卡/勘误卡/对照收据先转正)。
- **UI 原语选型(已核验)**:**Base UI 原语直用+自有 CSS modules 皮+自有 token**——唯一允许的行为依赖;shadcn 不整套娶(Tailwind 绑定),但 MIT 参考随便抄、**registry 格式=案例库分发先行艺术**(与 Open Design design-system 包并列研读);a11y 注:按钮命名是署名纪律,配 lint。(登记册三之二)
- **表示变换轴**:canvas object 增员沿此轴走,第一员=函数图(compute-engine+Mafs,两 MIT 包;Desmos/GeoGebra 非商用陷阱不碰)。(08-04 §二十)

## 6. 组件成长路径(「点菜不下厨」v2)

- **三级**:①**产房**(Open Design 当产房引擎现搓交互壳,沙盒落地,同场对话可用)→②**案例库**(模板留存,积使用收据)→③**转正**(凭使用收据晋升慢道,kind-general 注册,获完整真相层待遇)。**晋升凭使用**(与字段晋升/沉降同律)。(08-18 §七)
- **⭐ 内容与壳分离**:题目数据(带源锚)走真相层,交互壳走沙盒——**转正只升级壳,内容从未流浪**。全题型同构(选择/填空/画图/图片排序/图上标记)。
- **打磨三档**:实例覆盖/库级变体/默认晋升(旧实例不静默改——第三态)。两纪律:颜色永远进 token 不许内联;每次微调留收据(路由器判层分道)。(08-18 §八)
- **安全**:外来导入 JS 永不执行;应约现搓 JS 仅限无特权沙盒(iframe/无网/碰不到应用状态/整块锚)——请求出身不同待遇不同。
- **首发组件集缩小**:地板组件(TextFlow/基础卡/表格/公式图)+产房机制,其余让使用长出来。

## 7. 投影与导出

- **编译器**:对象→投影,排版预设内置(18 件标本的 token 系提取为预设 v0)。**真相存对象,投影出 HTML**(与"规格是真相,prompt 是编译产物"同一语法)。
- **三口味**:单文件 HTML(交付件,自足,出生证内嵌)/工程包(manifest+objects.json+assets,交换格式;读 JSON Canvas 规范与 Open Design 包格式)/**Obsidian vault 变体(严格单向)**。(08-18 §二/§十二)
- **使用≠修改**:应用外交互(折叠/勾选/做题/localStorage 答题态)=使用,无需回家机制,v1 即有;内容修改=homing projection(编辑日志按块 ID 回放),**v2+ 选装**。(08-16 §五之二)
- **逆向车间**:自产件凭出生证回家(定位或重建);外来件当标本拆解(/taste 出 token 包+慢道出组件提案),内容不吞并。(08-16 §六)
- **【待拍-4】格式即承诺**:分享出去的导出格式=永久对外契约,版本化+永远向后可读。

## 8. 交互系统

- **选区收据**:一切手势(Ctrl 多选/框选/文字选区/红笔圈/文字指代)在客户端解析成对象身份,归一为 `{对象 IDs,文字范围,几何,时刻}`;**选区收据=还没保存的锚**(锚系统的前半生)。零 OCR:不需要用眼睛认自己亲手画的东西;视觉仅在无身份像素与外观议题时兜底。(08-18 §九)
- **意图路由器**:小快模型毫秒级拆混合话语→意图清单(每条绑选区锚)→分道(快车道直接工具调用/设计道/订单道出候选/对话道)。三件套:封闭世界路由(目标词汇=末端执行器分类)/**拆解结果给用户看**(解释收据,可纠正)/分级放行(即时/出候选/需确认)。(08-18 §二.3)
- **AI 阅卷读收据不读画面**:客观题机械判分零 token;主观题读结构化数据+源锚引原文;唯视觉作答读截图;诊断讲解顺锚引原文。判分数据=错题史=credence 原料(使用态回流管线)。(08-18 §八)

## 10. Agent 岗位与 make-or-buy 边界
