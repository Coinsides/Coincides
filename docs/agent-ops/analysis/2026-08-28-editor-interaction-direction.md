# 编辑交互方向:Word 的安静

## §1 北极星(Henry 原话要义)

**Word 文档是我们的学习对象——它总体非常安静,一点也不吵闹。**本产品的编辑器默认姿态 = **一张安静的纸**:格式控件不常驻正文视野,行首不摆家伙,排版流里只有内容。

## §2 心智锚定(为什么是 Word 不是 Notion)

- 用户的操作心智来自 **Office 三件套世代**——越上年纪越是(80 岁老太太原则 / 陶渊明派,见组织总纲注意力公理);Notion 式行首交互对这代人是**再学习成本**,不是便利。
- **产品为 Henry 自己造**(只为一人设计),Henry 自认 Office 世代——「我不想让它变得这么别扭」。
- 行首的行内格式切换器(勾选框/有序列表那类)摆在每行前面「怪怪的」——**格式动作在 Word 心智里住在工具栏、右键、快捷键与选中态里,不住在行首**。本产品已有选中态工具条(SelectionToolbarLayer),正是这个方向的既有资产。

## §3 已裁与已停

- **已裁(小批照做,纯力学)**:行首控件迁檐下——只解决「控件像字符一样占位毁对齐」,绝对定位悬停现身;⛔ 本单不做任何交互重设计、不撤任何按钮(见会议记录附录 D 四续,范围就此收窄)。
- **🅿 停车(本文主体)**:编辑交互的完整设计——行首四控件存废过堂(行选/插入/标签/角色下拉——现物核实,非传闻中的三按钮;拖拽不在行首)、格式动作迁往何处(工具栏/右键/快捷键/选中态的分工)、行首彻底清空的路线。

## §4 触发器与设计输入

**触发器:V13 雅思线真实使用开跑后。**设计输入 = 真实使用攒下的**摩擦记录**(哪个动作卡了手、哪个控件从没被点过——使用收据即存废证据)。⛔ 不凭想象预制交互;交互设计的 grow-by-use:**先用安静的纸写两周字,纸自己会说缺什么。**
