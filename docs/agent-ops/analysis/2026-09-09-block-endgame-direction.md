# 块的终局 —— 方向档 v0

## 一、判决:块不删,块隐身

思想实验(对谈实录):假设删除块——①锚地址链(笔记→块→unit→偏移)塌掉中间层,必须给 unit 升户口,重映射爆炸半径从一块扩为全篇,036/059 锚、打印裁片、placement、item_ref、准备区、搬迁收据全部重铸=**溯源宪法翻修**;②段落自由重排失去唯一载体;③拖拽失去抓手,被迫给段落装把手——**重新发明块,只是改名**。

结论:**块的本质=户口段(地址中间层)+把手(直接操作抓手)**。这两样任何引用体系+直接操作体系都逃不掉。删名字不删需求,故:⛔ 删块;目标=**"感觉不到块的世界,想感觉也找得到"**(Henry 原话)。

## 二、Henry 定理:人写不分块,AI 整理天然分块

用户自己书写时不分块(可能百万字事实上住一块——现地址链允许,块内 unit 承段落粒度);AI/Agent 整理内容时天然分块——**分块对 Agent 编辑极其友好**:块=Agent 可寻址、可 diff、可提案、可挂锚的稳定单位(organized_note 提案按块写入;锚按块寻址;人有眼睛和光标,Agent 没有——块是它的手指)。

推论:**块的数量是使用模式的结果,不是本体强制**——手写笔记活成"一块世界",AI 整理笔记活成"多块世界",同一套地址共存,互不迁就。

## 三、终局四条腿

1. **地址**:块永在(户口段)——机器的事,人不感知;
2. **把手**:搬运抓手从"容器"移交给"选择"——用户选中什么就拖什么(选区=临时把手,13.4 的"选段→Send to staging/Ctrl+C 成引卡"已在此路上);块把手降级为"整段搬运"的快捷方式;
3. **视觉**:块边框淡化(灰虚线级;Henry 拍定)——与 F8 小签、状态形态同批裁**统一视觉语言**,⛔ 零敲碎打;
4. **类型冻结+收敛**(见 §四)。

## 四、块型收敛判据:"行为独异,才配当块型"

内容的**语义**住流里(unit 书写角色+行内结构物 InlineStructuredObject——TextFlow 现物已预留,slash "Inline formula" 占位即同张 IOU);块型收敛为封闭小集:

| 块型 | 存留理由 |
|---|---|
| **text**(万能纸) | 一切文字内容的家;段落/标题/列表/引用/待办=unit 角色;**公式收编**(行内 `$..$` 与独立成行 `$$..$$` 皆为行内结构物,⛔ 独立 formula block);**代码收编**(Code line unit 角色现成) |
| **投影**(item_ref 族,将来 CG/range 投影) | 行为独异:只读、带出处签、文字流穿不过 |
| **媒体**(image/table,13.5 粘贴图片候裁) | 行为独异:单元格交互/缩放,流穿不过 |

**类型表自此冻结**:新内容形态先问"能否为 unit 角色或行内结构物?"——答不出"行为独异"⛔ 开新块型。

## 五、落位(全部既有槽位,⛔ 新开单)

- 公式/代码收编+行内结构物的锚/偏移交互(占位字符约定)→ **TextFlow 欠条清算单**(13.5-13.6 已候裁)顺路兑现;存量 formula block 迁移=机械活;
- 块边框淡化 → 与 F8 小签效果同批的视觉语言裁定;
- 跨块光标/跨块选择(把块从手感里抹掉的第一刀)→ 13.5-13.6 候裁清单既有;
- 本档转正 → 13.5 专场,与流式 vs 自由摆放仲裁同场(块四条腿即该仲裁的答案骨架:流管语义、块管摆放与地址,两权威档由此和解)。

## 六、诚实边界

- 行内结构物占据文字坐标(选区/锚要数得到它)——非白捡,即当年推迟至"later TextFlow pass"的原因;
- "百万字一块"到真百万字时打印裁片/锚重映射会有性能账,届时自然分页,⛔ 预先强制;
- 本档不裁流式 vs 自由摆放本身,只供块侧结论:**无论仲裁何果,块的四条腿不变**。

## 七、Agent 编辑笔记(V14 note_patch 规格雏形;09-09 对谈补)

**电影五幕**(用户圈 3-4 篇原始文档→"整理成笔记"):圈料(材料库快照+锚)→起草(Agent 产**块清单**,每块=论述单元+源锚出处)→提案(organized_note,逐块差异预览)→**主权分票**(逐块采纳/打回,⛔ 全有全无)→迭代(按块施工)。

**块给 Agent 的便利**:①可寻址(精确制导⛔模糊匹配,LLM 改错地方的事故源=无地址文本);②可分票(块=主权分票单位,装卸区"拖上板才算数"的纸面版);③省 token 防漂移(改一块只重写一块;块=重写风险隔离舱);④锚的防火墙(重映射爆炸半径封在块内,逐块挂源锚逐块重验);⑤大纲即结构(reorder 两个 ID=便宜安全可验证)。

**麻烦的诚实分类——慢性三,急性二**(判据:解完之后它还在不在):

- 慢性(对策=降税,税永在):**切块判断**(定理兜底:**切块粒度=采纳粒度**——一块=用户可独立说要/不要的论述单元;判据让失手从瞎猜变有据,但"要判断"消不掉)/**块间接缝**(规范兜底:**全读局改**——上下文永远全文+源料,落笔只限点名块;分件编辑的连贯维护是分工内在属性)/**结构手术锚风险**(merge/split 永远带"锚跟谁走"的决策,drift 是手术内在属性;管理术=宁 drifted 保快照⛔静默跟错);
- 急性(一针见效):两步保存(提案事务通道终解,⛔ Agent 绕信封)/格式约束(改判为疫苗:受限格式=可验证格式)。
- 慢性病总药方=**失手可见、可拒、可退**(分票制/drifted 牌/提案信封)——与溯源宪法同一哲学:不消灭不确定性,让不确定性留收据。

**工具面四动词**:`replace_block / insert_blocks / reorder_blocks / delete_block`——全块寻址、全可 diff、全装提案信封;**结构手术(split/merge)v1 ⛔ 给 Agent**(机械闸:人类撤销栈盖不住的区域 Agent 不开写权;TextFlow 欠条清偿后人机同步解锁)。

**种子**:块带 actor 出生证(镜像装卸区 mounted_actor)——这块谁写的(人/Mr Zero),签色体系届时多一族签;**块墙对人与 Agent 是同一堵墙,一次拆两边受益**。
