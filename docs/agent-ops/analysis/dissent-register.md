# 分歧登记簿 (Dissent Register)

**为什么存在**:三方协作(Henry × Claude × Codex)的已知失效面是叙事锁定、重复加权与关系性迎合——分歧容易在摘要与上下文压缩中被抹平,被否掉的反对倾向于蒸发。本簿把分歧本身变成耐久工件:**被否掉的反对也留明面、带理由**——反对被正常化,是对迎合最便宜的解药。(设立依据:2026-07-12 Codex 设计复述 handoff §12.3 + Claude Result §R4;Henry 拍定,判断点 k。)

**协议**:
- **Append-only**:条目只增不删不改;状态翻转在条目内追记。
- 一条 = 一个具体主张上的分歧:谁主张 / 谁持异议 / 证据状态 / `open` 或 `resolved`(+怎么收的、谁让步、为什么)。
- **resolved-against 的条目照样留着**——这是本簿的核心价值,不是垃圾。
- 只登真分歧(讨论后仍有不同意见的),不登还没讨论的疑问(那归会议记录待拍清单)。
- 任何一方(含 Agent)可自行追加条目,无需批准;Henry 复核走 claude-log/会议记录常规通道。
- 第三者复核类 handoff 应把"查登记簿"列为常规步骤。
