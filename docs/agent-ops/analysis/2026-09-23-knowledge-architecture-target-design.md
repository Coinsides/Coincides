### 乙部 · 新增十三叉(审稿产出;前三叉为 schema/验收级阻塞)

**F11 · 词条簿作用域语义(阻塞:唯一性约束定不了)**
支线:a 全局单簿+作用域字段过滤 / b 每 project 一簿+跨簿认亲 / c 全局簿+规范名唯一性按作用域分区(同名异 term_id 合法)。
**推荐:c 并入 a**——全局单簿,唯一性按作用域分区:数学的 normal 和史学的 normal=异 term_id,扫描命中按作用域就近解析。多义词是先例头号杀手,跨域同名正是它的结构形态,分区唯一性是结构解。

**F12 · 机械行被耐久消费后的出身(阻塞:F6 的行为层漏洞)**
支线:a 消费即晋升 human-confirmed / b 耐久物内嵌不可变快照(term_id+锚+匹配档+时戳) / c 禁止耐久消费者读机械档(杀死依赖签名与 F10b,不可选)。
**推荐:b 为律,a 为快捷径**——耐久物一律内嵌快照(重扫/匹配器升级后履历不悬空);行动界面顺手给"确认这条"一键(行动者常乐意当场晋升)。此即第三律。

**F13 · 否决的持久化与再提名抑制(阻塞:止损线分母不可测)**
支线:a rejected=一等出身档(永存,同项不再提名) / b 会话级忽略(重扫复活=无限 nag) / c 否决带射程(仅此锚点 vs 本词条全局禁自动)。
**推荐:a+c**——否决永存,默认射程=此锚点,可一键升级为本词条禁自动;止损线分母=确认+否决之和。

**F14 · 词条合并/退役时在册确认行去向**
支线:改写 term_id 重指代表元(机器改人行,碰"永不毁"红线) / 行照存+查询期经等价类解析(零改写) / 删除:禁止 vs 墓碑 vs 降悬空。
**推荐:查询期解析,⛔改写人行;有确认行的词条禁物理删,走墓碑。**

**F15 · 撤销语义(融合手势的代价)**
"标 definition"一手势=铸金+登词,撤销拆不拆?
**推荐:拆分撤销**——金笔撤,词条留悬空(悬空=合法态,自然落点);耐久下游靠 F12 快照免级联。

**F16 · 源域导词 vs grow-by-use 铁律(v1 内部矛盾,审稿点名)**
支线:a 导入即休眠(登记但禁扫描禁提名,读到落点才激活) / b 导入即活跃(违律+噪音爆炸) / c 通道整体押后。
**推荐:a**——激活位入词条 schema(15.2 与 F11 同批)。

**F17 · 扫描语料射程**
支线:a 笔记域先行(源域词条只经导入通道入簿) / b 源域同扫(教科书命中入传记,但源域现状页级锚,精度掉档量级大)。
**推荐:a,且如实摆代价**——针六的原点场景(教科书内部一章 def↔十章 thm)在 a 下要等两处都做了笔记才被服务;过渡期由 F9a TOC+源域页级锚给**粗版传记**(标明精度档)。

**F18 · 重复/冲突定义裁决**
支线:a 单出生制(后来者降复述) / b 多出生制(按作用域并列) / c 裁决面板人选主定义。
**推荐:与 F11 联动**——异作用域=异词条(非双出生);**同作用域**第二定义→裁决面板,人选主,余者复述。用户手标与 Agent 提案撞车=同流程,人永远先手。
