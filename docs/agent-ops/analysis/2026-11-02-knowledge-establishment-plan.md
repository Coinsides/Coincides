## 一 · 教义定稿(宪章增补节正文,随本稿一并翻牌)

以下为 Henry 已逐条拍定的教义。翻牌通过后原文铸入方向宪章增补节。

1. **定位**:存在归档案馆(外部粗存储),转化归我们;入境即拣选,进门即贵宾;库存是公民,不是文件。源件可退休。
2. **零问话导入**:拣选只在门外(agent 层);门内全收全建;导入时永不问用户结构/范围问题(启动成本=拖延温床)。
3. **出生即公民,义务随成年**:每个知识点入境即建(名字/页锚/组籍/状态=未触);复习调度与关系判断等义务只随首次交手解锁;未触点**结构上不可能**进催办队列。未触公民=资产(藏书未读仍是藏书),非灌水。
4. **查漏补缺=未成年人口普查**:覆盖视图按章列「未触/有痕(何种痕)」,是 learning 类事由买到的核心功能;「这轮略过」=挂组员关系的免催标记,非掌握裁定。
5. **格子是谁切的,决定点的身份**:显性结构源(教材/论文/规范)照作者格建点=事实,硬边界;隐性结构源(会议记录/口述/常态笔记)由 agent 细读照**假设格**建点=软边界——用户重切一步让路,重投资候使用确认。显/隐判定=机械规则读转写结构角色统计,零额外模型调用。
6. **按纹理切格**:假设格单位取源件原生结构(决定/议题/行动项/主张),不硬套教材本体(definition/theorem)。
7. **原子/透镜分工**:item 照纹理切,**不带 purpose**;purpose 整体上移到组(透镜)。原子的内在属性=内容+锚+结构角色+痕迹;关系性属性(purpose/角色/进度)全在组籍上。同批原子可被多个 purpose 组各自收编,互不冲突。
8. **机器产物二性律**:凡用户亲笔,生而为事实;凡机器推断,生而为假设;假设见用户信号,一步让路。切格用之(作者格/假设格),purpose 解读用之,处处用之。
9. **痕迹账本**:行为=账本条目(episode),不是本体物种;行为发生时引用内容,不预先登记。痕迹意义由五消费者定义(漏的定义/成年扳机/purpose 修正器/agent 学习者画像/情景问答);**字段由问题倒推,没有消费者的字段不记**。两种墨水:**成年只认人墨**,agent 引用痕只喂画像与排序,永不触发义务。署名随进入路径;野路痕迹=无主,触发成年但不进普查,agent 可事后提议认领。
10. **记录不裁定**:机器永远不裁定「会不会」(判定不上脸);普查只陈列证据。内容面与状态面分离:笔记/组按连贯性组装,永不按状态过滤内容。
11. **purpose 卡**:原话层(用户原文,一字不动,=授权)+解读层(agent 起草:真目的/territory/行为模式/时间窗,=假设,痕迹流事件驱动地修正)+**锁**(锁=解读层升格为用户钦定事实,agent 修卡权收回;锁住后漂移痕迹照记、卡不动、普查陈列射程外痕迹数)。机器不得**无中生有**造 purpose(无用户事由凭空立组立义务,禁);起草/扩写/修正是分内事。行为用出形状后结晶为普查表上的存档视图,不新增物种。
12. **缓建记档(Henry 11-02 拍)**:purpose **退休机制缓建**。过渡期义务止息靠「这轮略过」标记+义务本就只随成年解锁;退休(组归档+义务清零)候后续版本。

> 本体冻结四件:**原子(item)/ 组(透镜)/ purpose 卡 / 痕迹账本**。

## 三 · 缺口清单(真正要造的东西)

1. **purpose 卡补层**:purposes 加原话层/解读层字段(user_verbatim、interpretation_json);锁语义核对(复用 sealed 或新增 locked);导入流捕获入境事由(零问话:有上文取上文,无上文 agent 起草默认卡);agent 起草/修卡服务(事件驱动:痕迹到账=判断窗口;锁后只记不改)。
2. **建点管线**:转写 fragments(十角色+锚)→items 批量出生;确定性 id(uuidv5 新命名空间,幂等可重跑);出生 provenance=格别(作者格/假设格/用户格,二性律落列);item_anchors 带 source_record_id+页锚(+bbox 入 range_json);同批入事由组名册(purpose_members,member_kind='item');未收编块→无主锚池(余料桶)。显/隐判定=角色统计机械闸。
3. **痕迹开读+补墨**:events 开读侧(普查联查、agent 画像查询);人墨 verb 窄幅增补(练/错/引/改/标——由五消费者倒推,拒绝全量监控);FSRS 逐次评分落账(小迁移);署名=入账时随进入路径带 purpose 归属。
4. **普查表(面)**:项目页新 section 或独立页:按章(源件结构树)列原子,「未触/有痕(何种痕)/略过」三态陈列,数据=名册(purpose_members)×痕迹(events)联查;余料桶挂尾部。
5. **纠错术**:五式手术(并=补 retired_into 路径/拆/改类/删/从余料认领),每刀升格 provenance 为用户格;整篇重切=用户显式召唤+一句话指示+**成年公民免疫**(有人墨痕迹的点不动,只重分未触点+余料),成本=一次细读,⛔重转写。
6. **纪律性负空间**(明确不做):义务机器不扩张(item 不进任何催办);不裁定掌握;机器不自产 purpose;退休缓建;词条簿(依附体)schema 随一期定稿后重呈呈批台,本计划不含其施工。

## 五 · 风险与止损
