# 外观族对标调研收敛报告

## 一 · 交互不变量十二条(跨家收敛,工单验收直接引用)

1. **example-first 存资产**:调到满意→「+」→命名(唯一必填,可选描述写用途⛔色相)→即存即用即选中,闭环零跳转(Figma Create style/Word Create a Style 同证);深度配置藏在可选二级;
2. **detach 降级合同**(token 系统最重要的一条):纸绑套装后改单个 token=该项自动脱离(保留改后值,其余继续跟);删除色/删除套装=消费者**静默保留解析值**降级为字面值——⛔弹窗⛔红错⛔外观突变。"断开引用的代价只是以后不跟,绝不是现在变丑"(Figma);
3. **非模态编辑零确认**:改动实时传播全体消费者,关卡即存,⛔应用/保存/取消三连(Figma 编辑小卡/Word);
4. **悬停即真预览**:hover 预设卡=整纸当场换装,移开还原;点击=生效零确认;可逆交给撤销(Word 样式集画廊——"敢做全局预览,预览成本再高也做在悬停上");触屏 fallback 另配(按住预览);
5. **快选卡=自渲染微缩样张**:四预设卡用各自真实 token 渲染微缩小纸(⛔静态截图),兼任当前态指示器(选中框)(Word 样式库);
6. **Custom 置前+右键收纳**:用户套装排入 Custom 区置于出厂之前;低频操作(重命名/删除/「更新套装为当前样子」=Update to Match Selection/设为默认)收右键或长按菜单;
7. **单一取色器全取色处共享**(全局跟随的全部机制,Figma/Canva/Word 三证):一个取色器组件,分区=①**当前调色板命名色第一屏**②标准色③最近使用④自由取色;**点池色存引用,点其他存绝对值**——换调色板时引用全局重算、绝对色不动;修 Word 的坑:引用/绝对⛔静默分叉——浮卡标注色源+绝对色给「入池」一键;
8. **就地编辑色池**(Canva):取色器内可直接加色(hex 一等公民)/改/删/建组——"家在设计室,随身编辑口在取色器,读写同一份";用户第一次发现缺色正在取色现场,当场补池;
9. **命名即分组**(Figma 斜杠):`暖调/杏黄` 自动成组,拖入组=改前缀,⛔独立分组数据结构;
10. **单开关裁定**(⛔Word 双开关坑):套装=token 值+部件开关+字体的**单一整包**,一级界面只此一个"换整套";分维度替换(只换调色板)=套装展开后的次级操作;
11. **偏差可见+橡皮擦**(Word Style Inspector):浮卡头部显示"基于哪个套装",被改离的 token 打偏差标记;逐项「还原到套装」+一键全还原;**换套装不清洗手工偏差**;
12. **破坏性才配确认**(Notion vs GoodNotes 对照):换皮可逆=点击即穿连续试穿⛔Apply 钮;将来若有破坏性替换(改版式动内容)才配显式确认。另:**至少留一件**硬规则(Canva:删除入口禁用⛔删后报错)。

## 二 · 浮卡 v1 交互规格(十条,浮板路收敛)

1. **生命周期(最优先,反 Figma 头号痛点)**:单实例,常开,跨选区跨纸存活始终作用当前纸;只被 X/Esc 关闭,⛔换选区自动关;
2. 实时应用无 OK/Cancel,纸即预览区(浮卡内⛔预览区);
3. 形态=单列窄卡 ~280px、高上限 ~60vh 内部滚动——从第一天按紧凑版设计,内容膨胀的泄压阀=设计室抽屉⛔加宽浮卡(Figma UI3 浮动主面板翻车回退的教训:临时工具卡⛔长成常驻面板);
4. 顶部通栏 header=唯一拖动区(四家共识),含标题/折叠/关闭;内容区⛔可拖;
5. 吸附只做两件:松手 clamp 进视口(四边 8px)+近边 16px 磁吸至 8px;⛔面板互吸⛔drop-zone 停靠;
6. 折叠=唯一形态:卷帘收成标题条(双击 header 或 chevron);折叠态随位置记忆;
7. 常驻 100% 不透明,⛔半透明⛔自动淡出(四家零例外);焦点=操作不夺焦、输入才夺焦(macOS becomesKeyOnlyIfNeeded 心智);
8. ⛔点击穿透⛔自动躲避(零先例,躲避毁空间记忆);遮挡四件套=窄+折叠+拖走+clamp;
9. 位置记忆:持久化 (x,y)+折叠态跨会话;首开锚触发钮旁(popover 心智),此后用记住位置(工具心智);恢复必 clamp 进当前视口(防丢屏外经典 bug);
10. 内容结构:头部=当前套装名+偏差标记区(不变量 11)→四预设快选条(不变量 4/5)→token 编辑区(每项吃统一取色器)→部件开关区→「存为套装…」(不变量 1)。

## 三 · 卡面封面取景规格(cropper+Notion 路收敛)

1. **范式 A 定框动图**(目标位已知的上传流全用它):框固定输出比例,用户拖/缩框后的图;⛔框拖柄⛔比例切换(多卡型比例=每型一个固定框);
2. 初始=cover 适配居中,zoom=1=cover fit 即**缩放下限**——任何状态框内⛔露底;拖动越界 clamp 碰墙即停;
3. 手势:桌面=可见滑杆+滚轮双通道(滚轮以指针为锚),触屏=捏合;
4. 确认=显式 Save/Cancel 双键⛔自动提交;**再编辑入口(卡面悬停浮条「重新取景」)与上传同批交付**——它就是非破坏存储的用户可见面(反 Twitter 无再编辑之坑);
5. 存储=非破坏:{assetId, crop 百分比参数};渲染由参数推;缩略为可重建缓存;
6. **语境分偏移**(Notion 逐卡 Reposition 印证我们 card/page 两框制):同一图在不同比例挂点各存一份偏移互不污染;
7. 谱系分工(HQ 裁):**卡面封面编辑=弹窗式**(Twitter/LinkedIn 谱系——卡面小,弹窗放大编辑);**V14 封面页 page 框=就地式**(Notion Reposition 状态机整抄:容器即取景框、单轴拖、Save position/Cancel、点外等效 Cancel);
8. 封面更换弹层骨架(Notion):三 tab(出厂库/上传/链接)+点击即穿连续试穿+Remove 恒右上;**instant-default-then-refine**(先随机穿一张再精修)入候选;
9. 实现选型:react-easy-crop 与上述条款一一对应(cover 下限/restrictPosition/wheel+pinch+受控 zoom/百分比保存),可直接进施工规格。

## 四 · 设计室五抽屉语法(一套画廊语法,⛔发明第二套)

**通用语法**:资产自渲染缩略+悬停真预览+点击应用(可逆类零确认)+Custom 区置前+右键/…菜单收管理;搜索框+分组折叠+缩略网格三件套;**浏览与管理分离**(选择器只管选,建组/导入/删除进管理入口);hover 显影(定制入口平时隐形)。

- **套装抽屉**=Word Document Formatting 画廊(+Reset to Default/设为默认);
- **调色板抽屉**=取色器第一屏的"家"(Canva Brand 页形态:多命名板,板尾常驻加号,hex 一等,至少留一板);
- **模板库抽屉**=GoodNotes 纸库三层结构:**变体维度外置为筛选器**(纸色/尺寸/方向在网格上方,一模板一格⛔组合爆炸)+用途分组+缩略即真预览;
- **部件抽屉**=Notion Layout 面板心智:短下拉+开关+三档单选,改动即时上纸,**档位化⛔自由数值**(Card size 只给 S/M/L 的教训);
- **贴纸抽屉**=GoodNotes Elements:工具级入口(与笔平级⛔埋设置页);集合制;**双插入手势**(tap=默认位落纸,拖=精确落点);**内容回流闭环**(纸上圈选→「存为贴纸」入集合——纸面产物一手势变可复用资产)。
