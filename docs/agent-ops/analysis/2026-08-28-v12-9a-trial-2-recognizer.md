## 1. 考卷(⭐ 本场的战场是「退化」,所以必须造对照)

**页源**:第 1 场同四卷官方样题(`D:/Coinsides/v12.9-selection/samples/`)。

**每页出两版,构成受控对照**:
| 版本 | 造法 | 作用 |
|---|---|---|
| **N · 原生页** | 200 dpi 直接渲染,⛔ 无退化 | **上界**:选手在干净图上的能力 |
| **S · 伪扫描页** | 150 dpi → 灰度 → **旋转 ±0.6°** → 高斯噪声 → JPEG q=72 | 战场:**退化对能力的削减量** |

⚠️ **「伪扫描」的已知局限,先写下来免得事后当成结论**:合成退化**不等于**真实拍摄/扫描件(无镜头畸变、无阴影、无折痕、无非均匀光照)。
⇒ **本场量的是「退化敏感度」,⛔ 不是「真实扫描件上的绝对表现」**。真件抽检是**后续独立事项**,本场不冒充。
📌 **合成的唯一好处也要说清**:N 版与 S 版**同一页**,且第 1 场已有该页的转写产物 ⇒ **有 ground truth**,准确率**可被量出**而不是目测。

**选页**(8 页,覆盖多题型;⛔ 不挑「好认的」):见 §4 实测表。

## 2. ⭐ 考题(两道,冻结)

### 题 1 · 题型识别(结构化产出)
给一页图,要求输出 **严格 JSON**:
```json
{"page_kind":"...", "tasks":[{"task_type":"...","question_numbers":"...","instruction":"..."}]}
```
`task_type` 从**闭集**选(⛔ 不许自由发挥):`matching_headings` / `true_false_notgiven` / `yes_no_notgiven` / `multiple_choice` / `gap_fill` / `table_completion` / `short_answer` / `essay_task` / `sample_answer` / `examiner_comment` / `toc` / `other`。

### 题 2 · ⭐ 出处携带(本场的真考题)
**每个 task 必须带 `bbox`**,归一化到 `[0,1000]` 的 `[x0,y0,x1,y1]`(左上原点)。
**判定方式与第 1 场同法 —— 独立裁剪回验**:把 bbox 换算回**原 PDF 坐标**,用 `pypdfium2`(**独立提取器**)裁原件取文本,检查模型给的 `instruction` 前 30 字是否命中(严格 / 归一两轮)。
⭐ **答对题型但指不到位置 = 题 2 不得分。** 理由:**碎片流要的是「可回到原件的答案」,不是「听起来对的答案」。**

## 3. ⭐ 打分口径(冻结于实跑之前)

| 维 | 2 分 | 1 分 | 0 分 |
|---|---|---|---|
| **F · 题型识别准确** | 闭集内选对且题号范围对 | 题型对、题号范围错/缺 | 题型错 |
| **G · 出处可回验**⭐ | 裁剪回验**命中** | bbox 存在但**指错位置** | **不给 bbox** 或格式不合 |
| **H · 格式服从** | 严格 JSON 一次过 | 需容错解析(带 markdown 围栏等) | 解析不出 |
| **I · 退化韧性** | S 版得分 **≥** N 版的 90% | 50%–90% | < 50% |
| **J · 文本侧结构化**(DeepSeek 档) | 碎片→结构化**且带回原碎片 `seq`** | 结构化但**丢来源** | 结构化失败 |

⚠️ **两条防自欺**:
1. ⛔ **空对空不算数** —— 某页若本就无可识别题型(如纯封面),该页 **F/G 记 N/A 不记 0**。
2. ⭐ **N 版与 S 版必须同 prompt、同参数、同解析器**;**⛔ 不许给 S 版加提示词补偿** —— 那量的就不是退化韧性了。
