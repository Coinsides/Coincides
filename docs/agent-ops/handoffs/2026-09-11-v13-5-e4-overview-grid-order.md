# E4 · Overview 多页网格

## 零 · 裁定原文

1. **真内容,非缩略卡**:每页=真实页面内容按比例缩放渲染(打印投影 fragment 管线现物,换排布),⛔截图/⛔简化占位;
2. **Word 感,空间用满**:多列网格铺满整个视口,页间距紧凑;列数随视口宽自适应(宽屏 3-4 列,窄屏 1-2 列);页多时纵向滚动,⛔一屏一页翻屏式(现"Previous/Next screen"翻屏废除);
3. **页脚页码**:每页下方页号(沿 Word 惯例小字居中);当前阅读页高亮描边;
4. **点击回读**:点任一页→关闭 Overview 并滚动到该页(现役语义保留);
5. 安静气质:去现版的标题区/说明文案大块头,顶部一行轻标题即可(或纯网格+Esc 退出),空间还给页面。

## 一 · 交付面

- 现"Page overview/Select a page…/Pages 1-1 of 1/Previous·Next screen"整套 chrome 清算:保留退出钮(右上 X 或 Esc),其余收敛;
- 页渲染复用 NoteReadOnlyPageContent/打印投影管线(E2 申报:该管线现不含标注章/高亮——维持现状,⛔本单扩);
- 性能:页数多时可视区外惰性渲染(申报策略),⛔一次性全量渲染大笔记卡死。
