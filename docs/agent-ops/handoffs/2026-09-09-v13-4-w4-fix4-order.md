### 实现与裁量

- G1：Ctrl（兼容 Meta）/Shift 点选共用 toggle；Ctrl/Shift 框选从手势开始的 Set 累加；Alt 框选从同一快照减选，框缩回时恢复未再覆盖的对象；Alt 点选减选一并实现。无修饰键新框替换选区。Esc 在板面与清单按钮焦点下均清空，进行中 marquee 同时终止，后续 pointermove/up 不重建选区。提示行同步。
- G2：`N selected` 旁新增 Selection list 按钮；右栏 **280px，与 Staging 互斥**，所有打开 Staging 的路径均收起清单。Cards（note/CG/item/range）、Chalk、Strokes、Connections 分组，逐行/整组 × 只剔除 selection keys。既有 shape/image/table 归额外 **Objects** 组，既有搬入 connector 归 Connections，避免选区内旧对象漏列。空选区时已打开的清单显示空态。
- 名称：卡标题/摘要、range excerpt、粉笔文本；笔画为 `Stroke n`，按全板 `created_at` 排序，同时间以 id 定序，层隐藏/选区加减/z 顺序不影响编号；删除后按当前存量重新计数。无微缩略图。
- G3：清单 pointer/focus → 对应板对象描边强调；板面悬停已选对象 → 清单行强调并仅滚动清单容器。板面悬停优先于残留键盘焦点，保持单笔强调。行点击只移动/适当缩放视口并短暂闪烁对象，不改选区；尊重 reduced-motion。清单关闭、剔除、换板均清理相关状态。
- 群拖、群删、Move to layer 继续消费原有 `selectedKeys`，无第二套选区，无命令栈改造。独立复查发现清单 z-index 会遮挡笔记弹窗，已在打开笔记时收起清单，并补回归验证原选区保持。
