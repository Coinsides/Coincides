# 走查修四 · 选区精修批

**定性**:选区清单=选区收据的可视化(V14 注意力框 UI 前身);本单只做人面,⛔ Agent 面(占位都不留)。

## G1 · 修饰键家族

- **Ctrl+框选=累加 marquee**(保持已选,继续框别处);**Ctrl+点选=加/减 toggle**(与既有 Shift 点选同义,双键都认);
- **Alt+框选=减选 marquee**(圈掉一片);Alt+点选=减(可选,便宜则做);
- 无修饰键行为不变(新框=替换选区);Esc 清空选区(若缺则补);
- 工具条提示行文案同步更新。

## G2 · 选区清单侧栏

- selectionBar "N selected" 旁挂按钮唤出**右侧窄栏**(与 Staging 同族形制/宽度;两栏并存时纵向堆叠或互斥按现物裁量,申报即可);
- **按类型分组**:卡(note/CG/item/range)/粉笔/笔画/连线;组头显类型名+计数;
- 行=类型图标+名称:卡显标题/摘要截断、粉笔显文本截断、range 显 excerpt 截断、**笔画显 "Stroke n"**(挂载序);⛔ 微缩略图(双向高亮代偿);
- **行尾 ✕ =逐条剔除出选区**(板上同步反高亮);**组头 ✕/chip=整组剔除**;
- 清单实时跟随选区变化(板上加减选即时反映)。

## G3 · 双向高亮

- **清单行 hover→板上对应对象高亮**(描边强调,复用既有选中/hover 样式家族,笔画单笔高亮);
- **板上 pointer 悬停已选对象→清单对应行高亮并滚动入视**;
- 行点击=板面闪烁定位该对象(⛔ 改变选区,点击≠剔除——剔除只走 ✕)。

## 裁量与停线

- 停线举证不改判;与单 4 命令栈/marquee 织合出乱序→停线;
- ⛔ Agent 面/Send to Agent 占位(V14);⛔ 新 event verb;⛔ 动 Staging 语义;
- 群拖/群删/Move to layer 对累加后选区照常生效(它们吃的是同一个 Set)。
