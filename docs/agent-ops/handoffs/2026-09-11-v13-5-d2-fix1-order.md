## HQ 裁定(2026-09-11):F18 销案——HQ 取证仪器伪症

builder 反证成立,采信。HQ 复查三步实锤:①硬重载后"复现"依旧,但 **preventDefault 全局探针零触发**(KeyboardEvent.prototype 打桩,按键期间 count=0)——全应用无任何代码取消该键;②**裸 textarea 对照**(appendChild 注入、与应用零关联)同样 Ctrl+A 无选区、Backspace 无删除——吞键者=HQ 浏览器面板的按键合成层(驱动 JS 监听器但不驱动 Blink 原生编辑命令),非应用;③builder 真 Chrome 原生键盘证据(两字段全选 0-24/替换/原生撤销 6/6)为准。

**F18 撤案,产品零改动,builder 免责。** 教训记档:判"键被吞"前必须先跑**仪器对照**(裸控件同键);合成键位能触发 JS 快捷键(D1 的 ctrl+z 撤销真实生效)但⛔原生编辑命令——两类通路分辨清楚再定性。与"壳 pid≠工作/观察者终点≠被观察者终点"同族:仪器的局限被读成了被测物的缺陷。
