## 2. 核心改法(⭐ 这是本单的裁定,⛔ 不许自行改弦)

把当前的 `PATHLIKE` 正则替换为一个**分类函数**:

```
classifyToken(token) -> 'repo-path' | 'foreign' | 'prose'
```

**判据(⛔ 按此实现,不许凭直觉简化)**:

- **`repo-path`**:token 从仓根归一化后**仍在仓内**(⛔ 未逃逸),**且**满足下列任一:
  ① `git ls-files` 认识它;② 它的**父目录在盘上存在**(⇒ 覆盖"本单将新建的文件");③ 它是 `**` / `*` 形式的 glob 且其固定前缀目录存在。
- **`foreign`**:归一化后**逃出仓根**(`../` 一类),**或**父目录不存在。⇒ 这一类正是**归档条目名 / 外部绝对路径**,⛔ 不得计入允许面,也⛔ 不得判红。
- **`prose`**:其余(普通词句)。

⭐ **为什么这一步同时治好四处边界**:根级 `package.json` git 认识它(治边界三);`.python-version` 父目录存在(治边界四);zip 条目名 `../../x` 逃逸(治边界二);普通词句父目录不存在(不再误吞)。**一个判据,四处同治** —— 这就是「函数化一次做完」的意思。

⚠️ **保留不动**:`ALLOW_HINT` / `DECLARES` / `FORBID_LINE` / `ASSERT_UNCHANGED` / `NPM_CMD` 与「切在 `## Result` 之前」的现有语义**一律不改**。本单只换**路径识别**这一层。

### ⚠️ 本单**不治**第一处边界(说明性引用被算进允许面)—— ⛔ 别以为"四处一次做完"

**现场(就在本单自己身上)**:把本单交给今天的闸,它列出的允许面**含 `docs/agent-ops/current-state/glossary-shape-vs-capability.test.mjs`** —— 那是 §1 里我**引作先例**的一句话,**不是允许触碰的条目**;同时它**漏了根级 `package.json`**。

⇒ **两处边界病根不同,⛔ 不可混为一谈**:
- **边界二/三/四**(`..` 误杀 / 根级假绿 / 连字符扩展名)= **token 识别**层 ⇒ **本单的 `classifyToken` 一次治好**。
- **边界一**(说明性引用被算进允许面)= **段落归属**层 —— 那个 token 被正确识别成了真路径,**错在"它出现在允许面段里"就被当成允许条目**。`classifyToken` 对此**无能为力**。

⇒ **本单⛔ 不治边界一,如实留档**。它需要的是另一种判据(例如:只认列表项行、或要求条目行以路径**开头**),**另立单再议**。
⚠️ **为什么必须写明**:否则收工回执会写成「四处边界一次做完」,而**下一个人会照着这句话相信闸已经不会把引用当允许项** —— 那正是「不可复核的声明比没有更危险」的又一形状。
