# D1 · 可调的墙 + 把手安家

## 零 · 裁定原文(约束一切实施细节)

1. **做墙不做标尺**:代理控件只配给抓不到的东西——控件只给墙(contentInset),⛔任何标尺条/每块标尺 UI;
2. **撞墙约束**:auto 块=长到墙为止,manual 块=自有盒但出不了墙;墙=一切 page_frame_local 块的硬极限;
3. **跟墙走语义,零坐标改写**:page_frame_local 原点=内容区原点,墙动=原点动——全体块存储坐标**不改写**而视觉整体跟随;⛔任何 rebase;唯一例外=墙内收后违反约束的 manual 块,同事务 clamp(只写违例块);
4. **横移语义维持现状**:auto 块横拖压墙变窄(F13 `constrainFrameLocalAutoWidth` 行为),⛔改;
5. **墙 v1=note 级**:一次调整统一写该 note 全部 page frame 的 contentInset(left/right;top/bottom 本单⛔动);
6. 媒体块同受墙 clamp;墨水(freehand)按现契约可越入边距区,⛔动。

## 一 · 交付面

### 1. 墙的直接操纵

- 纸面(page 模式)上,鼠标靠近左/右边距线时线显影(hover 显影,与"安静纸"三态同气质:平时零可见),可独立拖动;拖动中实时预览(auto 块宽度随动重排);
- 松手=提交:写该 note **全部** page frame 的 `contentInset.left/right`(持久化现物:`page_frame_extensions.content_inset_json`;写门走既有 frame 更新路由——若现役路由不收 inset 字段,在**既有人类路由**上最小扩面,⛔新开专用路由);
- 夹取:每侧 inset ∈ [24, 240] 且内容区宽(span)≥ 320;新建页继承 note 现行 inset(勘察显示新帧从 preset 取默认——改为优先取 note 现役帧的 inset,无帧才回落 preset);
- 参考线现物 `pageFrameGuideService` 的 left_margin/right_margin 从 inset 派生,应自动跟随——验证,若有硬编码假设一并修。

### 2. 同事务 clamp(唯一写坐标的场合)

- 提交墙调整时,对 page_frame_local 且 width_mode=manual 的块检查:`x + width > span'` 则 clamp x(`x = max(0, span' - width)`),仍超则 clamp width(`width = span'`);auto 块零写(宽度本就派生);
- clamp 与 inset 写入同一保存批次,撤销时一并恢复(见 §3);
- ⛔动 `isCanvasWorkspaceBlock`/退役闸的判定**语义**——但其消费的内容区宽必须与新 span 一致取值,逐处核对并在 Result 申报核对清单。

### 3. 撤销

- 墙调整作为一条撤销条目进**既有纸面撤销栈**(与块位移同栈;实施时申报接的是哪套机器);undo=恢复旧 inset+被 clamp 块的旧 layout,redo 对称;
- 机械闸法源:撤销覆盖不到的操作将来 Agent 不许有——本条不可裁剪。

### 4. 760 常量解耦(auto 宽长到墙)

- `constrainFrameLocalAutoWidth`(placementService.ts:357-373)及 auto 宽四处复用点(placementService.ts:465/:495、pageFrameService.ts:29、placementContractService.ts:316,勘察在案)中,`DEFAULT_PAGE_CONTENT_WIDTH` 封顶改为**逐帧派生**(`frame.width - inset.left - inset.right`),帧不可解析时才回落常量(workspace/tray/v1 兜底路径维持现状);
- 验收点:墙拓宽后 auto 块能长过 760 直到新墙;墙内收后 auto 块随收。F13 既有测试(placementAutoWidth.test.ts、autoWidthFrameSave.test.tsx)全数保绿并按新语义扩例(拓宽/内收两向)。

### 5. 把手安家(边距车道)

- 文本单元把手(`TextUnitGutterLayer` 按钮)移入左边距车道:块框外、纸内,不与块边框重叠不超块框;尺寸缩小(Henry 09-11 点名);
- 显隐三态维持现役(不点=安静、hover=现、选中=现),⛔加噪;拖拽/菜单行为零变。
