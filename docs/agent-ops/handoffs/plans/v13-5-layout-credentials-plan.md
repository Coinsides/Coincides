### 专场补遗(09-11):水平标尺三账题(议程 1/6 与 B1 的联动材料)

Henry 09-11 提出(B/C 波真机验收通过后):块默认铺满文字区+全局水平标尺(左右"钢线")+每块自有缩进标尺。三路勘察(workflow `ruler-groundwork-survey`)证实**三账地基全部现成**:①页账=`PageFrameModel.contentInset` 已逐帧持久化(`page_frame_extensions.content_inset_json`,A4 preset 760+72×2);②块账=`width_mode: auto|manual` 即绑定态(auto 每渲染重算≈铺满,manual 保存储宽);③行账=`TextUnit.indent_level` 已全线打通(Tab/Shift+Tab,0-6,契约 §2 冻结)。参考线雏形已在(`pageFrameGuideService` 的 left_margin/right_margin/center_line 吸附墙,显示-only)。

**Henry 已拍(09-11 对谈两轮)**:

1. **做墙不做标尺**——设计定律:代理控件只配给抓不到的东西;块与行缩进皆可直接操纵(拖盒/改宽/Tab 缩进),唯墙(contentInset)不可抓,故控件只给墙。每块标尺案**废**;随之知情放弃:绑定块内连续缩进(逃生口=脱绑拽盒边)与段首缩进(现代块编辑通行取舍,段间距替代);
2. **"默认铺满"降格为"撞墙约束"**——不引入绑定新概念:auto 块=长到墙为止,manual 块=自有盒但出不了墙;墙=一切块的硬极限。

**对谈中(HQ 已给解,候 Henry 认)**:

3. **墙移语义=跟墙走,零坐标改写**:page_frame_local 原点=内容区原点,墙动=原点动——全体块存储坐标不变而视觉整体跟随,贴左墙者贴着新墙,auto 块宽度现算自动改物理大小;前一稿的"坐标地雷+rebase 案"在此语义下**翻案为免费机制,撤案**;唯一例外=墙内收时侵越右墙的 manual 块,同事务 clamp(只写违例块,可撤销);
4. **横移语义维持现状**:auto 块横拖压墙变窄(F13 行为被墙模型追认为语义正确),"脱绑保宽"撤案降为候真实使用反馈的备选补丁;
5. 墙 v1=note 级设置统一写全帧 contentInset(拖墙线直接操纵+设置数值框),B1 铸版升版面模板 token(留英手册自带边距即此);媒体块不入铺满、同受墙 clamp;墨水按现契约可越入边距区(纸边写画,不动)。

工程件(随裁随排):`DEFAULT_PAGE_CONTENT_WIDTH`(760)封顶改逐帧派生(否则墙拓宽后 auto 块长不到墙);右墙 clamp;墙操作入撤销栈;把手安家边距车道(把手超框正解,⛔孤立微调);page_frame_local 契约权威散在 handoff/recon,随此题**补铸版**。
