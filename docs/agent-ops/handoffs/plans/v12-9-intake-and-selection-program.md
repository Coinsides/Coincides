# V12.9 入库体系与选品纲领

## §1 骨架(定案)

- **窄腰**:钉死产物标准(**带锚碎片流**:文本+结构角色+锚+顺序;markdown/渲染=读时投影),永不钉工具。
- **五锚族**:①页面族(页+区域)②流式结构族(路径+偏移)③表格族(表+单元格)④幻灯族(页+形状)⑤时间轴族(时间戳)——新格式一律按「回程票长什么样」归族。
- **底层载体 × 产品方言**:载体处理器重投资先建;方言(Obsidian/Notion/Anki/ChatGPT 导出)=容器+载体+私有约定,各配薄适配片(保语义角色),按需添。
- **入库永不拒收**:散沙层收字节;处理器只决定「能否拓印」。两兜底:文本兜底(未知后缀内容可判文本⇒纯文本收,行锚——代码后缀不枚举,自动覆盖);二进制兜底(只存不拓,等处理器)。
- **有数据不取渲染**:导出包内数据(JSON/SQLite/XML)与查看器 HTML 并存时,取数据。
- **拓印时机**:征用时,非入库时;拓印件带出生证(谁拓/版本/锚粒度),可重拓可对比。

## §6 第三场定案(2026-08-28 晚,Fable 裁;证据 `analysis/2026-08-28-v12-9a-trial-3-embedding.md`)

1. **嵌入选型推迟,非失败**:n=8 分不出高下(BGE-M3 与 voyage-4 同分)。**12.9d 施工用 BGE-M3 作默认工作假设**(免费本地、跨语实证同水平);Voyage 接线维持现状。**终选标准=≥50 组标注检索集,而标注集不人工造——V13 真实使用的检索采纳收据就是标注对**(grow-by-use 第五应用面)。
2. **检索层定为两段式(入宪)**:召回(最近邻,机器猜想)+ 判定(回真相层/交人/交强模型)——中位 margin 全负的实测 + 第 2 场「引用制」从两个方向撞出同一条:**最近邻永不直接当答案**。
3. **中英混排不分表不分模型**(跨语零损失实证,单变量证据)。
4. **向量存储钉 sqlite-vec**(T 维实证:与 better-sqlite3 同进程同连接全通,阳性对照归因);装进 server 为独立一单;两条使用约束(BigInt rowid / LIMIT 落 MATCH 层+CTE 再 JOIN)进施工单材料。
5. voyage.ts 代码默认与 env 不一致(voyage-3 vs voyage-4)——台账一行,落点 12.9d 接入单顺带。
