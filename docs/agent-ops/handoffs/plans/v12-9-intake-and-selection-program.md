# V12.9 入库体系与选品纲领

## §1 骨架(定案)

- **窄腰**:钉死产物标准(**带锚碎片流**:文本+结构角色+锚+顺序;markdown/渲染=读时投影),永不钉工具。
- **五锚族**:①页面族(页+区域)②流式结构族(路径+偏移)③表格族(表+单元格)④幻灯族(页+形状)⑤时间轴族(时间戳)——新格式一律按「回程票长什么样」归族。
- **底层载体 × 产品方言**:载体处理器重投资先建;方言(Obsidian/Notion/Anki/ChatGPT 导出)=容器+载体+私有约定,各配薄适配片(保语义角色),按需添。
- **入库永不拒收**:散沙层收字节;处理器只决定「能否拓印」。两兜底:文本兜底(未知后缀内容可判文本⇒纯文本收,行锚——代码后缀不枚举,自动覆盖);二进制兜底(只存不拓,等处理器)。
- **有数据不取渲染**:导出包内数据(JSON/SQLite/XML)与查看器 HTML 并存时,取数据。
- **拓印时机**:征用时,非入库时;拓印件带出生证(谁拓/版本/锚粒度),可重拓可对比。
