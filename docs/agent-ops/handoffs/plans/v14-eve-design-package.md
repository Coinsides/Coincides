## 一 · Mr Zero 壳规格 v1(14.5 实装,形状先立)

1. **形态**:Agent-first Home 大按钮+悬浮对话窗+任务队列栏+通知徽标(停车场 C 原案);**在场徽章**=Mr Zero 正在哪张纸/板干活,该文档标签亮(工作台标签条种子,与 Tauri 壳同批);

4. **对话锚**:纸上入口=侧桌投影区(谈判桌,§五)——圈选即议题,议题即语境。

## 四 · 宪法立法文本(转正时铸进 current-state 不变式档)

1. **四条永久禁区**:判断域只可 propose/不可逆删除永不给/用户文字永不无痕直写/永不模拟 UI 键鼠;
2. **机械闸**:人类撤销栈覆盖不到的操作,Agent 工具面不注册——撤销覆盖率=写权边界,机器可验;
3. **三不变量**(09-13 §十二,并入宪法):Agent 动人的东西,**可见/可拒/可退**任何 domain 全真——不缩放;
4. **仪式四档**(执行学,随 domain 缩放):改自己造的=直落整批可撤/润色一行=行内修订痕/改一块几块=就地 diff 分票/整篇批量=侧桌投影区分票;"直写"定义=**无痕静默替换**(唯一被禁形态);
5. **domain 解释学**:违宪之争先问三不变量、再挑仪式档,⛔逐案立新法。

## 五 · Proposal 体系总成(09-13 §十/§十一定稿,与 14.1 提案族对齐)

- **路由八字:有址在场,无址上桌**;
