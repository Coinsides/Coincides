## 北极星二号(成品面验收,Henry 09-09 口述)

**留英手册完整收录**:手册=一个 project,肉是纸(章),骨是板(装订/全貌),皮是版面;验收三级——
1. **静态收录**(13.5-13.6 射程):图/表以媒体块型复活进纸+版面模板+样式 token,章章成纸、封面成设计页、板作目录;
2. **按钮可动不失其功**(V14 中段):**组件块=块类型第四族**(text/投影/媒体之外;按"行为独异才配当块型"判据,交互组件满分过关——但块终局档类型表已冻结为三族,**此处需专场修宪追加第四族**)+内置件库先行(按钮/跳转卡/导航件,手工闭集⛔等产房);位置=布局账、功能=晚绑定实参账(产房章程 §1 三段律),分离即"可动不失其功";
3. **人机共造新件**(V14 尾/V15,产房落地):五站流水线+注意力框需求表达(13.4 选区清单=其 UI 前身)+OpenDesign 出皮+改骨骼提案流(手册的"七连点隐藏门"即闭集外行为的第一提案样本)。
**⛔ Figma 化红线(Henry 09-09 对谈拍向)**:板上永不编辑文字/内容永远长在纸上——组件块住纸,板只挂投影;设计感归纸的版面线,板的成熟方向=展览墙(阅读态/章节序/封面感)。

## 宪法四条(永久禁区,转正时铸进 current-state 不变式)

①**判断域永不给 Agent**——relation 的 confirm/reaffirm/revoke 与判断注只可 propose(出处保护:判断的全部价值在"这是 Henry 判断过的");②**不可逆删除永不给**(删板/删笔记/清回收站);③**用户文字永不直写**——只走差异预览提案(note_patch);④**永不模拟 UI 键鼠**——只走工具面(同门=路由的门,不是像素的门)。
**机械闸**:任何对象域,人类撤销栈覆盖不到的操作,Agent 工具不注册——撤销覆盖率=写权边界,机器可验⛔靠自觉。
