# V14 · Agent 时代 —— 总 plan 草稿 v0

**版本使命**:Mr Zero 出生——Agent 从学习规划半区走进知识工作台(笔记/板/内容组),**同门同钥**:与人共用同一套动词、同一道校验、同一种收据、同一根撤销栈。
**哲学总纲**(Henry 09-09 定位):本软件是**思考的延伸不是思考的替代**——Agent 是伙计不是神谕;判断永远归人。

## 北极星二号(成品面验收,Henry 09-09 口述)

**留英手册完整收录**:手册=一个 project,肉是纸(章),骨是板(装订/全貌),皮是版面;验收三级——
1. **静态收录**(13.5-13.6 射程):图/表以媒体块型复活进纸+版面模板+样式 token,章章成纸、封面成设计页、板作目录;
2. **按钮可动不失其功**(V14 中段):**组件块=块类型第四族**(text/投影/媒体之外;按"行为独异才配当块型"判据,交互组件满分过关——但块终局档类型表已冻结为三族,**此处需专场修宪追加第四族**)+内置件库先行(按钮/跳转卡/导航件,手工闭集⛔等产房);位置=布局账、功能=晚绑定实参账(产房章程 §1 三段律),分离即"可动不失其功";
3. **人机共造新件**(V14 尾/V15,产房落地):五站流水线+注意力框需求表达(13.4 选区清单=其 UI 前身)+OpenDesign 出皮+改骨骼提案流(手册的"七连点隐藏门"即闭集外行为的第一提案样本)。
**⛔ Figma 化红线(Henry 09-09 对谈拍向)**:板上永不编辑文字/内容永远长在纸上——组件块住纸,板只挂投影;设计感归纸的版面线,板的成熟方向=展览墙(阅读态/章节序/封面感)。

## 宪法四条(永久禁区,转正时铸进 current-state 不变式)

①**判断域永不给 Agent**——relation 的 confirm/reaffirm/revoke 与判断注只可 propose(出处保护:判断的全部价值在"这是 Henry 判断过的");②**不可逆删除永不给**(删板/删笔记/清回收站);③**用户文字永不直写**——只走差异预览提案(note_patch);④**永不模拟 UI 键鼠**——只走工具面(同门=路由的门,不是像素的门)。
**机械闸**:任何对象域,人类撤销栈覆盖不到的操作,Agent 工具不注册——撤销覆盖率=写权边界,机器可验⛔靠自觉。

## 记忆架构(Henry 09-10 点名补缺;设计章程并进 14.0 前夜包,⛔新段号)

**缺口自认**:agent_memories=语义碎片抽取,非对话记忆体系;"同一对话窗钻一年 project"场景无解——上下文塞爆即失忆。

**四层架构(草案,横切 14.2/14.5 实装)**:①场上层(活跃窗口+token 预算管理,现缺预算);②**情节层(真窟窿)**:对话滚动压缩成情节摘要,旧情节层级递压(日→周→阶段),锚点(资产 id/收据)原文保留⛔随压丢失;③语义层(agent_memories 现物,A1 人面已齐);④资产层(知识库本体+12.9d 检索)——**灵魂层**:长期项目记忆的正确形态=沉淀成一等公民资产,对话只留摘要+回锚;召回靠检索唤醒(Henry 奇点模型:唤醒优于常驻;二月 MU 框架与 07-09"沉淀成资产"宣言同源)。

**三裁定(候前夜包拍)**:1. **原始对话 append-only 全量留存,压缩=视图⛔销毁**(台账定律;唯一需 V14 开工前立的法——保证记忆工程晚到不丢料);2. 沉淀优先(资产>语义>情节);3. 唤醒优于常驻(检索召回⛔塞上下文)。

**分工**:orchestrator(Mr Zero 主对话)持全四层;工人 agent 无连续记忆(有活干活,Henry 裁)。实装节拍:检索随 12.9d,情节压缩随 14.5 壳;设计=前夜包,⛔加重 14 前中段。

**"能用版"具体形态(Henry 09-10 对谈收敛;参照 Fable harness 现役解剖)**:管家不背图书馆,管家带地图——
1. **常驻包**(每轮 system prompt 组装,全是薄索引⛔正文):宪法身份 + 工作语境地图(当前 project 的骨架:笔记题名/板名/item 计数,读侧现拼) + agent_memories 一行式索引 + 本对话最近 K 条情节摘要;
2. **找回=V14.2 知觉工具族本身**(零新发明):read_note/read_board/search_memories(现物)/12.9d 检索——回忆=读自己的知识库,上下文丢了无所谓,东西都在系统里且带出处;
3. **情节层 v1(唯一新造件)**:对话消息 append-only(台账法);token 看门狗过阈→最老一段压成 episode 行(摘要文本+时间范围+**锚点清单**:触及的 note/item/proposal id 原文保留⛔随压丢失);prompt 带最近 K 条,更老的 episode 可被检索工具搜到;即 Fable compaction 的朴素版;
4. **沉淀笔**:值得留的产出⛔进记忆,走交付管线(铸 item→装卸区)——知识出口到产品,记忆系统保持薄;
5. **人面对称**:episodes 与 agent_memories 同权可查改删(A4b 独立页将来加 Episodes 页签)。
**造价**:episode 表+看门狗+prompt 组装器,一张中单;其余全是现物或 14.2 已排。质量上限未知(Henry:能用即可,好用靠真实使用迭代⛔预设标准)。
