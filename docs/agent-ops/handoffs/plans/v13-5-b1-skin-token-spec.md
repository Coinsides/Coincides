# B1 · 皮 Token 表设计稿

## 一 · 纪律(铸进实装)

1. **给 token 不给 CSS**:用户与 Agent 的改装面=下表 token 与部件层枚举,⛔自由样式注入;
2. **挂点三级**:全局默认 → project 皮 → 单张纸/板覆写;下层缺省即继承上层;
3. **预设=一组 token 的命名快照**:暖纸/静墨/工作台三出厂预设一键切;用户微调=在预设基础上逐 token 覆写;
4. **打印/导出跟皮**(纸 token 决定打印呈现;暖纸案纸恒浅天然打印友好);
5. **Agent 改装面**(V14 接线,本单只留形状):Agent 改皮走与人同一路由;整组预设提案→人预览采纳;皮域=错改零内容损失域,undo 全覆盖(机械闸)。

## 四 · 部件层(有限枚举开关,⛔自由定制)

| 开关 | 选项 | 各预设默认 |
|---|---|---|
| 标题字 | 无衬线 / 衬线 | 静墨:无衬线细体;暖纸:衬线;工作台:无衬线重体 |
| 标签/刻度字 | 系统 / 等宽 | 静墨/暖纸:系统;工作台:等宽 |
| 菜单密度 | 舒适 / 紧凑 | 静墨/暖纸:舒适;工作台:紧凑 |
| 把手样式 | 胶囊 / 铆钉 | 静墨/暖纸:胶囊;工作台:铆钉 |

## 五 · 持久化形状(B1 工单细化)

- 全局:用户 settings 记 `skin: {preset, overrides?}`;project 记同形可空;纸/板记同形可空(挂 note/board 记录或既有 metadata,B1 勘定);
- 渲染=三级合并后注入 CSS 变量(`--sk-paper` 等),组件只消费变量;
- Typography(Font/Size/Line/Spacing 现役四参)保持独立不并入 token(它是文档属性不是皮)。

## 六 · 纸型预设(B1 同单)

A4(现役)/Letter/**Web 长页**(定宽不限长不分页)+ 建纸时选型;墙(contentInset)默认值随纸型,建后可调(D1 现役)。

## 七 · 补记(09-11,B1a 停线裁定)

预设为**四个**:「默认」(现役色忠实收敛,rollout 缺省,零视觉变化承诺的承担者;值由 B1a 实装时从现 CSS 逐面盘点)+ 静墨(§二原值=打样精修版,可选)+ 暖纸 + 工作台。静墨是否升任缺省,候 Henry 眼验后 13.6 品控另裁。字体类开关(§四部件层)随 B1b 生效,B1a 各预设一律系统字。

## 八 · 材质细则(09-11 Henry 真机反馈追样;预设内部参数⛔新用户 token)

Henry 真机切暖纸后裁:实机与打样气质有差(比例/墙存在感/纸外空间),按 HQ 审美追样。细则:

### 表头比例(跨皮统一,取打样 A 案比例)

纸顶 padding 56px → 标题(衬线皮 36px/1.2/600/字距 .01em;无衬线皮 34px/650)→ 间距 10px → description 13px 弱字 → 间距 12px → 元数据行 → 间距 28px → 正文起。表头带上限相应收敛;⛔再留大段死空(首块存量 y 间隙归 V14 分页,⛔本单动坐标)。

### 墙的常显度(皮级参数 --sk-wall-idle)

默认/静墨:0(现役 hover 显影不变);**暖纸:常显 0.55**(#D8CFBC 1px,顶部 72px 渐入——打样 a-margin 原样);**工作台:常显 1**(#33507A+刻度,B1b 已铺的语汇)。hover/拖动态一律现役。

### 暖纸材质(取打样 A 案原值)

- 桌面:radial-gradient(90% 72% at 50% 10%, #2B2520 0%, #211D19 46%, #1D1A17 78%)(台灯光晕);
- 纸:linear-gradient(#F9F5ED 0%, #F7F3EA 34%, #F5F0E5 100%);
- 纸影:0 22px 54px rgba(8,6,4,.55), 0 5px 16px rgba(8,6,4,.35), inset 0 1px 0 rgba(255,255,255,.55);
- **"本儿"感(边距区,克制)**:①纸左缘 10px 装订渐影(linear 向右淡出,rgba(8,6,4,.10→0));②左墙线换**笔记本红线**(#C26D5A @ 45%),右墙保持铅笔灰——真横格本语法;⛔纹理⛔打孔⛔任何噪音件。

### 工作台材质(取打样 C 案)

桌面网格(24px,#1B2028)+纸描边 #2A313C——B1b 未铺满处补齐。

### 静墨/默认

零材质加装(安静即气质)。
