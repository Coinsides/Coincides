# 笔记页设计文档

## 〇 · 总纲:三条公理

1. **每页结构同构**:页的骨架七层逐位相同;一切"这页不一样"都是骨架的枚举档位(封面档/异形页参数),⛔自由例外。恒定件声明在更高作用域(笔记级/装订段级),页只是投影目标,不是存储单元;
2. **树是内容,页是容器**:树(树干=笔记,枝=章,叶=块)零页概念;页零树存储;分页引擎把树灌进页序列,两边只靠三根线相连——版心(树的一段流过)、装订段(页眉页码设置)、计数器(显示页码)。重新分页=重算,树上零改写(与墙"视觉动,坐标不动"同法);
3. **页上之物三类**:恒定件(骨架,每页逐位相同)/字段件(槽恒定,值由结构自动供给,如页码计数器)/流动件(树的内容)。另有装饰层(皮)贯穿而不占结构。结构槽位必须进数据模型(Cornell 教训:纯视觉槽位零语义——不可锚定/检索/Agent 读)。

### 1.2 树:章节结构

- **标题=单行 heading 块**(存储仍 unit writing_role,零新块型;"标题块"=惯用形态);打 `#` 立章即分裂(TF-05 域);
- **章=派生域**:从标题块到下一个同级标题块之间的块序列;⛔实体容器("块属谁章"⛔第二份真相,Word .docx 无章容器为证);**章投影服务**=一等派生对象,UI(导航树/折叠/搬章把手)与 Agent(章级动词=语法糖展开块级四动词)同吃;
- 呈现部件化(编号/折叠箭头/章锚):显示归组件,真相归流;
- **删标题块=章解散**(内容归上一级,零删);拖标题把手=搬整章;⛔视觉容器箱(视觉承诺容器→用户期待容器行为→撞死);
- 树到叶为止,**叶内是水流**(TextFlow)——叶里不再分杈(⛔Notion 式块套块)。
- 出处:会议记录 09-12 §六/§八;块终局方向档(active)。

### 1.3 块与内容:四族+流内结构物

- 类型表冻结四族:**text**(万能纸)/**投影**(item_ref 族)/**媒体**(image/table)/**组件**(修宪记录一,随行法四条);判据="行为独异才配当块型";
- **媒体双形态**(09-13 §八):浮动型=独立媒体块(manual 布局,已落);嵌入型=行内结构物第三客户(formula/code 之后),F2 inline 主单先用 formula 打通,图片行内化随 V14 媒体主单;⛔第二套机制;
- paragraph→block 改名:排正式版命名清扫批。

### 1.4 覆盖性质:四档 × 三族(09-13 §九)

- **呈现态四档**(placement 性质轴,⛔是层):衬底(文字下:印章/水印)/在流(默认)/浮面(文字上,允许遮挡)/钉视口(脱页跟随:variable table/侧桌);
- **公民三族**:内容件(四族块+item:有出处入检索导出必带)/装饰件(印章/贴纸/水印:归外观系统与皮坐一桌,零语义不入检索,库=设计室贴纸抽屉)/装订件(页眉页码,住槽);**族不锁档,档不定族**;
- **护栏**:性质≠籍贯——钉视口者家仍在纸上(placement 不变,呈现态=标志位),幽灵件⛔;
- **覆盖序**:跨档天然序(衬底<在流<浮面,⛔可调);同档内 placement 序数+四动作(上移/下移/置顶/置底),⛔图层面板;
- 组件间接线(摇杆驱动可视化)另账:归 V14 组件线+组件动物园。

### 2.3 装订面(09-13 §九,V14 实装)

- **装订面**=页眉/页码/**封面图(cover 槽)**/折缝——装订阶段后于内容产出,服务气质、非必要、整体可关;
- **封面图=装订件,住第 0 页 cover 槽**(§十三):值=资产引用+按用途取景框参数集(card 框=卡面固定比例/page 框=随纸型);取景框=非破坏裁剪(原图恒存,槽存框参数,照抄社交头像裁剪交互);卡面联动=聚合投影读槽(⛔推断"首个媒体块");与版心分工:槽管门面,版心照常自由摆件;卡面封面 v1=13.6-V14 之交批,page 框随 V14 真封面页;
- **装订段**=页区间+一套装订设置(页眉文案/页码起始与制式/槽位微调/槽样式覆写);设置存笔记级,页零存储,段内每页同位同构;
- **双页码**:机械页码=页帧序号(系统真相永在,⛔用户改)≠显示页码=装订段计数器投影(起始可设;制式:阿拉伯/小写罗马/大写罗马);页码模板槽=`'前缀'+N+'后缀'`(N 不可删);
- **六槽**(眉左中右/脚左中右)+段级微调;样式两级=默认吃皮+槽级覆写(书名槽与章名槽异装天然支持);
- **页眉=纯手填**;自动吸收(mark)**⛔立项**(一页多章即废规则,边际收益极低——Henry 裁);
- 默认档:施工期页眉页码全开;成品默认关(发布前夕 Henry 调);封面档三件套静默。

## 三 · 功能篇

### 3.2 右舷侧桌:Staging 上纸(09-13 §十/§十一,排期候归批)

- **格局**:文档三边——左舷=结构位(导航窗格)/右舷=物流位(Staging/Groups)/顶=身份;
- **推纸动画**开侧桌(IDE 侧栏心智);**非模态**(⛔staging 模式——打开后一切编辑照常);独立滚动(纸滑百页,侧桌跟视口);窄屏退化回抽屉浮层;
- **两区**:**实体区**(来料台:无址交付/剪藏/拼一半;拖入纸=采纳)+**投影区**(谈判桌:回炉签议题+与 Agent 交流锚点);空间即语义,⛔贴签辨认;
- **回炉签**:拖纸上块进侧桌=圈选⛔搬运(placement 零变,侧桌现投影带引线,原块披待返工态);Agent 重做=原地施工;采纳→原地更新,议题消失——批量返工零拖回;真搬运=块菜单显式「移入准备区」(低频走菜单);
- 预拼 v1=排序+多选入纸(⛔merge 搭车);侧桌件带 actor 出生证签(人/Agent 双谱系)。

### 3.3 Proposal 体系(09-13 §十一/§十二)

- **路由八字:有址在场,无址上桌**——用户给位置→变更在场发生;没给→落实体区;
- **三不变量**(恒定,⛔缩放):可见/可拒/可退——任何 domain 里 Agent 动人的东西全真;
- **仪式四档**(按 domain 缩放):Agent 改自己造的=直落整批可撤;润色一行=行内修订痕(Word track changes 形态,勾=接受叉=还原);改一块几块=就地 diff 逐块采纳;整篇/批量=投影区分票;
- **"直写"定义收窄=无痕静默替换**(唯一被永禁);违宪之争先问三不变量再挑仪式档,⛔逐案立新法。
