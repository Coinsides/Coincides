# 闲谈记事簿

**为什么有这本簿**(Henry 2026-11-07):闲谈里聊出的「马上可以做」的东西,实际上没必要当下就做;先记下来,之后一起看遗漏,写版本设计或共同进度设计时再去整理。零散的想法和零散的观察都放这里。有些想法过期得很快(例:「每个文件上传自动建 purpose 卡」),所以要时不时回来看,过期的标掉而不是删掉。

**规矩**
- 一条一行,一两句话说清,带来源和日期。不展开论证;论证在台账或设计稿里,这里只放指针。
- 状态只有五种:**活** / **过期** / **已入设计** / **已派单** / **已做**。过期要写一句为什么。⛔删行。
- **复查触发**:①我动笔写任何设计稿、版本计划、订单之前先扫一遍;②Henry 说「看看遗漏」时逐条过;③闲时至少每周一次,改头部「上次复查」。
- 这里的条目**不是施工依据**。要做的,先过设计稿或订单,再把状态改成「已入设计 / 已派单」并给指针。
