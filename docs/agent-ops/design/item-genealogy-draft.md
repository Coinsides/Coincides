# item 家谱学 + 睡眠学(实验草案 v0)

## 一 · 六条公理

1. **切片有身份**:item=打碎母本(a set of 原始文档)时诞生的、带出处锚(座位)的切片;身份在打碎/拼的瞬间铸成,⛔在投影处铸;
2. **形态是拼法**:引用源/板/笔记/卡组=同一批切片的不同拼法,**平级衍生物**——平级防"复印件的复印件"(各形态保有对母本全清晰度访问权);入口由用户脑内模型所处生命周期决定(施工=板/成形=笔记/维护=卡),顺序可乱;
3. **亲缘出生登记**:凡衍生动作(降采样出同构子代/拼出多亲异构子代)在发生瞬间登记 derived_from 边;⛔事后相似度 DNA 鉴定。同构族=一个知识点的 **mipmap 分辨率阶梯**;检索返回族⛔返回散层,Agent 按任务选层;
4. **草稿是边数据**:衍生过程的取舍记录(含"考虑过未采用")=家谱边上的元数据,保存⛔蒸发——再衍生的配方+采样策略先例;
5. **卡片是探针层**:卡=item 的考官脸(正反面=面向检索练习的穿着);卡组=家谱树上现成的探针层;可被板/笔记引用(item 既有机制继承:锚/花瓣/快照/退役/投影);复习成绩=挂在知识族上的**清晰度回传**(哪块糊了系统知道);卡面亲笔措辞=人的字;
6. **睡眠**:系统需要写时/息时整合⛔读时整合——离线过程沿家谱选举/维护每族顶层代表(融合记忆=多亲合成 item),低层**沉降**出默认检索面(降权冷藏⛔删除)。铁则:**硬盘不忘,注意力忘**;带收据的遗忘(留原件+锚)使 schema 扭曲可审计——这是系统对大脑的超越点。FSRS 衰减模型反用作系统记忆的衰减调度候选。

## 二 · 卡片=item 的直接推论(Henry 拍方向)

- 卡入 item 族后:板引用卡=考试面空间化(采样空洞/aliasing 风险区在板上可见);笔记引用卡=item_ref 既有语义;答错跳原文=沿阶梯下潜,零新机制;
- 去重永远是错误答案,归档(收拢入族)是正确答案;
- Agent 建卡=替用户选采样策略,应按信息密度切;建卡提案=提案体系流量最大型(小、可拒、逐张收)。

## 三 · 工程落点(全部候拍,⛔本草案自带排期)

1. **最小版血缘登记**(可近期搭车):Agent 衍生路径(建卡提案/organized_note/未来 note_patch)在收据/对象上带 parent item 引用——写门收据机制现成,增量小;
2. **卡片筒仓 item 化**(数据改革,V15 候拍):card_decks/cards 并入 item 世界或建桥;复习状态挂探针面;
3. **睡眠机关**(V15+/实验):离线整合任务+族顶层选举+默认检索面分层;先在 Agent 记忆域小规模试(agent_memories 本就是 Henry #6 裁过真删的自域,试错成本最低);
4. 检索面(imprint/embedding)按族聚合返回——干扰治理的兑现点。
