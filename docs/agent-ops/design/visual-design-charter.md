# 视觉设计宪章(草案)

## 第一条 · 插座制

产品在设计域的交付物是**插座系统(接口)**,不是目录(库存)。元素集永远开放、永远追不完,也不必追;库存从使用中长出,接口是资产。图鉴 99 件的身份=同一设计系统的 99 个插座实例,不是 99 个设计,更不是天花板。

## 第二条 · 好看二分律

平民版「好看」=**码本自洽 + 编码忠实**:视觉差异与语义差异一一对应。

- **自洽(不违和)**:承诺一个系统并忠于它;罪不在选哪个系统,在混系统。审美区间宽——暖冷黑白皆可过线,只要成套。
- **忠实(讲清楚)**:每种视觉差异承载一种语义差异,一眼可辨。
- 两种故障、同一条法:**噪声**=有视觉差异无语义;**吞没**=有语义无视觉差异(如被吞的表格)。

## 第三条 · 气质三元

气质 = **引用 × 克制 × 一处署了名的偏离**。

1. **引用**:设计在引用一个物质/体裁世界(刻板印象共鸣);刻板印象分两层——**物理层**(老化/纹理,全球稳定)与**约定层**(圆角=科技,代际时尚会漂移),引用声明须记明引的是哪部词典;
2. **克制**:引用执行得有纪律才可信,处处引用=没有引用;
3. **署名偏离**:一处不可能来自平均值的、贯彻始终的故意反常(例:绢本手册里的现代答卡)。仅有前两项=得体(体裁平均值);第三项给出出彩。偏离**不可预制**(量产的签名=刻板印象),只能现场发生;可预备的是它的舞台(见第六条)。
4. 气质是**低频信号**:住在眯眼可见的页面统计量里(纸色/留白/密度/对比节奏),不住在单个元素里。

## 第四条 · 血统法(出生公约)

凡新元素——无论产房出品、OpenDesign 进货、G6 管线产出、还是人手工造——**出生即参数化于系统**:

- 色只从 token 取;字体只按角色取(titleFont/labelFont);间距走节奏刻度;圆角/发丝走系统常量;
- ⛔字面 hex;⛔硬编码字体;⛔私有间距;
- **导入闸查的就是血统**(09-16 已拍导入闸的精确检查单):过闸者上纸自动本地化,更新流再大不稀释气质;
- 该提前准备的不是元素,是**基材+法**:纸面材质、基础字体对、token 架构、本公约。
- 气质由此**逐件遗传**而非逐件设计——新器官穿 token 即穿气质(实证:答卡入绢本零违和)。

## 第五条 · 三件套(样子的分真相)

- **设计契约** = 应然(真相,人机共笔):①风格声明(值从哪个系统取——管自洽)②语义映射表(每种视觉变化表达什么——管忠实)③气质节(引用声明/统计参数/偏离登记簿);
- **纸面** = 呈现(投影);
- **元素清单 manifest** = 实然(收据,**派生投影零存储**,⛔手工维护);
- **契约 − 清单 = 偏差灯**,两色:**噪声灯**(未登记的视觉差异)与**吞没灯**(有语义无视觉);observe-only 亮灯⛔阻断;
- 状态栏=契约的蒸馏投影,落**浮卡**(09-12 已拍「人机同卡同旋钮」的纪律层扩建);
- **manifest 先行**:无传感器的契约必烂。

## 第六条 · 偏离登记簿与免改区

**噪声与风格的区别是一张收据。**同一处反常,无登记读作噪声(候噪声灯),登记读作签名(灯豁免)。免改区保护登记偏离**不被后来的 Agent「修正」回平均值**。与内容域「无收据宣称=红旗」同构,共用观察哲学。

## 第七条 · 呈现语法(缺的那个插座)

现状:component_kind 信封开放,但未知 kind 只渲染为占位符——数据层插座无限,渲染层仍须产房出码。补法=一门**受限呈现语法**:新组件以数据描述其样(几何基元+文本+token 引用+布局配方),⛔自由 SVG/HTML(注入/打印/无障碍三刃),语法自小闭集渐进扩。**定级 V15+ 真系统**。

> 注:本条生效后,**组件产房章程(2026-08-29)第 2 站候修订**——「样子」走呈现语法(数据),仅「行为」需出码走三级转正;行为永不现场造(诚实边界)。

## 第八条 · 界面哲学:建在「指」上,不建在「说」上

1 比特是表达通道的分辨率,不是感知的分辨率——人指认精准而命名匮乏。故:点住元素→状态栏亮其名/角色/所属纪律;改动以**具名变体并呈**供挑选(识别力高带宽),⛔要求用户描述(词汇力零带宽);选择回写契约。副作用即本产品的学习之道:**顺手教学**,五百年行会词汇随用随发。

## 第九条 · 三条毒性警告(常设)

1. **契约字段必须机械可查**(token/枚举/可检规则);自由文本的「优雅一点」进契约=把 bullshit 搬进表单;
2. **状态栏必须是蒸馏面**(一行总风格+三五条纪律+偏差灯),全参数留抽屉;280px 窄卡纪律照守,临时工具卡⛔长成常驻面板;
3. **无偏差灯的契约必烂**——manifest 是契约的传感器,必须先行。
