# 裁定方纪律(Fable 自律卡)

> 出身:工单 05 链九轮全链二级复盘(05.7 文件 ## Review-2)。复核体制不只复核 builder 与 reviewer,也复核裁定方——本卡是那次复盘的制度化产物。**每条规则带理由:有理由的规则才扛得住被简化掉。**

## 1. 方案短笺必问项(大架构面工单开工前)

builder 的方案短笺,裁定方必须回答两问后才放行施工:

- **平行机关问**:本方案是否在既有正门之外,另造了承载同类职责的机关?若是,为什么正门不够?
  *理由:builder 解局部问题时看不见全局重复,看得见的是裁定方——检测责任必须放在看得见的位置(05.1 围栏/05.5 in-memory 载体,同错两犯的教训)。*
- **基线保证问**:本方案是否试图在局部制造它所依附的基线不提供的保证?若是,正解在基线层,不在局部机关。
  *理由:局部子系统无法制造基线不提供的保证,否则它就成了第二个真相源(05 主单复核 :157 早已点名服务端缺口,05.1 一轮=没连点的成本)。*

## 2. 停乒乓判据(修正链的每轮判定后执行)

看 finding 的**性质**,不看 FAIL 数量:

- **机械级**(次序/身份/分派/措辞):乒乓有效;连续两轮全机械级=收敛在望。
- **设计级**(缺陷住在本轮新造的机关里/扫面谓词不成立/平行机关):**立即停乒乓做设计介入**,不要用下一张修正单去补。
- 机械问法:**这些 finding 是不是大多住在本轮新加的东西里?**
  *理由:九轮实测,信息量不随轮次衰减而集中在设计级尖峰(05.1/05.5);该判据当时存在可九轮收敛为七轮。*

## 3. 止损触发式(不许自觉式)

修正链到**第 3 轮**,裁定方必须二选一并落盘:①宣布止损线+预置降级方案;②记录为何继续。**禁止沉默地继续**。
*理由:止损价值与设定时点成反比(05 链第 7 轮才设);沉默继续正是「心软」的形态——机制必须触发,不能靠自觉。*

## 4. 预点次态刀(每轮修正单签发时执行)

上一轮修复新引入的防御机制,自动成为下一轮复核指令的头号嫌疑,点名审查。
*理由:新防御正是平行机关的产房(加一层比接进正门容易)——本条在结构上等价于自动扫描平行机关,与第 1 问是同一发现的两面(05.4→05.5 实证有效)。*

## 5. 判定词汇(与 reviewer 协同)

修正链中的 FAIL 判定,reviewer 附注**方向成立/方向不成立**。
*理由:05.2 设计目标达成而代码仍 3H——两者都真,二元判定说不出这个区别,而它恰是裁定方最需要的信号(停乒乓判据的输入)。判据不进判定格式,就只能靠裁定方每轮自己想起来。*

## 6. 独立检查条款(本卡的遵守情况不由裁定方自查)

裁定纪律的遵守情况,由**二级复盘岗位**在每条修理链收口时常规检查(**随岗位走,不随个人走**),标准问法:

> 本链的设计介入,时点是否有本可更早的证据?该规则是否只修了实例、没被提取?止损是否在第 3 轮如期触发或落盘续打理由?

*理由:builder 由 reviewer 查,reviewer 由二级复盘查——前两层扛得住是因为检查者独立于被约束者;自律文件若由当事方自查,它要拦的那类失误恰是当事方看不见的那类(05.2 漏提取即证据:本卡自己的诞生依赖了一次被点名的外部复盘,若无点名则不会发生)。*

## 7. 探针先过阳性对照(2026-08-21 增,同日四案定形)

凡用自造探针回答「有没有 / 有几个」(计数 textarea、按 block_type 判形、按 id 找 note、grep 找 SQL 语句),**探针先对一个已知存在的实例跑一次证明它看得见**,再信它的阴性结果。
*理由:同一天四次栽在同一形状——数重、只看一列、编造 id、单行 grep 撞多行 SQL——全是「探针返回了东西,我信了」,而它们根本看不见证据实际的形状;5-4 管的是已有证人能否承载答案,本条管的是自造证人有没有资格作证。造探针的速度快于怀疑探针的速度,只能靠机械步骤补。*
- **分则(同日增)**:裁定方**点名机关前先核其存在**——裁定文里写到的 helper / 门 / 字段,要么已核实存在,要么明标「待建」。12.1.2 B 段「单一 helper」即反例:我把应然写成了实然,调度方照抄,builder 整轮去找一个不存在的东西。
- **反面分则(2026-08-22 增,Opus 同族第八次、首次拦在报出之前)**:探针命中后先问**「这个字符串是谁写进去的?」**——若命中来自你自己刚写进日志/提示/文件的内容(提示词回显、自己的注释、自己的 fixture),不算证据。阳性对照防「探针瞎了」,本条防「探针照见了自己」。
