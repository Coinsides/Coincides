### ⭐ 一条反直觉结论

**对备胎用途，「套餐内更省心」是错的**：

- 套餐内（Spark）：**会用完，且与主力共用同一道配额闸** —— 失效时刻与主力重合，这是备胎最不该有的性质；
- API 按量（Grok/Gemini）：**不会用完，只会花钱**。

> **备胎的价值不在便宜，在于不与主力共享失效模式。** 按量计费恰恰是优点 —— 它把「额度耗尽」换成了「花钱」这个可控成本。这也给 Fable 的 $300–500 预留提供了一条独立理由：**不只是够用，是它在结构上才是备胎**。
