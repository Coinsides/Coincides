# 实操标本册(field-notes)

**性质**:Agent 技能探索的进料台账。经验可来源于任何地方——我们自己的实操、Mr Zero 的实测、builder 的施工、外部借鉴。它不替代说明书/评测集/工单,它是三者的**共同进料口**:每个标本消化后流向它们。

**业界对应**:dogfooding + error analysis + eval-driven development + postmortem→runbook 文化的合流。

## 标本格式(一坑一文件,四栏)

1. **现场**:谁在干什么,撞了什么;
2. **根因**:选型错?产品缺口?知识缺口?(可多选,分开认账);
3. **正解**:当时应该怎么做;
4. **去处**:说明书补哪行 · 评测集加哪题 · 工单开不开(逐项可勾销,全勾销=标本消化完毕,状态头转 digested)。

命名:`YYYY-MM-DD-specimen-NNN-短名.md`。无责文化:标本记流程⛔记罪责,制造者自己的坑照记(标本 #001 即是)。
