# V2.BN.2 Engineering Spec - Natural Page Writing

## Contract

V2.BN.2 introduces the first natural writing surface for ordinary notes.

The user-facing contract is:

```text
click page
  -> write
  -> persist as NoteBlock
```

The engineering contract is:

```text
draft UI state
  -> existing NoteBlock create/update APIs
  -> runtime template metadata
```

V2.BN.2 must not introduce a second content truth model.

## Primary Files

- `client/src/pages/Notes/NoteDetail.tsx`
  - note loading;
  - draft block state;
  - natural writing page surface;
  - inline editing;
  - slash command integration;
  - convert flow integration.

- `client/src/pages/Notes/NoteDetail.module.css`
  - page-like writing layout;
  - quiet block reading state;
  - selected/hover/edit controls;
  - slash command menu;
  - conversion preview panel.

- `client/src/pages/Notes/noteSlashCommands.ts`
  - first-version command list;
  - runtime template mapping;
  - create vs convert classification.

- `client/src/pages/Notes/noteBlockConversion.ts`
  - deterministic conversion helpers;
  - paragraph -> definition seed;
  - paragraph -> formula seed;
  - conversion warnings.

- `client/src/services/templateOptions.ts`
  - reuse existing runtime template option helpers;
  - do not fork template metadata logic into NoteDetail.

## Behavior Rules

### Draft Block

- Draft block is local state.
- Empty draft is never persisted.
- Whitespace-only draft is never persisted.
- The first meaningful text input creates a NoteBlock.
- If persistence fails, keep the draft text visible and show an error.

### Default Text Block

New blank writing should prefer:

```text
template_key: text.paragraph
legacy_block_type: paragraph/text fallback from existing helper
taxonomy_version: existing runtime metadata behavior
```

Use `metadataForTemplateOption()` where possible.

### Slash Command

Slash command has two modes:

```text
empty draft or empty block:
  create target block type

non-empty paragraph/text block:
  convert current block to target structured block
```

First-version command groups:

```text
Basic:
  Text
  Heading
  Quote

Structured:
  Definition
  Formula

Media / Technical:
  Image
  Code
```

If a runtime template is missing, the UI should fall back to static template options and show a light warning.

### Conversion

First-version conversion is deterministic and conservative.

Definition conversion:

- If text contains `:` or `-`, use the left side as a suggested concept/name and the right side as description.
- If not, preserve the full text as description and leave concept/name blank or derived from the first short phrase.
- Always show a confirmation preview before mutating an existing block.

Formula conversion:

- Preserve original text.
- If text looks like `$...$`, `$$...$$`, or contains common math operators, put it into a formula body/latex candidate.
- If uncertain, keep the text as the body and only update template metadata after confirmation.

### Keyboard

- `Enter`: newline within the current block.
- `Ctrl+Enter`: save current block and create/focus a new draft block.
- `Escape`: close slash menu or conversion preview.
- Browser-native copy/paste/select all shortcuts must remain intact.

### Delete / Undo

Product rule:

```text
delete means delete, with undo when available
```

V2.BN.2 may keep the existing trash-based API if implementing reliable undo would expand the version too far. If so, record the gap in review and do not rename the action as "remove from page".

## Non-Goals

- No freeform block resize.
- No multi-column layout.
- No source picker.
- No relation edits.
- No complete field schema editor.
- No migration.
- No AI generation.
