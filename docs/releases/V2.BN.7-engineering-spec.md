# V2.BN.7 Engineering Spec - Runtime Autopsy, Branch Closure, And Canvas Engine Gate

## 摘要

V2.BN.7 是 Better Notebook 在进入 Canvas Engine Foundation 前的收口版本。

本版本不实现新 UI、不做 migration、不创建 clean branch、不启动 Canvas Engine。它把 V2.BN.1 到 V2.BN.6 中已经做出的 self-owned editor prototype 作为证据，完成三件事：

```text
current runtime autopsy
current branch closure
Canvas Engine gate
```

换句话说，V2.BN.7 不是继续修旧 `NoteDetail.tsx` runtime，而是判断旧 runtime 证明了什么、暴露了什么，以及未来 V2.BN.8 Canvas Engine 应该如何开工。

## Engineering Decisions

### 当前 branch 收口

当前 branch 进入：

```text
experiment / fallback / reference
```

它的价值是经验和后备路线，不是长期 Canvas Engine 地基。

### V2.BN.8 默认路线

V2.BN.8 默认路线是：

```text
self-owned Canvas Engine on clean branch
```

AFFiNE / BlockSuite 继续作为体验与架构参考，不默认成为 canonical runtime。

### 不背实验布局兼容债

当前 `better_notebook_layout` 是实验性 layout payload。除非未来出现真实用户数据，否则不应为它设计长期 converter。

### Canvas Engine 需要 V2.BN.8.x 打磨空间

Canvas Engine 不应被设计成一版完成。V2.BN.8 后应预留 V2.BN.8.1 / V2.BN.8.2 / V2.BN.8.3 等小版本，直到工程可靠和用户体验可靠。

## Verification

本版本需要：

- 确认 V2.BN.7 内部产物文件存在；
- 确认 roadmap 中 A7 / A8 / A8.x / A9 顺序正确；
- 确认 V2.BN.7 plan checklist 完成；
- `git diff --check`；
- changed-file secret scan。

本版本不要求：

- TypeScript build；
- server/client restart；
- browser smoke；
- database migration test；
- AI provider test。

## 交付判断

V2.BN.7 完成后，下一阶段不应直接“继续修旧编辑器”，而应进入：

```text
V2.BN.8 Canvas Engine Foundation
```

并在 V2.BN.8.x 中反复打磨到：

- 工程可靠；
- 用户体验至少接近 V2.BN.1-V2.BN.5 已经磨出的稳定效果；
- ideally 超过旧 runtime。
