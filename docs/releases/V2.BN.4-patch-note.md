## Canvas Scratch / Preview Folding Patch

- Adjusted Canvas mode toward a clearer "formal page inside scratch workspace" model.
- Made the Canvas workspace grid visible and gave the formal page boundary a stronger page-card feel.
- Moved the scratch workspace label into a lightweight workspace badge instead of leaving it as plain text.
- Changed export preview from "show block rows by default" to summary-first groups.
- Added collapsible preview groups for included blocks, excluded/scratch blocks, AI-visible blocks, and AI-hidden blocks.
- Added an internal scroll area for expanded preview groups so large notes do not push the preview off-screen.

## Edgeless Workspace Patch

- Reworked Canvas mode from a narrow finite scratch area into a large scrollable edgeless workspace seed.
- Kept the formal Page boundary as a framed region inside the Canvas workspace instead of treating the whole Canvas as a bounded page container.
- Enabled both horizontal and vertical workspace scrolling in Canvas mode.
- Increased the Canvas coordinate width so blocks can be moved far outside the formal page area.
- Added a resize observer for the block workspace so layout constraints update after switching Page / Canvas mode.
- Shifted the formal Page region inward inside Canvas mode so it behaves more like an object in an edgeless workspace, with scratch space visible around it.
- Kept stored block coordinates relative to the formal Page origin so this visual offset does not require a data migration.

## Elastic Avoidance Product Note

- Recorded the accidental block collision "spring" feel as `Elastic Avoidance / 弹性避让`.
- Defined it as a Page-mode layout assist rather than a global canvas behavior.
- Documented that Canvas / Edgeless workspace should still allow intentional block overlap.
- Added the behavior to the product and UX contract so it can be refined intentionally instead of treated as an undefined bug.
- Rolled back the local four-direction elastic avoidance experiment after product review.
- Kept the first implementation conservative: Page mode currently uses vertical stacked avoidance only.
- Limited the stacked collision resolver to Page mode so Canvas / Edgeless workspace can still support intentional overlap.
- Clarified that Elastic Avoidance is not Page-mode overlap permission; if a block cannot be pushed within page bounds, future behavior should stop, clamp, or rollback rather than overlap.

## Policy Label / Title Autosave Patch

- Hid per-block export / AI visibility / boundary labels from normal writing and layout mode.
- Made Preview the diagnostic state that reveals export / AI visibility / boundary labels on the page.
- Reduced the minimum NoteBlock width so narrow side notes and right-column blocks are not artificially wide.
- Removed the title Save button; note titles now save on Enter or when the title input loses focus.
- Prevented Canvas workspace placements from being clamped into the formal Page layout when switching back to Page mode.

## Preview Label Toggle / Workspace Visibility Patch

- Changed Preview so it opens the export boundary panel without automatically showing per-block policy labels.
- Added a Page labels toggle inside Preview to show or hide export, AI visibility, and boundary labels on the page.
- Made Page labels an independent display mode, so closing the Preview panel no longer turns labels off.
- Hid `canvas_workspace` NoteBlocks from Page mode; workspace blocks now appear only in Canvas mode.
- Added a legacy placement fallback so old blocks stored beyond the formal page width are treated as workspace blocks in Page mode.
- Kept Page mode as the formal document surface while Canvas mode owns scratch/workspace placements.
