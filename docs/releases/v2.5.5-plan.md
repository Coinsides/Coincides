# v2.5.5 Plan - Package Studio Lite / Export-Import Foundation

## Goal

v2.5.5 creates the first `.coincides` package export/import foundation.

The goal is to let `TemplateDefinition`, `CompositionTemplate`, `DomainBlockSet`, and `PackageManifest` be packaged as a safe JSON bundle that can be previewed, exported, imported, and recovered through audit records.

## Scope

v2.5.5 includes:

- additive package export/import schema;
- `.coincides` JSON bundle contract;
- Light and Trusted package levels;
- source inclusion modes `omit`, `reference_only`, and `snapshot_text`;
- export preview, persisted export, and JSON download;
- import preview, conflict detection, apply, discard, and recovery records;
- Template Studio Package Studio Lite UI;
- Agent Operating Manual updates;
- graph-native migration evidence.

## Out Of Scope

v2.5.5 does not include:

- full project backup;
- zip archive;
- marketplace;
- executable plugin system;
- original file bundling;
- live source row recreation from package import;
- TemplateMigrationProposal changes;
- DomainRefinementProposal;
- GraphDB migration.

## Acceptance Criteria

v2.5.5 is complete when:

- Light exports include templates, compositions, domain sets, package manifest, and memberships;
- Trusted exports can include source reference metadata or source snapshot text as recovery material;
- export preview does not mutate runtime records;
- export creates a stable JSON bundle and content hash;
- import preview blocks same key/version/different content conflicts;
- import apply creates operation batch, import record, and item records;
- import apply imports missing safe runtime objects without overwriting existing objects;
- discard mutates only preview status;
- Template Studio exposes Package Studio Lite without crowding Course or Canvas work;
- review records graph-native migration evidence.
