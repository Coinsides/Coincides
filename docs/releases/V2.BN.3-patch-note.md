## Smoke Patch - Resize Reflow And Draft Misclick

- Fixed BlockBox height staying too tall after text reflow by measuring inner content instead of the outer box min-height.
- Fixed right-edge resize so the resized block can shrink or grow to its current text content instead of only growing.
- Added a first-pass same-column reflow: blocks below a resized block move by the height delta when their horizontal ranges overlap.
- Added a render-time same-column collision repair so older persisted layouts with overlapping vertical positions are displayed with safe spacing.
- Fixed BlockBox visual height mismatch by switching rendered boxes from content-box `min-height` to border-box `height`, so layout math and visible borders use the same height.
- Increased same-column collision spacing slightly to keep selected borders from visually touching the next block.
- Changed empty page block creation from single-click to double-click to reduce accidental draft blocks.
- Cleared empty draft state on blur so accidental empty drafts do not leave hidden block data behind.
- Smoke status: pending Henry verification. This patch is not considered passed until Henry says it passed.
