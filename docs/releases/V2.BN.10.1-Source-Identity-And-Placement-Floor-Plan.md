## 目标

建立 V10 的 Source 身份地基，证明以下四种生命周期彼此独立：

```text
source_records
source_files
source_materializations
source_project_placements
```

本小版本结束时，数据库与服务层能够稳定表达“一个全局 Source 身份 + 一个不可变事实附件 + 一个 durable materialization run + 多个 Project placement”，并完成 Home、Note class 与 receipt 接缝。它不上传文件、不解析文档、不创建 SourceProjection UI。

## 锁定不变量

1. Source identity 不以 Project 为 owner；Origin 与 Placement 分离。
2. 同一用户同一 content hash 至多一个 `source_file`。
3. 同一 Source / Project placement 幂等且唯一。
4. v1 每个 Source 至多一个 materialization run；状态与 projection pointer 保持一致。
5. Home 每用户至多一个，公共 API 不能伪造系统身份，也不能删除或改名 Home。
6. Source receipt 指稳定 `source_record`；未来删除只清活指针，不清 excerpt / locator。
7. canvas backing notes 必须稳定标记为 `note_class='system'`，包括历史 backfill 与全部前向创建路径。
8. `source_sync_status='stale'` 读写往返不得被洗回 `fresh`。

## 非目标

- upload / multer / blob storage；
- parser / SourceArtifact / materialization 执行器；
- Source Library 或 Project Sources UI；
- SourceProjection 写守卫与只读体验；
- Project 删除迁 Home、Source 硬删除和文件 quarantine；
- legacy Documents 迁移；
- Agent、embedding、GraphRAG 或 Relation。

## RED-first 检查

先写失败测试，至少覆盖：

1. migration 045 创建四张表、必要索引和新增列，并可重复执行。
2. 同用户重复 hash 被数据库拒绝，不同用户可拥有相同 hash。
3. placement 重复被数据库拒绝；删除 Project 只级联该 placement。
4. v1 第二个 materialization run 被唯一约束拒绝。
5. materialized 状态必须具有 projection note id，其他状态不得携带该指针。
6. Project 删除后 `origin_course_id` 变为 NULL，`origin_course_name_snapshot` 保留。
7. `note_block_sources` 具备 `source_record_id / source_materialization_id` 接缝。
8. 既有 canvas backing note 被 backfill 为 `system`；两个创建路径新建的 backing note同样为 `system`。
9. ensureHomeCourse 幂等；数据库不允许第二个 Home。
10. Home 的 DELETE 和 name PUT 被拒绝，普通 Project 行为不回归。
11. create/update Course 与普通 Note 的公共 validator 不接受 system identity / note class 注入。
12. stale 状态经过读取和保存后仍是 stale。

## 实现边界

- migration 使用现有版本化迁移机制；`safeAlter` 后必须断言列真实存在，不能吞掉 typo 后继续记为已迁移。
- 数据库 CHECK / UNIQUE / FK 承担可以由数据库表达的不变量；服务层不重复假装自己是唯一防线。
- Source 服务只提供 10.2 会复用的最小领域操作，例如按 hash 查找、读取 identity、幂等 placement、建立 identity floor；不提前暴露未闭合 upload route。
- Home 使用确定性 identity 或唯一约束实现幂等；路由守卫只保护 `system_kind='home'`，不影响普通 Project。
- `note_class` / `system_kind` 不进入普通 create/update validator。
- 不为未来 Edition、多个 parser run 或 Agent 预造额外字段；未来扩展保持 additive。

- canvas backing 前向路径无回归；
- stale 状态修复有回归测试；
- server build 与全量 v2 suite 通过；
- `verify:v2-bn8-runtime`、`git diff --check`、changed-file secret scan 通过；
- Review / CHANGELOG / current-state 或明确的 10.1 回执已同步。
