V2.BN.0 prepares the Better Notebook productization track by aligning the active top-level docs, current implementation reality, and future `V2.BN.x` planning template.

## Scope

V2.BN.0 includes:

- release state docs for the first Better Notebook version;
- top-level PRD / Architecture / Data Model realignment;
- Better Notebook phase plan template;
- current implementation reality check;
- continuity update for `V2.BN.x` planning rules.

## Out Of Scope

V2.BN.0 does not include:

- UI changes;
- route/API changes;
- migrations;
- relation runtime implementation;
- source reconstruction;
- GraphRAG adapter;
- AFFiNE / BlockSuite adapter;
- note editor rewrite;
- canvas rewrite;
- real AI provider tests.

## Acceptance Criteria

V2.BN.0 is complete when:

- top-level active docs no longer point future work at stale v2.0-only framing;
- `PRD.md` describes Coincides as a refined information-processing notebook/report surface;
- `ARCHITECTURE.md` states Coincides Core, projection, and adapter boundaries;
- `DATA_MODEL.md` separates content truth, layout truth, source truth, relation truth, and adapter/index state;
- future `V2.BN.x` plans have a reusable template;
- current implementation reality is recorded without pretending future UX already exists.
