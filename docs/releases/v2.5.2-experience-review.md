# v2.5.2 Experience Review

**Current Experience Status**: `PASS_WITH_FOLLOWUP`
**Version**: v2.5.2 Composition / Section Template Seed

## UI / Visual Findings

- Canvas Document now exposes a small composition selector and `Use composition` action.
- Proposal preview shows slots, block count, suggested relation count, confidence, and warnings.
- The visual treatment is intentionally seed-level and reuses the existing proposal panel.

## Interaction Findings

- User flow:
  1. open Course Detail Canvas Document;
  2. select a composition;
  3. create a proposal;
  4. review slots/warnings;
  5. apply or discard.
- Apply refreshes the canvas instead of navigating away to the backing note.
- Missing required slot content currently falls back to deterministic placeholder text with warnings.
- Browser smoke after local server restart confirmed this flow works on the real Course Detail page: selecting `Theorem / Proof / Example`, creating a proposal, applying it, and reloading preserved the new canvas section.
- Canvas node removal wording now uses `Hide` instead of `Archive`; hidden nodes remain restorable from the canvas inspector, which better matches the actual reversible projection behavior.

## Workflow Findings

- The flow keeps CompositionTemplate proposal-first.
- Apply creates a section-like group on the canvas without editing old blocks.
- Discard leaves content and canvas projection untouched.

## Product Fit Findings

- This is a good foundation for reusable section templates.
- It is not yet a true Composition Studio or designer.
- It supports Henry's direction that partial/section templates should become a central layer of the future template engine.

## Accessibility / Density Findings

- The selector/button are compact and fit the Canvas toolbar.
- Future UX work should avoid crowding the Canvas header as Package Studio, DomainBlockSet, and template actions grow.

## Deferred UX Debt

- Full Composition Studio remains deferred.
- Drag/drop slot designer remains deferred.
- Better preview/edit affordances for filled slots remain deferred.
- Composition library organization by domain/package remains deferred.
- Visual styling should be revisited during broader v2.6+ UX polish.
- Full node delete/permanent cleanup UX remains deferred; current behavior is intentionally hide/restore only.

## Henry Acceptance / Priority Decisions

- Pending Henry release/hold decision.
- Suggested acceptance focus:
  - seeded composition choices feel directionally right;
  - proposal preview is understandable;
  - apply creates visible canvas section records;
  - deferring full editor/designer is acceptable.
