## Scope

v2.5.6 includes:

- additive domain refinement schema;
- `domain_refinement` proposal creation and apply;
- dry-run diff, package impact, affected counts, warnings, blockers, samples, and recovery plan;
- `alias_mapping`, `soft_migration`, and conservative `hard_cascade`;
- domain object classification records for `note_block`, `template_definition`, and `composition_template`;
- Template Studio Domain Refinement panel;
- Agent Operating Manual and continuity updates;
- graph-native migration evidence.

## Out Of Scope

v2.5.6 does not include:

- rich editor adapter;
- GraphDB migration;
- AI-driven domain research;
- marketplace or executable packages;
- source, NoteBlock content, ObjectRelation, CanvasEdge, uploaded file, or proposal truth rewrites;
- standalone Domain Studio.

## Acceptance Criteria

v2.5.6 is complete when:

- creating a domain refinement proposal does not mutate runtime objects;
- proposals report domain diff, membership diff, package impact, affected counts, samples, warnings, blockers, and recovery plan;
- alias apply creates mapping and records only;
- soft migration can create target domains, write classifications, and preserve created-with/current history;
- hard cascade blocks ambiguous split/merge/reclassify requests without explicit mappings;
- package/domain membership changes are explicit and auditable;
- Template Studio exposes a compact proposal-first UI;
- review records graph-native migration evidence.
