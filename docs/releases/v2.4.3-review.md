## Graph-native Migration Notes

`canvas_layout` proposal is a view/projection mutation record. It should inform future ViewPreset/projection modeling, not graph truth.

Future v3.x graph modeling should treat:

- NoteBlocks/source/evidence/relation objects as graph-truth candidates when semantic;
- CanvasNodes/CanvasFrames/layout proposals as projection/view state;
- applied layout proposals as useful view history or preset evidence, not knowledge edges.
