# V2.BN.3 Experience Review - Freeform NoteBlock Box And Layout Mode

## Status

Preliminary review completed from implementation and build. Browser smoke is pending after frontend/backend restart.

## Experience Questions

V2.BN.3 should be accepted only if the page starts to feel like a flexible notebook surface:

- Can a user resize a paragraph without feeling they are editing an admin card?
- Does text reflow instead of being clipped?
- Can a user make a simple left/right layout?
- Does layout mode make handles discoverable without making reading noisy?
- Does the insert path feel spatial enough?
- Does the top chrome stay outside the page content?

## Preliminary Observations

Impeccable review lens:

- The feature moves Coincides closer to its own product identity: a refined notebook/report surface, not a linear form editor.
- Using a move grip is a good first compromise because it prevents accidental drag while editing text.
- Persisting layout in placement overrides keeps the implementation product-aligned instead of turning layout into content metadata.

Taste review lens:

- The right-edge resize handle is intentionally light and should not dominate reading mode.
- Layout mode gives a clearer affordance for batch positioning work.
- The first version still needs browser validation for crowded notes, long blocks, and small viewport behavior.

Risk to inspect during smoke:

- Whether default y spacing feels too mechanical for old notes.
- Whether slash menu placement still feels natural inside an absolute-positioned page.
- Whether source badges and formula previews make block height estimation feel jumpy.
- Whether the Insert side tool overlaps the formal page too often.

## Browser Smoke Checklist

After Henry restarts backend/frontend:

```text
Open a note
Create a paragraph block
Toggle Layout
Use the move grip to move the block
Resize the block from the right edge
Verify text wraps and remains visible
Click empty space to the right
Create another block there
Reload page
Verify layout persists
Open an old note
Verify old note still renders
```
