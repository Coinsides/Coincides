# v2.3.3 Experience Review - Source Board Seed

**Created**: 2026-05-22
**Updated**: 2026-05-22
**Current Experience Status**: `PASS_WITH_FOLLOWUP`

---

## UI / Visual Findings

Course Detail now includes a minimal Source Board panel inside the source/material workspace.

The visual treatment is intentionally list/group based. It does not attempt to be the final Canvas or spatial board.

## Interaction Findings

Implemented interactions:

- create a Source Board;
- select an active Source Board;
- add current active SourceScopes to the selected board;
- open/jump a board node back to source text;
- archive a board node;
- use selected board scopes for new proposals.

## Workflow Findings

Source Board should feel like a structured source-range workspace, not a Canvas, source deletion tool, annotation editor, or final import surface.

The UI copy explicitly states that Source Board organizes selected source ranges and is not Canvas, annotation, final import, or source deletion.

## Product Fit Findings

Source Board Seed should connect selected source ranges to later proposal and Canvas workflows without creating a second source of truth.

The first board version references existing SourceScopes/Anchors and prepares a bridge:

```text
Source Snapshot / SourceScope
  -> Source Board node
  -> proposal input
  -> later Source Board / Canvas maturity
```

## Accessibility / Density Findings

Light check only. Controls use readable button labels, but the Course Detail source workspace is growing dense. Heavy visual acceptance remains deferred.

## Deferred UX Debt

Heavy visual acceptance remains deferred to v2.3.x / v2.4-v2.5 batch review after Source Board or Canvas maturity.

Future Source Board work should revisit:

- board naming/editing;
- archived board/node management from UI;
- grouping/filtering nodes by source or role;
- eventual spatial layout only after Canvas work starts.

## Henry Acceptance / Priority Decisions

Henry v2.3.x batch acceptance remains pending.
