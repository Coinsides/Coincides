## Quality Review

## Data Decision

Chosen path:

```text
note_block_placements.display_overrides_json
  -> better_notebook_layout
  -> x/y/width/height + export_role + ai_visibility
```

Reason:

- Page/canvas/export policy is placement/projection state.
- It should not be stored in `note_blocks.content_json`.
- It is too early to add a final typed table before V2.BN.6 data contract consolidation.

Known limitation:

- The first page boundary uses a single formal page width, not a multi-page export engine.
- Canvas mode is a seeded workspace, not full edgeless pan/zoom.
- Export role is object-level, not source-aware or relation-aware yet.
- AI visibility is local UI policy, not yet connected to a real AI context builder.

## Graph-Native / Adapter Evidence

- Export role and AI visibility are projection/policy evidence, not semantic graph truth.
- Page-outside scratch content may still be a future graph-visible object if explicitly AI-visible.
- Visual placement still must not be converted into ObjectRelation.
- Future GraphRAG adapter should treat export visibility and AI visibility as filters, not as relation facts.
