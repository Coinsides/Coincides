## 1. Goal

v2.3.2 lets users save page, page-range, anchor, source-material, or material-segment selections as reusable SourceScopes.

Core product rule:

```text
SourceScope = selected source range for later proposals
SourceScope != annotation, deletion, final import, Source Board, PDF renderer, or Canvas
```

---

## 2. Scope

Included:

- additive `source_scopes` schema;
- SourceScope create/list/detail/update/archive/restore/jump APIs;
- Course Detail source snapshot page and page-range selection;
- selected scopes as optional inputs for material map, organized note, and material reconciliation proposals;
- v2.3.x continuity update for deferred Henry batch acceptance.

Out of scope:

- Source Board;
- annotation/highlight editor;
- PDF visual rendering;
- manual text offset selection;
- bbox / region selection;
- Canvas / 2.5D / 3D;
- external source snapshot tools.

---

## 3. API / Contracts

Routes:

```text
GET /api/source-scopes?course_id=...&status=...
POST /api/source-scopes
GET /api/source-scopes/:id
PUT /api/source-scopes/:id
POST /api/source-scopes/:id/archive
POST /api/source-scopes/:id/restore
GET /api/source-scopes/:id/jump-target
```

Proposal routes accept optional `source_scope_ids`:

```text
POST /api/proposals/material-map
POST /api/proposals/organized-note
POST /api/proposals/material-reconciliation
```

Rules:

- SourceScopes are user/course scoped.
- Creating, archiving, restoring, or jumping to a scope must not mutate source snapshot, anchor, note, evidence, or material rows.
- Archived scopes are not accepted for proposal narrowing.
- Invalid scope ids fail clearly.
