# v2.2.1 Engineering Spec - Evidence Set + Conservative Merge Apply

**Created**: 2026-05-21
**Updated**: 2026-05-21
**Status**: Implemented

---

## 1. Implementation Boundary

v2.2.1 adds persistent EvidenceSet storage and group-level apply decisions for `material_reconciliation` proposals.

It does not create canonical NoteBlocks or mutate source material state.

---

## 2. Migration

Add migration:

```text
server/src/db/migrations/017_v2_reconciliation_evidence.ts
```

The migration creates:

```text
evidence_sets
evidence_items
material_reconciliation_decisions
```

`server/src/db/schema.sql` must mirror the migration for fresh DB initialization.

---

## 3. Apply Contract

`POST /api/proposals/:id/apply` passes request body into proposal apply handlers.

For `material_reconciliation`:

```json
{
  "group_decisions": [
    {
      "group_id": "candidate-group-id",
      "decision": "accepted_evidence_set"
    }
  ]
}
```

If `group_decisions` is omitted or empty:

- keep v2.2.0 compatibility;
- create review-shell operation batch only;
- do not create decisions or evidence sets.

If `group_decisions` is provided:

- validate every group id exists in the proposal;
- validate decision value;
- create one operation batch;
- create decision rows for every provided group decision;
- create EvidenceSet and EvidenceItems only for `accepted_evidence_set`.

---

## 4. Evidence Mapping

Group kind mapping:

```text
DUPLICATE -> duplicate
OVERLAP -> overlap
SAME_CONCEPT_EVIDENCE -> same_concept
CONFLICT -> conflict
```

EvidenceItem fields are copied from candidate group evidence:

- source material;
- source fragment;
- material segment;
- document;
- document chunk;
- page range;
- excerpt;
- reason;
- confidence from group;
- metadata with source group kind/title.

---

## 5. UI Contract

Course Detail reconciliation proposal panel adds per-group decision controls:

```text
Accept evidence
Keep separate
Defer
```

The apply button sends only selected group decisions.

User-facing wording must make clear:

- accepting evidence does not merge content;
- sources remain untouched;
- recovery/unmerge is later work.
