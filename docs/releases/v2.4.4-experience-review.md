# v2.4.4 Experience Review - Canvas Edges + ObjectRelation Seed

**Created**: 2026-05-23
**Updated**: 2026-05-23
**Current Experience Status**: `PASS_WITH_FOLLOWUP`

---

## UI / Visual Findings

- The canvas now exposes a recognizable Connect mode with visible node ports and an edge inspector.
- Edge rendering is intentionally minimal and functional: curved SVG connectors, selected-edge highlight, incomplete-edge dash, and relation-backed styling.
- The v2.4.4 UI is still foundation-grade, not final AFFiNE-level polish.

## Interaction Findings

- Users can conceptually work in three steps: draw a visual connector, inspect it, then upgrade it into a semantic relation.
- This matches Henry's preferred model: not every arrow is a relation, and not every relation needs to be visible as an arrow.
- Full browser gesture validation remains pending until the local backend is restarted with v2.4.4 routes.

## Workflow Findings

- v2.4.4 clarifies the workflow boundary:
  - incomplete edge: user intent without a stable target;
  - visual edge: connected canvas artifact;
  - object relation: confirmed system-readable semantic edge.
- Layer visibility is useful as a seed, but a real layer manager is intentionally deferred.

## Product Fit Findings

- This version is an important product shift from "canvas as layout" toward "canvas as graph-ready interaction surface."
- It preserves the canvas-first direction while keeping Coincides data sovereign and graph-ready.

## Accessibility / Density Findings

- Ports and inspector controls are compact and may need larger hit targets later.
- Dense canvases will need better edge selection affordances, keyboard controls, and layer filtering.

## Deferred UX Debt

- Full edge styling, custom arrows, custom shapes, and user-designed visual systems remain out of v2.4.4.
- Full RelationLayer management remains out of v2.4.4.
- Heavy subjective visual acceptance remains deferred to the v2.4.x batch review.

## Henry Acceptance / Priority Decisions

Henry v2.4.x batch acceptance remains pending.
