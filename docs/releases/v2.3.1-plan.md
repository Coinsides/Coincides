## 1. Goal

v2.3.1 creates a stable SourceAnchor layer so existing source references can jump back to source snapshot pages or page ranges.

Core product rule:

```text
SourceAnchor = stable source pointer
SourceAnchor != range selector, Source Board, annotation editor, PDF renderer, or Canvas
```

---

## 2. API / Contracts

Routes:

```text
GET /api/source-anchors?course_id=...&target_type=...&target_id=...
POST /api/source-anchors/generate
GET /api/source-anchors/:id
GET /api/source-anchors/:id/jump-target
POST /api/source-anchors/:id/refresh
```

Generate payload:

```json
{
  "course_id": "course-id",
  "target_type": "optional note_block | evidence_set | proposal",
  "target_id": "optional target id"
}
```

Jump target response:

```json
{
  "anchor": {},
  "snapshot": {},
  "page": {},
  "focus": {
    "page_start": 1,
    "page_end": 2,
    "text_start_offset": null,
    "text_end_offset": null
  },
  "warnings": []
}
```

---

## 3. Data Model

Add migration:

```text
server/src/db/migrations/020_v2_source_anchors.ts
```

Create:

```text
source_anchors
source_anchor_links
```

Rules:

- SourceAnchors are additive and do not replace `note_block_sources`, `evidence_items`, or source snapshot rows.
- Anchors are generated from existing NoteBlock source references and EvidenceItems.
- Missing source snapshots produce warnings rather than crashing generation.
- Re-running generation is idempotent and must not duplicate anchors or links.

---

## 4. UI Behavior

- Note editor source reference rows show `View source` when an anchor exists.
- Course Detail Source Snapshot panel can open a snapshot with a focused page.
- Focus means opening the matching page-like section and applying a visible focused style.
- EvidenceSet jump-back may be exposed only where the current UI already has evidence items available.
