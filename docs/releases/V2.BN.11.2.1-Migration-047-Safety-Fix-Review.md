## 3. R2 - Runner 级失败回滚

失败注入不再直调 migration `.up()`，而是删除 047 收据后经 `runMigrations` 重跑。测试证明失败后：

1. `items / item_snapshots / item_anchors / relations / relation_assessments` 均不存在；
2. `db_migrations` 不留下 `047_v2_item_relation_floor` 收据；
3. 六张退役表仍在；
4. `content_group_members` 保持 046 形状，不残留 rename 临时表，原始非法 fixture 仍在。

该行为依赖 migration runner 自 2026-03 已存在的“每个 migration body 与其 receipt 同事务”机制，本补丁只是首次把 047 的收据回滚纳入行为测试，并未新建 runner 事务能力。
