# v2.5.5 Engineering Spec - Package Studio Lite / Export-Import Foundation

## Boundary

v2.5.5 implements a preview-first `.coincides` JSON package layer for runtime package objects.

It packages runtime contracts, not user project truth. Notes, source rows, canvas nodes, ObjectRelations, proposals, original files, provider keys, passwords, and executable code are not imported or exported as live project state in this version.

## Data Model

Migration: `server/src/db/migrations/029_v2_package_import_export.ts`

Tables:

- `package_exports`
- `package_import_previews`
- `package_import_records`
- `package_import_record_items`

`package_exports` stores export audit and serialized bundle JSON.

`package_import_previews` stores uploaded/pasted bundle JSON, validation result, conflict report, recovery report, warnings, blockers, and preview status.

`package_import_records` stores applied import run metadata and operation batch linkage.

`package_import_record_items` stores per-object outcomes: `imported`, `resolved_existing`, `skipped`, `blocked`, or `recovery_only`.

## Bundle Contract

Bundle format:

```json
{
  "package_format": "coincides.package.bundle",
  "bundle_version": "v2.5.5",
  "package_level": "light",
  "source_inclusion": "omit",
  "manifest": {},
  "contents": {
    "template_definitions": [],
    "composition_templates": [],
    "domain_block_sets": [],
    "domain_template_memberships": [],
    "domain_composition_memberships": [],
    "source_references": [],
    "source_snapshots": []
  },
  "integrity": {
    "content_hash": "sha256:...",
    "exported_at": "..."
  }
}
```

Package levels:

- `light`: package manifest, templates, compositions, domain sets, memberships.
- `trusted`: may additionally include source reference metadata or source snapshot text.

Source inclusion:

- `omit`: no source metadata.
- `reference_only`: source reference metadata only.
- `snapshot_text`: source snapshot text as recovery material only.

Deferred source modes:

- `snapshot_media`
- `bundle_original`
- `full_project_backup`

## Validation

Blockers:

- unsupported package format/version;
- unsupported package level/source inclusion;
- secret-like keys such as API keys, passwords, tokens, provider keys;
- executable package content;
- same key/version with different content;
- missing required template or composition references.

Warnings:

- content hash mismatch;
- optional missing references;
- source recovery material cannot recreate live source rows in v2.5.5.

## API

Export routes:

- `GET /api/package-exports`
- `POST /api/package-exports/preview`
- `POST /api/package-exports`
- `GET /api/package-exports/:id`
- `GET /api/package-exports/:id/download`

Import routes:

- `GET /api/package-imports`
- `POST /api/package-imports/preview`
- `GET /api/package-imports/:id`
- `POST /api/package-imports/:id/apply`
- `POST /api/package-imports/:id/discard`

## Apply Rules

Import apply:

- requires an active preview with no blockers;
- creates one `operation_batches` row;
- creates one `package_import_records` row;
- creates `package_import_record_items`;
- imports missing package manifests, template definitions, composition templates, domain block sets, and memberships;
- resolves exact existing objects without duplication;
- records source metadata as recovery-only;
- never overwrites existing runtime objects;
- never mutates NoteBlocks, sources, canvas nodes, ObjectRelations, or proposals.

## Frontend

Template Studio gains Package Studio Lite:

- export panel for package level and source inclusion;
- export preview and JSON download;
- import file/paste field;
- import preview, apply, and discard;
- conflict and recovery result display.

Course, Canvas, and Note daily work surfaces remain unchanged.

## Tests

Automated tests cover:

- migration table creation;
- Light export contents;
- Trusted source snapshot text as recovery material;
- stable JSON bundle and hash;
- conflicting same key/version import blocker;
- missing-object import without overwriting existing objects;
- discard preview status-only mutation.
