## 3. Future Contracts

Source Annotation future concepts:

```text
SourceAnnotation
AnnotationTarget
AnnotationLayer
AnnotationKind
```

Intended meaning:

- `SourceAnnotation`: user or system note attached to source evidence.
- `AnnotationTarget`: stable target such as SourceSnapshot page, SourceAnchor, SourceScope, SourceBoardNode, future bbox, or future text range.
- `AnnotationLayer`: separates user notes, AI suggestions, extracted highlights, review marks, and future collaboration layers.
- `AnnotationKind`: highlight, comment, question, correction, importance mark, relationship hint, or future media marker.

Media Snapshot future concepts:

```text
MediaSnapshot
MediaSnapshotFrame
MediaAnchor
MediaTranscriptSegment
```

Intended meaning:

- `MediaSnapshot`: normalized source-view layer for video/audio assets.
- `MediaSnapshotFrame`: optional keyframe or visual checkpoint, not required for first transcript-first implementation.
- `MediaAnchor`: stable pointer into timestamp ranges or frame ranges.
- `MediaTranscriptSegment`: transcript-first source unit for proposal and board workflows.

## 4. Candidate External Tools

No external tool is adopted in v2.3.4.

Candidates to evaluate under the External Tool Gate in a later version:

- PDF rendering: `PDF.js`, `EmbedPDF`.
- Web snapshot: `Mozilla Readability`, `DOMPurify`, `Playwright`, `SingleFile`.
- Media snapshot: transcript-first pipeline first; keyframe/frame extraction later.

The future tool gate must check:

- why existing Source Snapshot text layer is insufficient;
- local Windows viability;
- license and downstream reuse implications;
- package/runtime complexity;
- adapter strategy so Coincides keeps ownership of source evidence, anchors, scopes, boards, and proposals;
- removal/rollback path if the tool is replaced.
