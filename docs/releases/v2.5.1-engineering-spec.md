# v2.5.1 Engineering Spec - User-facing Template Editor Seed

**Status**: in progress

## Summary

v2.5.1 adds guided editing APIs and a Template Studio page over the v2.5.0 `TemplateDefinition` runtime. It uses existing `template_definitions` storage and avoids silent migration of old NoteBlocks.

## Backend Contract

Extend `server/src/services/templateDefinitions.ts` with editor operations:

- create user draft template;
- copy template to user draft;
- update user template with structural safety checks;
- activate, deprecate, archive, and restore;
- get template usage summary.

Extend `server/src/routes/templates.ts` with:

```text
POST /api/templates
POST /api/templates/:id/copy
PUT /api/templates/:id
POST /api/templates/:id/activate
POST /api/templates/:id/deprecate
POST /api/templates/:id/archive
POST /api/templates/:id/restore
GET /api/templates/:id/usage
```

Validation:

- `system_type` is one of `text | latex | code | source_quote | task | media | table`;
- `learning_role` is one of `note | concept | definition | theorem | proof | formula | example | exercise | answer | warning | source`;
- `field_schema` has 1-8 fields;
- field kind is `text | textarea | latex | code | checkbox | list`;
- field keys match `^[a-z][a-z0-9_]*$`;
- policy presets are expanded into behavior objects.

Safety:

- system templates reject update/lifecycle mutation except copy;
- structural fields can change only while `status = draft`;
- active templates with usage reject structural edits and return `proposal_required`;
- archive rejects templates with usage;
- deprecate keeps runtime resolver compatibility.

## Frontend Contract

Add `#/templates` route and sidebar item.

Template Studio shows:

- template list with system/user/status filters;
- detail editor;
- copy and new draft actions;
- lifecycle actions;
- compatibility warning panel;
- preview tabs for Reading, Editing, Debug, and Proposal.

Runtime template use:

- Note editor fetches active runtime templates from `/api/templates`;
- Canvas Add Block fetches active runtime templates from `/api/templates`;
- both keep static registry fallback when runtime fetch fails.

## Preview Contract

Preview is client-side and non-mutating.

Minimum preview behavior:

- render title, label, template key, status, field list, and sample default content;
- show reading mode with subtle type label;
- show editing mode with field controls disabled;
- show debug mode with key metadata;
- show proposal mode with source/relation/proposal policy summary.

## Graph-Native Migration Evidence

Record in review:

- user-created templates remain `TemplateDefinition` node candidates;
- copy/fork source should be preserved as provenance metadata;
- usage summaries provide evidence for future `USES_TEMPLATE` edges;
- edit safety classification is policy evidence, not graph truth.
