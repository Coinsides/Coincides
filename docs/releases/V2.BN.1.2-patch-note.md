# V2.BN.1.2 Patch Note - Note-First Workspace Restructure

## Summary

This patch continues `V2.BN.1` after the visual baseline reset. It changes the Project detail experience from "open Project and immediately see Canvas Document" to a note-first hierarchy:

```text
Project detail
  -> Notes & Canvas Documents
      -> Canvas document workspace
```

This is still shell work. It does not implement Natural Page Writing, slash command, freeform block resize, source chain behavior, or relation runtime changes.

## Product Decision

Opening a Project should not drop the user into an engineering canvas panel. A Project can contain many notes and canvas documents, so the Project detail page should first show the available work items. A selected canvas document should open as its own top-level workspace.

## Changes

- Added a Project-scoped canvas workspace route:

```text
/projects/:courseId/notes/:canvasId
```

- Changed Project detail to render a `Notes & Canvas Documents` section first.
- Canvas documents now appear as selectable work items instead of auto-opening.
- Existing text notes remain available and still open through the existing note route.
- Creating a new canvas document now opens that document as a workspace.
- Canvas workspace header now uses the active canvas title instead of the generic `Canvas Document` label.
- Canvas workspace is visually treated as a top-level note workspace when opened through the new route.

## Preserved

- Existing Course/Project data shape.
- Existing `course_id` storage.
- Existing canvas nodes, edges, viewport, source board node workflows, composition proposal, and layout proposal handlers.
- Existing standalone note route:

```text
/notes/:noteId
```

## Out Of Scope

- Natural Page Writing.
- Blank-page caret behavior.
- Slash command.
- Freeform NoteBlock box resize.
- SourceReference / provenance changes.
- ObjectRelation runtime changes.
- Database migration.
- AI note generation.

## Verification

- Client build required.
- Browser smoke should confirm:
  - Project opens to a note-first list.
  - Canvas document opens as its own workspace route.
  - Returning to Project brings the user back to the list.
  - Existing canvas content remains visible in the workspace.
