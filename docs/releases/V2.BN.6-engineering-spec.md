# V2.BN.6 Engineering Spec - Better Notebook Data Contract

## 摘要

V2.BN.6 是 Better Notebook 的文档与数据契约收口阶段。

本版本不实现新 UI、不做 migration、不重写 editor、不启动 Canvas Engine。它把 V2.BN.1 到 V2.BN.5 中已经暴露出来的核心对象、truth layer、adapter 边界、source / relation / template / canvas 规则整理成可执行 contract。

## 范围

本版本产出：

- truth-layer audit；
- block contract；
- source reconstruction contract intake；
- canvas / page / surface contract；
- source / provenance contract；
- link / source / relation boundary contract；
- template / category contract；
- editor state / rebuild / undo contract；
- top-level docs sync；
- release review / experience review / changelog；
- V2.BN.7 plan 的前置输入。

## 代码触碰规则

本版本默认 docs-only。

只有在当前已实现的 V2.BN.2 到 V2.BN.5 用户流程因为数据缺口会明显出错时，才允许小型代码修补。修补必须服务于已经写明的 contract，不能扩展成新的功能阶段。

当前 engineering spec 不要求新增 migration、route、API 或 UI。

## Truth Boundaries

```text
NoteBlock content truth
BlockBox / Placement layout truth
SourceReference provenance truth
ObjectRelation semantic relation truth
TemplateDefinition / TemplateVariant template truth
EditorSnapshot / overlay / selection editor state
Adapter output candidate / proposal / projection / index
```

核心边界：

- 内容 truth 不应被 layout、preview overlay 或 adapter index 覆盖。
- 布局 truth 应能承载位置、尺寸、层级、未来 rotation、relation port / connector reserve。
- source provenance 是证据链，不是 semantic relation。
- Link 是导航对象，不是证据，也不是语义关系。
- AI / GraphRAG 自动发现的关系默认是 CandidateRelation 或 proposal，不是已确认 ObjectRelation。

## Migration

V2.BN.6 不需要数据库 migration。

未来 Canvas Engine 阶段可以选择 clean branch 和 clean layout reset，因为产品尚未公开，当前 layout 数据仍是实验性数据，不应为了兼容早期实验布局背上长期 converter 技术债。

## Runtime Restart

docs-only 执行不需要 frontend / backend restart。

如果未来为了完成 V2.BN.6 临时触碰 client/server 代码，则 Henry 应重启对应 dev process 后再做 browser smoke。
