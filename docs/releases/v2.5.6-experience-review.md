## Intended Experience

Template Studio should let Henry inspect and refine a domain package without leaving the template/runtime workspace.

The UI should make clear that domain refinement is:

- proposal-first;
- previewable before mutation;
- recoverable through records;
- not a hidden rewrite of old notes or source truth.

## Current UI Surface

- Domain Packages remains the overview/list area.
- Package Studio Lite remains export/import.
- Domain Refinement is a compact panel inside Template Studio.

The panel supports:

- source domain selection;
- action selection;
- migration mode selection;
- target existing domain or preview target patch;
- optional selected-template classification sample;
- proposal preview;
- apply/discard;
- recent records.

- Hard cascade is intentionally conservative and may feel strict.
