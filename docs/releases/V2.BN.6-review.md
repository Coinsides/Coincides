# V2.BN.6 Review - Better Notebook Data Contract

## Review Result

V2.BN.6 是 docs / contract release。它的目标不是新增功能，而是在 V2.BN.7 runtime review 和未来 Canvas Engine 之前，把 Better Notebook 的底层边界说清楚。

## 已覆盖内容

- content truth 与 layout truth 的分离；
- structured block 的 `FieldSchema` / `FieldValue` / `FieldLayout`；
- paragraph 转 structured block 的保守转换规则；
- Canvas / Page / Workspace 模型；
- Canvas Engine clean branch 与 fallback 决策；
- source reconstruction intake 与 `SourceRegion` 边界；
- source provenance chain 与 source delete / degraded 状态；
- Link / SourceReference / ObjectRelation 三分法；
- template category 与第一版 category entry；
- editor state / rebuild / undo 边界；
- relation budget 与 CandidateRelation 原则。

## 质量判断

已经确认的强决策：

- Coincides Core 继续拥有 truth。
- Adapter 不能直接覆盖 canonical truth。
- GraphRAG / AI 自动发现的边默认是 candidate / proposal，不是 confirmed ObjectRelation。
- 当前 branch 是实验场和 fallback，未来 Canvas Engine 可以在 clean branch 中重写。

仍然带到后续版本的风险：

- 当前 `NoteDetail.tsx` 仍然是实验性 layout/runtime。
- 当前 source implementation 还不支持完整 SourceDocument / SourceVersion / SourceChain。
- InternalLink 已有产品和数据 contract，但 runtime 尚未完整。
- RelationType / RelationGroup / RelationPack 仍然延后。
- OperationBatch 只是 audit seed，不是完整 undo/redo truth。

## Verification Note

V2.BN.6 是 docs-only pass。本轮没有跑 TypeScript build、server restart 或 browser smoke，因为本版本故意不改 runtime code、不做 migration、不改 API。当前工作区里已有的代码改动属于前面 Better Notebook 功能补丁，不作为 V2.BN.6 contract work 的新增范围。

## Review Verdict

V2.BN.6 的数据契约方向足够清晰，可以进入 V2.BN.7 Editor Runtime Spike Gate。

V2.BN.7 必须把当前 runtime 当作 prototype evidence，而不是成熟 engine truth。也就是说，下一步不是继续盲目堆功能，而是审计当前 editor runtime 到底哪些值得保留、哪些必须在 Canvas Engine clean branch 中重做。
