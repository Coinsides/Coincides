## Goal

Create the first command and interaction layer over the v2.4 canvas. The user should be able to select a canvas node or edge and see safe, contextual commands. Future AI commands should be able to read a stable command context, but this version does not call real AI.

## Version Boundary

v2.4.5 includes:

- command, tool mode, input binding, selected object scope, and AI command context seed definitions;
- read-only command context API for a canvas and optional selected object;
- frontend command registry for current canvas actions;
- selected node / selected edge command bar;
- safe keyboard bindings for zoom, reset, connect mode, add block, and escape behavior;
- docs, review, experience review, changelog, and graph-native continuity notes.

v2.4.5 excludes:

- real AI command execution;
- user-customizable keyboard shortcuts;
- command history tables;
- generic `POST /commands/execute`;
- new database migration;
- visual-only shapes, paint tools, custom arrow styles, and full canvas toolbar redesign;
- full app shell visual redesign.

## Command Contract

Stable seed concepts:

```text
ToolMode:
  select
  connect
  insert_block

SelectedObjectScope:
  none
  canvas_node
  canvas_edge

CommandExecutionMode:
  local_ui
  existing_api
  proposal_required
  future_ai_context_only
```

Seed command IDs:

```text

```

## API / Contracts

Add:

```text
GET /api/canvases/:id/command-context
```

Query:

```json
{
  "selected_type": "none | canvas_node | canvas_edge",
  "selected_id": "optional-selected-id",
  "visible_relation_layer_ids": ["optional-layer-id"]
}
```

Response must include:

- canvas and course IDs;
- selected object scope;
- tool modes;
- active relation layers;
- available commands with enabled state and disabled reason;
- AI command context seed;
- warnings.

The endpoint is read-only and must not create operation batches or mutate canvas, source, note, evidence, relation, or proposal rows.

## Frontend Contract

The Canvas Document surface should:

- keep current select, connect, insert block, zoom, move, resize, edge bind/unbind behavior;
- centralize those actions into a small command registry;
- show contextual commands for selected nodes and edges;
- expose selected object scope clearly;
- support safe shortcuts only when the canvas surface is focused and text input is not active;
- treat layout and AI-like operations as proposal-first.
