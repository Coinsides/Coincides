## Code Review

v2.4.0 implemented the first Canvas-first document foundation:

- additive Learning Canvas persistence schema;
- server services and routes for canvases, nodes, viewport state, and Source Board seeding;
- Course Detail `Canvas Document` seed panel with a default A4-style preview;
- node jump-back delegation to existing SourceScope / SourceAnchor / SourceBoard target behavior.

The implementation keeps Canvas as a projection layer over existing source-grounded objects. It does not copy source truth, rewrite notes, or introduce a third-party canvas SDK.
