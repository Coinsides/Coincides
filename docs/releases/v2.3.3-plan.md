## 1. Goal

v2.3.3 creates the first persistent Source Board layer so users can organize selected source ranges into reusable board workspaces.

Core product rule:

```text
Source Board = structured source-range workspace
Source Board != Canvas, annotation editor, PDF renderer, source deletion, or final import
```

Henry decision:

```text
Each Course may have multiple Source Boards.
```

---

## 2. Scope

Included:

- additive `source_boards` and `source_board_nodes` schema;
- board create/list/detail/update/archive/restore APIs;
- board node create/update/archive/restore/jump APIs;
- idempotent seeding from active SourceScopes;
- optional `source_board_id` for material map, organized note, and material reconciliation proposals;
- Course Detail Source Board panel.

Out of scope:

- Canvas / 2.5D / 3D;
- free positioning or drag/drop;
- visual edges / relationship graph;
- annotation/highlight editor;
- PDF visual rendering;
- real Anthropic / Voyage / Qwen tests in default v2.3.3 verification.

---

## 3. API / Contracts

Routes:

```text
GET /api/source-boards?course_id=...&status=...
POST /api/source-boards
GET /api/source-boards/:id
PUT /api/source-boards/:id
POST /api/source-boards/:id/archive
POST /api/source-boards/:id/restore
POST /api/source-boards/:id/seed-from-scopes
POST /api/source-boards/:id/nodes
PUT /api/source-board-nodes/:id
POST /api/source-board-nodes/:id/archive
POST /api/source-board-nodes/:id/restore
GET /api/source-board-nodes/:id/jump-target
```

Proposal routes accept optional `source_board_id`:

```text
POST /api/proposals/material-map
POST /api/proposals/organized-note
POST /api/proposals/material-reconciliation
```

Rules:

- SourceBoards and SourceBoardNodes are user/course scoped.
- Seeding from SourceScopes is idempotent.
- Board/node archive is reversible and non-destructive.
- Active board SourceScope nodes are resolved into proposal source scopes.
- Archived boards are rejected as proposal inputs.
- Valid boards with no active SourceScope nodes produce a warning and fall back to course-level proposal behavior.
