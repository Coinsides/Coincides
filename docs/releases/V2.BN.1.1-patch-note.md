# V2.BN.1.1 Patch Note - Visual Baseline And Theme Reset

## Summary

This patch resets the Better Notebook shell away from the earlier purple glassmorphism direction and toward a calmer product baseline:

```text
solid surfaces
clear light/dark theme tokens
restrained accent color
less decorative chrome
more room for notebook work
```

The goal is not final visual polish. It is a baseline reset before Natural Page Writing, freeform NoteBlock layout, source badges, and relation tools add more interface density.

## Product Decision

Coincides should feel like a quiet notebook/report workspace, not an engineering dashboard or decorative demo surface. Visual personality should come from content, layout, source structure, relation views, and later user customization, not from default background effects.

## Changes

- Replaced the default purple gradient background with solid light/dark application surfaces.
- Kept both light and dark theme paths available through shared tokens.
- Removed decorative ambient background shapes from the main app shell.
- Converted legacy glass variables to solid surface tokens so older components inherit the calmer baseline without a large rewrite.
- Simplified Project cards, Course/Project modal surfaces, and Canvas workspace panels toward solid readable surfaces.
- Reduced glow-heavy borders and transparent layered panels.

## Preserved

- Existing Project/Course data.
- Existing Source, Template, Canvas, NoteBlock, CanvasEdge, and ObjectRelation behavior.
- Existing app routes and command surfaces.
- Existing CSS variable names where broad renaming would create unnecessary churn.

## Out Of Scope

- Final typography system.
- Final icon/button inventory.
- Natural Page Writing.
- Freeform NoteBlock resize.
- Block visual language.
- Relation visual style editor.
- User-created themes.

## Verification

- Client build required.
- Browser smoke should confirm:
  - app shell no longer reads as purple glassmorphism;
  - Project cards and Canvas workspace are solid/readable;
  - Source Library and Template Studio routes remain reachable;
  - existing canvas content still renders.
