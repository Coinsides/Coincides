## Code Review

Status: `PASS_WITH_FOLLOWUP`

- Added additive migration `016_v2_material_proposal.ts`.
- Added Course Material Library seed service for syncing existing documents into source materials and fragments.
- Added authenticated routes for course material sources, fragments, and current segments.
- Added material segment update route scaffold for later Step 2 work.
- Added deterministic material segment derivation for document, heading, page-range, and chunk-group segments.
- Segment derivation is idempotent and links segments to source fragments through `material_segment_fragments`.
- Added `material_map` proposal creation over selected or all course materials.
- Material map proposal payloads snapshot source material ids, segment ids, fragment ids, confidence, and warnings.
- Added `material_map` apply behavior through the existing proposal apply route.
- Applying a material map proposal accepts material segments and creates an `operation_batches` row with `source_type = 'proposal'`.
- Applying a material map proposal does not create notes or NoteBlocks.
- Added `organized_note` proposal creation over selected or accepted material segments.
- Organized note proposal payloads include candidate NoteBlocks, source references, confidence, and warnings.
- Added AI-first generation through existing provider settings, with deterministic fallback for missing keys, provider failure, or invalid AI output.
- Added `organized_note` apply behavior through the existing proposal apply route.
- Applying an organized note proposal creates a v2 note, NoteBlocks, placements, source references, and an `operation_batches` row with `source_type = 'proposal'`.
- Applying an organized note proposal updates source material proposal state and usage count.
- Existing proposal discard behavior remains side-effect free for notes and accepted segments.
- Existing documents and document_chunks remain the source layer and are not rewritten.
- Added Course Detail Course Material / Proposal workspace.
- Added user-facing proposal review panes for material map and organized note proposals.
- Added apply/discard controls for v2.1 proposals.
- Applying an organized note proposal navigates to the generated v2 Note editor.
- Fixed material status refresh after automatic segment derivation so the UI does not show stale material segment status beside generated segments.
