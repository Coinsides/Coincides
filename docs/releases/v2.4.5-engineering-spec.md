# v2.4.5 Engineering Spec - Command & Interaction System Seed

**Created**: 2026-05-23
**Status**: Implemented / verified

---

## 1. Implementation Contract

v2.4.5 adds a deterministic command layer over the existing Learning Canvas. Commands describe what the current user can do with the active canvas and selected object.

This version does not add command persistence, real AI command execution, or a generic command execution API.

---

## 2. Server Contract

Add:

```text
GET /api/canvases/:id/command-context
```

Supported query fields:

```text
selected_type = none | canvas_node | canvas_edge
selected_id = optional selected object id
visible_relation_layer_ids = optional comma-separated layer ids
```

Validation:

- canvas must belong to the authenticated user;
- selected canvas node must belong to the canvas;
- selected canvas edge must belong to the canvas;
- invalid selected objects fail with a clear `400` or `404`;
- no rows are inserted, updated, archived, or deleted.

The response includes:

- selected object scope;
- tool modes;
- active relation layers;
- available commands;
- AI command context seed;
- warnings.

---

## 3. Command Rules

Available commands must include:

```text
canvas.zoom_in
canvas.zoom_out
canvas.reset_view
canvas.clear_selection
canvas.toggle_connect_mode
canvas.open_insert_block
canvas.open_selected_target
canvas.archive_selected_node
canvas.archive_selected_edge
canvas.bind_selected_edge_relation
canvas.unbind_selected_edge_relation
canvas.plan_layout
canvas.toggle_relation_layer
canvas.inspect_command_context
```

Each command has:

```text
command_id
label
execution_mode
enabled
disabled_reason
proposal_required
input_binding
```

`canvas.plan_layout` is proposal-required. AI-like layout/content/relation generation remains proposal-first.

---

## 4. Frontend Contract

`LearningCanvasSurface` owns local command execution for v2.4.5:

- select / connect / insert tool mode state;
- selected node and selected edge scope;
- command bar in the inspector;
- safe keyboard bindings;
- command context request for debug / future AI context display.

Keyboard bindings:

```text
Escape: close insert panel, cancel connect mode/draft, or clear selection
Ctrl+= / Ctrl+Plus: zoom in
Ctrl+-: zoom out
Ctrl+0: reset view
C: toggle connect mode
A: open Add Block panel
```

Bindings must not fire while focus is inside input, textarea, select, button, or editable content.

---

## 5. Data Safety

Command context is read-only.

Local UI commands may call existing APIs, but v2.4.5 does not create a new command execution mutation surface.

Direct command actions may change:

- viewport state;
- canvas node layout/status through existing handlers;
- canvas edge status/binding through existing handlers.

Proposal-required actions stay proposal-first:

- layout generation;
- future AI relation generation;
- future content generation.

---

## 6. Graph-native Notes

v2.4.5 should record:

- `SelectedObjectScope` is a bridge from interaction to graph objects, not graph truth.
- `InputBinding` is UI/control state, not graph truth.
- `AICommandContext` is a future agent read contract. It should help AI choose objects, relation layers, and allowed operations without mutating truth directly.
