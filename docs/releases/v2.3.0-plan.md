## 1. Goal

v2.3.0 makes course sources inspectable through a normalized text-first Source Snapshot layer.

This is the first source-viewing foundation after v2.2 reconciliation. It should let users see course-level source documents as page-like text sections derived from existing parsed `documents` and `document_chunks`.

Core product rule:

```text
Source Snapshot = inspectable source representation
Source Snapshot != final PDF reader, annotation editor, Source Board, or Canvas
```

---

## 2. Scope

Included:

- additive source snapshot schema;
- idempotent snapshot generation from completed parsed documents;
- snapshot list/detail/pages APIs;
- Course Detail source snapshot entry;
- minimal text-first Source Snapshot Viewer.

Out of scope:

- PDF.js / EmbedPDF integration;
- webpage snapshot pipeline;
- SourceAnchor;
- NoteBlock -> source jump back;
- source range selection;
- Source Board;
- annotation/highlight editor;
- bbox / region selection;
- OCR;
- video/audio snapshot;
- canvas / 2.5D / 3D;
- source authority ranking;
- stronger reconciliation merge.

---

## 3. API / Contracts

Routes:

```text
GET /api/source-snapshots?course_id=...
POST /api/source-snapshots/generate
GET /api/source-snapshots/:id
GET /api/source-snapshots/:id/pages
```

Generate payload:

```json
{
  "course_id": "course-id",
  "document_id": "optional-document-id",
  "source_material_id": "optional-source-material-id"
}
```

Rules:

- Omitting `document_id` and `source_material_id` generates snapshots for all completed course documents with source materials.
- Generation is idempotent and must not duplicate page rows.
- Failed, pending, or unparsed documents produce warnings rather than crashing the entire course generation.
- APIs are user-scoped and course-scoped.
