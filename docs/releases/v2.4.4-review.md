## Graph-native Migration Notes

- `CanvasEdge` is a projection/interaction connector. It can be incomplete, visual-only, stale, or broken, so it should not automatically become graph truth.
- `ObjectRelation` is the semantic edge candidate for v3.x graph-native modeling.
- `RelationLayer` represents relation purpose, visibility, and AI/human usage grouping. v3.x must decide whether layers become graph labels, relationship properties, subgraph/perspective records, or a separate view/policy layer.
- Incomplete and visual-only edges are valuable user intent, but they should stay recoverable/projection-side unless explicitly upgraded.
