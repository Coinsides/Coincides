# V2.BN.7 Experience Review - Runtime Autopsy And Canvas Engine Gate

## 体验判断

V2.BN.1 到 V2.BN.6 的最大收获，是当前 prototype 已经磨出了一些真实可感的 Better Notebook 体验：

- 页面更像笔记，而不是工程卡片；
- block 可以自然编辑；
- resize 后文字会重排；
- slash command 有用户心智；
- selected block control bar 有操作价值；
- preview/debug overlay 可以把工程状态按需显示；
- structured field seed 让 definition / formula 不再只是普通文字；
- page 外 workspace / canvas seed 证明了未来无限画布方向。

这些体验规则必须被未来 Canvas Engine 继承。

## 当前体验的上限

当前体验也暴露了旧 runtime 的上限：

- block measurement 不稳定时，文字会溢出或 overlap；
- toolbar / preview / slash menu 会发生图层冲突；
- page/canvas mode 切换仍然像视图过滤，不像统一画布；
- elastic avoidance 有有趣手感，但当前实现容易误触发；
- formula input 展开会压迫下方内容；
- large note / relation-heavy / media-heavy 尚未验证。

这些问题不应再靠旧 runtime 继续局部补丁解决。

## 未来 Canvas Engine 的体验目标

V2.BN.8 / V2.BN.8.x 需要达到：

```text
工程上更稳定
体验上不低于当前 prototype
长期上能承载 Template Studio / Source Library / Relation Runtime
```

最低体验要求：

- PageFrame 上的写作要像普通笔记一样自然；
- PageFrame 外 workspace 要像真正 canvas area，而不是页面外的小技巧；
- block selection / resize / drag / overlay 不应互相打架；
- preview/debug overlay 不应遮挡主要操作；
- block type / AI / export badges 默认不污染正文；
- formula / definition field editor 不应打乱布局；
- pan/zoom 进入后，slash menu 和 toolbar 仍然定位正确；
- user should feel the canvas is a stable surface, not a patched page.

## AFFiNE / BlockSuite 体验参考

AFFiNE 的 page / edgeless 经验仍然值得参考：

- page 与 edgeless 可以共存；
- frame 是 canvas 中很重要的组织单位；
- connector 是视觉关系，不等于 semantic ObjectRelation；
- bottom toolbar / floating tools 能降低 canvas 操作摩擦；
- zoomed-out 时不应全量渲染细节。

但 Coincides 不应照抄 AFFiNE：

- Coincides 更重 source provenance；
- Coincides 的 NoteBlock 有 structured field truth；
- Coincides 的 relation 有 semantic truth；
- Coincides 未来需要 GraphRAG sidecar；
- Coincides 的 export / AI visibility / source chain 是自己的产品逻辑。

## 体验风险

V2.BN.8 最危险的失败不是“功能少”，而是：

```text
新 Canvas Engine 做出来后，写作体验反而不如当前 prototype。
```

所以 V2.BN.8.x 必须允许反复打磨，不要急着进入 Template Studio / Source / Relation。

## Experience Verdict

当前 branch 的体验成果应被保留为 benchmark。

V2.BN.8 不应追求炫技，而应先证明：

- 画布稳定；
- 写作稳定；
- overlay 稳定；
- 选中和 resize 稳定；
- 用户不觉得自己在跟工程结构搏斗。

当这些成立后，Better Notebook 才能继续往 Template Studio、Source Library、Relation Runtime 走。
