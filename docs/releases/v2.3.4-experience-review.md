# v2.3.4 Experience Review - Source Annotation / Media Snapshot Planning Patch

**Created**: 2026-05-22
**Updated**: 2026-05-22
**Current Experience Status**: `DEFER_RECOMMENDED`

---

## UI / Visual Findings

No UI changed in v2.3.4.

This planning patch intentionally avoids adding temporary annotation, media, or PDF UI before Source Board / Canvas maturity.

## Interaction Findings

No interaction behavior changed.

The future interaction direction is:

```text
inspect source
  -> jump to anchor/scope
  -> collect into Source Board
  -> later annotate or project to Canvas
```

## Workflow Findings

v2.3.4 clarifies that annotation and media snapshots should extend the source inspection workflow rather than replace Source Snapshot, SourceAnchor, SourceScope, or SourceBoard.

Source Annotation should be a layer over stable source targets. Media Snapshot should start transcript-first and later add keyframe or frame-based navigation when needed.

## Product Fit Findings

The planning direction supports Henry's broader product goal: Coincides should become a source-grounded learning and information workspace, not a generic note app clone.

The v2.3.x source chain now has a clearer future path into v2.4 Canvas without forcing Canvas into v2.3.

## Accessibility / Density Findings

No current UI density changed.

Future annotation/media UI should avoid creating a dense inspector before the board/canvas interaction model is clear.

## Deferred UX Debt

Deferred to later versions:

- visual PDF fidelity;
- annotation and highlight editor;
- bbox / region selection;
- web snapshot review UI;
- video/audio transcript and timestamp navigation;
- Source Board visual layout;
- Canvas projection.

## Henry Acceptance / Priority Decisions

Henry subjective acceptance remains deferred to v2.3.x / v2.4-v2.5 batch testing.

v2.3.4 only needs Henry to treat the future contract as directionally acceptable.
