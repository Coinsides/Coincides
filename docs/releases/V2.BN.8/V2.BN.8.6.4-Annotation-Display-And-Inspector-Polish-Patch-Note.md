# V2.BN.8.6.4 Annotation Display And Inspector Polish Patch Note

## Impeccable Design Read

- Surface: Better Notebook note editor.
- Register: product UI.
- Visual goal: make annotation structure legible without making the writing surface noisy.
- Preserve: dark restrained UI, compact controls, existing token vocabulary, familiar product affordances.
- Retire: card-in-card Annotation Stack, block-corner label piles, internal Draft wording, metadata dominance.

## Scope

This patch polishes annotation display and management without changing AnnotationTruth data truth.

It keeps the notebook surface quiet while still making labels discoverable when the user wants to inspect them.

## Implemented

- Added `annotationDisplayService.ts` as a display-only helper for:
  - label overlay visibility;
  - visible annotation filtering;
  - text-unit badge clusters;
  - block-level badge fallback.
- Added Preview-level label overlay toggle.
- Threaded label overlay state through the runtime surface, chrome, writing surface, block editor, text projection, and annotation overlay layers.
- Label overlay off hides text highlights, inline label badges, block label badges, and annotation overlay artifacts without mutating AnnotationTruth.
- Draft selection highlight remains visible even when label overlay is off.
- Text-backed labels now cluster near the relevant TextUnit instead of piling every label on the whole block corner.
- Text-backed badge placement now anchors to the local TextUnit row instead of the row's far-right edge.
- Text-backed badge placement now measures the first annotation range start offset inside the textarea mirror and positions the badge near that marked text instead of using a fixed row corner.
- Child labels no longer inflate the parent label badge as `+N`; they render as distinct local highlights with their own small child-label badge.
- Child label ranges now keep the parent label highlight visible underneath; child labels add a second local accent instead of replacing the parent visual layer.
- Child label badges are real selectable controls, so clicking a child label opens Annotation Stack with the parent stack visible and the child item focused.
- Parent and child label badges now use separate vertical anchors, so a child label no longer visually replaces or hides the parent label badge.
- Added a controlled annotation color palette in Annotation Stack for parent and child labels.
- Annotation color is stored on `AnnotationTruth.visual_style.color_token`, so color choice survives refresh and stays part of annotation truth.
- Annotation color saves now use the latest note metadata snapshot with stale-response protection, so color changes are persisted instead of being reverted by an older note update.
- Removed visible `+N` annotation counts from text-unit and block badges. Counts remain inspector metadata, not writing-surface labels.
- Text-backed parent labels now render as separate local badges per parent annotation, so multiple parent labels in the same TextUnit keep their visible names after `+N` counts are removed.
- Removed visible `+N` from the Annotation Stack title. The panel now focuses on the active annotation name.
- Annotation Stack now opens one active parent annotation and collapses the other selected root annotations into compact summary rows.
- Annotation Stack header now shows only the panel name instead of repeating the active label name above the active label card.
- Removed redundant `Label`, `Color`, and `Children` captions from the primary editing path.
- Removed the empty child-label instruction block from Annotation Stack. Child-label creation remains driven by selecting text inside an existing range.
- Child labels now render as compact nested items inside the parent annotation instead of parallel full-size cards.
- Details metadata is still available, but the four metadata values are lighter and stay behind the collapsed Details surface.
- Range preview editors now auto-size from one to four rows so long selected snippets remain readable instead of collapsing into a one-line scroller.
- Annotation range cache now rebases when the user edits source text inside an existing annotation range, keeping the Stack preview and source highlight synchronized for safe in-range edits.
- Block-level badge remains as fallback only for block annotations.
- Selection toolbar no longer exposes internal `Draft` wording and keeps the primary label action direct.
- Annotation Stack hierarchy is flatter:
  - label;
  - ranges;
  - children;
  - collapsed details;
  - actions.
- Metadata is collapsed by default and no longer dominates the panel.
- Child labels remain subordinate inside the parent card.
- Added model contract smoke coverage for annotation display service.

## Non-Goals

- No full custom selection engine rewrite.
- No per-label visibility filter.
- No full label style editor beyond the first controlled color-token palette.
- No CanvasObject, image, drawing, table, or source-region annotation UI.
- No Relation endpoint UI.
- No final design-system-grade Annotation Stack redesign.
