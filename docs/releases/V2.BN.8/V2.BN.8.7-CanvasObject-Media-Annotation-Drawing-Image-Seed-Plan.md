**Goal:** 建立第一版 `CanvasObject` 运行时种子，让 workspace 不再只能摆放 NoteBlock，而是可以承载最小画笔、shape、image、region selection，并让这些对象成为未来 annotation / relation / export 的可寻址对象。

**Architecture:** V2.BN.8.7 延续 self-owned minimal hybrid NoteCanvas 路线：TextBlock / NoteBlock 继续由 DOM 负责自然写作和内容渲染；CanvasObject 进入单独的数据层、对象层和交互层，不塞回 NoteBlock；annotation 通过 `AnnotationRangeV1.target_kind = 'canvas_object'` 或带 region metadata 的 range 指向 CanvasObject。第一版只做能被手测、能被保存、能被标注、不会污染 TextFlow 的对象 seed，不做完整 whiteboard / drawing app。

**Tech Stack:** React 18, TypeScript, Vite, Coincides NoteCanvas runtime, CanvasObject service, CanvasObject layer, AnnotationTruth service, note metadata persistence, `client/scripts/canvasEngineModelContractCheck.ts`, Henry manual visual pass.

## 0. Scope Lock

V2.BN.8.7 是 `CanvasObject` / media annotation / drawing seed，不是完整无限画布产品，也不是完整绘图软件。

### In Scope

- `CanvasObjectV1` 数据模型 seed。
- `CanvasObject` 持久化到 note metadata。
- `CanvasObject` 进入 NoteCanvas runtime model。
- `CanvasObjectLayer` 渲染 freehand stroke、rectangle shape、image、region。
- 最小工具入口：select / pen / rectangle / image / region。
- 最小对象选择、移动、删除。
- 最小 freehand drawing：pointer down / move / up 生成 stroke object。
- 最小 shape drawing：拖拽生成 rectangle object。
- 最小 image insert：通过本地 file input 插入 image object。
- 最小 region selection：拖拽生成 translucent region object。
- `CanvasObject` / image / region 可以被创建 `AnnotationTruth` range。
- Annotation Inspector / projection 能显示 `canvas_object` range 的可读摘要。
- Model contract checks 覆盖 CanvasObject creation、serialization、geometry、annotation range。
- 文档同步：V2.BN.8 README / Plan / CHANGELOG / Open Issue / Review / Experience Review，以及 Annotation / Notebook Object Inventory / Canvas State contract 的必要增量。

### Out Of Scope

- 完整 drawing tool：压感、橡皮擦、stroke smoothing、lasso、grouping、复杂图形编辑不进本版。
- 完整 infinite canvas 性能工程：viewport culling / virtualization / true boundless world dynamic expansion 不进本版。
- 多 frame 产品化、presentation mode、mini map、export region 不进本版。
- 完整 image asset backend、云端文件管理、图片裁剪编辑器不进本版。
- PDF / video / audio / 3D preview 不进本版。
- Relation runtime / relation line overlay 不进本版，只保留 endpoint / anchor 预留。
- AI 读图、AI 解释草图、VLM pipeline 不进本版。
- Source snapshot reconstruction 不进本版。

## 1. Product Decisions

### 1.1 CanvasObject 不是 NoteBlock

`NoteBlock` 继续回答：

```text
这段笔记内容是什么？
它如何参与 TextFlow、source、AI、export、relation？
```

`CanvasObject` 回答：

```text
画布上这个对象是什么？
它在哪里？
它怎样显示？
它是否进入 export / AI context？
它能否被标注？
```

因此：

- freehand stroke 不应该存进 TextBlock；
- rectangle / region 不应该伪装成 NoteBlock；
- image 可以未来拥有独立 ImageBlock，但 8.7 的 image object 首先是 CanvasObject；
- CanvasObject 默认不等于知识真相，只有被 annotation 标注或进入 export/AI policy 后才进入更上层的理解链。

### 1.2 CanvasObject 是空间思考的第一层

V2.BN.8.7 的目标不是炫技，而是让用户感觉 workspace 开始像一个真实的 scratch area：

```text
用户可以在 PageFrame 外写草稿；
用户可以画一条线或框一个区域；
用户可以贴一张图；
用户可以把图或区域标成 "important diagram"；
用户可以稍后再把这些内容整理进正式 PageFrame。
```

### 1.3 Image Insert 先走 CanvasObject，不急着做完整 Media Library

第一版 image insert 只需要支持本地手测：

```text
select image file
  -> create CanvasObjectV1(kind = 'image')
  -> render image on canvas
  -> persist object metadata
  -> allow select / move / annotate whole image
```

如果使用 data URL，必须加大小限制和风险说明。后续真正产品化时再进入 asset backend / source library / media contract。

### 1.4 Region 是 Annotation Range 的桥

Region object 是一个轻量 rectangle，不等于 source truth，不等于 relation，不等于 frame。它的第一版价值是：

```text
用户框住一块画布区域；
系统把这块区域作为 CanvasObject；
用户可以 annotate 这个 region；
未来 AI / export / relation 可以把它当作一个可寻址区域。
```

### 1.5 8.7 保留“玩起来”的感觉，但不牺牲底层清晰度

Henry 希望先做出画笔 / shape / image 的真实操作感，这个方向成立。但工程边界必须清楚：

```text
可以画一笔，不等于做完整画图软件。
可以插一张图，不等于做完整素材库。
可以框一个 region，不等于做 source crop / export region。
可以 annotate CanvasObject，不等于做 relation runtime。
```

### 2.3 Deferred Open Issue Routing

Open Issue 里已经记录了很多和 CanvasObject 相邻、但不应该被 8.7 吞掉的问题。8.7 plan 对这些问题的处理方式如下：

#### Keep In 8.7

这些问题直接进入本版实现：

- `CanvasObject` 从 reserve 进入 runtime seed。
- 画笔工具只做最小 pen/freehand stroke。
- shape 只做 rectangle。
- image 只做本地小图片 seed，并带文件大小保护。
- region selection 只做可保存、可标注的 translucent region object。
- `AnnotationTruth` 支持指向整个 CanvasObject 或 region object。
- CanvasObject 必须有 `export_role` 和 `ai_visibility` seed 字段，但 UI 只需要最低限度展示/保存，不做真实 export pipeline。

#### Reserve But Do Not Productize

这些问题需要在数据和命名上留口子，但不进入完整体验：

- image region annotation：可以预留 `metadata.region_rect`，但不做 crop editor / region editor。
- relation endpoint：CanvasObject 可以成为未来 endpoint 候选，但不做 relation line overlay、inspector 或 graph runtime。
- PageFrame export boundary：CanvasObject 记录 export policy，但不做 PDF / image export。
- true boundless world：对象坐标必须是 world coordinate，但不做真正无边界动态扩展、mini map 或 virtualization。
- z-index：对象要保存 `z_index`，但不做图层面板或复杂层级管理。

#### Move To Later V2.BN.8.x Or Register

这些问题明确不属于 8.7。如果实现中遇到，只记录或做防崩溃保护：

- mature infinite canvas pack：viewport culling、virtualization、true boundless world dynamic expansion、multi-frame、presentation mode、mini map、export region、高对象数量性能。
- complete drawing app：eraser、lasso、pressure、stroke smoothing、grouping、shape library、layer panel。
- complete media system：asset backend、image crop editor、PDF/video/audio/3D preview、source-library media binding。
- TextFlow assembly/editor：split、merge、extract/promote、paste fidelity、right-click command palette、TextUnitGroup editor。
- Project surface redesign：calendar 恢复、favorites 语义、Project Material / Documents 合并、source snapshot fidelity、empty project layout redesign。
- source reconstruction / structured source snapshot：保留方向，不进入本版。
- relation / graph database / GraphRAG：完全不进入本版。

#### Patch Boundary Rule

如果某个 deferred item 在 8.7 中表现成 bug，只允许按下面标准处理：

```text
If it prevents CanvasObject seed from loading, saving, rendering, selecting, moving, deleting, or being annotated,
fix the narrow bug.

If it asks for a complete product surface, advanced editor workflow, AI pipeline, relation runtime, export engine, or source pipeline,
record it and defer.
```

## 4. Data Contract Delta

### 4.1 CanvasObjectV1

在 `runtimeDataTypes.ts` 新增：

```ts
export type CanvasObjectKindV1 =
  | 'freehand'
  | 'shape'
  | 'image'
  | 'region';

export type CanvasObjectStatusV1 = 'active' | 'hidden' | 'deleted';

export type CanvasObjectExportRoleV1 = 'included' | 'excluded' | 'scratch';

export type CanvasObjectAIVisibilityV1 = 'visible' | 'hidden';

export interface CanvasObjectGeometryV1 {
  x: number;
  y: number;
  width: number;
  height: number;
  rotation: number;
  z_index: number;
}

export interface CanvasObjectFreehandPayloadV1 {
  points: Array<{ x: number; y: number }>;
  stroke_color: string;
  stroke_width: number;
}

export interface CanvasObjectShapePayloadV1 {
  shape_kind: 'rectangle';
  fill_color: string;
  stroke_color: string;
  stroke_width: number;
}

export interface CanvasObjectImagePayloadV1 {
  source_kind: 'local_data_url';
  src: string;
  filename: string;
  mime_type: string;
  byte_size: number;
}

export interface CanvasObjectRegionPayloadV1 {
  label: string | null;
  fill_color: string;
  stroke_color: string;
}

export type CanvasObjectPayloadV1 =
  | CanvasObjectFreehandPayloadV1
  | CanvasObjectShapePayloadV1
  | CanvasObjectImagePayloadV1
  | CanvasObjectRegionPayloadV1;

export interface CanvasObjectV1 {
  id: string;
  note_id: string;
  canvas_id: string;
  kind: CanvasObjectKindV1;
  geometry: CanvasObjectGeometryV1;
  payload: CanvasObjectPayloadV1;
  export_role: CanvasObjectExportRoleV1;
  ai_visibility: CanvasObjectAIVisibilityV1;
  status: CanvasObjectStatusV1;
  created_at: string;
  updated_at: string;
  metadata: Record<string, unknown>;
}
```

Rules:

- `freehand.points` are stored in world coordinates.
- `geometry` is always the object's bounding rect in world coordinates.
- `rotation` exists but remains `0` in V2.BN.8.7 UI.
- `image.source_kind = 'local_data_url'` is accepted only for local seed with size guard.
- Future asset backend can replace payload without changing object identity.

### 4.2 Note Metadata Persistence

In `useNoteCanvasDataAdapter.ts`:

```ts
const NOTE_CANVAS_OBJECTS_METADATA_KEY = 'canvas_engine_canvas_objects_v1';
```

Hydration rule:

```text
Malformed objects are ignored with a warning path, not allowed to crash note load.
Deleted objects stay in metadata until later cleanup policy exists.
```

### 4.3 AnnotationRangeV1 Region Reserve

In `AnnotationRangeV1`, 8.7 can add:

```ts
metadata?: Record<string, unknown>;
```

For image or region sub-area:

```ts
metadata: {
  region_rect?: {
    x: number;
    y: number;
    width: number;
    height: number;
  };
}
```

Rules:

- Whole CanvasObject annotation uses `target_kind = 'canvas_object'` and `canvas_object_id`.
- Region object annotation can point to the region object's id.
- Image region annotation may use `metadata.region_rect` as reserve, but 8.7 does not need a full crop editor.

## 9. Risks

### Risk 1: Data URL Image Storage Can Become Heavy

V2.BN.8.7 uses local image seed only. Storing images as data URLs in note metadata is not a production asset strategy.

Mitigation:

- 2 MB file size guard.
- Patch note must state production asset backend remains future work.
- Do not encourage uploading large images.

### Risk 2: Drawing Tool Can Become A Product Sinkhole

Drawing tools naturally invite eraser, lasso, pressure, grouping, smoothing, shape recognition, touch support, and export.

Mitigation:

- Only pen / rectangle / region.
- No eraser.
- Delete selected object is enough.
- No grouping.
- No shape library.

### Risk 3: CanvasObject Selection Can Fight Text Editing

If object gestures start while user edits text, writing experience degrades.

Mitigation:

- Tool controller must check editing focus.
- Select mode is default.
- Drawing tools are explicit modes.

### Risk 4: Annotation On CanvasObject Can Confuse Semantic Truth

CanvasObject is not automatically knowledge truth.

Mitigation:

- Only user-created annotation gives it semantic meaning.
- Inspector labels range as CanvasObject.
- AI-readable projection does not invent description.

### Risk 5: Object Layer Z-Index Can Cover Blocks

Images/regions may cover text unintentionally.

Mitigation:

- Default z-index should place new CanvasObjects above grid but below active block toolbar.
- Selected object controls use overlay layer.
- Future z-order controls are deferred but data keeps `z_index`.
