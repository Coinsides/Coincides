# V2.BN.8.11.9 Object Inspector And Context Actions Patch Note

> **Status**: implemented
> **Date**: 2026-06-30
> **Scope**: ordinary CanvasObject inspection / safe object-level actions / context-menu parity

## Summary

本轮把普通 CanvasObject 的「看得懂」和「可安全操作」补上了第一版。

此前 shape / sticky note / visual connector / image / table 已经能作为 durable CanvasObject 存在，但用户和测试侧还缺一个统一入口去确认它们的 kind、backing、placement、mount、AI-readable 状态和安全动作。本轮新增 Object Inspector，并让右键菜单复用同一套 action availability，避免 inspector 和 context menu 各说各话。

## What Changed

- 新增 `objectInspectorService.ts`，作为 inspector 派生模型和动作可用性的唯一边界。
- 新增 `ObjectInspectorLayer.tsx`，在 Canvas Mode 选中对象后显示紧凑 inspector。
- Inspector 展示对象 identity、kind、backing、object class、surface、export visibility、geometry、content mount、AI tree 状态和对象摘要。
- 右键菜单新增或统一对象级动作：inspect object、open original、duplicate object、hide/show from export、delete object。
- Duplicate 只允许安全对象：
  - pure shape 可以复制；
  - image 复制时复用同一 asset；
  - table 复制时 deep copy structured payload，并重新生成 row / column / cell id。
- Sticky note / block-backed shape 暂不复制，避免共享或误复制 TextFlow truth。
- Open original 只对 `ContentMount.targetKind = note_block` 的对象启用。
- Export visibility 通过 placement 的 `visibilityState` 在 `normal` 和 `export_hidden` 之间切换。
- Delete 复用现有对象删除路径；PageFrame 不进入本轮 generic delete。
- AI tree 查找改为 flatten 后索引，避免 table 这类嵌套在 PageFrame 节点下的对象被误报为 missing。

## Browser Smoke

已用 Browser Harness 走过以下路径：

- 打开 8.11.8 table smoke note，进入 Canvas Mode。
- 选中 table 后 inspector 可见，显示 `AI tree readable`。
- table inspector 中 `open original` 禁用，`duplicate` / `hide from export` / `delete` 可用。
- duplicate table 后对象数量从 1 变 2；删除 duplicate 后回到 1，inspector 清空。
- table 右键菜单中的动作与 inspector 可用性一致。
- export visibility 可在 visible / hidden 间切换。
- 空白 canvas 右键创建 sticky note 后，inspector 显示 block-backed shape、note_block mount、sticky presentation 和 AI-readable 状态。
- sticky note 的 duplicate 禁用，open original / export toggle / style toggle / delete 可用；删除后未留下测试对象。

## Non-goals

- 不做 ContentGroup reference / duplicate / fork / materialize。
- 不做 PageFrame inspector。
- 不做完整 top bar / ribbon / component menu。
- 不做 selected-range rich styling。
- 不做 Relation runtime。

## Remaining Risk

- Inspector v1 是对象读数和安全动作入口，不是最终对象管理 UX。
- Duplicate 对 block-backed 对象仍需后续单独设计 copy semantics。
- PageFrame 和 ContentGroup projection 仍保持特殊路径，后续不能直接套普通对象动作。
