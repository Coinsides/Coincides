# V2.BN.8.9.15 PageStack Content Flow v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 PageStack 具备最小可用的自然续写能力：当默认写作落点超过当前 PageFrame 内容区时，系统能在同一 PageStack 内选择下一页，必要时创建下一页，并把后续输入引导到下一页。

**Architecture:** 8.9.15 不做完整 Word-like 自动分页，也不拆分逻辑 block。新增一个纯模型服务负责把 `PageFrameCollection + current frame + draft layout` 编译成“继续留在当前页 / 跳到下一页 / 追加下一页”的 plan；runtime 只消费这个 plan，负责保存 PageStack 和激活 draft。

**Tech Stack:** React + TypeScript, existing Canvas Engine model services, existing `canvasEngineModelContractCheck.ts`, Vite client build.

---

## 边界

本版本做：

- 默认自然写作续写落点。
- PageStack 内已有下一页时，后续 draft 落到下一页内容区顶部。
- PageStack 末页越界时，追加一个同 Stack 下一页，再把 draft 落到新增页内容区顶部。
- 模型合约检查覆盖 fit / next-existing / append-new 三种情况。
- UI/runtime 只做最小集成，让用户通过自然写作路径看到下一页被激活。

本版本不做：

- 不做完整自动分页。
- 不把一个长 paragraph block 自动切成上下页 fragment。
- 不做 PageSlice snapshot/reference/member。
- 不改变 TextFlow 真相。
- 不建立 Block 被 PageFrame 拥有的持久归属表。
- 不让双击画布任意点创建对象时自动被 PageStack 接管。

## 验收标准

1. 新建或已有 PageStack 中，默认续写位置超出当前 PageFrame 内容区时，后续输入不会继续挤在当前页外。
2. 如果当前 Stack 已经有下一页，则下一次默认 draft 落到下一页内容区。
3. 如果当前页是 Stack 末页，则系统追加下一页，并把 draft 落到新增页内容区。
4. 8.9.15 不拆 block，不做 PageSlice，不做自动分页。
5. 模型合约、运行边界、client build、diff whitespace 检查通过。

- [ ] **Step 1: Implement minimal flow service**

Create the service:

```ts
import {
  DEFAULT_PAGE_FRAME_CONTENT_INSET,
  getPageFrameContentRect,
} from './pageFrameService';
import {
  appendPageFrameToStack,
  resolvePageStackContext,
} from './pageStackCollectionService';
import type { BlockBoxLayout } from './runtimeLayout';
import type {
  PageFrameCollectionModel,
  PageFrameModel,
} from './types';

type BaseInput = {
  collection: PageFrameCollectionModel;
  currentFrameId: string | null | undefined;
  draftLayout: BlockBoxLayout;
  blockWorldOffsetX?: number;
};

export type PageStackContentFlowPlan =
  | {
    kind: 'stay_on_current_page';
    targetFrameId: string;
    targetLayout: BlockBoxLayout;
  }
  | {
    kind: 'move_to_existing_next_page';
    targetFrameId: string;
    targetLayout: BlockBoxLayout;
  }
  | {
    kind: 'append_next_page';
    stackId: string;
    afterFrameId: string;
    targetLayout: BlockBoxLayout;
  }
  | {
    kind: 'no_page_stack_target';
    targetLayout: BlockBoxLayout;
  };

function findFrame(collection: PageFrameCollectionModel, frameId: string | null | undefined): PageFrameModel | null {
  if (!frameId) return null;
  return collection.pageFrames.find((frame) => frame.id === frameId) || null;
}

function createDraftLayoutForFrame(pageFrame: PageFrameModel, draftLayout: BlockBoxLayout): BlockBoxLayout {
  const contentRect = getPageFrameContentRect(pageFrame);
  return {
    ...draftLayout,
    x: contentRect.x,
    y: contentRect.y,
    width: Math.min(draftLayout.width, contentRect.width || DEFAULT_PAGE_FRAME_CONTENT_INSET.left),
  };
}

export function resolvePageStackContentFlowPlan({
  collection,
  currentFrameId,
  draftLayout,
  blockWorldOffsetX = 0,
}: BaseInput): PageStackContentFlowPlan {
  const currentFrame = findFrame(collection, currentFrameId);
  if (!currentFrame) {
    return { kind: 'no_page_stack_target', targetLayout: draftLayout };
  }

  const currentContentRect = getPageFrameContentRect(currentFrame);
  const draftTopInWorld = draftLayout.y;
  const currentContentBottom = currentContentRect.y + currentContentRect.height;
  if (draftTopInWorld <= currentContentBottom) {
    return {
      kind: 'stay_on_current_page',
      targetFrameId: currentFrame.id,
      targetLayout: draftLayout,
    };
  }

  const context = resolvePageStackContext(collection, currentFrame.id);
  if (!context) {
    return { kind: 'no_page_stack_target', targetLayout: draftLayout };
  }

  const nextFrameId = context.stack.frameIds[context.index + 1] || null;
  const nextFrame = findFrame(collection, nextFrameId);
  if (nextFrame) {
    return {
      kind: 'move_to_existing_next_page',
      targetFrameId: nextFrame.id,
      targetLayout: createDraftLayoutForFrame(nextFrame, draftLayout),
    };
  }

  const appendedCollection = appendPageFrameToStack(collection, context.stack.id, currentFrame.id);
  const appendedFrame = findFrame(appendedCollection, appendedCollection.selectedFrameId);
  return {
    kind: 'append_next_page',
    stackId: context.stack.id,
    afterFrameId: currentFrame.id,
    targetLayout: appendedFrame
      ? createDraftLayoutForFrame(appendedFrame, draftLayout)
      : {
        ...draftLayout,
        x: draftLayout.x + blockWorldOffsetX,
      },
  };
}
```

- [ ] **Step 2: Wrap default `activateDraft`**

Inside `useRuntimeNaturalWritingController`, create a wrapper:

```ts
const activateDraftWithPageStackFlow = useCallback((layout?: BlockBoxLayout) => {
  const candidateLayout = layout || options.defaultDraftLayout;
  const isExplicitCanvasPoint = Boolean(layout);
  if (isExplicitCanvasPoint || !options.pageFrameCollection) {
    activateDraft(layout);
    return;
  }

  const plan = resolvePageStackContentFlowPlan({
    collection: options.pageFrameCollection,
    currentFrameId: options.selectedPageFrameId || options.pageFrameCollection.selectedFrameId,
    draftLayout: candidateLayout,
  });

  if (plan.kind === 'append_next_page') {
    const nextCollection = appendPageFrameToStack(options.pageFrameCollection, plan.stackId, plan.afterFrameId);
    void options.onSavePageFrameCollection?.(nextCollection);
    const nextFrame = nextCollection.pageFrames.find((frame) => frame.id === nextCollection.selectedFrameId);
    if (nextFrame) options.onFocusPageFrame?.(nextFrame);
    activateDraft(plan.targetLayout);
    return;
  }

  if (plan.kind === 'move_to_existing_next_page') {
    const nextFrame = options.pageFrameCollection.pageFrames.find((frame) => frame.id === plan.targetFrameId);
    if (nextFrame) options.onFocusPageFrame?.(nextFrame);
    activateDraft(plan.targetLayout);
    return;
  }

  activateDraft(plan.targetLayout);
}, [activateDraft, options]);
```
