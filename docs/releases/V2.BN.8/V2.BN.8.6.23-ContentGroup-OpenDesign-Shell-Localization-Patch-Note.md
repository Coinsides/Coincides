# V2.BN.8.6.23 ContentGroup OpenDesign Shell Localization Patch Note

Date: 2026-06-21

## What Changed

- Archived the three OpenDesign HTML shells under `docs/brainstorm/产品完善/assets/2026-06-20-contentgroup-visual-reference/opendesign-html/`.
- Split the ContentGroup experience into three clearer surfaces:
  - `Groups Rail`: a lightweight note-side resource drawer for quick folder selection, new group creation, and drag/drop intake.
  - `Group Gallery`: a full-page resource manager for folder/topic/role browsing.
  - `Single ContentGroup Editor`: a standalone workbench for title, topic, role, summary, members, petals, and identity status.
- Added a shared Gallery data helper so Gallery and Single Editor read/write the same note metadata path.
- Added `/group-gallery/editor` as the standalone editor route.
- Moved Gallery away from the old mixed layout where folder browsing and detailed editing were stacked inside one page.

## Product Boundary

- This patch localizes the OpenDesign shells into the app; it is not yet the final mature ContentGroup Editor.
- Drag/drop intake is preserved through the existing content-group drag payload, but broader “drag selected text to arbitrary note/canvas destinations” remains a later global drag feature.
- Single Editor can edit group identity, members, and petals. Full source-context preview refresh is intentionally conservative until the editor loads note runtime context.
