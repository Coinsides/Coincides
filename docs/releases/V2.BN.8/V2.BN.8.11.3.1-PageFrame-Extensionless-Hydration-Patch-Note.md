# V2.BN.8.11.3.1 PageFrame Extensionless Hydration - Patch Note

> Status: implementation complete, browser smoke complete
> Date: 2026-06-28
> Owner: Henry + Codex

## 1. 问题

在 8.11.3 的浏览器 smoke 中发现：同一篇 note 在 Page Mode 可以看到页面纸张，但切换到 Canvas Mode 后 PageFrame 边界消失。

排查后确认不是 CSS 覆盖，也不是 PageFrame 被挤到屏幕外，而是 persistence payload 中出现了一个断裂状态：

- `canvas_objects` / `canvas_placements` 里仍然存在 `kind='page_frame'` 的对象和几何位置。
- `canvas_page_collections` 仍然记录了 primary frame / page stack。
- 但 `page_frame_extensions` 缺少对应行，导致 `getNoteCanvasPersistence()` 只读到空的 `pageFrames`。

结果是 Canvas Mode 的 `noteCanvasRuntime.pageFrames` 为空，无法渲染 `.formalPageBoundary`。

## 2. 修复

- 后端 PageFrame hydration 改为以 `canvas_objects + canvas_placements` 作为 PageFrame 存在性的主线。
- `page_frame_extensions` 改为左连接增强信息；当 extension 缺失时，仍然可以从 placement 恢复 PageFrame 的 `id / x / y / width / height / exportable`。
- 新增回归测试，覆盖“PageFrame object 和 placement 存在，但 extension 缺失”的断裂状态。

## 4. 边界

本补丁只修复 PageFrame hydration 断裂，不改变：

- PageFrame collection 保存路径。
- Shape / paragraph block projection 持久化逻辑。
- 自由画布允许零 PageFrame 的模型语义。
