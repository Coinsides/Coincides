# V2.BN.8.7.8 Single Editor Refine Shell And Logic Foundation Patch Note

Date: 2026-06-22

Status: completed first scoped pass and verified.

## Summary

8.7.8 把 Single ContentGroup Editor 从旧的 `identity board + member board + petal board + source board` 表单/卡片布局，推进成一个更明确的非 Canvas refine surface。

核心边界保持不变：

```text
Rail = collect
Gallery = organize
Single Editor = refine
```

这个版本故意没有照搬 OpenDesign `single-contentgroup-editor.html` 里的自由工作台 / Canvas 部分。当前只铺非 Canvas 逻辑：topbar、summary bar、material shelf、Petal dock、source drawer、状态视图模型和契约检查。

## Completed

- Added `V2.BN.8.7.8-Single-Editor-Refine-Shell-And-Logic-Foundation-Plan.md`.
- Added `singleContentGroupEditorShellModel.ts` as the Single Editor display-model layer.
- Added `check:single-editor-shell` and wired it through both client and root package scripts.
- Added a missing root `check:group-gallery-shell` script so the three ContentGroup shell checks can be run from the workspace root.
- Refactored Single Editor header into a compact refine topbar:
  - back to Gallery;
  - editable title;
  - status chip;
  - role and topic compact inputs;
  - info popover;
  - Save draft;
  - Open note.
- Moved summary into an expandable summary bar.
- Reframed the member area as `Materials` / source packages instead of a generic member card board.
- Reframed the Petal area as a `Petal dock` while preserving existing Petal behavior.
- Reframed source context into a `Source drawer` that states source truth is not moved or rewritten.
- Preserved existing behavior:
  - title/topic/role/summary save;
  - accept/reject/archive;
  - member drop intake;
  - member deletion;
  - Petal create/rename/delete/reorder;
  - fragment assignment;
  - return to source note.

- Material shelf remains list-like; if Henry wants the OpenDesign workbench feel before 8.8, that should be a separate explicit decision.
