## Supersession Note

2026-06-28 决策：原 8.11 的 ContentGroup projection / reuse 路线暂时后移。

原因是 ContentGroup 不是普通 CanvasObject。它需要拆解 projection、usage、folder/tile 展示、mini editor、Reference / Duplicate / Fork / Materialize、Open original、Petal reserve、source/member 边界、跨 note / project 写回或副本策略等多层语义。直接从 ContentGroup 开始做，会把特殊对象的复杂性误当成普通对象生命周期的复杂性。

新顺序：

1. `V2.BN.8.11` 先做普通 / 结构化 CanvasObject 家族，让 shape、connector、image、table、diagram/chart/math graph 这类对象把投影、选择、移动、保存、读取、导出预览、AI-readable metadata 跑顺。
2. `V2.BN.8.12` 再回到 ContentGroup projection and reuse，把 ContentGroup 当成特殊 CanvasObject 处理。

`V2.BN.8.11.1 Canvas Persistence Cutover Gate` 已完成，不改号。它现在作为 8.11 和 8.12 的共同地基存在。
