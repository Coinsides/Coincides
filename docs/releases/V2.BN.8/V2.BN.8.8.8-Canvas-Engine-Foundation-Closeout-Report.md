# V2.BN.8.8.8 Canvas Engine Foundation Closeout Report

Date: 2026-06-25

Status: 8.8 foundation closeout.

## Conclusion

V2.BN.8.8 已经可以作为 Canvas Engine Foundation 收口：它没有把完整 Canvas 产品做完，但已经把后续继续做 PageFrame、CanvasObject、ContentGroup Projection、Relation View、Agent 写入路径所需要的第一层工程骨架搭起来了。

这一版最重要的结果不是“画布上能加很多花哨对象”，而是确认并保护了这条边界：

```text
TextFlow = 内容真相
ContentGroup = 知识结构真相
Canvas = AI-readable layout / 空间组织真相
```

Canvas 负责对象如何存在、在哪里、占多大空间、如何被选择、移动、投影、读取。它不取代 TextFlow，也不把普通视觉箭头误认成 Relation。

## Completed Scope

### 8.8.1 Data Contract Foundation

- Added runtime-level Canvas contracts for `NoteCanvas`, `CanvasObject`, `CanvasPlacement`, `ContentMount`, `PageFrameExtension`, `VisualStyle`, `VisualConnector`, `CanvasAIReadableSnapshot`, `CanvasCommand`, and `CanvasDelta`.
- Reframed current block placement as a compatibility bridge rather than final truth.
- Derived existing PageFrame / paragraph block layout into CanvasObject-style runtime records.

### 8.8.2 Canvas Runtime Kernel Seed

- Added runtime scene/index service for Canvas placements.
- Added viewport/world coordinate conversion.
- Added rectangular hit-test seed and CanvasObject-centered selection seed.
- Added move command / placement delta seed.

### 8.8.3 PageFrame v1 Foundation

- Added PageFrame outer/content rect service boundary.
- Added primary PageFrame resolution and delete-primary fallback rule.
- Added Page Mode focus viewport seed.
- Added PageFrame as an AI-readable container concept.

### 8.8.4 Block Projection v1 Foundation

- Added paragraph block projection service.
- Created paragraph `NoteBlock`, TextFlow content, layout metadata, CanvasObject, Placement, ContentMount, and optional VisualStyle together.
- Added placement-only move / resize helpers so layout change does not mutate TextFlow.
- Added restore helper for existing layout metadata.

### 8.8.5 Shape And Visual Connector Foundation

- Added pure shape projection.
- Added block-backed shape promotion / demotion.
- Confirmed shape text is represented by paragraph TextFlow content, not by a second text truth hidden inside the shape.
- Added visual connector seed and locked its meaning to `visual_only`.
- Kept Relation runtime out of ordinary Canvas Mode.

### 8.8.6 Canvas Command / History Seed

- Added command dispatcher boundary.
- Supported create, move, resize, style, and delete command application against runtime model.
- Commands return next runtime model plus `CanvasDelta`.
- Kept persisted command log, visible undo stack, collaboration, and Agent write UI out of scope.

### 8.8.7 Canvas AI Tree v1 Hardening

- Moved Canvas AI-readable snapshot derivation into a dedicated service.
- Added selected context, PageFrame child reading order, block text projection, workspace shape node, and visual connector node.
- Confirmed AI Tree is derived read model, not durable truth.

## What Is Not Done

These are intentionally not completed in 8.8:

- Durable CanvasObject / CanvasPlacement database migration.
- Complete infinite or chunked canvas world.
- Multi-PageFrame visible management, templates, header/footer/page number, ruler, snap-wall behavior.
- Visible shape creation UI.
- Visible visual connector drawing UI.
- ContentGroup / Petal projection as CanvasObject.
- Relation View / semantic relation arrows.
- Agent write path and command proposal execution UI.
- OCR, raw ink understanding, document layout understanding, image layout understanding.
- Full overlap / occlusion scoring in AI Tree.
- Full undo / redo UI and persisted command history.

## Engineering Judgment

8.8 is enough to move the project forward, because the foundational seams now exist:

- Canvas records can be reasoned about independently from source text.
- Block-backed objects can still use TextFlow as the text substrate.
- Pure visual objects can exist without pretending to be knowledge truth.
- Visual arrows are separated from semantic Relation.
- AI-readable layout has a first read-model boundary.
- Commands have a first pure service boundary for future undo / Agent proposal.

The next versions should stop expanding 8.8 and instead mature the specific areas one by one.

- Add visible multi-PageFrame management.

### 8.10 CanvasObject Projection And Reuse

- Add visible shape and connector tools.
- Add block-backed shape UI.
- Add ContentGroup / Petal projection planning.
- Decide durable CanvasObject database migration boundary.

### 8.11 Structured Object Families

- Add table / image / chart / diagram object family planning.
- Keep each object family block-backed or data-backed only when it has AI-readable content.

### 8.12+ Relation View

- Separate ordinary Canvas Mode visual arrows from ContentGroup Mode semantic relation arrows.
- Let Relation View visualize and create real KnowledgeRelation records through proposal flow.

### 9.x Agent / GraphRAG

- Use AI Tree and command proposal boundaries before allowing Agent writes.
- Keep all Agent writes proposal-first.
