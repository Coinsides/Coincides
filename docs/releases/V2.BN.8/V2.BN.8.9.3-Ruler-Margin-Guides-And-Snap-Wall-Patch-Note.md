# V2.BN.8.9.3 Ruler / Margin Guides / Snap Wall Patch Note

Date: 2026-06-26

Status: completed scoped PageFrame guide pass.

## Goal

Turn PageFrame `contentInset` from hidden layout data into a visible and testable writing boundary:

- top ruler line
- left/right margin guides
- temporary center guide
- snap-wall behavior that helps alignment without hard-clipping objects

This keeps PageFrame useful as a writing surface while preserving Canvas freedom.

## What Changed

### PageFrame Guide Service

Added `pageFrameGuideService.ts` as the service boundary for PageFrame guide calculation.

It exports:

- `createPageFrameGuides`
- `snapRectToPageFrameGuides`
- `shouldShowPageFrameGuides`

The guide model is based on PageFrame content rect:

- `left_margin` aligns to `contentRect.x`
- `right_margin` aligns to `contentRect.x + contentRect.width`
- `center_line` aligns to the content center
- `top_ruler` aligns to the content top

### Snap Wall Semantics

Snap is now edge-aware for PageFrame content guides:

- near left margin: object left edge snaps to left margin
- near right margin: object right edge snaps to right margin
- near center: object center snaps to center line
- far outside PageFrame: object remains free
- snap disabled: object remains free and emits no guide

This is an alignment helper, not a hard wall.

### Canvas Draft Placement

Canvas Mode draft placement now allows workspace placement across `CANVAS_WORKSPACE_WIDTH`.

When snap is on, a draft created near PageFrame content guides can snap to them. When snap is off, placement is free. Page Mode natural writing still uses the default writing-flow draft when snap is on.

### Visible Guides

`NoteWritingSurfaceLayer` now renders:

- `data-page-frame-guide="top-ruler"`
- `data-page-frame-guide="left-margin"`
- `data-page-frame-guide="right-margin"`
- `data-page-frame-guide="center-line"`

Center guide appears only during Layout Mode or active block drag/resize. There is no explanatory helper text in the writing surface.
