# V2.BN.8.11.1 Canvas Persistence Cutover Gate Patch Note

> Status: completed
> Date: 2026-06-27
> Owner: Henry + Codex
> Scope: Canvas persistence / AnnotationTruth persistence / active editor cutover

## 这次做了什么

这次把三颗已经承重的 seed 从旧容器里拔出来，放进了独立实体层：

1. `canvas_engine_page_frames_v1` -> `canvas_objects / canvas_placements / page_frame_extensions / canvas_page_collections`
2. `better_notebook_layout` -> `canvas_placements + content_mounts`
3. `canvas_engine_annotations_v1` -> `annotation_truths / annotation_ranges`

这不是一个可见功能版本，而是 8.11 继续做 ordinary / structured CanvasObject family，以及 8.12 再做 ContentGroup projection / reuse 前的地基修正。

## 工程变化

- 新增 migration:
  - `035_v2_canvas_objects.ts`
  - `036_v2_annotation_truths.ts`
- 新增后端服务与路由:
  - `services/canvasObjects.ts`
  - `routes/canvasObjects.ts`
  - `services/annotationTruths.ts`
  - `routes/annotationTruths.ts`
- 新增前端 repository:
  - `canvasObjectRepository.ts`
  - `annotationTruthRepository.ts`
- `useNoteCanvasDataAdapter.ts` 改为:
  - 从 Canvas persistence repository 读取 PageFrame collection；
  - 从 AnnotationTruth repository 读取 AnnotationTruth；
  - 保存 PageFrame collection 到实体表；
  - 保存 block layout 到 `canvas_placements`；
  - 保存 AnnotationTruth 到 `annotation_truths / annotation_ranges`。
- `CourseDetail.tsx` 新建 note 时不再把 PageFrame seed 写进 note metadata，而是在 note 创建后写入 PageFrame entity。
- 旧 `/notes/:id/block-placements/:placementId` 路由会剥离 `better_notebook_layout`，防止旧路径继续复活旧布局 seed。
- PageFrame hydrate 时以 `canvas_page_collections.primary_frame_id` 作为主副身份权威，不再允许旧 extension metadata 里的 `role` 反向覆盖 collection truth。

## Cutover 语义

- Legacy metadata / override 只作为 import-once 来源。
- 成功导入后会 strip legacy key。
- 前端本地 note state 也会 strip legacy key，避免保存 typography 等 metadata 时把旧 key 再带回数据库。
- `canvas_layout` 只是前端运行时从 `canvas_placements` 投影出来的兼容字段，不是第二份持久化真相。

## 明确没有做

- 没有做 ContentGroup as CanvasObject projection。
- 没有做 full CanvasObject reuse UI。
- 没有迁移 shape / connector / dormant projection seed 的内部 helper。
- 没有做 PageSlice extraction UI。
- 没有做 GraphRAG / relation runtime。

## 剩余注意点

- `blockProjectionService.ts` 和 `shapeProjectionService.ts` 仍然引用 `writeLayoutOverride`，但它们属于休眠 projection seed，不是当前 Note 编辑器活跃写入路径。
- `pageFrameCollectionService.ts` 仍保留 legacy metadata parser/writer，主要用于 import-once 和历史 seed/测试脚本，不再是 active editor truth。
- 后续 8.11 projection/reuse 扩展应以新实体表为入口，不再新增 `note.metadata` 或 `display_overrides_json` 承重字段。
