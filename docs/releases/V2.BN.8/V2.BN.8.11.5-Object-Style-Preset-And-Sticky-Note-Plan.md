# V2.BN.8.11.5 Object-Style Preset And Sticky Note Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 解耦 `block type` 与 `object-style`，让 sticky note 成为 `paragraph block` / block-backed CanvasObject 的视觉 preset，而不是新的内容类型。

**Architecture:** 继续让 `TextFlow / note_block` 承担内容真相，让 `CanvasObject + CanvasPlacement + ContentMount` 承担身份、几何和挂载关系。本版本只新增轻量 object-style preset 语义，先持久化在 `canvas_objects.metadata.object_style` 中；不新建 `canvas_object_styles` 表，避免把 preset seed 膨胀成完整样式库。

**Tech Stack:** React 18 + TypeScript + Vite；Node/Express + SQLite；现有 CanvasObject generic persistence；现有 shape/block-backed path。

## 0. Version Position

8.11.3 已证明 pure shape 可以作为第一个真实普通 CanvasObject。
8.11.4 已证明 shape 可以挂真实 paragraph block，文字保存在 TextFlow / note_block，不保存在 shape metadata。
8.11.5 要证明第三件事：

```text
同一个内容真相
  paragraph note_block / TextFlow

可以有不同的 canvas presentation
  default shape-with-text
  sticky note preset
```

这个版本是 8.11.6 visual connector、8.11.7 image、8.11.8 table 之前的样式地基，不是完整 UI polish。

## 1. Scope Fence

### 1.1 This Version Does

- 定义 object-style preset 的最小合同。
- 让 `shapeSavePayload()` 保留并规范化 object-style metadata，不再只写 `shape_type` 导致样式丢失。
- 新增 sticky note preset。
- 支持从空白 canvas / PageFrame context menu 直接创建 sticky note。
- 支持把已有 block-backed shape 切换成 sticky note presentation。
- 支持 sticky note 重置回 default shape presentation。
- 支持 `Remove text` 时把 sticky note 降回 pure default shape，而不是留下“无内容 sticky”。
- 支持 AI-readable layout 读取 object presentation：AI 能知道这是 sticky note presentation，但内容仍从 `contentRef` / backing block 读取。
- 支持 browser smoke：创建 sticky、输入文字、reload、移动/缩放、切换 preset、remove text 后无 orphan / 无重复 block。
- 更新 8.11 主计划 / Review / Experience Review / Patch Note / current-state 中与本版本相关的状态。

### 1.2 This Version Does Not Do

- 不新建 `canvas_object_styles` 表。
- 不做用户自定义样式库。
- 不做完整 style inspector。
- 不做 top bar / ribbon。
- 不做复杂颜色面板。
- 不做 sticky note 的多模板库。
- 不做 shape 内富文本 span 样式。
- 不做 formula / table / image 填充到 sticky note 内。
- 不做 ContentGroup projection。
- 不做 visual connector。
- 不做 Relation runtime。
- 不做 undo/redo history stack。
- 不把 sticky note 变成新的 `block_type`。

### 1.3 Non-Negotiable Product Boundary

Sticky note 不是内容类型。
Sticky note 是 presentation。

```text
Wrong:
  block_type = sticky_note

Right:
  block_type = paragraph
  CanvasObject.kind = shape
  CanvasObject.backing = note_block
  CanvasObject.objectClass = block_backed
  CanvasObject.metadata.object_style.preset_id = shape.sticky_note
```

## 3. Data Contract

### 3.1 Metadata Shape

Object-style v1 持久化在 `CanvasObject.metadata.object_style`。

```ts
export type CanvasObjectStylePresetId =
  | 'shape.default'
  | 'shape.sticky_note';

export interface CanvasObjectStyleMetadata {
  preset_id: CanvasObjectStylePresetId;
  family: 'shape';
  variant?: 'default' | 'yellow';
  text_inset?: number;
}
```

Legal examples:

```ts
{
  shape_type: 'rectangle',
  object_style: {
    preset_id: 'shape.default',
    family: 'shape',
    variant: 'default'
  }
}
```

```ts
{
  shape_type: 'rectangle',
  object_style: {
    preset_id: 'shape.sticky_note',
    family: 'shape',
    variant: 'yellow',
    text_inset: 12
  }
}
```

### 3.2 Sticky Validity Rule

`shape.sticky_note` is legal only when:

```ts
CanvasObject.kind === 'shape'
CanvasObject.backing === 'note_block'
CanvasObject.objectClass === 'block_backed'
metadata.shape_type === 'rectangle'
ContentMount.targetKind === 'note_block'
```

Pure shape must not persist sticky preset.
When a sticky note is demoted through `Remove text`, it becomes:

```ts
CanvasObject.backing = 'none'
CanvasObject.objectClass = 'pure'
metadata.object_style.preset_id = 'shape.default'
```

### 3.3 AI-Readable Presentation Ref

Add a presentation reference to `CanvasAIReadableNode`:

```ts
presentationRef?: {
  presetId: CanvasObjectStylePresetId;
  family: 'shape';
  label: 'Default shape' | 'Sticky note';
  textBacked: boolean;
}
```

The AI reads style as layout/presentation context only.
The actual user text still comes from:

```ts
contentRef: {
  kind: 'note_block',
  id: backingBlockId,
}
text: textByContentTargetId[backingBlockId]
```

- [ ] **Step 3: Implement metadata readers/writers**

Use this behavior:

```ts
export function normalizeCanvasObjectStyleMetadata(
  value: unknown,
): CanvasObjectStyleMetadata {
  const record = Boolean(value && typeof value === 'object' && !Array.isArray(value))
    ? value as Record<string, unknown>
    : {};
  const presetId = record.preset_id === STICKY_NOTE_STYLE_PRESET_ID
    ? STICKY_NOTE_STYLE_PRESET_ID
    : DEFAULT_SHAPE_STYLE_PRESET_ID;
  return {
    preset_id: presetId,
    family: 'shape',
    variant: presetId === STICKY_NOTE_STYLE_PRESET_ID ? 'yellow' : 'default',
    text_inset: typeof record.text_inset === 'number' && Number.isFinite(record.text_inset)
      ? Math.max(6, Math.min(24, record.text_inset))
      : presetId === STICKY_NOTE_STYLE_PRESET_ID ? 12 : 10,
  };
}

export function readCanvasObjectStyleMetadata(
  metadata: Record<string, unknown> | undefined,
): CanvasObjectStyleMetadata {
  return normalizeCanvasObjectStyleMetadata(metadata?.[OBJECT_STYLE_METADATA_KEY]);
}

export function writeCanvasObjectStyleMetadata(
  metadata: Record<string, unknown> | undefined,
  style: CanvasObjectStyleMetadata,
): Record<string, unknown> {
  return {
    ...(metadata || {}),
    [OBJECT_STYLE_METADATA_KEY]: normalizeCanvasObjectStyleMetadata(style),
  };
}
```

export function resolveCanvasObjectStyle(
  metadata: Record<string, unknown> | undefined,
): ResolvedCanvasObjectStyle {
  const style = readCanvasObjectStyleMetadata(metadata);
  if (style.preset_id === STICKY_NOTE_STYLE_PRESET_ID) {
    return {
      presetId: STICKY_NOTE_STYLE_PRESET_ID,
      family: 'shape',
      label: 'Sticky note',

      fill: 'var(--canvas-sticky-fill, #2a2412)',

  return {
    presetId: DEFAULT_SHAPE_STYLE_PRESET_ID,
    family: 'shape',
    label: 'Default shape',
    cssClassName: 'canvas-object-style-default-shape',
    fill: 'var(--canvas-shape-fill)',
    stroke: 'var(--canvas-shape-stroke)',

    borderRadius: 8,
    opacity: 1,
