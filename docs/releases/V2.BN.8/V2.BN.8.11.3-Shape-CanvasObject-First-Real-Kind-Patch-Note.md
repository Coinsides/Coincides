# V2.BN.8.11.3 Shape CanvasObject First Real Kind - Patch Note

> Status: implementation complete, browser smoke complete
> Date: 2026-06-28
> Owner: Henry + Codex

## 1. 本次目标

8.11.3 的目标不是做一套完整图形编辑器，而是让 `shape` 成为第一个真实用户可见的普通 CanvasObject，用它证明 8.11.1.2 / 8.11.1.3 搭好的 kind-general pipeline 不再只是 PageFrame 和 paragraph block projection 两个特例。

本次保留边界：

- 不做 shape 填字。
- 不做 block-backed shape。
- 不做 sticky note。
- 不做 visual connector / image / table。
- 不做 Relation / ContentGroup projection。
- 不做完整 style inspector / top bar / ribbon / undo-redo stack。

## 2. 已完成

### 2.1 Server shape kind

- 在 `saveCanvasObjectSchema` 中加入 `kind='shape'` 的严格 validator。
- 在 CanvasObject service 的 kind handler registry 中注册 `shape`：
  - `backing='none'`
  - `objectClass='pure'`
  - 无 ContentMount
  - 无 PageFrame extension
  - 无新 extension table
- 补充 `v2CanvasPersistenceCutover.test.ts`：
  - shape round-trip。
  - shape delete cascade placement。
  - malformed shape payload rejection。

### 2.2 Client persistence normalization

- 新增 `canvasPersistenceNormalizer.ts`，把 server snake_case payload 统一归一为 client camelCase runtime shape。
- `canvasObjectRepository.ts` 改为复用 pure normalizer，避免渲染层直接认识 `object_id` / `placement_id` / `shape_type`。
- `useNoteCanvasDataAdapter.ts` 开始消费 persisted generic arrays：
  - `canvasObjects`
  - `canvasPlacements`
  - `contentMounts`
- active editor 增加 generic CanvasObject save/delete callback。

### 2.3 Runtime and UI

- runtime layout model 接入 persisted generic objects / placements / mounts。
- command surface 增加：
  - `Rectangle`
  - `Ellipse`
  - shape shell `Delete object`
- Canvas Mode 中支持：
  - 右键空白画布创建 rectangle / ellipse。
  - shape 渲染。
  - shape 选择。
  - shape 移动。
  - shape 删除。
  - shape reload 后恢复。
- 新增 `ShapeObjectLayer.tsx`，让 shape 渲染从 `NoteWritingSurfaceLayer.tsx` 中抽出成独立薄层。

### 2.4 Contract / boundary

- `canvasEngineModelContractCheck.ts` 增加 shape persistence normalization 和 command surface 断言。
- `canvasRuntimeBoundaryCheck.mjs` 增加：
  - `ShapeObjectLayer.tsx` 必须存在。
  - writing surface 必须接入 shape persistence。
  - shape layer 必须输出 AI/browser 可读标记。
  - shape CSS markers 必须存在。

## 3. Browser smoke

已在本地浏览器中实测通过：

- 打开 `test note 1`。
- 切换到 Canvas Mode。
- 右键空白画布打开 CANVAS menu。
- 创建 rectangle。
- 创建 ellipse。
- 拖动 rectangle。
- 刷新页面，切回 Canvas Mode 后 rectangle 位置与 ellipse 均保留。
- 通过 shape context menu 删除 rectangle。
- 再次刷新后 rectangle 不再返回，ellipse 仍保留。
- 补测 resize handle：创建新 rectangle 后拖拽右下角 resize handle，尺寸从 `168 x 104` 变为 `270 x 176`。
- 刷新页面并重新切回 Canvas Mode 后，rectangle 仍保持 `270 x 176`，确认 resize 写回持久化。

补测说明：browser harness 的 CDP Input 通道在 resize 拖拽上持续 timeout；改用 Chrome 控制通道完成真实拖拽 smoke。纯 DOM PointerEvent 未触发 resize，不作为有效验收依据。

## 5. 剩余风险

- Resize UI 已通过 Chrome 控制通道补测；browser harness 的 CDP Input timeout 仍可作为工具侧注意事项保留。
- Shape visual style 仍是固定 v1 样式；style preset/editor 留给 8.11.5。
- Shape 仍是 pure CanvasObject；填字、sticky、block-backed shape 留给 8.11.4 / 8.11.5。
- 当前实现只证明普通对象最小路径，不代表 connector / image / table 的 typed extension 已完成。
