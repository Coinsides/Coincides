# V2.BN.8.10.5 Selection Typography Mini Toolbar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a small floating typography toolbar near selected TextFlow text, so typography controls become available during writing without introducing a global top bar or selected-text style truth.

**Architecture:** Reuse the existing note-level `DocumentTypographyProfile`, existing TextFlow selection draft state, and existing overlay placement helper. The floating toolbar patches the note-level typography profile through `patchDocumentTypographyProfile(...)` and `onSaveDocumentTypographyProfile(...)`; it does not create rich text spans, per-character typography, or a second style source.

**Tech Stack:** React, TypeScript, Vite client, existing Canvas Engine layers under `client/src/pages/Notes/canvasEngine`, `SelectionToolbarLayer` / `overlayService` placement patterns, `typographyProfileService.ts`, runtime boundary and model contract smoke scripts.

---

## 1. Version Boundary

This patch is about discoverability and writing ergonomics.

It adds:

```text
TextFlow selection -> floating mini typography toolbar -> note-level typography profile patch
```

It must not add:

- a Word-style top bar or ribbon;
- selected-range typography truth;
- rich text span persistence;
- bold / italic / underline implementation;
- per-block typography;
- PageFrame-specific typography;
- automatic pagination;
- Export / PDF execution;
- CanvasObject / CanvasPlacement database migration.

The screenshot reference is useful for control density and placement, but V2.BN.8.10.5 should not copy the whole Word toolbar. The first usable cut only needs the typography controls that already have data truth in V2.BN.8.10.1-8.10.4.

## 2. Current Ground

Already available:

- `DocumentTypographyProfile` in `client/src/pages/Notes/canvasEngine/types.ts`.
- `DOCUMENT_FONT_FAMILY_OPTIONS`, `DOCUMENT_TYPOGRAPHY_LIMITS`, `DEFAULT_DOCUMENT_TYPOGRAPHY_PROFILE`, and `patchDocumentTypographyProfile(...)` in `typographyProfileService.ts`.
- Note-level typography persistence through `text_flow_typography_profile_v1`.
- More -> Typography controls in `NoteChromeLayer.tsx`.
- `SelectionToolbarLayer.tsx`, which already uses `placeSelectionToolbar(...)`.
- `NoteWritingSurfaceLayer.tsx`, which owns `selectionDraft`, `draftRangeCount`, and `latestDraftRange`.

Important current limitation:

```ts
SelectionToolbarLayer currently returns null when draftRangeCount <= 1.
```

That means the existing label toolbar is not the right visible surface for this patch. The clean cut is to add a sibling layer named `SelectionTypographyToolbarLayer`, rendered by `NoteWritingSurfaceLayer` when there is exactly one selected TextFlow range.

## 3. Product Rules

### Show

Show the toolbar when all are true:

- `selectionDraft` exists;
- `latestDraftRange` exists;
- `draftRangeCount === 1`;
- the text selection context menu is not open;
- the note is in a normal writing surface, not inside a blocking modal.

### Hide

Hide the toolbar when any are true:

- selection is collapsed;
- selection draft is cleared;
- text selection right-click context menu opens;
- multi-range selection exists;
- user presses Escape;
- user clicks the close button.

### Scope Label

The toolbar must make scope clear:

```text
Document typography
```

or:

```text
Applies to note
```

This prevents a false Word-like expectation that only the selected characters are being restyled.

### Interaction Preference

Use selection-triggered display, not hover-only display.

Reason:

- native text selection already has fragile pointer behavior;
- hover-only behavior can flicker when the user moves from selected text to the toolbar;
- selection state is already modeled in the app.

## 7. Task C - Create `SelectionTypographyToolbarLayer`

**Files:**

- Create: `client/src/pages/Notes/canvasEngine/layers/SelectionTypographyToolbarLayer.tsx`

- [ ] **Step C1: Create component shell**

Create:

```tsx
import {
  RotateCcw,
  X,
} from 'lucide-react';
import {
  useCallback,
  useEffect,
  type ChangeEvent,
} from 'react';
import { placeSelectionToolbar } from '../overlayService';
import type { CapturedSelectionRange } from '../selectionRangeService';
import type { DocumentTypographyProfile } from '../types';
import {
  DEFAULT_DOCUMENT_TYPOGRAPHY_PROFILE,
  DOCUMENT_FONT_FAMILY_OPTIONS,
  DOCUMENT_TYPOGRAPHY_LIMITS,
  patchDocumentTypographyProfile,
} from '../typographyProfileService';
import styles from '../../NoteDetail.module.css';

interface SelectionTypographyToolbarLayerProps {
  selection: {
    range: CapturedSelectionRange;
    anchorRect: DOMRect;
  } | null;
  typographyProfile: DocumentTypographyProfile;
  onSaveTypographyProfile: (profile: DocumentTypographyProfile) => void | Promise<void>;
  onClose: () => void;
}
```

- [ ] **Step C2: Add profile patch helper**

Inside the component:

```tsx
  const savePatch = useCallback((patch: Partial<DocumentTypographyProfile>) => {
    const nextProfile = patchDocumentTypographyProfile(typographyProfile, patch);
    void onSaveTypographyProfile(nextProfile);
  }, [onSaveTypographyProfile, typographyProfile]);
```

- [ ] **Step C3: Add handlers**

Add:

```tsx
  const handleFontFamilyChange = useCallback((event: ChangeEvent<HTMLSelectElement>) => {
    savePatch({ fontFamily: event.currentTarget.value });
  }, [savePatch]);

  const handleFontSizeChange = useCallback((event: ChangeEvent<HTMLInputElement>) => {
    savePatch({ fontSizePx: Number(event.currentTarget.value) });
  }, [savePatch]);

  const handleLineHeightChange = useCallback((event: ChangeEvent<HTMLInputElement>) => {
    savePatch({ lineHeightPx: Number(event.currentTarget.value) });
  }, [savePatch]);

  const handleParagraphSpacingChange = useCallback((event: ChangeEvent<HTMLInputElement>) => {
    savePatch({ paragraphSpacingPx: Number(event.currentTarget.value) });
  }, [savePatch]);

  const handleReset = useCallback(() => {
    void onSaveTypographyProfile(DEFAULT_DOCUMENT_TYPOGRAPHY_PROFILE);
  }, [onSaveTypographyProfile]);
```

- [ ] **Step C4: Add Escape close**

Add:

```tsx
  useEffect(() => {
    if (!selection) return undefined;
    const handleKeyDown = (event: globalThis.KeyboardEvent) => {
      if (event.key !== 'Escape') return;
      onClose();
    };
    window.addEventListener('keydown', handleKeyDown);
    return () => window.removeEventListener('keydown', handleKeyDown);
  }, [onClose, selection]);
```

- [ ] **Step C5: Render controls**

Render:

```tsx
  if (!selection) return null;

  const placement = placeSelectionToolbar({
    anchorRect: selection.anchorRect,
    toolbarWidth: 520,
    toolbarHeight: 44,
  });
  const minimumLineHeightPx = Math.max(
    typographyProfile.fontSizePx + 2,
    DOCUMENT_TYPOGRAPHY_LIMITS.minLineHeightPx,
  );

  return (
    <div
      className={styles.selectionTypographyToolbar}
      style={{ left: placement.x, top: placement.y }}
      role="toolbar"
      aria-label="Selection typography toolbar"
      data-selection-typography-toolbar="true"
      data-selection-typography-scope="document"
      onMouseDown={(event) => event.preventDefault()}
    >
      <span className={styles.selectionTypographyScope}>Document typography</span>
      <select
        className={styles.selectionTypographySelect}
        value={typographyProfile.fontFamily}
        onChange={handleFontFamilyChange}
        aria-label="Document font family"
        data-selection-typography-font-family="true"
      >
        {DOCUMENT_FONT_FAMILY_OPTIONS.map((option) => (
          <option key={option.id} value={option.value}>
            {option.label}
          </option>
        ))}
      </select>
      <input
        className={styles.selectionTypographyNumber}
        type="number"
        min={DOCUMENT_TYPOGRAPHY_LIMITS.minFontSizePx}
        max={DOCUMENT_TYPOGRAPHY_LIMITS.maxFontSizePx}
        step={1}
        value={typographyProfile.fontSizePx}
        onChange={handleFontSizeChange}
        aria-label="Document font size"
        data-selection-typography-font-size="true"
      />
      <input
        className={styles.selectionTypographyNumber}
        type="number"
        min={minimumLineHeightPx}
        max={DOCUMENT_TYPOGRAPHY_LIMITS.maxLineHeightPx}
        step={1}
        value={typographyProfile.lineHeightPx}
        onChange={handleLineHeightChange}
        aria-label="Document line height"
        data-selection-typography-line-height="true"
      />
      <input
        className={styles.selectionTypographyNumber}
        type="number"
        min={DOCUMENT_TYPOGRAPHY_LIMITS.minParagraphSpacingPx}
        max={DOCUMENT_TYPOGRAPHY_LIMITS.maxParagraphSpacingPx}
        step={1}
        value={typographyProfile.paragraphSpacingPx}
        onChange={handleParagraphSpacingChange}
        aria-label="Document paragraph spacing"
        data-selection-typography-paragraph-spacing="true"
      />
      <button
        type="button"
        className={styles.selectionTypographyButton}
        onClick={handleReset}
        aria-label="Reset document typography"
      >
        <RotateCcw size={13} />
      </button>
      <button
        type="button"
        className={styles.selectionTypographyButton}
        onClick={onClose}
        aria-label="Close typography toolbar"
      >
        <X size={13} />
      </button>
    </div>
  );
```
