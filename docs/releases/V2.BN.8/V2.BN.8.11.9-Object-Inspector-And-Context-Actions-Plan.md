# V2.BN.8.11.9 Object Inspector + Context Actions Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 给已经落地的普通 CanvasObject 家族补上最小对象检查器和统一安全动作层，让用户和 AI 都能看清一个对象是什么、背后挂了什么、能做哪些动作。

**Architecture:** 不新增新的 CanvasObject kind，不改变持久化主模型。新增一个前端派生服务把 `CanvasObject + CanvasPlacement + ContentMount + kind-specific extension + AI node` 编译成 inspector view model；UI layer 只消费这个 view model，并把动作派发回现有 generic save/delete 路径。Context actions 只做普通对象的安全动作，不引入 ContentGroup reuse verbs。

**Tech Stack:** React 18 + TypeScript + Vite；现有 self-owned canvas runtime；现有 generic CanvasObject persistence；现有 command surface / context menu；现有 boundary、model-contract、runtime verification scripts。

---

## 0. Version Position

8.11.3 到 8.11.8 已经证明：

```text
shape = pure CanvasObject
sticky = block-backed shape presentation
visual_connector = visual-only CanvasObject
image = asset-backed CanvasObject
table = structured-backed CanvasObject
```

现在的问题不是“再加一种对象”，而是：对象越来越多以后，用户和开发者需要一个统一地方看到：

- 这个对象的 `kind / backing / objectClass / status` 是什么。
- 它的 `placement` 在哪里，是否 export-visible。
- 它有没有 `contentMount / imageRef / connectorRef / structuredRef / presentationRef`。
- AI-readable layout 现在能不能读到它。
- 这个对象能不能安全 `open original / duplicate / delete / style / placement`。

11.9 就是这个统一对象查看与动作层的最小版本。

## 1. Scope Fence

### 1.1 This Version Does

- 新增最小 Object Inspector：
  - 选中普通 CanvasObject 后显示。
  - 展示 kind、backing、object class、status。
  - 展示 placement：x、y、width、height、rotation、surface、frameId、zIndex、export visibility。
  - 展示 truth / backing 信息：content mount、image asset、table size、connector endpoints、presentation preset。
  - 展示 AI-readable 状态：visible、summary、contentRef、imageRef、connectorRef、structuredRef 是否存在。
- 新增 inspector action availability：
  - `open_original`：只在有明确 backing content 时启用，例如 `ContentMount.targetKind='note_block'`。
  - `duplicate_object`：只对安全对象启用：pure shape、image、table。block-backed shape / sticky 暂不启用 duplicate，避免无意共享或复制 TextFlow truth。
  - `delete_object`：普通 generic CanvasObject 启用；PageFrame 不走本 inspector。
  - `toggle_export_visibility`：切换 placement 的 `visibilityState` 在 `normal` 与 `export_hidden` 之间。
  - `toggle_shape_style`：复用已有 plain/sticky style 切换，但只在现有规则允许时启用。
  - `toggle_image_fit`：复用 image contain/cover 切换。
- 在 shape / image / table / visual connector 的 context menu 中加入最小 inspector / action 入口。
- Browser smoke 验证 table 或 shape 的 inspect、duplicate、export visibility toggle、delete。
- 更新 boundary、model-contract、patch note、Review、Experience Review、CHANGELOG、current-state。

### 1.2 This Version Does Not Do

- 不做全局 top bar / ribbon。
- 不做完整组件菜单。
- 不做 PageFrame inspector；PageFrame 仍由 Layout panel / PageFrame 专属逻辑处理。
- 不做 ContentGroup Reference / Duplicate / Fork / Materialize。
- 不做 ContentGroup projection。
- 不做 Relation endpoint / Graph relation 操作。
- 不做跨 note / cross-project reuse。
- 不做 undo / redo 专门栈。
- 不做复杂样式面板、颜色 picker、层级列表、alignment toolbar。
- 不做 image asset library、table spreadsheet 操作、connector routing editor。

### 1.3 Non-Negotiable Boundary

Object Inspector 是派生视图，不是新的 truth。

```text
Right:
  Inspector reads CanvasObject + placement + extension + AI node.
  Inspector actions call existing save/delete routes.
  Duplicate is enabled only when copying is safe.
  Open original is enabled only when an actual original/backing target exists.

Wrong:
  Creating a second object truth table.
  Treating visual connector as Relation.
  Treating ContentGroup reuse verbs as generic CanvasObject actions.
  Duplicating sticky note by accidentally sharing a note_block truth.
  Letting PageFrame use generic delete/duplicate.
```

## 3. Data and UI Contract

### 3.1 Inspector View Model

Create the model in `objectInspectorService.ts`.

```ts
export type CanvasObjectInspectorActionId =
  | 'open_original'
  | 'duplicate_object'
  | 'delete_object'
  | 'toggle_export_visibility'
  | 'toggle_shape_style'
  | 'toggle_image_fit';

export interface CanvasObjectInspectorAction {
  actionId: CanvasObjectInspectorActionId;
  label: string;
  enabled: boolean;
  reason?: string;
}

export interface CanvasObjectInspectorModel {
  objectId: string;
  title: string;
  kind: CanvasObject['kind'];
  backing: CanvasObject['backing'];
  objectClass: CanvasObject['objectClass'];
  status: CanvasObject['status'];
  placement: {
    x: number;
    y: number;
    width: number;
    height: number;
    rotation: number;
    surface: CanvasSurface;
    frameId?: string;
    zIndex: number;
    exportVisible: boolean;
    visibilityState: CanvasPlacement['visibilityState'];
  };
  truth: {
    contentMount?: ContentMount;
    imageObject?: ImageCanvasObject;
    structuredObject?: StructuredCanvasObject;
    visualConnector?: VisualConnector;
    presentationRef?: CanvasObjectPresentationRef;
  };
  ai: {
    readable: boolean;
    visible: boolean;
    summary?: string;
    hasContentRef: boolean;
    hasImageRef: boolean;
    hasConnectorRef: boolean;
    hasStructuredRef: boolean;
  };
  actions: CanvasObjectInspectorAction[];
  warnings: string[];
}
```

### 3.2 Action Availability Rules

```text
open_original:
  enabled only when contentMount.targetKind === 'note_block'
  action focuses/selects the backing note block through existing onFocusBlock / onSelectBlock

duplicate_object:
  enabled for:
    shape + backing none
    image + backing asset
    table + backing structured_object
  disabled for:
    page_frame
    paragraph_block_projection
    visual_connector
    block-backed shape / sticky note
    content_group_projection

delete_object:
  enabled for generic non-page_frame CanvasObject
  uses existing onDeleteCanvasObject

toggle_export_visibility:
  enabled when placement exists
  flips placement.visibilityState:
    export_hidden -> normal
    undefined/normal/scratch/ai_hidden -> export_hidden

toggle_shape_style:
  enabled for shape objects when existing style rules allow it
  no new style truth

toggle_image_fit:
  enabled for image objects
  flips contain / cover through existing image payload save
```

### 3.3 Duplicate Rules

`duplicate_object` must offset the new placement and create new durable ids.

```text
offset: +32 x, +32 y
zIndex: original zIndex + 1
status: active
source: copied from original source only if safe; otherwise source = { duplicatedFrom: originalId }

shape:
  copy object metadata and visual style
  no content mount

image:
  copy object metadata
  reuse same assetId
  copy caption / altText / fit
  do not duplicate blob

table:
  deep-copy table payload
  regenerate rowId / columnId / cellId
  preserve text and sizes

sticky/block-backed shape:
  duplicate disabled in 11.9
  reason: requires explicit note_block clone semantics
```

## 5. Acceptance Criteria

11.9 is complete only when:

- Selecting a normal CanvasObject opens a visible inspector.
- Inspector shows identity, placement, truth/backing refs, and AI-readable state.
- Shape / image / table / visual connector all have a readable inspector state.
- Duplicate is enabled only for safe objects.
- Sticky / block-backed shape duplicate is disabled with a clear reason.
- Open original works for note_block-backed objects.
- Delete works from inspector without breaking existing context menu delete.
- Export visibility toggle persists through refresh.

## 6. Risks and Mitigations

| Risk | Severity | Mitigation |
| --- | --- | --- |
| Inspector becomes a new truth layer | High | Keep it derived from runtime model and AI node only; no new database table. |
| Duplicate accidentally shares mutable TextFlow truth | High | Disable duplicate for block-backed shape / sticky in v1. |
| Context menus and inspector disagree | Medium | Centralize action availability in `objectInspectorService.ts`. |
| PageFrame generic actions corrupt PageStack state | High | Exclude PageFrame from 11.9 generic inspector. |
| Visual connector starts looking like Relation | Medium | No label, no relation type, no endpoint role; inspect only visual endpoints. |
| Panel covers the canvas too much | Low | Use compact right-side floating panel; close button and Escape/blank selection clear selection. |
| More UI creates more noise | Medium | Keep panel visible only when an object is selected; no global top bar in this version. |
