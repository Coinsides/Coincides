# V2.BN.8.9.9 PageFrame Command Surface And Creation Patch Note

Date: 2026-06-27

Status: completed

## Summary

This patch gives PageFrame creation a real command surface instead of leaving it hidden inside the Layout panel only.

The change is intentionally small:

- Toolbar can create a new PageFrame.
- Canvas Mode blank-space right-click can create a new PageFrame.
- Canvas Mode PageFrame area right-click can duplicate, set primary, or delete that PageFrame through the shared command menu vocabulary.
- `create_page_stack` is reserved as a disabled command, because continuous PageStack / PageSlice behavior still needs its own design and implementation pass.

## Product Judgment

PageFrame is already treated as the first special CanvasObject. A special object needs an object-like command entry, not only a developer-oriented Layout panel.

This patch does not try to build the full context-menu system. It only stabilizes the first PageFrame command path so later toolbar, shortcut, right-click, and Agent proposal paths can call the same command vocabulary.

## Implementation

- Added `canvas_blank` and `page_frame_shell` command surface kinds.
- Added PageFrame command actions:
  - `create_page_frame`
  - `create_page_stack`
  - `duplicate_page_frame`
  - `set_primary_page_frame`
  - `delete_page_frame`
- Added `buildCanvasBlankMenu()` and `buildPageFrameShellMenu(...)`.
- Added toolbar PageFrame creation in `NoteChromeLayer`.
- Routed `onCreatePageFrame` through `useRuntimePresentationController` and existing `pageFrameCollectionService`.
- Added Canvas Mode context menu handling in `NoteWritingSurfaceLayer`.
- Extended model-contract and runtime-boundary checks.

## Not Included

- Continuous PageStack.
- PageSlice extraction / merge / split.
- Full per-object context-menu system.
- PageFrame drag/move/resize/configuration maturity.
- TextFlow typography controls.
- ContentGroup projection.
- Durable generic CanvasObject / CanvasPlacement database cutover.
