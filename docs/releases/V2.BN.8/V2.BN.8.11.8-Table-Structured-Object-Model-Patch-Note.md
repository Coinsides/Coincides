# V2.BN.8.11.8 Table / Structured Object Model Patch Note

> **Status:** implemented
> **Date:** 2026-06-30
> **Scope:** Structured Object Family / table object / structured CanvasObject sidecar

## 1. 本次完成了什么

8.11.8 把表格推进成第一类 `structured-backed CanvasObject`。它不是 TextFlow block，也不是图片 OCR 结果，而是通过通用 CanvasObject 管线保存身份和布局，再通过 typed sidecar 保存结构化行列数据。

边界如下：

```text
CanvasObject.kind = table
CanvasObject.backing = structured_object
CanvasObject.objectClass = structured
StructuredObjectExtension.structuredKind = table
StructuredObjectExtension.schemaVersion = table.v1
```

这一版证明 CanvasObject 不只能承载纯图形、block-backed 文本、visual connector 和 asset-backed image，也可以承载结构化数据。

## 2. 工程改动

- 新增 `structured_object_extensions` 表，用于保存结构化对象 sidecar。
- `saveCanvasObject` 新增 `kind='table'` handler，表格继续走 `canvas_objects` / `canvas_placements` 通用管线，行列和单元格进入 typed extension。
- 后端 validator 新增 table payload 校验，拒绝 malformed structured object payload。
- 客户端新增 `tableObjectService.ts`，封装 table v1 payload、结构规范化、单元格编辑、增删行列等纯模型操作。
- Runtime hydrate / engine model / AI-readable tree 接入 `structuredExtensions`，AI 可以读取 `rowCount`、`columnCount`、rows、columns 和 cell matrix。
- 新增 `TableObjectLayer.tsx`，支持表格渲染、单元格选中、双击编辑、Enter 提交、Esc 取消、blur 保存。
- Table 右键菜单新增基础操作：添加下方行、添加右侧列、删除当前行、删除当前列。
- Writing Surface 接入 table 创建、编辑、行列 mutation、保存和读回。
- Boundary / model-contract / server persistence tests 均加入 table 结构化对象覆盖。

## 3. 没有做什么

- 没有做 Excel / CSV / Word / PDF / 图片表导入。
- 没有做公式、排序、筛选、冻结行列、复杂合并单元格。
- 没有做富文本单元格。
- 没有把每个单元格变成 paragraph block。
- 没有把 table 放进 TextFlow 正文。
- 没有做 spreadsheet engine。
- 没有做 table export / PDF 精确导出。
- 没有做 ContentGroup member 复用 UI。
- 没有做大表虚拟滚动或性能专项。
- 没有做完整 object inspector / 全局组件菜单；空白画布全局建对象菜单仍留给后续版本。

## 5. 剩余风险

- 表格入口仍是工程 v1，后续需要 object inspector / context actions / 组件菜单把入口做顺。
- 当前表格是小表模型，没有大表虚拟滚动，也没有 spreadsheet-level 操作。
- 未来 Excel / Word / PDF / 图片表导入要填入同一 table payload，但导入链路尚未开始。
- 表格与 ContentGroup、PageSlice、export、工程包的关系仍需在后续版本单独设计。
