# V2.BN.8.10.4 Typography Measurement And PageFrame Sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make typography measurement, PageStack flow, cross-page block fragments, Export Preview, and AI-readable PageFrame state read the same note-level `DocumentTypographyProfile`.

**Architecture:** V2.BN.8.10.1-8.10.3 already created and exposed the note-level typography profile. V2.BN.8.10.4 adds a pure measurement service and threads that same profile into the existing PageFrame-adjacent read models without turning typography into TextFlow content truth. Measurement remains estimate-based and cheap; real auto-pagination, PDF export, and per-block typography stay outside this patch.

**Tech Stack:** TypeScript, React, Vite client, local canvas engine services, existing model/runtime boundary smoke scripts.

## 4. Design Decisions

### Measurement Is Layout Estimate Truth

Typography measurement is not content truth. The source text remains TextFlow / block content. The new service only answers layout questions such as:

- how many wrapped lines this text probably occupies;
- how high a block probably is;
- how many document lines a PageFrame content area can show.

### Average Character Width Comes From The Profile

Use `DocumentTypographyProfile.averageCharWidthPx` after normalization. If callers pass malformed profile data, normalize it through `normalizeDocumentTypographyProfile(...)` before estimating.

### Paragraph Spacing Counts Between Text Paragraphs

For plain text split by `\n`, apply `paragraphSpacingPx` between non-final paragraphs:

```ts
const paragraphSpacingTotal = Math.max(0, paragraphs.length - 1) * normalized.paragraphSpacingPx;
```

This is an estimate for document writing, not a rich text layout engine.

### PageStack Flow Uses Fit, Not Ownership

PageFrame does not own blocks. V2.BN.8.10.4 only improves the geometric decision:

```text
draft estimated bottom <= PageFrame content bottom -> stay
draft estimated bottom > PageFrame content bottom -> move or append next PageStack page
```

This does not split existing blocks. It only decides where a draft block should land when natural writing continues.

### Export Preview Explains Typography; It Does Not Export

Export Preview should tell the user and the AI-readable debug surface which typography profile the PageFrame is being interpreted with. It must not pretend to be final PDF output.

- [ ] **Step C1: Create the service**

Create the file with this public contract:

```ts
import {
  BLOCK_HORIZONTAL_CHROME,
  BLOCK_VERTICAL_CHROME,
  MIN_BLOCK_HEIGHT,
} from './runtimeLayout';
import {
  normalizeDocumentTypographyProfile,
} from './typographyProfileService';
import type {
  DocumentTypographyProfile,
} from './types';

export interface TypographyMeasurementInput {
  text: string;
  width: number;
  typography: DocumentTypographyProfile;
  title?: string | null;
  showPreview?: boolean;
  sourceReferenceCount?: number;
}

export interface TypographyTextBlockMeasurement {
  text: string;
  width: number;
  textWidth: number;
  charsPerLine: number;
  lineCount: number;
  heightPx: number;
  averageCharWidthPx: number;
  lineHeightPx: number;
  paragraphSpacingPx: number;
}

export function estimateAverageCharWidth(profile: DocumentTypographyProfile): number {
  return normalizeDocumentTypographyProfile(profile).averageCharWidthPx;
}

export function estimateTypographyTextBlockHeight({
  text,
  width,
  typography,
  title,
  showPreview = false,
  sourceReferenceCount = 0,
}: TypographyMeasurementInput): TypographyTextBlockMeasurement {
  const normalized = normalizeDocumentTypographyProfile(typography);
  const textWidth = Math.max(80, width - BLOCK_HORIZONTAL_CHROME);
  const averageCharWidthPx = estimateAverageCharWidth(normalized);
  const charsPerLine = Math.max(12, Math.floor(textWidth / averageCharWidthPx));
  const paragraphs = text.split('\n');
  const wrappedRows = paragraphs.reduce(
    (total, line) => total + Math.max(1, Math.ceil(line.length / charsPerLine)),
    0,
  );
  const titleRows = title ? 1 : 0;
  const lineCount = Math.max(1, wrappedRows) + titleRows;
  const paragraphSpacingPx = Math.max(0, paragraphs.length - 1) * normalized.paragraphSpacingPx;
  const previewExtra = showPreview ? 72 : 0;
  const sourceExtra = sourceReferenceCount > 0 ? 34 : 0;
  const heightPx = Math.max(
    MIN_BLOCK_HEIGHT,
    BLOCK_VERTICAL_CHROME + lineCount * normalized.lineHeightPx + paragraphSpacingPx + previewExtra + sourceExtra,
  );

  return {
    text,
    width,
    textWidth,
    charsPerLine,
    lineCount,
    heightPx,
    averageCharWidthPx,
    lineHeightPx: normalized.lineHeightPx,
    paragraphSpacingPx: normalized.paragraphSpacingPx,
  };
}

export function estimatePageFrameLineCapacity({
  contentHeight,
  typography,
}: {
  contentHeight: number;
  typography: DocumentTypographyProfile;
}): number {
  const normalized = normalizeDocumentTypographyProfile(typography);
  return Math.max(1, Math.floor(contentHeight / normalized.lineHeightPx));
}
```
