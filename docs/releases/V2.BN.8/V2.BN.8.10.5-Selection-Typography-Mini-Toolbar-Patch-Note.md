# V2.BN.8.10.5 Selection Typography Mini Toolbar Patch Note

- Added `SelectionTypographyToolbarLayer.tsx` as a floating typography shortcut for single TextFlow selections.
- Reused the note-level `DocumentTypographyProfile` as the only typography truth.
