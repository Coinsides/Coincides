# V2.BN.8.9.5 PageFrame Template / Background / Style Patch Note

Date: 2026-06-26

Status: implemented

## Why

8.9.3.1 gave PageFrame a print-scale baseline and 8.9.4 gave it owned page chrome slots. The next missing layer is template/style identity: PageFrame should not remain only a fixed rectangle with hardcoded visual treatment.

This patch keeps the scope conservative. It adds template/background/style tokens as PageFrame-owned state, without introducing a template library UI or changing TextFlow typography.

## What Changed

- Added `client/src/pages/Notes/canvasEngine/pageFrameTemplateService.ts`.
- Added PageFrame template contracts:
  - `PageFrameTemplateId`
  - `PageFrameBackgroundStyle`
  - `PageFrameTemplate`
- Added four first template seeds:
  - `a4_portrait`
  - `letter_portrait`
  - `screen_note`
  - `custom`
- Extended `PageFrameModel` with optional `templateId` and `background`.
- Extended `PageFrameExtension` with:
  - `templateId`
  - `background`
  - `defaultTypographyToken`
- Runtime PageFrame extension assembly now resolves a template for every PageFrame.
- Canvas AI-readable PageFrame nodes now expose:
  - `pageFrameRef.templateId`
  - `pageFrameRef.defaultTypographyToken`
  - `pageFrameStyle.background`
- The writing surface exposes stable template/background DOM markers:
  - `data-page-frame-template`
  - `data-page-frame-background`
- PageFrame background, border, and shadow now flow through CSS variables:
  - `--page-frame-background`
  - `--page-frame-border-color`
  - `--page-frame-shadow`
- Added contract coverage proving template application changes PageFrame layout/style state without mutating TextFlow content.

## Not Included

- No template picker UI.
- No rich template library.
- No editable PageFrame background panel.
- No white-paper visual redesign pass.
- No TextFlow font/size/line-height controls.
- No export preview refinement.
- No crossing-object export policy.
- No CanvasObject database migration.
