# V2.BN.8.9.7 Crossing Object Export Policy Patch Note

Date: 2026-06-26

Status: implemented

## Why

8.9.6 made Export Preview PageFrame-aware, but crossing objects were still only a warning bucket. That left export interpretation vague: an object could visually intersect a PageFrame, but the system had no stable rule for whether it should be exported, clipped, excluded, or deferred to manual choice.

This patch defines the first crossing-object export policy layer without changing TextFlow content and without moving objects.

## What Changed

- Added crossing export policy contracts in `client/src/pages/Notes/canvasEngine/types.ts`.
- Added `DEFAULT_PAGE_FRAME_CROSSING_EXPORT_POLICY = include_if_center_inside`.
- Added `resolvePageFrameCrossingExportDecision` in `client/src/pages/Notes/canvasEngine/geometry.ts`.
- Supported policy names:
  - `exclude_workspace`
  - `include_if_center_inside`
  - `include_if_intersects`
  - `clip_to_page_frame`
  - `manual`
- Export Preview rows can now carry an `exportPolicy` decision.
- `ExportPreviewModel` now exposes `crossingExportPolicy`.
- Export Preview included/excluded counts now use policy interpretation for crossing/workspace-only rows.
- `ExportPreviewLayer.tsx` now displays the active crossing policy and per-row policy decision.
- Added model-contract coverage for default, include-if-intersects, exclude-workspace, clip, manual, and workspace-only cases.
- Added runtime-boundary coverage for the new geometry policy service boundary and UI markers.

## Policy Rules

- Policy changes export interpretation only.
- Policy does not mutate TextFlow content.
- Policy does not move, resize, or rebase Canvas placements.
- AI-readable layout should continue to report actual object bbox and boundary state.
- The first default is conservative: `include_if_center_inside`.

## Not Included

- No final PDF/export engine.
- No actual export clipping renderer.
- No manual export decision UI.
- No per-note/per-frame persisted policy picker.
- No ContentGroup projection.
- No Relation runtime.
- No Agent write path.

## Follow-Up

- Final export/PDF generation should consume this policy layer later.
- `clip_to_page_frame` currently records clipped geometry for interpretation; it does not render a clipped PDF output yet.
- `manual` currently records that a manual decision is required; it does not open a decision UI yet.
- Later versions can add a UI picker for crossing policy per export job, PageFrame, or note.
