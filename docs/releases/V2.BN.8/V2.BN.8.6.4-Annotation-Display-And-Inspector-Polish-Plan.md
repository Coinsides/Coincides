# V2.BN.8.6.4 Annotation Display And Inspector Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILLS: Use superpowers:executing-plans to implement this plan task-by-task. Use `impeccable` before changing visual UI. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 annotation 显示层从“能用”推进到“不打扰写作”：label 可以总开关显示/隐藏，badge 靠近被标注文字，多个 label 局部聚合，Annotation Stack 更清楚，SelectionDraft 工具条更稳定。

**Architecture:** V2.BN.8.6.4 只处理 annotation display / inspector / selection-toolbar polish，不改变 AnnotationTruth 的数据真相，也不重写完整 selection engine。新增一个轻量 `annotationDisplayService.ts` 负责可见性、badge 聚合和显示摘要；React layer 只消费这个 service 的结果。Preview 继续承载 overlay visibility 开关，Annotation Stack 继续承载管理和检查。

**Tech Stack:** React 18, TypeScript, Vite, Coincides Canvas Engine runtime, AnnotationTruth / AnnotationRange, TextFlow / TextUnit, AnnotationInspectorPanel, AnnotationOverlayLayer, SelectionToolbarLayer, ExportPreviewLayer, model contract smoke, Henry manual visual pass.

### In Scope

- Preview panel 增加 `Label overlay` 总开关。
- 关闭 label overlay 时，正文 annotation highlight、inline badge、block-level annotation badge 都隐藏。
- 选中 annotation 或打开 Annotation Stack 时，Inspector 仍可显示被选中的 annotation 内容。
- Text-backed annotation badge 不再堆在 block 右上角；它跟随对应 TextUnit / text range 附近显示。
- 多个 annotation 落在同一段局部文本时，显示局部聚合 badge，例如 `Definition +2`。
- block-level annotation 继续允许使用 block-level badge，因为它没有更小的文本锚点。

- Selection toolbar 保持轻量、临时、可逃离：Esc、关闭按钮、空白点击都能清除 draft / toolbar。

## 1. Product Rule

用户需要两种状态：

```text
Label overlay on
  正文显示 annotation highlight。
  被标注文字附近显示 label badge / cluster。
  用户可以通过 badge 打开 Annotation Stack。

Label overlay off
  正文保持干净，不显示 annotation highlight / label badge。
  Annotation truth 不删除、不隐藏、不改变状态。
  用户重新打开 overlay 后，所有 label 恢复显示。
```

`hide annotation` 和 `label overlay off` 不是一回事：

```text
hide annotation
  改 annotation 自己的 status。
  这个 annotation 本身不再参与默认显示。

label overlay off
  只改当前 note UI 的显示模式。
  annotation truth 仍然 active。
```

```ts
import type { AnnotationTruthV1 } from './runtimeDataTypes';
import { annotationVisibleInHierarchy } from './annotationHierarchyService';

export interface AnnotationDisplayStateV1 {
  labelsVisible: boolean;
}

export interface AnnotationBadgeClusterV1 {
  anchor_kind: 'text_unit' | 'block';
  block_id: string;
  text_unit_id?: string;
  annotation_ids: string[];
  labels: string[];
  primary_label: string;
  extra_count: number;
  selected: boolean;
}

export const DEFAULT_ANNOTATION_DISPLAY_STATE: AnnotationDisplayStateV1 = {
  labelsVisible: true,
};

export function visibleAnnotationsForDisplay(input: {
  annotations: AnnotationTruthV1[];
  displayState: AnnotationDisplayStateV1;
}): AnnotationTruthV1[] {
  if (!input.displayState.labelsVisible) return [];
  return input.annotations.filter((annotation) => annotationVisibleInHierarchy({
    annotation,
    annotations: input.annotations,
  }));
}
```

- [ ] **Step 2: Add cluster builder**

Add:

```ts
function unique(values: string[]): string[] {
  return Array.from(new Set(values));
}

function selectedFirst(input: {
  annotations: AnnotationTruthV1[];
  selectedAnnotationIds: string[];
}): AnnotationTruthV1[] {
  const selected = new Set(input.selectedAnnotationIds);
  return [...input.annotations].sort((a, b) => {
    const aSelected = selected.has(a.id) ? 1 : 0;
    const bSelected = selected.has(b.id) ? 1 : 0;
    if (aSelected !== bSelected) return bSelected - aSelected;
    return input.annotations.indexOf(a) - input.annotations.indexOf(b);
  });
}

function clusterFromAnnotations(input: {
  anchorKind: 'text_unit' | 'block';
  blockId: string;
  textUnitId?: string;
  annotations: AnnotationTruthV1[];
  selectedAnnotationIds: string[];
}): AnnotationBadgeClusterV1 | null {
  if (input.annotations.length === 0) return null;
  const ordered = selectedFirst({
    annotations: input.annotations,
    selectedAnnotationIds: input.selectedAnnotationIds,
  });
  const selected = ordered.some((annotation) => input.selectedAnnotationIds.includes(annotation.id));
  return {
    anchor_kind: input.anchorKind,
    block_id: input.blockId,
    text_unit_id: input.textUnitId,
    annotation_ids: ordered.map((annotation) => annotation.id),
    labels: unique(ordered.map((annotation) => annotation.raw_label)),
    primary_label: ordered[0].raw_label,
    extra_count: Math.max(0, ordered.length - 1),
    selected,
  };
}
```

- [ ] **Step 3: Add text-unit and block cluster APIs**

Add:

```ts
export function buildTextUnitAnnotationCluster(input: {
  annotations: AnnotationTruthV1[];
  displayState: AnnotationDisplayStateV1;
  blockId: string;
  textUnitId: string;
  selectedAnnotationIds?: string[];
}): AnnotationBadgeClusterV1 | null {
  const selectedAnnotationIds = input.selectedAnnotationIds || [];
  const annotations = visibleAnnotationsForDisplay({
    annotations: input.annotations,
    displayState: input.displayState,
  }).filter((annotation) => annotation.ranges.some((range) => (
    range.block_id === input.blockId
    && range.text_unit_id === input.textUnitId
    && (range.target_kind === 'text_span' || range.target_kind === 'text_unit')
  )));
  return clusterFromAnnotations({
    anchorKind: 'text_unit',
    blockId: input.blockId,
    textUnitId: input.textUnitId,
    annotations,
    selectedAnnotationIds,
  });
}

export function buildBlockAnnotationCluster(input: {
  annotations: AnnotationTruthV1[];
  displayState: AnnotationDisplayStateV1;
  blockId: string;
  selectedAnnotationIds?: string[];
}): AnnotationBadgeClusterV1 | null {
  const selectedAnnotationIds = input.selectedAnnotationIds || [];
  const annotations = visibleAnnotationsForDisplay({
    annotations: input.annotations,
    displayState: input.displayState,
  }).filter((annotation) => annotation.ranges.some((range) => (
    range.block_id === input.blockId
    && range.target_kind === 'block'
  )));
  return clusterFromAnnotations({
    anchorKind: 'block',
    blockId: input.blockId,
    annotations,
    selectedAnnotationIds,
  });
}
```

## 7. Acceptance Boundary

V2.BN.8.6.4 passes when:

- label overlay can be globally shown and hidden from Preview;
- global overlay hide does not mutate annotation truth;
- text-backed annotation labels no longer pile at block top-right;
- local multi-label cluster opens Annotation Stack correctly;
- block-level annotation still has a block-level fallback badge;
- Annotation Stack is visibly flatter and easier to scan;
- selection toolbar no longer exposes confusing internal `Draft` wording;
- Esc, close button, and blank click clear temporary selection UI predictably;
- model contract smoke and changed-file secret scan pass;
- Henry manual visual pass accepts the display behavior.

## 8. Explicit Deferrals

These stay outside V2.BN.8.6.4:

- per-label visibility filter;
- full label style editor beyond the controlled color-token palette;
- complete custom selection engine rewrite;
- cross-block selection productization;
- dragging or moving selected ranges;
- CanvasObject / image / drawing annotation display;
- relation endpoint editor;
- Annotation Stack final product-grade visual redesign with full design-system review.

V2.BN.8.6.4 should make annotation display calm and usable. It should not become a new foundation rewrite.
