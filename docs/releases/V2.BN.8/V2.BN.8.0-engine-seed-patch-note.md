# V2.BN.8.0 Patch Note - Canvas Engine Seed

## 本次补丁目标

给 V2.BN.8 新分支加入第一版 Canvas Engine 样本，但不重写已有 Note 编辑体验。

## 做了什么

- 新增 `client/src/pages/Notes/canvasEngine/`：
  - `types.ts`：定义 NoteCanvas、PageFrame、BlockPlacement、CanvasObject reserve、RelationEndpoint reserve；
  - `geometry.ts`：定义 world/screen 坐标转换、viewport world rect、visible block 计算；
  - `engineModel.ts`：定义 `Self-owned Minimal Hybrid NoteCanvas Engine` 第一版 runtime seed。
- `NoteDetail.tsx` 接入 `noteCanvasRuntime`：
  - 当前 block 渲染仍沿用旧 runtime；
  - PageFrame、workspace width、visible block count 开始由 engine seed 提供；
  - `better_notebook_layout` payload 升级到 `V2.BN.8`，并预留 `rotation`。
- `NoteDetail.module.css` 改为读取 PageFrame / world width CSS 变量，减少硬编码。

## 没做什么

- 没有实现真正 pan / zoom。
- 没有实现 virtualization。
- 没有重写 selection / hit-testing。
- 没有引入外部 canvas engine。
- 没有 migration。

## 验证

- `client` build：通过。
- browser smoke：受 Chrome remote debugging Allow prompt 阻塞，未完成。
