# V2.BN.8.11.11 Structured Object Family Closure Gate Plan

> **Status**: active
> **Date**: 2026-06-30
> **Scope**: V2.BN.8.11 ordinary / structured CanvasObject family closure

## 1. Route Decision

Henry 决定跳过 `V2.BN.8.11.10 First Structured Family Gate`，直接进入 `V2.BN.8.11.11 Closure Gate`。

这不是取消 diagram / mind map / chart / math graph 等结构化对象候选，而是确认它们不应该阻塞 8.11 的普通对象家族收口。8.11 的核心目标是：

```text
kind-general CanvasObject pipeline
+ ordinary object family
+ AI-readable layout
+ safe object actions
```

复杂结构化家族可以在后续按证据单独开版本，而不是塞进当前收口。

## 2. Closure Questions

8.11 可以关闭，前提是下面问题都有清晰答案：

- CanvasObject 管线是否已经 kind-general？
- shape / sticky note / visual connector / image / table 是否都骑通用管线？
- visual connector 是否仍然只是 visual-only，不污染 Relation？
- table 是否证明 AI-readable layout 可以读取结构化对象？
- Object Inspector 是否让普通对象的 kind / backing / placement / mount / AI-readable state 可见？
- ContentGroup projection 是否明确顺延到 8.12，而不是被普通对象家族未完成项阻塞？
- 剩余风险是否已经分流到后续版本，而不是隐藏在“已完成”里？

## 3. Verification Gate

必须运行：

```powershell
npm run verify:v2-bn8-runtime
cd server; npm run test:v2
git diff --check
npm run check:changed-file-secrets
```

如果 `verify:v2-bn8-runtime` 已包含 diff / secrets，仍需在最后补跑一次轻量检查，覆盖 closure 文档本身。

## 4. Closure Report Required

产出：

```text
docs/releases/V2.BN.8/V2.BN.8.11.11-Structured-Object-Family-Closure-Report.md
```

报告必须包含：

- closure judgment；
- completed 8.11 scope；
- stable enough；
- accepted carry-forward；
- 8.12 readiness；
- verification evidence；
- manual test status。

## 5. Non-goals

- 不新增 8.11.10 的第一类复杂结构化对象。
- 不实现 ContentGroup projection / reuse verbs。
- 不实现 Relation runtime。
- 不实现完整 top bar / component menu。
- 不做 real PDF/export execution。
- 不清理整个脏工作区。
