# V2.BN.8.6.3 Source-Backed Annotation Range Editing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Annotation Stack 里的 range preview 和原始 TextFlow source 建立双向同步：改 preview 必须回写原文，改原文必须刷新 annotation range cache。

**Architecture:** `range_text_cache` 只能是缓存，不能成为第二份文本真相。本版本在现有 `rangeRebaseService.ts` 上增加 source-backed edit service，把 TextFlow text diff、range rebase、child annotation preservation、Annotation Stack range editor 和 model contract smoke 串起来。UI 仍保持轻量，8.6.3 不做 Annotation Stack 视觉重设计。

**Tech Stack:** React 18, TypeScript, Vite, Coincides Canvas Engine runtime, TextFlow / TextUnit, AnnotationTruth / AnnotationRange, AnnotationInspectorPanel, range rebase service, model contract smoke, Henry manual visual pass.


## 1. Product Rule

用户看到的是两类可编辑文字，但它们的职责不同：

```text
Annotation label input
  改的是 annotation 的名字。
  不改变原文。
  不改变 range preview。

Annotation range preview editor
  改的是被标记的原文片段。
  必须回写 TextFlow source。
  必须刷新 range_text_cache。
```

验收例子：

```text
原文 TextUnit:
  Price drives demand.

Annotation:
  label = "definition"
  range preview = "demand"

用户把 label 改成空或改成 "concept":
  原文仍然是 "Price drives demand."
  range preview 仍然是 "demand"

用户把 range preview 从 "demand" 改成 "market demand":
  原文变成 "Price drives market demand."
  annotation range cache 变成 "market demand"
```

## 3. Data Rules

### 3.1 Cache Is Not Truth

```ts
AnnotationRangeV1.range_text_cache
```

is a display cache only.

Text-backed ranges must derive their current text from:

```text
target_kind = "text_span"
  -> block_id + text_flow_id + text_unit_id + start_offset + end_offset

target_kind = "text_unit"
  -> block_id + text_flow_id + text_unit_id
```

### 3.2 Supported First-Version Edits

8.6.3 supports same-TextUnit text edits:

```text
text_span range preview edit
  supported

text_unit range preview edit
  supported

block range preview edit
  not editable in 8.6.3

canvas_object / source_region range preview edit
  not editable in 8.6.3

cross-block range preview edit
  not editable in 8.6.3
```

### 3.3 Rebase Policy

For a TextUnit text edit:

```text
range before edit
  keep offsets, refresh cache

range after edit
  shift offsets by delta, refresh cache

range equal to edited range
  update end_offset to start_offset + replacement length, refresh cache

text_unit range
  cache becomes full new TextUnit text

range overlapping edited boundary
  keep annotation object, mark range id in invalidated_range_ids, keep safe cache, show warning in debug output
```

Do not silently delete annotations.

- [ ] **Step 1: Add text diff helper**

Add a helper that derives one conservative edit interval from old/new text.

```ts
export interface TextEditDelta {
  editedStartOffset: number;
  editedEndOffset: number;
  replacementText: string;
}

export function deriveSingleTextEditDelta(oldText: string, newText: string): TextEditDelta {
  if (oldText === newText) {
    return {
      editedStartOffset: oldText.length,
      editedEndOffset: oldText.length,
      replacementText: '',
    };
  }

  let prefix = 0;
  while (
    prefix < oldText.length
    && prefix < newText.length
    && oldText[prefix] === newText[prefix]
  ) {
    prefix += 1;
  }

  let suffix = 0;
  while (
    suffix < oldText.length - prefix
    && suffix < newText.length - prefix
    && oldText[oldText.length - 1 - suffix] === newText[newText.length - 1 - suffix]
  ) {
    suffix += 1;
  }

  return {
    editedStartOffset: prefix,
    editedEndOffset: oldText.length - suffix,
    replacementText: newText.slice(prefix, newText.length - suffix),
  };
}
```

- [ ] **Step 2: Add annotation-wide TextUnit rebase helper**

Add a helper that applies `rebaseTextUnitAnnotationRanges` to every annotation containing ranges in the edited TextUnit.

```ts
export interface RebaseAnnotationsForTextUnitEditResult {
  next_annotations: AnnotationTruthV1[];
  invalidated_range_ids: string[];
  warnings: string[];
}

export function rebaseAnnotationsForTextUnitEdit(input: {
  annotations: AnnotationTruthV1[];
  blockId: string;
  textFlowId: string;
  textUnitId: string;
  oldText: string;
  newText: string;
}): RebaseAnnotationsForTextUnitEditResult {
  const delta = deriveSingleTextEditDelta(input.oldText, input.newText);
  const touchedRanges = input.annotations.flatMap((annotation) => annotation.ranges).filter((range) => (
    range.block_id === input.blockId
    && range.text_flow_id === input.textFlowId
    && range.text_unit_id === input.textUnitId
  ));
  const rebase = rebaseTextUnitAnnotationRanges({
    textUnitId: input.textUnitId,
    oldText: input.oldText,
    newText: input.newText,
    editedStartOffset: delta.editedStartOffset,
    editedEndOffset: delta.editedEndOffset,
    replacementText: delta.replacementText,
    ranges: touchedRanges,
  });
  const rangesById = new Map(rebase.next_ranges.map((range) => [range.id, range]));
  return {
    next_annotations: input.annotations.map((annotation) => ({
      ...annotation,
      ranges: annotation.ranges.map((range) => rangesById.get(range.id) || range),
    })),
    invalidated_range_ids: rebase.invalidated_range_ids,
    warnings: rebase.warnings,
  };
}
```

- [ ] **Step 3: Add source-backed range preview edit helper**

Add a helper that edits a selected `AnnotationRangeV1` and returns the exact TextUnit text change plus rebased annotations.

```ts
export interface SourceBackedAnnotationRangeEditResult {
  next_text: string;
  next_annotations: AnnotationTruthV1[];
  invalidated_range_ids: string[];
  warnings: string[];
}

export function applySourceBackedAnnotationRangeEdit(input: {
  annotations: AnnotationTruthV1[];
  annotationId: string;
  rangeId: string;
  currentText: string;
  replacementText: string;
}): SourceBackedAnnotationRangeEditResult | null {
  const annotation = input.annotations.find((item) => item.id === input.annotationId);
  const range = annotation?.ranges.find((item) => item.id === input.rangeId);
  if (!annotation || !range || !range.block_id || !range.text_flow_id || !range.text_unit_id) return null;

  const start = range.target_kind === 'text_span' ? range.start_offset ?? 0 : 0;
  const end = range.target_kind === 'text_span' ? range.end_offset ?? start : input.currentText.length;
  const nextText = `${input.currentText.slice(0, start)}${input.replacementText}${input.currentText.slice(end)}`;

  const rebase = rebaseTextUnitAnnotationRanges({
    textUnitId: range.text_unit_id,
    oldText: input.currentText,
    newText: nextText,
    editedStartOffset: start,
    editedEndOffset: end,
    replacementText: input.replacementText,
    ranges: input.annotations.flatMap((item) => item.ranges).filter((candidate) => (
      candidate.block_id === range.block_id
      && candidate.text_flow_id === range.text_flow_id
      && candidate.text_unit_id === range.text_unit_id
    )),
  });

  const rangesById = new Map(rebase.next_ranges.map((item) => [item.id, item]));
  return {
    next_text: nextText,
    next_annotations: input.annotations.map((item) => ({
      ...item,
      ranges: item.ranges.map((candidate) => rangesById.get(candidate.id) || candidate),
    })),
    invalidated_range_ids: rebase.invalidated_range_ids,
    warnings: rebase.warnings,
  };
}
```

```ts
function captureTextareaPreviewSelection(
  textarea: HTMLTextAreaElement,
): Omit<RangeChildDraft, 'parentAnnotationId' | 'parentRangeId'> | null {
  const startOffset = textarea.selectionStart;
  const endOffset = textarea.selectionEnd;
  if (startOffset === endOffset) return null;

    endOffset: end,
```

```ts
const handleBlockTextFlowChange = async (
  block: NoteBlock,
  nextTextFlow: TextBlockContentV1,
) => {
  const previousTextFlow = blockTextFlowDrafts[block.id] || getTextFlowContent(block.content_json);
  onBlockTextFlowChange((current) => ({ ...current, [block.id]: nextTextFlow }));
  if (!previousTextFlow) return;

  let nextAnnotations = annotationTruths;
  previousTextFlow.units.forEach((previousUnit) => {
    const nextUnit = nextTextFlow.units.find((unit) => unit.id === previousUnit.id);
    if (!nextUnit || nextUnit.text === previousUnit.text) return;
    const rebase = rebaseAnnotationsForTextUnitEdit({
      annotations: nextAnnotations,
      blockId: block.id,
      textFlowId: textFlowIdForBlock(block.id),
      textUnitId: previousUnit.id,
      oldText: previousUnit.text,
      newText: nextUnit.text,
    });
    nextAnnotations = rebase.next_annotations;
  });

  if (nextAnnotations !== annotationTruths) {
    await onSaveAnnotationTruths(nextAnnotations);
  }
};
```
