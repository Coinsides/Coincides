# V2.BN.8.9.10 Canvas World Auto-Expand And PageFrame Focus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make newly created PageFrames visible and reachable by letting the finite Canvas world expand around real content, then focusing the selected/new PageFrame.

**Architecture:** Keep the current finite Canvas model. Derive the Canvas world from PageFrame, block, and reserve object bounding boxes, pass that dynamic world into viewport clamping, and add a small PageFrame focus path that toolbar, blank Canvas command, and Layout panel can share.

**Tech Stack:** React + TypeScript, Vite, existing Canvas runtime model, `viewportService`, `pageFrameCollectionService`, `useViewportTransformController`, `useRuntimePresentationController`, `NoteChromeLayer`, `NoteWritingSurfaceLayer`, and V2.BN.8 model/boundary smoke scripts.

---

## 0. Scope Lock

### This version does

- Derive Canvas world bounds from current PageFrames, block placements, and reserved Canvas objects.
- Keep Page Mode world behavior unchanged.
- Use dynamic world bounds when clamping pan, scroll, zoom, and viewport resize.
- Focus/select the PageFrame that was created, inserted, duplicated, or selected from the Layout panel.
- Let the Layout panel row itself jump to a PageFrame, instead of only exposing small action buttons.
- Add model and boundary checks so PageFrames outside the old default world cannot disappear silently again.

### This version does not do

- Full infinite Canvas / chunked world.
- Continuous PageStack.
- PageStack-scoped page numbering. Current PageFrame collection numbering remains transitional and must not become the future Continuous PageFrame model.
- PageSlice extraction / merge / split.
- PageFrame drag / move / resize.
- Full context-menu system.
- TextFlow typography maturity.
- ContentGroup projection.

- [x] **Step 1: Add failing checks**

Add a check requiring:

```ts
const farFrame = createRuntimePageFrame({
  contentX: DEFAULT_PAGE_FRAME_CONTENT_INSET.left,
  height: DEFAULT_PAGE_FRAME_HEIGHT,
});
const farPageFrame = {
  ...farFrame,
  id: 'page-frame-far',
  x: 3600,
  y: 5200,
};
const world = createRuntimeWorld('canvas', DEFAULT_PAGE_FRAME_HEIGHT, {
  pageFrames: [farFrame, farPageFrame],
  blockPlacements: [],
  canvasObjectReserve: [],
});
assertAtLeast(world.width, farPageFrame.x + farPageFrame.width + 800, 'canvas world expands to include far PageFrame width');
assertAtLeast(world.height, farPageFrame.y + farPageFrame.height + 800, 'canvas world expands to include far PageFrame height');
```

Run:

```text
npm run smoke:canvas-engine-model-contract
```

Expected: fail because `createRuntimeWorld` does not accept runtime content and still returns the fixed default Canvas world.

- [x] **Step 2: Implement dynamic finite world derivation**

Add to `viewportService.ts`:

```ts
const CANVAS_WORLD_PADDING = 800;

export function createRuntimeWorld(
  surfaceMode: SurfaceMode,
  pageFrameHeight: number,
  options: {
    pageFrames?: PageFrameModel[];
    blockPlacements?: BlockPlacementModel[];
    canvasObjectReserve?: CanvasObjectReserve[];
  } = {},
): CanvasWorldModel
```

Rules:

1. Page Mode returns the current page world unchanged.
2. Canvas Mode starts from `DEFAULT_CANVAS_WORLD`.
3. Include all PageFrame outer rects.
4. Include all block placement rects.
5. Include all reserve object rects.
6. Expand right and bottom by `CANVAS_WORLD_PADDING`.
7. Keep origin at `{ x: 0, y: 0 }` for this version.

- [x] **Step 3: Wire runtime model**

In `useNoteCanvasLayoutModel.ts`, call:

```ts
createRuntimeWorld(surfaceMode, pageContentHeight, {
  pageFrames: runtimePageFrameCollection.pageFrames,
  blockPlacements: canvasBlockPlacements,
  canvasObjectReserve: [],
})
```

- [x] **Step 4: Verify green**

Run:

```text
npm run smoke:canvas-engine-model-contract
```

Expected: pass.

## 9. Done criteria

- New PageFrames no longer disappear beyond the fixed old Canvas world.
- Canvas world grows from real content while staying finite.
- Viewport clamp uses the dynamic world.
- Creation and Layout row selection can focus PageFrames.
- Page Mode remains unchanged.
- No continuous PageStack or full infinite Canvas is attempted in this version.
- Future PageStack / Continuous PageFrame must treat page numbers as stack-local. `PageFrameCollection` is the note-level Canvas object collection, not a continuous document group.
