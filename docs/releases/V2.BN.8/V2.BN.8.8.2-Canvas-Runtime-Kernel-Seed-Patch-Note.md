# V2.BN.8.8.2 Canvas Runtime Kernel Seed Patch Note

Date: 2026-06-25

Status: completed scoped engineering pass and verified.

## Summary

8.8.2 承接 8.8.1 的 Canvas Data Contract，把合同推进到最小 runtime kernel。

这一步仍然不追求可见 UI 改造，而是让 CanvasObject / CanvasPlacement / ContentMount 能进入一个可计算的 scene runtime：

```text
Canvas Data Contract -> Canvas Scene Runtime -> Hit Test / Selection / Command Delta
```

它回答的是 Canvas Engine 最底层的问题：

- 对象是否能进入统一 scene index？
- pan / zoom 后，命中测试是否仍然基于 world 坐标？
- selection 是否能以 CanvasObject id 为中心，而不是散落在 DOM 或 block UI 里？
- command 是否能先变成 delta，而不是让 UI 事件直接到处写状态？

## Completed

- Added `canvasRuntimeKernelService.ts` as the first pure runtime kernel service.
- Added `CanvasPlacementIndex`:
  - `all`
  - `visible`
  - `zOrdered`
  - `byObjectId`
  - `byPlacementId`
- Added `CanvasSceneRuntime`:
  - keeps the runtime model;
  - indexes CanvasObjects;
  - indexes CanvasPlacements;
  - indexes ContentMounts.
- Added hit-test seed:
  - accepts viewport point;
  - converts it into world point;
  - resolves topmost visible placement by z-index.
- Added selection seed:
  - selection is based on valid CanvasObject ids;
  - missing ids are ignored;
  - first valid object becomes primary selection.
- Added move command / delta seed:
  - `createMoveCanvasObjectCommand`;
  - `createCanvasDeltaForCommand`;
  - move command produces `canvas_placement` delta only.
- Added `worldPointToViewportPoint` to complete the current viewport/world coordinate boundary.
- Exported the runtime kernel service from the canvasEngine index.
- Updated model contract smoke with a new `Canvas runtime kernel seed` group.
- Updated canvas runtime boundary check so the kernel service becomes part of the protected architecture.

## Engineering Boundary

This patch keeps the runtime kernel pure and does not bind it directly to React components yet.

Important boundaries:

- Hit test reads runtime scene data; it does not query DOM layout.
- Placement remains world-coordinate data.
- Selection is CanvasObject-centered, not block-DOM-centered.
- Command delta is a seed for future history / undo / Agent proposal integration; it does not write durable data yet.
- Move command updates placement semantics only; it does not mutate TextFlow content.

## Not Included

- No visible pan / zoom UI rewrite.
- No full `CanvasRuntimeProvider` state machine rewrite.
- No drag / resize migration to command dispatcher.
- No durable CanvasObject database table.
- No PageFrame v1 UI behavior.
- No shape creation UI.
- No visual connector drawing UI.
- No ContentGroup projection.
- No Relation runtime, Agent write path, or GraphRAG.

## Remaining Risks

- The kernel service is not yet wired into all existing drag / resize / selection UI paths.
- Hit testing currently uses rectangular placement bounds and ignores rotation.
- Command delta supports the first move-object seed only; resize/style/delete/create command execution remains later work.
- Scene index is rebuilt from runtime model in memory; it is not yet an incremental index with cache invalidation.
