## Buttons Hidden Or Renamed

- Selection toolbar now only exposes `Label` and close for multi-range drafts.
- Text selection menu uses `Create group` for direct creation and `Open groups` for surface opening.
- Label highlight menu uses `Create group from label`.
- Block shell menu uses `Create group from block`.
- Groups Rail row action is now `Add current item`, because it has a concrete target group.
- Single Editor hides the rough `Use members` Petal shortcut.
- User-visible `Annotate` wording was tightened toward `Label` in row tools, toolbar aria labels, and slash feedback.

## Manual Test Checklist

- Select one normal text range: no large toolbar should appear.
- Right-click selected text: `Label`, `Create group`, and `Open groups` should be visible.
- Choose `Create group`: a new ContentGroup should be created from that selection and Groups Rail should open.
- Create or select a Label, right-click its highlight, then choose `Create group from label`: the new group should contain that label/range input.
- Right-click a block shell and choose `Create group from block`: the new group should contain a block member.
- Open Groups Rail: no targetless top-level `Add selected` button should appear.
- Expand a group row: `Add current item` should be present only as a target-specific action.
- Open Single Editor: `Use members` should not appear on Petal rows.

## Deferred To 8.6.25+

- Direct add to an already active group from a generic right-click menu needs a stable active-group target model.
- Inline formula/code/link conversion stays out of the toolbar until TextFlow inline editing is stable.
- Petal assignment from exact fragments is deferred to the Petal assignment version.
- Full visual parity with the OpenDesign shell is deferred to the later visual parity version.
