# V2.BN.8.6.30 TextFlow Drag-Reorder / Insert Safety Gate Patch Note

## What Changed

- Added `insertPlainTextIntoTextFlow` as the explicit copy-insert helper for drag insertion.
- TextBlock text units can accept Draft Range / Label payload drops.
- The first implementation inserts copied plain text at the nearest textarea offset.
- Drop into TextFlow uses the same TextFlow save path as normal editing.

## Safety Boundary

Supported:

- copy insert Draft Range / Label text into an existing TextBlock;
- preserve source text and source Label;
- save inserted TextFlow content through the normal block save path.

Not supported:

- destructive move;
- true reorder of the original source text;
- full offset rebase for every downstream range.

If source ranges become stale after manual editing, future integrity/refresh work must handle that explicitly.
