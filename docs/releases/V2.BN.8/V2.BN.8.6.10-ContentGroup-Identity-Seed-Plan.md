# V2.BN.8.6.10 ContentGroup Identity Seed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the confusing ContentGroup `interpretation` field with a clear `identity` state machine on ContentGroup itself. Accepted identity is a ContentGroup state, not a second object.

**Architecture:** ContentGroup remains the only user-facing content package object. `identity.status = accepted` means this ContentGroup is review-accepted for AI reading and later relation work. Draft identity replaces the old interpretation concept. GroupFolder / ContentGroup Gallery will organize and browse ContentGroups; list/index behavior is derived view behavior rather than a separate truth table.

**Tech Stack:** React 18, TypeScript, Vite, ContentGroup runtime metadata, ContentGroup service helpers, model contract smoke scripts.

---

## 1. Product Rule

```text
ContentGroup
  content package

ContentGroup.identity.status = draft
  former interpretation / possible understanding

ContentGroup.identity.status = accepted
  reviewed / accepted content identity

GroupFolder / ContentGroup Gallery
  future organization and derived browsing/query view over ContentGroups
```

Users should not manage a separate accepted-content object. They should only see ContentGroup plus a simple identity status.

## 2. Identity State Machine

Allowed states:

```text
none
  ordinary content package with no knowledge identity

draft
  AI / user / system has proposed role/topic/summary, but it has not been accepted

accepted
  this ContentGroup is accepted for ContentGroup Gallery / future AI reading / later relation work

rejected
  this ContentGroup should not currently be treated as accepted content identity

archived
  previously useful identity is hidden from default index views
```

Required transitions:

```text
none -> draft
draft -> accepted
draft -> rejected
accepted -> draft when members or Petals change
accepted -> archived
rejected -> draft
archived -> draft
```

## 3. File Responsibility Map

- `client/src/pages/Notes/canvasEngine/runtimeDataTypes.ts`

```ts
function normalizeContentGroupIdentity(group: Partial<ContentGroupV1> & { interpretation?: { role?: string | null; topic?: string | null; brief?: string | null } }): ContentGroupIdentityV1 {
  const existing = group.identity;
  const oldInterpretation = group.interpretation;
  const now = new Date().toISOString();

  return {
    status: existing?.status || (oldInterpretation ? 'draft' : 'none'),
    role: cleanOptionalText(existing?.role ?? oldInterpretation?.role),
    topic: cleanOptionalText(existing?.topic ?? oldInterpretation?.topic),

    created_by: existing?.created_by || 'human',
    reviewed_by: existing?.reviewed_by || null,
    confidence: typeof existing?.confidence === 'number' ? existing.confidence : null,
    updated_at: existing?.updated_at || now,
    accepted_at: existing?.accepted_at || null,
    metadata: existing?.metadata || {},
  };
}
```

```ts
export function updateContentGroupIdentityDraft(input: {
```

- [ ] **Step 2: Add accept/reject/archive helpers**

Add:

```ts
export function acceptContentGroupIdentity(group: ContentGroupV1, reviewedBy: ContentGroupIdentityCreatedBy = 'human'): ContentGroupV1 {
  const normalized = normalizeContentGroup(group);
  const now = new Date().toISOString();
  return {
    ...normalized,
    identity: {
      ...normalized.identity,
      status: 'accepted',
      reviewed_by: reviewedBy,
      updated_at: now,
      accepted_at: now,
    },
  };
}

export function rejectContentGroupIdentity(group: ContentGroupV1, reviewedBy: ContentGroupIdentityCreatedBy = 'human'): ContentGroupV1 {
  const normalized = normalizeContentGroup(group);
  return {
    ...normalized,
    identity: {
      ...normalized.identity,
      status: 'rejected',
      reviewed_by: reviewedBy,
      updated_at: new Date().toISOString(),
      accepted_at: null,
    },
  };
}

export function archiveContentGroupIdentity(group: ContentGroupV1, reviewedBy: ContentGroupIdentityCreatedBy = 'human'): ContentGroupV1 {
  const normalized = normalizeContentGroup(group);
  return {
    ...normalized,
    identity: {
      ...normalized.identity,
      status: 'archived',
      reviewed_by: reviewedBy,
      updated_at: new Date().toISOString(),
    },
  };
}
```

- [ ] **Step 3: Add accepted invalidation helper**

Add:

```ts
function invalidateAcceptedIdentity(group: ContentGroupV1): ContentGroupV1 {
  if (group.identity.status !== 'accepted') return group;
  return {
    ...group,
    identity: {
      ...group.identity,
      status: 'draft',
      reviewed_by: null,
      accepted_at: null,
      updated_at: new Date().toISOString(),
      metadata: {
        ...(group.identity.metadata || {}),
        invalidated_reason: 'content package changed after acceptance',
      },
    },
  };
}
```
