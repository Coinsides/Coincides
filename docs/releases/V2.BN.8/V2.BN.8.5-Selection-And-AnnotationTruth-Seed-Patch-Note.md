# V2.BN.8.5 Selection And AnnotationTruth Seed Patch Note

## Summary

This patch implements the first code seed for the V2.BN.8.5 selection and AnnotationTruth plan.

It keeps the product direction agreed in the plan:

- TextFlow remains the natural writing substrate.
- AnnotationTruth becomes the first durable semantic mark layer.
- `/definition` is no longer a DefinitionBlock creation path.
- Inline formula / code / link remain reserved actions in this pass.
- Full AI reading, relation runtime, source region attachment, and Structure Studio remain out of scope.

## Implemented

- Added `AnnotationTruthV1`, `AnnotationRangeV1`, `AnnotationSetV1`, and `AnnotationProposalV1` runtime types.
- Added `annotationTruthService.ts` for creating, renaming, soft-deleting, accepting, and rejecting annotation/proposal seeds.
- Added `selectionRangeService.ts` for same-TextUnit selection normalization and conversion into annotation ranges.
- Added TextUnit-level annotation anchors to TextBlock projection.
- Added a compact selection toolbar with an active `Annotate` action and reserved formula/code/link actions.
- Added subtle annotation row marking and a compact annotation badge.
- Added an Annotation Inspector seed for label viewing, rename, soft delete, status, marker, and range preview.
- Stored annotation truth seed data on note metadata under `canvas_engine_annotations_v1`.
- Routed `/definition` to `annotation_action` metadata instead of block template creation.
- Extended the canvas engine model contract smoke test to cover AnnotationTruth, AnnotationProposal, selection range, and `/definition` command behavior.

## Follow-up Fix - Selection Range Expansion

Henry's manual test confirmed the seed works, but exposed two 8.5-level accuracy bugs:

- selecting half of a TextUnit could visually behave as if the entire TextUnit had been annotated;
- invalid or collapsed selection ranges could fall back to the whole TextUnit text cache.

This patch tightens the seed behavior:

- `createAnnotationRangeFromCapturedSelection` now stores only the actually selected substring in `range_text_cache`.
- Collapsed selections no longer expand to the full TextUnit cache.
- TextBlock projection only renders the full-row annotation background when the annotation range covers the whole TextUnit.
- Partial text-span annotations keep their exact offsets and can still be inspected through the annotation badge, but no longer paint the whole TextUnit as if it were selected.
- Multi-TextUnit / overlapping / block-level annotation UX has been moved into the V2.BN.8.6 handoff section in `Open-Issue-And-Brainstorm-Checklist.md`.

## Follow-up Fix - Partial Span Highlight Visibility

Henry's next manual pass confirmed that partial annotations kept their label badge, but no longer had any visible text highlight.

This patch restores a first-version visible partial highlight without re-expanding the annotation to the whole TextUnit:

- Added `createTextUnitAnnotationHighlightSegments` to split a TextUnit into plain and highlighted visual segments from exact annotation offsets.
- TextBlock projection now renders a non-interactive text highlight layer behind the textarea, so partial spans such as the second half of `1233213` or only `Yes` can be visibly marked.
- Full-TextUnit annotations still keep the quiet row-level affordance; partial spans only paint the selected character range.
- Selected annotation spans receive a stronger highlight tint while preserving the annotation badge / inspector entry.

## Current Limits

- Selection capture is intentionally limited to a single TextUnit in this seed.
- Textarea rendering now has a first-version non-interactive highlight projection for partial spans. Multi-label overlap blending, resilient range rebasing, and richer span editing remain deferred to V2.BN.8.6.
- Multi-range annotation editing, child annotations, right-click menu integration, source region annotation, and resilient range rebasing are deferred.
- The Inspector is a seed, not the final Annotation Studio.
- Browser Harness smoke is intentionally skipped for this pass per Henry's instruction; the patch stops before Henry manual testing.
