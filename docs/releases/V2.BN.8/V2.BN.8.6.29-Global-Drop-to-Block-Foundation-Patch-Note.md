# V2.BN.8.6.29 Global Drop-to-Block Foundation Patch Note

## What Changed

- Added `plainTextFromContentGroupDragPayload`.
- Added `createTextFlowFromDroppedText`.
- Draft Range / Label payloads can now project into plain text for visible block creation.
- Blank Page / Canvas surface drops can create a new TextBlock using copy/projection semantics.
- Existing ContentGroup drops remain reference-only and do not move source writing.

## Safety Boundary

Drop into Page / Canvas creates visible copied content.
It does not delete the source text, source Label, or source block.

## Deferred

- Precise insertion into existing paragraphs.
- Destructive move semantics.
- Block copy fidelity for complex blocks.
- Full drop preview polish.
