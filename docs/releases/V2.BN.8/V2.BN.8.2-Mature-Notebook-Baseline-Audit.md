# V2.BN.8.2 Mature Notebook Baseline Audit

> 本文是 V2.BN.8.2 的产品基线审查。目的不是扩 scope，而是防止 Canvas Engine 打磨时忘记 Coincides 首先必须是一款成熟、安静、可靠的笔记软件。

## 1. 当前判断

Better Notebook 现阶段的产品重心仍然是成熟笔记能力，Canvas 能力是辅助用户整理、排版、推导、临时存放想法的扩展层。

换句话说：

- Page / Note 写作体验是主线。
- Canvas / Scratch Workspace 是思路延展和自由排版能力。
- 后续 Canvas native 可能成为产品主哲学，但 V2.BN.8.2 不应该提前把所有能力压到 Canvas 上。

## 2. 成熟笔记软件的基础能力层

状态口径：

- `already usable`：当前版本已经能用于基础流程；
- `seed exists but immature`：已有种子能力，但体验、数据契约或边界还不成熟；
- `planned later`：已经在 Better Notebook 或 V2.BN.8 后续小版本里有方向；
- `missing and should become register item`：当前缺口明确，后续需要进入 register / roadmap。

### Layer 1 - 写作与编辑

用户需要稳定完成：

- 创建 note；
- 创建 paragraph / definition / formula / code 等 block；
- 连续写作；
- 粘贴长文本；
- block 自动增高；
- 选中、移动、resize；
- slash command 创建 block；
- Ctrl+Z / Ctrl+Y 撤回和重做。

V2.BN.8.2 关注点：

- Canvas viewport 不能破坏自然写作。
- Page mode 下 block 仍应保持像文档一样的阅读和写作节奏。
- Slash menu 必须支持键盘上下选择和 Enter 确认。

| Item | Status | Note |
| --- | --- | --- |
| 创建 note | seed exists but immature | Project -> Note 流程已有，但 note 管理还不完整。 |
| 创建 paragraph / definition / formula / code block | already usable | V2.BN.8.2 继续保留基础 block 创建。 |
| 连续写作 / 粘贴长文本 | seed exists but immature | 可用，但 inline rich text、inline math 和长文分页仍需后续增强。 |
| block 自动增高 | already usable | 当前已作为基础体验修过多轮。 |
| 选中、移动、resize | seed exists but immature | 可用，但仍需要 V2.BN.8 后续打磨 handles、snap 和 history。 |
| slash command 创建 block | already usable | V2.BN.8.2 已补键盘上下和 Enter。 |
| Ctrl+Z / Ctrl+Y | seed exists but immature | 移动/布局 history seed 已有方向，但完整 operation history 仍未成熟。 |

### Layer 2 - 页面与画布

用户需要理解：

- PageFrame 是可导出、可阅读、近似现实纸张的正式区域。
- Scratch Workspace 是 PageFrame 外的自由区域。
- Canvas mode 是查看和操作 PageFrame + Scratch Workspace 的视图，不应该让用户感觉被锁死在左上角。

V2.BN.8.2 关注点：

- Canvas mode 单一 viewport，不出现外层和内层双滚动互相打架。
- 初始 Canvas 视角要看到 PageFrame，同时保留上方/左侧 workspace headroom。
- Workspace block 刷新后不能被挤回 PageFrame。

| Item | Status | Note |
| --- | --- | --- |
| PageFrame 正式区域 | already usable | 可视边界、content inset 和正式 block 区分已进入 runtime。 |
| Scratch Workspace | seed exists but immature | workspace block 可存在并持久化，但 pan/zoom、drawing object 仍在早期。 |
| Canvas viewport | seed exists but immature | V2.BN.8.2 建立第一版 pan/zoom/transform，仍需真实鼠标手感验收。 |
| 多 frame / presentation | planned later | 当前明确不产品化，只保留一个主 PageFrame。 |

### Layer 3 - 组织与导航

成熟笔记软件至少需要：

- Project / Note 层级；
- Back to Project；
- note title；
- favorites；
- recent；
- future trash / restore；
- future search。

V2.BN.8.2 关注点：

- 不新增完整组织系统。
- 保持 top chrome 简洁稳定。
- Canvas mode 下 top chrome 是 viewport 外的稳定工具层。

| Item | Status | Note |
| --- | --- | --- |
| Project / Note 层级 | seed exists but immature | 基础入口可用，管理能力还不成熟。 |
| Back to Project / note title | already usable | 当前作为 top chrome 基础能力保留。 |
| favorites / recent | seed exists but immature | 有入口和方向，但还不是完整成熟组织系统。 |
| trash / restore | missing and should become register item | 成熟笔记必须有缓冲删除，当前仍未实现。 |
| search | missing and should become register item | Note 内 / Project 内搜索需要后续排期。 |

### Layer 4 - 信息状态与视图提示

用户需要知道：

- block 是什么类型；
- block 是否进入 export；
- block 是否 AI visible；
- block 是否属于正式 PageFrame 或 scratch/workspace。

V2.BN.8.2 关注点：

- 这些状态默认不应该干扰写作。
- Preview / overlay 可以作为状态查看入口。
- Overlay 和 block toolbar 必须跟随 viewport 规则，而不是压进 block 内容流。

| Item | Status | Note |
| --- | --- | --- |
| block type visibility | already usable | 通过 overlay / preview 控制显示，不默认干扰写作。 |
| AI visible / export 状态 | seed exists but immature | 状态提示和 overlay 已有，但批量操作还未完整。 |
| scratch/workspace 状态 | seed exists but immature | 数据面能区分 surface，视觉语言仍需后续打磨。 |
| Preview panel | already usable | V2.BN.8.2 Browser Use 已确认图层高于 block chrome。 |

### Layer 5 - 导入导出与持久化

成熟笔记软件最终需要：

- export PDF / image / markdown；
- import note / source；
- snapshot / version；
- crash-safe persistence；
- deleted item restore。

V2.BN.8.2 关注点：

- 不实现完整导入导出。
- 记录导出仍是基础能力缺口。
- PageFrame 边界和 content inset 要为未来 export 保留可信依据。

| Item | Status | Note |
| --- | --- | --- |
| export PDF / image / markdown | planned later | PageFrame 契约为导出留依据，但导出引擎未做。 |
| import note / source | planned later | Source / condensed source 已在产品文档和 register 中有方向。 |
| snapshot / version | missing and should become register item | 成熟笔记和 source chain 都需要，但不属于 V2.BN.8.2。 |
| crash-safe persistence | seed exists but immature | 基础保存存在，但还没有成熟恢复/损坏提示。 |
| deleted item restore | missing and should become register item | 与 trash/restore 同属成熟笔记基础能力。 |

### Layer 6 - 模板与复用

成熟笔记软件最终需要：

- default block set；
- Template Studio；
- block category membership；
- structured field values；
- field layout / render template；
- reusable note/block pattern。

V2.BN.8.2 关注点：

- 不进入 Template Studio 产品化。
- 保持 Definition / Formula / Code 等 block 的当前基础体验不退化。
- 后续模板能力应建立在稳定的 content truth / layout truth / viewport truth 之上。

| Item | Status | Note |
| --- | --- | --- |
| default block set | seed exists but immature | 当前收窄为 paragraph / definition / formula / code 等基础集合。 |
| Template Studio | planned later | Better Notebook 需要，但不进入 V2.BN.8.2。 |
| block category membership | planned later | 已在 Block Contract 中定义 default / math / user defined 方向。 |
| structured field values | seed exists but immature | Definition / Formula 字段种子可用，但 AI-assisted convert 仍在后续。 |
| field layout / render template | planned later | 当前只保留固定样板，不做完整模板编辑器。 |
| reusable note/block pattern | planned later | 依赖 Template Studio 和稳定 field/layout truth。 |

## 3. 当前版本应做与不应做

### V2.BN.8.2 应做

- 稳定 Canvas Shell。
- 稳定 PageFrame 与 Scratch Workspace 的边界。
- 建立第一版 pan / zoom / viewport transform。
- 让双击创建、拖拽、resize 使用 viewport/world 坐标。
- 让 slash menu 可以键盘上下选择和 Enter 确认。
- 记录成熟笔记能力缺口。

### V2.BN.8.2 不应做

- 不做完整导出系统。
- 不做完整导入系统。
- 不做 drawing tool。
- 不做多 frame 产品化。
- 不做 Template Studio。
- 不做 relation runtime。
- 不做 Graph DB / GraphRAG / Agent。

## 4. 后续开放问题

这些问题不阻塞 V2.BN.8.2，但应进入后续 open issue / roadmap 讨论：

- Export 的最低可用版本是什么：PDF、image、markdown 哪个先做？
- PageFrame 的 ruler / margin 控件是否应该进入 V2.BN.8 后续小版本？
- Trash / restore 应该在 Better Notebook 哪个阶段进入？
- Search 是 note 内优先，还是 Project 内优先？
- Code block 是否需要 line selection / per-line copy？
- Inline formula conversion 属于笔记基础能力，还是 AI/skill 接入后的增强能力？
- CanvasObject 层、drawing tool、shape、image、region selection 应该在哪个小版本进入？

## 5. V2.BN.8.2 验收视角

V2.BN.8.2 通过时，不代表 Coincides 已经是一款完整成熟笔记软件。

它只代表：

- 当前 Canvas Engine shell 不再破坏基础笔记体验；
- Page / Canvas 两种视图的边界更清楚；
- viewport transform 有第一版工程依据；
- 后续成熟笔记能力缺口已经被显式记录，不会被遗忘。
