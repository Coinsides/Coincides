# V2.BN.8.10 TextFlow Typography Maturity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make document typography a stable, configurable, measurable truth shared by TextFlow, PageFrame, Export Preview, and AI-readable layout.

**Architecture:** V2.BN.8.10 promotes the document typography baseline from V2.BN.8.9.3.1 into a real note-level typography profile. TextFlow remains content truth; typography is layout/display truth. This version does not implement complete Word-like auto-pagination, PDF export, rich text spans, per-character styling, or CanvasObject database migration.

**Tech Stack:** React, TypeScript, Vite, existing Canvas Engine services under `client/src/pages/Notes/canvasEngine`, note metadata persistence, `canvasEngineModelContractCheck.ts`, `canvasRuntimeBoundaryCheck.mjs`, V2.BN.8 release docs.

---

## 0. Version Boundary

V2.BN.8.10 has one job:

```text
Typography profile -> CSS variables -> measurement estimate -> PageFrame / Export / AI-readable consistency.
```

It must not become:

- a full rich text editor;
- a complete Word clone;
- automatic pagination with content splitting;
- PDF/export execution;
- a CanvasObject / CanvasPlacement database cutover;
- ContentGroup projection;
- a complete style/template system.

### Stable Product Decisions

- TextFlow is still content truth.
- Typography is display/layout truth.
- The first mature typography surface is document-level, not per-character.
- Per-block or role-specific typography can be reserved later, but must not block 8.10.
- Canvas zoom must never mutate document font size.
- PageFrame style/background/template must not mutate TextFlow content.
- Measured auto-pagination waits until this version creates a reliable typography measurement baseline.

### Main Persistence Decision

Use note metadata for V2.BN.8.10 typography persistence:

```text
note.metadata.text_flow_typography_profile_v1
```

This is intentionally transitional and note-scoped. It is not a new database table.

Reason:

- Typography belongs to the note/document experience now.
- TextFlow block content should not be rewritten just because a user changes font size.
- Final document/package/export format can later decide how typography becomes part of a broader project package.

## 3. Data Contract

### Document Typography Profile v1

The active v1 profile should remain close to the existing shape:

```ts
export interface DocumentTypographyProfile {
  profileId: string;
  fontFamily: string;
  fontSizePx: number;
  lineHeightPx: number;
  paragraphSpacingPx: number;
  averageCharWidthPx: number;
}
```

V2.BN.8.10 may add optional metadata fields only if needed:

```ts
export interface DocumentTypographyProfile {
  profileId: string;
  fontFamily: string;
  fontSizePx: number;
  lineHeightPx: number;
  paragraphSpacingPx: number;
  averageCharWidthPx: number;
  version?: 'DocumentTypographyProfileV1';
  updatedAt?: string;
}
```

If adding `version` creates too much churn, keep versioning in the note metadata wrapper instead:

```ts
export interface DocumentTypographyMetadataV1 {
  version: 'DocumentTypographyMetadataV1';
  activeProfile: DocumentTypographyProfile;
}
```

The preferred metadata shape is:

```json
{
  "text_flow_typography_profile_v1": {
    "version": "DocumentTypographyMetadataV1",
    "activeProfile": {
      "profileId": "default-document",
      "fontFamily": "Aptos, Calibri, \"Segoe UI\", Arial, sans-serif",
      "fontSizePx": 15,
      "lineHeightPx": 22,
      "paragraphSpacingPx": 0,
      "averageCharWidthPx": 7.2
    }
  }
}
```

### Allowed Value Ranges

Use conservative clamps:

```text
fontSizePx: 10..28
lineHeightPx: max(fontSizePx + 2, 14)..48
paragraphSpacingPx: 0..32
averageCharWidthPx: derived from fontSizePx unless explicitly valid
```

Font family allowlist for first UI:

```text
Aptos / Calibri / Segoe UI
Arial
Georgia
Times New Roman
Cambria
Consolas
Inter
System Sans
```

Store actual CSS font-family strings, but display short labels in UI.

## 10. Risk Register

### Risk: Typography Becomes Content Truth

Symptom:

```text
fontSizePx or lineHeightPx appears inside TextFlow unit text data.
```

Response:

```text
move it back to note-level typography metadata or a future explicit style layer.
```

### Risk: 8.10 Accidentally Starts Auto-pagination

Symptom:

```text
implementation starts splitting blocks, reordering TextFlow units, or materializing page slices.
```

Response:

```text
stop and defer to a post-8.10 auto-pagination version.
```

### Risk: UI Becomes Too Heavy

Symptom:

```text
top chrome grows into a word processor toolbar.
```

Response:

```text
move controls into a compact popover or More Actions panel.
```

### Risk: Measurement Is Expensive

Symptom:

```text
performance smoke regresses because typography measurement depends on DOM reads or repeated layout thrashing.
```

Response:

