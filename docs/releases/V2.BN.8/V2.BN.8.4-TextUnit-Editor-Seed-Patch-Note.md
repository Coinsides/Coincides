# V2.BN.8.4 TextUnit Editor Seed Patch Note

## Follow-up Patch - TextUnit Role Preservation And Reflow - 2026-06-16

Henry's Browser/manual smoke exposed a deeper TextUnit editor bug: when plain text and `text_flow.units` temporarily diverged during Enter, slash role changes, or tail empty-line edits, the editor could rebuild the whole TextFlow from plain text and silently flatten writing roles back to `paragraph`.

Fixed in this patch:

- Preserve existing TextUnit identity and writing roles when aligning plain text back to TextFlow.
- Generate new TextUnit ids only for genuinely added lines instead of rebuilding the whole block.
- Keep TextUnit groups only when all referenced units still exist after line reconciliation.
- Preserve tail empty TextUnits for existing blocks so Enter at the end of a block keeps the new writable line alive.
- Make Enter after a toggle item create a normal paragraph row instead of cloning toggle state.
- Make Enter after a todo item create another unchecked todo row.
- Allow active paragraph/text measurement reflow so a growing TextBlock pushes following blocks down instead of overlapping them.
- Adjust list marker vertical alignment so numbered and bullet markers sit on the same visual line as text.

Verified:

- Browser Harness: existing paragraph Enter keeps the new line alive.
- Browser Harness: toggle Enter no longer removes bullet/number list structure.
- Browser Harness: `/todo` converts the target row without flattening existing list roles.
- Browser Harness: todo Enter creates another unchecked todo row.
- Browser Harness: TextBlock growth pushes the following block downward.
- `npm run smoke:canvas-engine-model-contract` passed.
- `npm run build` passed in `client`.

Remaining / deferred:

- Slash command focus after selecting a TextUnit writing role is still rough in some cases and should be polished in the next interaction pass.
- Snap alignment drag overlap is still a separate placement/collision issue and should not be mixed into the TextUnit role-preservation patch.

## Follow-up Patch - First Layer TextUnit Fixes - 2026-06-16

This follow-up patch addresses Henry's first manual test findings before the next manual pass:

- Stabilized TextUnit line splitting after `Enter` by synchronously publishing structural keyboard edits and immediately focusing the newly created TextUnit textarea.
- Kept tail-split empty TextUnits addressable so a line created at the end of an existing TextUnit is not eaten by projection.
- Fixed plain TextUnit rows so they occupy the full writing width instead of accidentally shrinking into the marker column.
- Replaced global `index + 1` numbered-list markers with continuous same-level numbered-list ordinals.

- Added first interactive toggle metadata support through a collapse / expand marker button.

## Summary

本补丁把 V2.BN.8.4 从计划推进到第一版代码种子：`TextBlock` 不再只是一个扁平 textarea，而是可以承载 `TextUnit` 行级编辑。它仍然不是完整富文本编辑器，也不是 TextUnitGroup / InlineStructure 编辑器；本轮只把自然写作最基础的行级能力打稳。

## Implemented

- 新增 `textUnitEditorService.ts`，集中处理 TextUnit 的纯函数编辑规则：
  - split TextUnit；
  - merge with previous TextUnit；
  - set writing role；
  - indent / outdent；
  - paste plain text into TextFlow；
  - split / merge TextFlow seed。
- `TextBlockProjection` 改为第一版 TextUnit editor：
  - Enter 拆出下一个 TextUnit；
  - Backspace 在行首合并上一行；
  - Tab / Shift+Tab 调整缩进；
  - 多行粘贴会尝试保留 heading / quote / bullet / numbered / todo 意图；
  - 保存时把 TextFlow truth 一起写回。
- 新增 `TextUnitGutterLayer`：
  - hover / focus 时显示低噪声行工具；
  - 支持插入下一行；
  - 支持切换 paragraph / heading / quote / bullet / numbered / todo / toggle / code line。
- Slash command foundation 前进一小步：
  - `/heading`、`/quote`、`/bullet`、`/numbered`、`/todo`、`/toggle` 走 TextUnit writing role；
  - `/definition` 继续保持未来 TextUnitGroup / inline structure 角色标记，不重新变成 DefinitionBlock；
  - `/code` 继续保留独立 CodeBlock 创建入口。
- Draft block 支持带 TextFlow 创建，因此空白输入中使用 writing role slash command 时可以直接落成 TextBlock seed。
- 模型契约更新：
  - TextUnit editor service 行为进入 `canvasEngineModelContractCheck`；
  - slash command foundation 现在把 list/todo/toggle 视为 active TextUnit writing role。
