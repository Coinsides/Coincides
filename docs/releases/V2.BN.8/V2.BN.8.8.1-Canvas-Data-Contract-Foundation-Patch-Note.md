# V2.BN.8.8.1 Canvas Data Contract Foundation Patch Note

Date: 2026-06-25

Status: completed scoped engineering pass and verified.

## Summary

8.8.1 是 Canvas Engine Foundation 的第一步：先不做新的视觉画布，也不做完整 PageFrame / shape / connector UI，而是把 Canvas 未来要承载的核心对象合同立起来。

这一步确认三件事：

```text
TextFlow     = content truth
ContentGroup = knowledge structure truth
Canvas       = layout truth
```

CanvasObject 不是内容真相本身；它是内容、页面、结构化对象、投影对象在画布上的空间存在方式。8.8.1 的目标是让这些对象以后可以被 runtime、AI-readable snapshot、command/delta、PageFrame、Block projection、ContentGroup projection 和 Agent proposal 继续接上，而不是继续停留在零散的 block placement metadata 里。

## Completed

- Added the first formal Canvas data contracts:
  - `NoteCanvas`
  - `CanvasObject`
  - `CanvasPlacement`
  - `ContentMount`
  - `PageFrameExtension`
  - `VisualStyle`
  - `VisualConnector`
  - `CanvasAIReadableSnapshot`
  - `CanvasCommand`
  - `CanvasDelta`
- Classified CanvasObject as:
  - `pure`
  - `block_backed`
  - `structured`
  - `projection_backed`
- Kept `BlockPlacementModel` as the current compatibility bridge while making it extend the generic `CanvasPlacement` contract.
- Derived PageFrame into:
  - a formal `page_frame` CanvasObject;
  - a matching CanvasPlacement;
  - a PageFrameExtension record for page size, content inset, ruler/snap/export/header-footer/page-number reserves.
- Derived paragraph block placements into:
  - `paragraph_block_projection` CanvasObjects;
  - CanvasPlacements;
  - `ContentMount` records pointing back to `note_block`.
- Preserved canvas object reserves as seed objects so future shape/image/region work can land without changing the top-level runtime contract again.
- Added `CanvasAIReadableSnapshot` as a derived runtime snapshot, not durable truth.
- Updated the model contract smoke check to fail unless the runtime exposes the new CanvasObject / Placement / Mount / PageFrame / AI snapshot fields.
- Updated the canvas runtime boundary check so the architecture gate protects the new data contract.

## Engineering Boundary

This patch intentionally keeps old runtime behavior working. Existing note blocks still render through the current runtime path; 8.8.1 only gives them a clearer model layer underneath.

Important boundaries:

- `preview_text` / display cache is not introduced as a second content truth.
- Canvas placement and style remain separate from TextFlow content.
- PageFrame is treated as the first special CanvasObject, but full PageFrame UI is not implemented here.
- Visual connectors are only contract seeds. They do not create Relation or KnowledgeRelation data.
- AI-readable snapshot is derived from runtime and can be regenerated; it is not a database entity in this patch.

## Not Included

- No browser-visible canvas redesign.
- No complete PageFrame v1 interaction.
- No shape creation UI.
- No block-backed shape promotion/demotion UI.
- No visual connector drawing UI.
- No ContentGroup projection, mini editor, Materialize, Fork, Duplicate, or Reference UI.
- No Relation runtime, GraphRAG, or Agent write path.
- No full database migration for CanvasObject tables.
- No complete infinite canvas.

## Remaining Risks

- The new contracts are still runtime-level TypeScript contracts, not durable database tables.
- `CanvasObjectReserve` still represents early seed metadata; later shape/image work should migrate it into formal CanvasObject writes.
- AI-readable snapshot currently carries bbox / frame / z-index / contentRef basics only. Reading order, overlap semantics, occlusion, and selection context need a later dedicated pass.
- PageFrame ruler, snap wall, header/footer, page number, template, and export semantics are only reserved in the extension contract.
