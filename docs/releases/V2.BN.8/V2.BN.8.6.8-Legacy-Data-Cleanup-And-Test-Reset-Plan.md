# V2.BN.8.6.8 Legacy Data Cleanup And Test Reset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retire the legacy Better Notebook data surfaces that now conflict with TextFlow-first / ContentGroup-first design, then reset all prototype account data so the next subversion starts from a quiet schema and clean test state.

**Architecture:** This cleanup is staged as retreat, removal, data reset, and full verification. Each risky surface is handled in its own rollback block: first hide user entrances, then remove the model path, then wipe prototype data only after code and smoke checks pass. `AnnotationSet` and old structured block templates can be removed earlier; `TextUnitGroup` is the highest-risk cleanup and must be handled last because it touches active TextFlow editing.

**Tech Stack:** React 18, TypeScript, Vite, Express, SQLite, Better Notebook canvas engine metadata, model contract smoke scripts, server/client build scripts.

---

## 1. Version Position

```text
V2.BN.8.6.7
  ContentGroup Rebuild And Legacy Retreat

V2.BN.8.6.8
  Legacy Data Cleanup And Test Reset

V2.BN.8.7
  CanvasObject, Media Annotation, Drawing Tool, And Image Insert Seed
```

V2.BN.8.6.8 exists because V2.BN.8.6.7 created the new ContentGroup / Petal direction but did not fully remove the older prototype surfaces. Starting CanvasObject work while these old surfaces remain active would let future relation and media work accidentally build on the wrong object layer.

This version is allowed to delete all existing user and account data because the app is not in production and every current account is a test account.

## 2. Product Truth After Cleanup

### Keep As Active Product Truth

| Object / Surface | Status | Reason |
| --- | --- | --- |
| `TextFlow` | keep | Content root for human writing and AI reading. |
| `TextUnit` | keep | Natural writing unit inside a TextFlow. |
| `SelectionDraft` | keep | User selection truth and future ContentGroup member input. |
| `AnnotationTruth` | keep, downgraded | User-visible label / highlight layer. It is not the main content-package truth. |
| `ContentGroup` | keep | Serious content package and future accepted-identity input. |
| `ContentGroupPetal` | keep | Local part inside a ContentGroup. Replaces child-label semantics. |
| `paragraph/text block` | keep | Primary writing block. |
| `formula block` | keep | Large standalone formula display still has a real layout role. |
| `code block` | keep | Multi-line code area needs standalone rendering and interaction. |

### Retire Or Remove

| Object / Surface | Target Action | Reason |
| --- | --- | --- |
| `AnnotationSet` | remove from normal runtime | It competes with ContentGroup and no longer represents product truth. |
| `TextUnitGroup` | remove or rewrite into ContentGroup member logic | It was a useful predecessor but now hurts natural writing and duplicates ContentGroup. |
| child label as independent hierarchy | remove from product meaning | Petal owns local sub-part semantics inside ContentGroup. |
| Definition/theorem/proof/example/exercise/answer/heading block templates | remove from insert/template surfaces | These are roles or text styles, not permanent independent block families. |
| `DefinitionBlockProjection` | remove | Definition is no longer a block family. |
| Advanced Insert | hide first, then remove | Fixed block-template insertion conflicts with TextFlow / ContentGroup direction. |
| metadata prototype keys for retired objects | drop during reset | No production migration is required. |
