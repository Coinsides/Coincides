# V2.BN.8.7.6 Groups Rail OpenDesign Shell Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 note 右侧 Groups Rail 打磨成接近 OpenDesign `groups-rail.html` 的轻量 collect 面板，让用户在自然写作时能快速把当前选区收进 ContentGroup。

**Architecture:** 8.7.6 只处理 Groups Rail 的壳体、视觉密度、collect 心智和现有交互闭环，不把 Rail 扩张成完整 Gallery。实现上先用工程 contract 固定 `Rail = collect`、Member/source 边界和现有 drop/create/open editor 行为，再用同视口截图对比 OpenDesign；工程过关但视觉不像，版本仍然不能验收。

**Tech Stack:** React + TypeScript + CSS Module + Vite；现有 `ContentGroupPanel`、ContentGroup / GroupFolder service、entity-backed ContentGroup / GroupFolder / Member / Petal 数据；轻量 Node contract check；Browser / browser-harness 截图 smoke。

## 0. Version Scope

### Visual Target

本版本视觉目标是用户自有 OpenDesign 原型：

```text
C:/Users/70208/OneDrive/Desktop/Working/Open design/Coincides_Content_group_design/groups-rail.html
```

这不是盲目照抄 HTML。最终 Rail 必须在第一屏结构、密度、顶部工具、folder path、drop zone、group row、expanded area 和 bottom status 上接近原型。差异必须分类：

- `fix`：不必要差异，本版本必须修。
- `keep`：真实产品必要差异，可以保留，但必须写明原因。
- `defer`：需要 8.7.7 / 8.8+ 或额外产品判断，记录到 patch note / Open Issues。
- `reject`：原型里的未来信号或与当前 doctrine 冲突的内容，不实现。

### Product Boundary

- Rail = collect。
- Gallery = organize。
- Single Editor = refine。
- Rail 可以显示当前 folder path、当前选区、compact group rows、drop target、Open editor。
- Rail 不做完整资源管理器，不做跨项目 Gallery，不做 Graph scope runtime。
- `Folder / Topic / Role / All` segmented control 是否进入 Rail 是产品判断项。8.7.6 可以做轻量视觉壳或 disabled/recorded decision，但不能偷偷实现完整 Gallery 视图系统。

### In Scope

- Rail 固定到右侧轻量面板心智，接近 OpenDesign rail 宽度和密度。
- Header：active dot、`Groups`、open Gallery、close。
- Folder path bar：显示当前 note folder path，可打开 Gallery / folder selector。
- Tool row：New group、Search、filter/view affordance、current folder status。
- Search row：可展开，过滤当前 Rail 内 groups。
- View segmented control：按产品判断做轻量版本；如实现，必须保持 Rail-local，不替代 Gallery。
- Selected-content drop zone：只在有当前选区 / 可拖入内容时突出。
- Compact group row：topic strip、title、role badge、status chip、chevron。
- Expanded group：drop selected content here、Open editor、source note indicator、Add current item、Move here 必要入口。
- Bottom status：group count、selected content ready / no selection。
- 保留现有 create group、add current item、drag/drop add members、open Gallery、open Single Editor、soft delete group、folder placement move 能力。

### Out Of Scope

- 不做 Gallery shell，这已经是 8.7.5。
- 不做 Single Editor shell/workbench，这是 8.7.7 轻量收口或 8.8+。
- 不做 CanvasObject / ContentGroup projection / mini editor。
- 不做 Reference / Duplicate / Fork / Materialize UI。
- 不做 Graph scope runtime。
- 不做 full folder manager。Rail 只选择/显示 folder，不负责完整 folder CRUD。
- 不做 destructive source mutation。
- 不做完整 mobile redesign；只做不重叠、不崩坏的窄屏 smoke。

- [ ] **Step 1: Create display model file**

Create pure helpers:

```ts
import {
  summarizeContentGroupStability,
} from '../contentGroupService';
import {
  groupFolderPath,
} from '../groupFolderService';
import type {
  AnnotationTruthV1,
  ContentGroupIdentityStatus,
  ContentGroupMemberV1,
  ContentGroupV1,
  GroupFolderV1,
} from '../runtimeDataTypes';

export interface RailGroupRowView {
  title: string;
  roleLabel: string;
  topicLabel: string;
  statusLabel: ContentGroupIdentityStatus | 'draft';
  stabilityReason: string;
  memberCountLabel: string;
  sourceLabel: string;
}

export function cleanRailLabel(value: string | null | undefined, fallback: string): string {
  const text = value?.trim();
  return text ? text : fallback;
}

export function railFolderPathText(folders: GroupFolderV1[], folderId: string | null | undefined): string {
  const parts = groupFolderPath(folders, folderId).map((folder) => folder.title);
  return parts.length > 0 ? parts.join(' / ') : 'Note groups';
}

export function railSelectionLabel(count: number): string {
  if (count === 0) return 'No active selection';
  return `${count} selected item${count === 1 ? '' : 's'}`;
}

export function buildRailGroupRowView(input: {
  group: ContentGroupV1;
  folder: GroupFolderV1 | null;
  sourceNoteTitle: string;
}): RailGroupRowView {
  const { group, folder, sourceNoteTitle } = input;
  const stability = summarizeContentGroupStability({ group, folder });
  const status = group.identity.status === 'none' ? 'draft' : group.identity.status;
  return {
    title: group.title,
    roleLabel: cleanRailLabel(group.identity.role, 'no role'),
    topicLabel: cleanRailLabel(group.identity.topic, 'No topic'),
    statusLabel: status,
    stabilityReason: stability.reason,
    memberCountLabel: `${group.members.length} member${group.members.length === 1 ? '' : 's'}`,
    sourceLabel: cleanRailLabel(sourceNoteTitle, 'Current note'),
  };
}

export function railMemberPreview(
  member: ContentGroupMemberV1,
  annotationById: Map<string, AnnotationTruthV1>,
): string {
  if (member.current_content) return member.current_content;
  if (member.kind === 'annotation' && member.target_id) {
    const annotation = annotationById.get(member.target_id);
    if (annotation) {
      return annotation.ranges
        .map((range) => range.range_text_cache?.trim())
        .filter((text): text is string => Boolean(text))
        .join(' | ') || annotation.raw_label;
    }
  }
  return member.preview_text || member.label || member.target_id || 'No preview';
}
```
