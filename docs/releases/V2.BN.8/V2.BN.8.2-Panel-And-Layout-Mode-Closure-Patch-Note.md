# V2.BN.8.2 Panel And Layout Mode Closure Patch Note

## Scope

This patch only closes the current panel / layout-mode interaction loop.

It does not touch Canvas shell sizing, Project surface layout, source snapshot UX, export engine behavior, drawing tools, relation overlay, or full infinite-canvas behavior.

## Decisions

- Note Info remains a lightweight note summary.
- Export Preview owns export boundary, AI visibility, export status, and block type overlay controls.
- Note Actions no longer owns `Snap alignment`.
- Layout owns layout-specific controls such as `Snap alignment`.
- Top-bar `Layout` is the persistent layout mode entry.
- Block control-bar move/resize starts a temporary layout mode only for the current placement operation.

## Expected Behavior

- Clicking `Layout` in the top bar opens the Layout controls panel and enables persistent Layout Mode.
- Clicking `Layout` again exits persistent Layout Mode.
- Clicking the move handle on a block enables temporary Layout Mode for the current drag.
- Temporary Layout Mode exits when the drag/resize operation ends or when the user leaves the current selection flow.
- `Snap alignment` appears in the Layout panel, not in More Note Actions.
- More Note Actions stays reserved for note-level actions such as history, duplicate, archive, delete, import, and export.

## Implementation Result

- Added `off / persistent / temporary` layout mode state.
- Added a Layout panel overlay.
- Moved `Snap alignment` from More Note Actions into the Layout panel.
- Kept Note Info as a summary panel.
- Clarified Export Preview as the owner of export / AI / block type overlay controls.
- Changed block move/resize to use temporary Layout Mode for the current operation.
- More Note Actions now stays reserved for note-level actions.

## Follow-up Adjustment

- Block control bar placement no longer clamps to the viewport top edge; when its owner block scrolls out of view, the toolbar follows the block's true viewport position instead of parking near the top bar.
- Clicking the top-bar `Layout` button now only toggles persistent Layout Mode.
- Hovering over `Layout` briefly opens the Layout controls panel.
- Closing the Layout controls panel no longer exits persistent Layout Mode.
- The Layout controls panel remains the first home for `Snap alignment`.
- More Actions design is intentionally left for the next discussion; this patch does not decide note-level action contents.
- Block control bar now uses a lower floating portal layer plus a top-bar safe clipping area, so it passes underneath top-bar actions during manual scroll instead of occluding them.
