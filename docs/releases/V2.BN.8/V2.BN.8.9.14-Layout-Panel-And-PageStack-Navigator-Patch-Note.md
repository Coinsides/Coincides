# V2.BN.8.9.14 Layout Panel And PageStack Navigator Patch Note

Date: 2026-06-27

## Scope

本补丁把 Layout panel 从开发期的 PageFrame 列表，推进成真正的 PageStack navigator。

Completed:

- 明确 `PageStack` 是用户可见的页面 / 文档单元；`PageFrame` 退回为 PageStack 内部的物理页切片。
- 更新 `normalizePageFrameCollection(...)`，让旧数据或插入/复制产生的未归属 PageFrame 自动补成单页 PageStack。

- 将 `detachPageFrameFromStack(...)` 从“变成独立 PageFrame”改为“生成新的单页 PageStack”。
- 新增 `splitPageStackAtFrame(...)`，支持从某一页开始把一个多页 PageStack 拆成两个 PageStack。
- 复用 `mergePageStacks(...)`，在运行时新增“合并到上一个 PageStack”的用户操作。
- Layout panel 移除可见的 `Independent PageFrames` 区域，改成只展示单页 / 多页 PageStack。
- Toolbar 和空白画布可见命令从 `New PageFrame` 收敛为 `New PageStack`。
- Layout panel 页面行新增：
  - add page below；
  - split stack here；
  - duplicate to new stack；
  - set primary；
  - detach to new stack；
  - delete page。
- 新增模型契约检查，覆盖 PageStack coverage、detach-to-new-stack、split、merge、可见命令词。
- 更新 runtime boundary 检查，使 8.9.14 的 PageStack navigator 成为受保护边界。

## Product Decision

这次把命名和心智彻底收口为：

```text
PageStack = 用户可见的页面 / 连续文档单位，可以只有一页。
PageFrame = PageStack 里的物理页切片。
新建页面 = 新建一个单页 PageStack。
添加页 = 增长当前 PageStack。
detach = 从原 PageStack 抽离，并形成新的单页 PageStack。
split = 从指定页开始切出一个新的 PageStack。
merge = 把一个 PageStack 合并到前一个 PageStack。
```

这比“独立 PageFrame + PageStack”两套心智更顺。用户只需要理解 PageStack；PageFrame 仍然存在，但主要是工程内部和渲染/导出层的对象。
