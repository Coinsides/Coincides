# V2.BN.8.8.5 Shape And Visual Connector Foundation Patch Note

Date: 2026-06-25

Status: completed scoped engineering pass and verified.

## Summary

8.8.5 把第一批非 PageFrame / 非普通 paragraph block 的 CanvasObject 做成了服务层种子：

```text
Pure Shape = visual object only
Block-backed Shape = shape + paragraph TextFlow block + ContentMount
Visual Connector = visual_only arrow, not Relation
```

这一版仍然不做 visible shape toolbar / arrow drawing UI。重点是先让底层语义成立，避免后续 UI 把图形、文字、Relation 混成一团。

## Completed

- Added `shapeProjectionService.ts`.
- Added `createPureShapeProjection`:
  - creates a `shape` CanvasObject;
  - creates a CanvasPlacement;
  - optionally creates VisualStyle;
  - does not create NoteBlock or ContentMount.
- Added `fillShapeWithParagraphBlock`:
  - keeps CanvasObject kind as `shape`;
  - changes backing to `note_block`;
  - changes object class to `block_backed`;
  - creates a paragraph NoteBlock with TextFlow content;
  - creates ContentMount from shape object to paragraph block.
- Added `clearBlockBackedShapeText`:
  - demotes block-backed shape back to pure shape;
  - removes ContentMount;
  - reports the paragraph block and mount ids that should be deleted by the caller.
- Added `createVisualConnectorProjection`:
  - creates `visual_connector` CanvasObject;
  - creates VisualConnector with `relationKind: visual_only`;
  - does not create ContentMount or KnowledgeRelation.
- Added `Shape and visual connector foundation` model contract group.
- Updated runtime boundary check to protect the shape projection service.
- Updated the Canvas Engine implementation checklist.

## Engineering Boundary

The service draws a hard boundary between visual layout and semantic relation:

- Pure shape is not a Block.
- Shape with text becomes block-backed, but remains a shape as CanvasObject kind.
- Shape text lives in paragraph TextFlow content truth.
- Clearing shape text demotes the shape instead of leaving an empty hidden block truth.
- Visual connector is ordinary canvas visual language and never implies Relation.

## Not Included

- No visible shape creation UI.
- No visible shape text editor.
- No visual arrow drawing interaction.
- No connector binding interaction.
- No Relation runtime.
- No ContentGroup Mode / Relation View.
- No durable CanvasObject database migration.

## Remaining Risks

- Shape / connector behavior is service-level only.
- Visible UI still cannot create or edit these objects directly.
- Command dispatcher integration is still pending.
- Canvas AI Tree has not yet been hardened for shape / connector readable nodes beyond the service contract.
