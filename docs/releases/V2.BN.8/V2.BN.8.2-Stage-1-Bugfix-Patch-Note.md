# V2.BN.8.2 Stage 1 Bugfix Patch Note

## Scope

This patch is the first stage of the current V2.BN.8.2 polish pass.

It only targets two production bugs found during Henry's manual testing:

1. Responsive PageFrame / block width desync.
2. Selected block control bar drifting away from the selected block after scroll / pan.

The following UX design items are explicitly deferred to Stage 2:

- moving `Snap alignment` from Note Actions into the Layout surface;
- splitting persistent Layout Mode from temporary move/resize Layout Mode;
- redesigning the boundary between Note Info and Export Preview;
- broader Project surface / source snapshot / favorites / calendar information architecture.

## Bug 1: Responsive PageFrame / Block Size

When Chrome changes from fullscreen to a narrower window, PageFrame width changes but existing PageFrame blocks keep their previous width. This makes formal page blocks overflow the page boundary.

Expected behavior:

- default writing-flow blocks should follow PageFrame inner width;
- user-resized blocks should keep their manual width;
- scratch/workspace blocks should not be compressed by PageFrame resize;
- Page / Canvas mode switching should not pull workspace blocks back into PageFrame.

## Bug 2: Block Control Bar Drift

When a block is selected and the user scrolls or pans the canvas/page, the block control bar can detach from the selected block.

Expected behavior:

- the control bar anchor should be recomputed from the selected block's current layout/world rect;
- viewport scroll / pan / zoom should move the control bar with the block;
- the bar should not rely on a stale first DOM measurement.

## Verification Plan

- Run non-browser checks after implementation.

## Implementation Result

- Added an explicit `width_mode` distinction for block placement.
- Default PageFrame writing blocks now stay auto-width and follow the current PageFrame inner width.
- User-resized blocks are marked manual-width and keep their chosen size.
- Scratch / workspace blocks keep their own width and are not compressed by PageFrame resize.
- Block control bar anchoring now recomputes from the selected block's current layout/world rect instead of relying on a stale first DOM measurement.
