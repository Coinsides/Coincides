# V2.BN.8.6.7 ContentGroup Rebuild And Legacy Retreat Patch Note

status: implemented to browser-self-test gate; waiting for Henry manual validation

## Scope

V2.BN.8.6.7 starts the shift from the transitional AnnotationSet / TextUnitGroup editor seed toward the long-term ContentGroup model.

ContentGroup is now treated as the serious content package: it can hold selected text ranges, AnnotationTruth labels, block references, and future object references as members. Petal is introduced as the local internal part of a ContentGroup.

## Implemented

- Added `ContentGroupV1`, `ContentGroupMemberV1`, `ContentGroupPetalV1`, and interpretation metadata to the canvas runtime data contract.
- Added `contentGroupService.ts` with create, normalize, rename, soft-delete, member add/remove, Petal create/rename/delete, and Petal member add/remove helpers.
- Persisted ContentGroups through note metadata under `canvas_engine_content_groups_v1`.
- Added a right-edge ContentGroup launcher and a dedicated ContentGroup side rail.
- The rail opens collapsed by default and does not auto-expand a group.
- A new group can be created from the rail.
- Existing groups can accept the current selected label or selection-derived ranges as members.
- Group detail view supports title, topic, role, brief, member inspection/removal, Petal creation, Petal rename, Petal deletion, and Petal member add/remove.
- ContentGroup panel suppresses the legacy Annotation Stack panel while it is open, so the right side does not show stacked competing panels.
- Added ContentGroup coverage to the canvas engine model contract smoke test.

## Deferred

- Real drag-and-drop into the rail is not complete yet; this patch uses explicit `Add selected` buttons as the reliable first interaction.
- Full-screen ContentGroup workspace is not complete yet; the detail workspace is currently a right-rail detail view.
- AnnotationSet is still present as legacy/transitional code. It is not removed in this patch.
- TextUnitGroup is not removed in this patch.
- Petal content editing is reference-first. Full source-backed edit surfaces for ContentGroup/Petal content are deferred.
- ContentGroup visual design is acceptable for seed validation but still needs Henry manual review and likely another polish pass.
