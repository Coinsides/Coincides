## 为什么补这个小版本

8.11 structured object family 已经让 table 成为 durable structured CanvasObject，但表格编辑仍有一个产品红线没有收掉：删行/删列会直接改写 table payload，并且不进入画布 undo/redo。

这会造成一个很别扭的断裂：画布上的 layout、block 创建、block 删除都有撤销心智，但表格结构 mutation 反而没有。更麻烦的是，非空行列删除会直接过滤掉 cells；用户一旦误删，数据就被静默毁掉。

本补丁目标很窄：把 table 结构 mutation 纳入和画布其他编辑同等级别的撤销、安全确认、草稿提交和回归测试。

## 核心判断

- 表格结构 mutation 是 structured object truth 的变更，不是 layout 变更。
- undo/redo 应保存 `before/after` payload by value，不能从当前状态反推。
- 只有结构 mutation 进入 runtime history；普通 cell 文本编辑仍走 cell 编辑/浏览器文本编辑心智，不塞进画布结构撤销栈。
- 非空行/列删除需要确认；空行/列删除不打扰用户。
- Escape 取消 cell 编辑的意图高于 blur autosave，不能被 textarea 卸载时的 blur 重新保存。
- 打开表格上下文菜单或执行结构 mutation 前，必须先提交正在编辑的 cell draft，避免用户正打的字无反馈消失。

## 本轮修复范围

### A. Structured mutation runtime history

- `RuntimeHistoryEntry` 新增 `structuredMutation` 类型，记录 `objectId`、`before`、`after`。
- `historyService` 拆出显式的 undo/redo apply helper：
  - undo structured mutation 时持久化 `before`；
  - redo structured mutation 时持久化 `after`；
  - structured mutation 不会误落入 `trashedBlock` 兜底分支。
- `usePlacementHistory` 新增 `pushStructuredMutationHistory`，并通过 runtime controllers 一路传到 writing surface。
- 表格 add row / add column / delete row / delete column 成功持久化后，压入 structured mutation history。

### B. Non-empty delete confirmation

- 删除非空行/列前检测目标 row/column 是否存在非空 cell。
- 非空 row/column 弹确认；用户取消时不写 payload、不压 history。
- 空 row/column 不弹确认，保持高频编辑轻量。
- 1x1 floor 继续由 `deleteTableRow` / `deleteTableColumn` 的纯函数守住，不因 history 接入而放松。

### C. Escape cancel authority

- `TableObjectLayer` 增加一次性 cancel guard。
- Escape 时标记本次编辑已取消并退出编辑态。
- 随后的 blur commit 会先检查 cancel guard；若来自 Escape 取消，则不保存 draft。
- 正常 blur 仍会提交 cell 文本。

### D. Commit pending draft before table menu

- `TableObjectLayer` 在触发表格 context menu 时把当前 pending cell edit 一并传给 writing surface。
- `NoteWritingSurfaceLayer` 打开表格菜单前先提交 pending draft，再展示菜单。
- 因此用户在 cell 内输入后直接右键删另一行/列，正在输入的文本不会丢。

### E. Table mutation regression locks

- 在 canvas engine model contract 中补 table mutation math 测试：
  - `addTableRowBelow` 增加 row count，并创建空 cell；
  - `deleteTableColumn` 保留其余列文本，并重排 column / cell index；
  - `updateTableCellText` 只改一个 cell；
  - `deleteTableRow` / `deleteTableColumn` 在 1x1 时 no-op；
  - `normalizeTablePayload` 修复 jagged / duplicate / discontinuous payload。
- 补 structured mutation runtime history 测试：
  - undo 持久化 `before`；
  - redo 持久化 `after`；
  - 不调用 block restore/trash 回调。
- runtime boundary check 增加 guard，锁住：
  - writing surface 必须走 `persistTableMutationPayload`；
  - 非空删除确认函数必须存在；
  - pending cell draft 必须在菜单打开前提交；
  - Escape cancel guard 必须优先于 blur autosave。

## 不做什么

- 不做 table export / export-to-file 管线。
- 不做 table inspector 细节体验升级。
- 不做 Excel / Word / PDF 导入。
- 不做 structured object 的通用 cell-level editing history。
- 不推进 ContentGroup / Source / Agent / Relation。
- 不整理整个 dirty workspace。
