# V2.BN.8.6.9 ContentGroup Hardening And Integrity Gate Patch Note

status: implemented to non-browser verification gate

## Scope

V2.BN.8.6.9 hardens the ContentGroup / Petal foundation after the V2.BN.8.6.8 cleanup. It does not introduce accepted identity, GroupFolder / ContentGroup Gallery, relation endpoints, AI proposal review, or cross-project grouping.

The focus is narrower:

- ContentGroup members remain references.
- `preview_text` is a display cache, not source truth.
- broken or unsupported references become visible through integrity metadata.
- Petal members follow the same reference and integrity rules as top-level ContentGroup members.

## Implemented

- Added `ContentGroupMemberIntegrityStatus`:
  - `valid`
  - `stale`
  - `orphaned`
  - `unsupported`
- Added integrity metadata fields on ContentGroup members:
  - `integrity_status`
  - `integrity_reason`
  - `preview_refreshed_at`
- Added pure ContentGroup service helpers:
  - `markContentGroupMemberIntegrity`
  - `refreshContentGroupMemberPreview`
  - `refreshContentGroupPreviews`
  - `auditContentGroupMemberIntegrity`
  - `auditContentGroupIntegrity`
  - `resolveRangePreviewFromBlocks`
  - `createContentGroupPreviewResolver`
- Added source-backed preview resolving for:
  - annotation members;
  - block members;
  - text-unit and text-span content-range members.
- ContentGroup Panel now audits groups against the current runtime source data for display.
- Member rows now show compact stale / source missing / unsupported states.
- Detail view has an explicit refresh action that rewrites preview caches from source references.
- Petal member rows use the same warning state as top-level members.
- Model contract smoke now covers integrity marking, preview refresh, orphan detection, and Petal-member audit behavior.

## Verification

Both passed.

## Product Boundary

ContentGroup after this patch is the active serious content package. It is still not accepted identity by default.

V2.BN.8.6.10 should add identity on top of this hardened package instead of creating a second user-facing accepted-content object.

## Deferred

- Full browser/manual UX validation.
- Drag-and-drop ContentGroup member insertion.
- Full ContentGroup workspace page.
- Cross-project / source-document / CanvasObject member resolution.
- GroupFolder / ContentGroup Gallery.
- Relation endpoint behavior.
