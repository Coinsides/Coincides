## 4. Priority 2 - Pan / Zoom / Viewport Transform

### Goal

建立第一版真正的 viewport transform，让 canvas 具备独立 pan、独立 zoom、world coordinate 和 viewport coordinate 的双向转换。

### Required Product Behaviors

- [x] Canvas mode 支持抓手拖动画布。
- [x] Canvas mode 支持独立 zoom，不依赖浏览器整页缩放。
- [x] wheel / trackpad / keyboard 的输入规则清晰。
- [x] 双击创建 block、拖拽 block、resize block 都使用 viewport -> world 坐标。
- [x] block projection、snap guide、selection、overlay anchor 都能使用 world -> viewport 坐标。
- [x] Page mode 与 Canvas mode 的 pan / zoom 能力边界清楚。

### Implementation Tasks

- [x] **Task 2.1: Define viewport transform model**

  Files:
  - Modify: `client/src/pages/Notes/canvasEngine/types.ts`
  - Modify: `client/src/pages/Notes/canvasEngine/engineModel.ts`
  - Modify: `client/src/pages/Notes/canvasEngine/viewportService.ts`
  - Modify: `client/scripts/canvasEngineModelContractCheck.ts`

  Work:
  - Define viewport offset, zoom, bounds, and conversion helpers.
  - Keep zoom finite and clamped.
  - Keep transform serializable as runtime state, not content truth.

  Suggested model shape:

  ```ts
  type CanvasViewportTransform = {
    offsetX: number;
    offsetY: number;
    zoom: number;
    minZoom: number;
    maxZoom: number;
  };
  ```

  Required helper contracts:

  ```ts
  function worldToViewportPoint(point: { x: number; y: number }, transform: CanvasViewportTransform) {
    return {
      x: (point.x - transform.offsetX) * transform.zoom,
      y: (point.y - transform.offsetY) * transform.zoom,
    };
  }

  function viewportToWorldPoint(point: { x: number; y: number }, transform: CanvasViewportTransform) {
    return {
      x: point.x / transform.zoom + transform.offsetX,
      y: point.y / transform.zoom + transform.offsetY,
    };
  }
  ```

## 5. Priority 3 - Overlay / Anchor 统一

- [x] Slash menu / slash manual 支持键盘上下选择候选项。

- [x] Formula、Definition、Code 等候选项都能被键盘高亮、切换和确认，不要求用户只能用鼠标点选。
- [x] Block toolbar 随 selected block 移动、pan、zoom 而保持正确位置。
- [x] Preview panel 是 viewport overlay，不和 block toolbar 混层。
- [x] Formula help / Source picker 使用同一套 overlay path。
- [x] Future relation endpoints 只预留 anchor，不做 relation 产品化。
