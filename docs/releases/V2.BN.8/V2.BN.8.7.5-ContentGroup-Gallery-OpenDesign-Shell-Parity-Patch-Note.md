# V2.BN.8.7.5 ContentGroup Gallery OpenDesign Shell Parity Patch Note

Date: 2026-06-22

## Summary

V2.BN.8.7.5 turns Group Gallery into the first mature OpenDesign-aligned ContentGroup resource-manager surface.

The implementation keeps the current entity-backed ContentGroup System as truth and changes only the Gallery shell:

- `Gallery = organize`
- folder movement remains organization placement only
- cards display ContentGroup / GroupFolder / Member / Petal facts without creating UI-only truth
- CanvasObject projection, graph scopes, and reuse action UI stay deferred

## OpenDesign Visual Comparison

Each category below lists the final comparison judgment.

- 2026-06-22 parity correction:
  - Current implementation still does not look close enough to `group-gallery.html`.
  - The largest mismatch is structural, not cosmetic: the real page is still trapped inside the normal Coincides app sidebar and padded content shell, while the OpenDesign target is a full-width resource-manager workspace.
  - The card mismatch is also structural: cards currently expose an extra action row, member/Petal/folder facts, and a tall business-card body; the target uses compact folder tiles with an info dot, role tab, topic/source block, and one status chip.
  - The header mismatch comes from the visible inline folder-name input and oversized page typography.
  - This patch must treat the OpenDesign screenshot as the visual target and only keep differences that are required by real data or current runtime constraints.
- 2026-06-22 parity correction result:
  - Group Gallery now uses a dedicated full-width workspace route instead of the normal Coincides sidebar/content padding shell.
  - The page grid now follows the OpenDesign shape: 64px top bar, 292px folder pane, right-side viewbar, breadcrumb row, tile body, and bottom statusbar.
  - The header now matches the prototype direction: compact title/subtitle, button-only New folder, New group, and Chinese return button.
  - Folder view no longer adds an extra visible section title above the cards.
  - Cards now use the OpenDesign folder-tile structure: 148px tile, role tab, vertical topic accent, info dot, compact title/summary, topic/source block, and one status chip.
  - Member/Petal/folder facts were moved into the info dot tooltip so the real data remains reachable without breaking the visual target.
  - The folder placement move route was restored after `check:canvas-runtime-boundary` caught that the first correction had accidentally removed the `moveContentGroupFolderPlacement` boundary.
- Kept as necessary difference:
  - The implementation may show fewer cards than the prototype when the local dev account has fewer real ContentGroups.
  - Real cards keep member / Petal / folder facts in the info affordance because the entity-backed system has those facts and they are useful for inspection.
  - Empty-folder and real-data states differ from the prototype's seeded twelve-card mock.
- Fixed during comparison:
  - Removed the normal app sidebar and 28px page padding from Group Gallery routes.
  - Replaced the inline folder-name input with a button-only New folder action.
  - Restored full breadcrumb context in the second row.
  - Replaced the visible card action row with an info-dot affordance and context-only placement action.
  - Changed identity status display from engineering stability text such as `Empty group` to visual status chips such as `draft`.
  - Card width was increased to avoid cramped topic/source text.
  - Topic/source metadata was changed from a squeezed horizontal split to a stable stacked card meta area.
  - Card actions were compacted so the card reads closer to the OpenDesign folder-card style.
  - Status label now reads as a chip instead of plain footer text.
- Deferred:
  - Gallery All view needs Henry decision.
  - Saved graph scopes stay deferred until graph scope/runtime exists.
  - ContentGroup projection/materialization stays deferred to 8.8+.
  - Single Editor workbench/canvas visual parity stays deferred to 8.8+.
- Rejected as prototype-only:
  - Treating saved graph scopes as real Gallery data in 8.7.5.
  - Adding Reference / Duplicate / Fork / Materialize actions to Gallery cards before the reuse UI is designed.
  - Letting Gallery imply that folder placement moves source truth.
