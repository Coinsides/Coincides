# V2.BN.8.9.13 Continuous PageStack v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make PageStack the explicit continuity layer for PageFrame, so A4-style notes can write across pages naturally without turning every independent PageFrame into a fake page sequence.

**Architecture:** This version does not split PageFrame into two product species named fixed and continuous. It introduces `PageStackModel` as a layout-continuity relation over ordered PageFrames: PageStack owns page order and stack-local numbering, while PageFrame owns physical page geometry and Block/PageFrame affiliation remains geometry-derived. TextFlow remains the content truth; PageStack is layout continuity truth, not block ownership truth.

**Tech Stack:** React + TypeScript client runtime, Vite, CSS modules through `NoteDetail.module.css`, Canvas Engine services under `client/src/pages/Notes/canvasEngine`, model-contract checks under `client/scripts`, V2.BN.8 release docs.

---

## 0. Product Decision

### 0.1 We do not build two user-facing PageFrame modes

Do not create this mental model:

```text
fixed PageFrame
continuous PageFrame
```

That model makes every later behavior branch twice: creation, deletion, numbering, extraction, merging, export, AI-readable layout, and browser tests all become mode-specific.

Use this unified model instead:

```text
PageFrame = one physical page slice on the canvas.
PageStack = an ordered continuity relation among PageFrames.
Independent PageFrame = a PageFrame with no PageStack membership.
One-page PageStack = a normal PageStack that currently has one PageFrame.
```

So a "fixed page" is not a separate entity. It is either:

- an independent PageFrame, if the user created a standalone formal page on canvas;
- or a one-page PageStack, if the user is in a formal writing note that can grow later.

### 0.2 PageStack is not content ownership

PageStack must not introduce `ownerPageFrameId`, `parentPageFrameId`, or block ownership.

Current doctrine remains:

```text
TextFlow = content truth.
PageFrame = formal page geometry / export boundary.
PageStack = ordered page continuity and stack-local numbering.
Block affiliation with PageFrame = derived from geometry.
ContentGroup = knowledge package, not part of PageStack v1.
```

This matters because users can drag a Block out of a PageFrame, drag it into another PageFrame, or place it between pages. The correct answer is a geometry-derived classification, not a permanent ownership mutation.

V2.BN.8.9.12.1 adds the immediate helper needed by this doctrine:

```text
LayoutAffiliation = sparse geometry-derived transaction helper.
PageFrame move cohort = fully-contained Blocks only.
Crossing Blocks = explicit edge cases, not silently owned page content.
```

PageStack work may reuse this helper, but it must not reinterpret it as hard PageFrame ownership.

### 0.3 What 8.9.13 must deliver

- New A4 note seed can be represented as one primary PageStack containing the first PageFrame.
- Independent PageFrames remain independent unless the user explicitly creates or attaches them to a stack.
- PageStack has stack-local numbering such as `1 / 3`; `PageFrameCollection.pageFrames.length` is never used as page total.
- Canvas Mode can show long PageStacks without forcing the user to unfold hundreds of pages.
- UI exposes the first usable PageStack controls: create stack, add page to stack, select stack/page, collapse/expand stack.
- AI-readable and browser-testable markers expose stack identity, local page index, total pages, and collapsed state.

### 0.4 What 8.9.13 must not deliver

- Full TextFlow typography and real pagination measurement. That belongs to V2.BN.8.10 TextFlow Typography Maturity.
- PageSlice extraction, split confirmation, and snapshot/reference semantics. That belongs to V2.BN.8.9.14.
- Cross-page Block fragment rendering and continuation markers. That belongs to V2.BN.8.9.14.
- Durable generic CanvasObject / CanvasPlacement database migration.
- Infinite / chunked canvas.
- Relation arrows, ContentGroup Mode, or Agent write path.
- True destructive reorder of TextFlow blocks.

## 1. User Scenario Matrix

The implementation must be judged against these user situations. The common solution is always PageStack membership plus geometry-derived content affiliation.

| Situation | User expectation | Unified behavior |
| --- | --- | --- |
| User creates an A4 note and starts writing | It feels like a document; if it grows, pages continue naturally | Seed a primary PageStack with one PageFrame. The stack may gain pages through explicit add-page v1, and later through measured pagination in 8.10 |
| User creates a new PageFrame from blank canvas | It is a separate formal page or workspace artifact, not automatically page 2 | Create an independent PageFrame with no stack membership |
| User chooses New PageStack | A new continuous writing unit appears | Create one PageFrame and one PageStack containing it; select and focus the first page |
| User has one PageFrame and wants a next page | It should be page 2 of the same writing unit | Add a PageFrame after the selected frame inside the same PageStack |
| User has independent PageFrame A and independent PageFrame B and wants them continuous | They should become page 1 and page 2 of one stack | Provide attach/merge behavior through PageStack service; v1 can expose this through Layout panel or shell menu if the command surface is ready |
| User drags a stacked PageFrame away visually | The page can move as an object, but the stack relation is still explicit | Moving a PageFrame changes geometry only; stack membership remains unless user detaches it |
| User detaches page 2 from a PageStack | It becomes an independent PageFrame; remaining stack renumbers locally | Remove the frame id from `PageStackModel.frameIds`; do not move or split Blocks |
| User deletes a page from a PageStack | Stack should survive if there are other pages | Remove PageFrame from collection and stack; if stack has no frames, remove stack; if primary frame is deleted, choose a surviving frame |
| User creates 200 pages | Canvas should not become unusable | Canvas Mode shows collapsed tail / preview affordance; Page Mode or preview opens the stack for reading |
| User references one page | That page is a page slice candidate | 8.9.13 reserves stable page identity and stack index; 8.9.14 implements PageSlice snapshot/reference semantics |
| A paragraph visually crosses a page boundary | User needs a visible continuation rule | 8.9.13 does not split it; 8.9.14 adds cross-page fragment markers and split confirmation |
| User wants export | Page order should follow stack order | Export preview groups stack pages by stack-local order; independent pages stay independent |
| AI reads the layout | AI can see which pages belong together | AI-readable tree includes PageStack container, collapsed state, and child PageFrame ids/order |

### 1.1 The generic rule

Every situation above can be expressed by three questions:

```text
1. Is this PageFrame a member of a PageStack?
2. If yes, what is its stack-local index?
3. Which Blocks geometrically intersect this PageFrame right now?
```

No situation needs a separate "fixed mode" or "continuous mode" branch.

### 2.2 Metadata rule

Continue writing the collection under:

```ts
export const NOTE_PAGE_FRAME_COLLECTION_METADATA_KEY = 'canvas_engine_page_frames_v1';
export const PAGE_FRAME_COLLECTION_VERSION = 'V2.BN.8.9.13';
```

Reason:

- the current persistence path already loads and saves PageFrame collection metadata;
- PageStack is PageFrame-specific continuity metadata;
- adding a second metadata key would force a second save path before it buys us real database independence.

### 2.3 Normalization rule

Normalization must separate three cases:

```text
No PageFrame metadata exists:
  create the default primary PageStack seed.

PageFrame metadata exists and contains pageFrames but no pageStacks:
  keep those PageFrames independent.

PageFrame metadata exists and contains pageStacks:
  validate stack frame ids against existing pageFrames, remove invalid ids, remove empty stacks.
```

This prevents existing independent PageFrames from being silently converted into page 1 / page 2 / page 3.

Create `pageStackCollectionService.ts` with these exported functions:

```ts
import { insertPageFrameAfter, normalizePageFrameCollection } from './pageFrameCollectionService';
import type { PageFrameCollectionModel, PageFrameModel, PageStackModel } from './types';

const DEFAULT_STACK_GAP = 40;
const DEFAULT_COLLAPSED_PREVIEW_PAGES = 1;

function nextPageStackId(pageStacks: PageStackModel[] = []): string {
  const existing = new Set(pageStacks.map((stack) => stack.id));
  let index = pageStacks.length + 1;
  let candidate = `page-stack-${index}`;
  while (existing.has(candidate)) {
    index += 1;
    candidate = `page-stack-${index}`;
  }
  return candidate;
}

export function createPageStackFromFrame(
  pageFrame: PageFrameModel,
  options: Partial<Pick<PageStackModel, 'id' | 'displayName' | 'createdFrom'>> = {},
): PageStackModel {
  return {
    id: options.id || 'page-stack-1',
    displayName: options.displayName || 'PageStack',
    frameIds: [pageFrame.id],
    primaryFrameId: pageFrame.id,
    selectedFrameId: pageFrame.id,
    collapsed: false,
    numbering: { enabled: true, startAt: 1 },
    layout: {
      direction: 'vertical',
      gap: DEFAULT_STACK_GAP,
      collapsedPreviewPages: DEFAULT_COLLAPSED_PREVIEW_PAGES,
    },
    createdFrom: options.createdFrom || 'user_created',
  };
}

export function createPageStackForFrame(
  collection: PageFrameCollectionModel,
  frameId: string,
  options: Partial<Pick<PageStackModel, 'displayName' | 'createdFrom'>> = {},
): PageFrameCollectionModel {
  const normalized = normalizePageFrameCollection(collection);
  const pageFrame = normalized.pageFrames.find((frame) => frame.id === frameId);
  if (!pageFrame) return normalized;
  if (resolvePageStackContext(normalized, frameId)) return normalized;
  const stack = createPageStackFromFrame(pageFrame, {
    id: nextPageStackId(normalized.pageStacks || []),
    displayName: options.displayName,
    createdFrom: options.createdFrom || 'user_created',
  });
  return normalizePageFrameCollection({
    ...normalized,
    pageStacks: [...(normalized.pageStacks || []), stack],
    primaryStackId: normalized.primaryStackId || stack.id,
    selectedStackId: stack.id,
    selectedFrameId: frameId,
  });
}

export function normalizePageStacks(collection: PageFrameCollectionModel): PageStackModel[] {
  const frameIds = new Set(collection.pageFrames.map((frame) => frame.id));
  const rawStacks = collection.pageStacks || [];
  return rawStacks
    .map((stack) => {
      const validFrameIds = stack.frameIds.filter((frameId) => frameIds.has(frameId));
      return {
        ...stack,
        frameIds: validFrameIds,
        primaryFrameId: validFrameIds.includes(stack.primaryFrameId || '')
          ? stack.primaryFrameId
          : validFrameIds[0] || null,
        selectedFrameId: validFrameIds.includes(stack.selectedFrameId || '')
          ? stack.selectedFrameId
          : validFrameIds[0] || null,
        collapsed: Boolean(stack.collapsed),
        numbering: stack.numbering || { enabled: true, startAt: 1 },
        layout: stack.layout || {
          direction: 'vertical',
          gap: DEFAULT_STACK_GAP,
          collapsedPreviewPages: DEFAULT_COLLAPSED_PREVIEW_PAGES,
        },
      };
    })
    .filter((stack) => stack.frameIds.length > 0);
}

export function resolvePageStackContext(collection: PageFrameCollectionModel, frameId: string) {
  const stacks = normalizePageStacks(collection);
  const stack = stacks.find((candidate) => candidate.frameIds.includes(frameId));
  if (!stack) return null;
  const index = stack.frameIds.indexOf(frameId);
  const pageNumber = stack.numbering.startAt + index;
  const total = stack.frameIds.length;
  return {
    stack,
    index,
    pageNumber,
    total,
    pageNumberLabel: stack.numbering.enabled ? `${pageNumber} / ${total}` : '',
  };
}

export function appendPageFrameToStack(
  collection: PageFrameCollectionModel,
  stackId: string,
  afterFrameId: string,
  options: { id?: string } = {},
): PageFrameCollectionModel {
  const normalized = normalizePageFrameCollection(collection);
  const stacks = normalizePageStacks(normalized);
  const stack = stacks.find((candidate) => candidate.id === stackId);
  if (!stack || !stack.frameIds.includes(afterFrameId)) return normalized;
  const withFrame = insertPageFrameAfter(normalized, afterFrameId, options);
  const insertedFrameId = withFrame.selectedFrameId;
  if (!insertedFrameId) return withFrame;
  const insertIndex = stack.frameIds.indexOf(afterFrameId) + 1;
  const nextStacks = stacks.map((candidate) => (
    candidate.id === stack.id
      ? {
        ...candidate,
        frameIds: [
          ...candidate.frameIds.slice(0, insertIndex),
          insertedFrameId,
          ...candidate.frameIds.slice(insertIndex),
        ],
        selectedFrameId: insertedFrameId,
      }
      : candidate
  ));
  return normalizePageFrameCollection({
    ...withFrame,
    pageStacks: nextStacks,
    primaryStackId: normalized.primaryStackId || stack.id,
    selectedStackId: stack.id,
  });
}

export function detachPageFrameFromStack(
  collection: PageFrameCollectionModel,
  frameId: string,
): PageFrameCollectionModel {
  const normalized = normalizePageFrameCollection(collection);
  const stacks = normalizePageStacks(normalized);
  const nextStacks = stacks
    .map((stack) => {
      if (!stack.frameIds.includes(frameId)) return stack;
      const frameIds = stack.frameIds.filter((candidate) => candidate !== frameId);
      return {
        ...stack,
        frameIds,
        primaryFrameId: frameIds.includes(stack.primaryFrameId || '') ? stack.primaryFrameId : frameIds[0] || null,
        selectedFrameId: frameIds.includes(stack.selectedFrameId || '') ? stack.selectedFrameId : frameIds[0] || null,
      };
    })
    .filter((stack) => stack.frameIds.length > 0);
  return normalizePageFrameCollection({
    ...normalized,
    pageStacks: nextStacks,
    selectedFrameId: frameId,
    selectedStackId: null,
  });
}

export function mergePageStacks(
  collection: PageFrameCollectionModel,
  firstStackId: string,
  secondStackId: string,
): PageFrameCollectionModel {
  const normalized = normalizePageFrameCollection(collection);
  const stacks = normalizePageStacks(normalized);
  const first = stacks.find((stack) => stack.id === firstStackId);
  const second = stacks.find((stack) => stack.id === secondStackId);
  if (!first || !second || first.id === second.id) return normalized;
  const merged: PageStackModel = {
    ...first,
    frameIds: [...first.frameIds, ...second.frameIds],
    selectedFrameId: second.selectedFrameId || first.selectedFrameId,
    createdFrom: 'merge',
  };
  return normalizePageFrameCollection({
    ...normalized,
    pageStacks: [merged, ...stacks.filter((stack) => stack.id !== first.id && stack.id !== second.id)],
    selectedStackId: merged.id,
    selectedFrameId: merged.selectedFrameId || merged.primaryFrameId,
  });
}

export function setPageStackCollapsed(
  collection: PageFrameCollectionModel,
  stackId: string,
  collapsed: boolean,
): PageFrameCollectionModel {
  const normalized = normalizePageFrameCollection(collection);
  const stacks = normalizePageStacks(normalized);
  return normalizePageFrameCollection({
    ...normalized,
    pageStacks: stacks.map((stack) => (
      stack.id === stackId ? { ...stack, collapsed } : stack
    )),
    selectedStackId: stackId,
  });
}
```

function validPageStack(item: unknown): item is PageStackModel {
  if (!item || typeof item !== 'object') return false;
  const stack = item as Partial<PageStackModel>;
  return typeof stack.id === 'string'

## 6. Risk Notes

### 6.1 Circular import risk

`pageStackCollectionService.ts` can import `pageFrameCollectionService.ts`, but `pageFrameCollectionService.ts` should not import `pageStackCollectionService.ts`. If shared normalization becomes awkward, extract tiny pure helpers into `pageStackModelService.ts` rather than creating a two-way dependency.

### 6.2 Auto-pagination risk

Do not fake full auto-pagination in 8.9.13. Without V2.BN.8.10 typography measurement, auto-splitting content across pages will be fragile. 8.9.13 can provide explicit add-page and PageStack continuity; 8.10 can make writing overflow smarter.

### 6.3 Collapse semantics risk

Collapsed means hidden from the user's Canvas view, not deleted and not invisible to AI. AI-readable layout should still know the PageStack has hidden pages.

### 6.4 Detach semantics risk

Detaching a page only changes PageStack membership. It must not split Blocks, move Blocks, delete Blocks, or rewrite TextFlow.

### 6.5 Existing test data risk

Existing notes with old `canvas_engine_page_frames_v1` metadata may contain multiple PageFrames. Do not infer that they are one PageStack. Only new seed collections and explicit user commands create PageStacks.
