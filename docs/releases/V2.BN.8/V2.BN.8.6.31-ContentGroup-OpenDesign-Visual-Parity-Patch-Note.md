status: first 8.7 maturity pass started

## OpenDesign Visual Contract

| Surface | Reference file | Must preserve | Must remove from current UI |
| --- | --- | --- | --- |
| Groups Rail | `groups-rail.html` | compact rail, folder path, active group, focused intake target | full editor fields, large preview, persistent metadata form |
| Group Gallery | `group-gallery.html` | full-page resource manager, folder tree, card grid, Folder / Topic / Role switch | right-side pseudo editor, sparse old management cards, explanatory cards as main content |
| Single Editor | `single-contentgroup-editor.html` | workbench, member pieces, petal dock, compact chips | vertical CRUD form, bubble-form stacking, source locator internals |

## Current Failure To Correct

- 8.6.23 had the route/data split, but visual parity was still incomplete.
- Group Gallery can browse folders and cards, but still has guide cards and some old management-screen language.
- Groups Rail was still too easy to read as a small control center instead of a collect drawer.
- Single Editor has members and Petals, but identity/topic/role still lean toward form editing.
- Browser screenshots are still required before calling the visual migration complete.

## Completed In This Pass

- Added `contentGroupSurfaceRoleService` as a shared role contract:
  - Rail = Collect.
  - Gallery = Organize.
  - Single Editor = Refine.
- Added a model-contract smoke check so these three surface roles cannot drift silently.
- Added `data-content-group-surface` and `data-content-group-role` markers to Rail, Gallery, and Single Editor.
- Routed visible surface labels through the same shared helper.
- Made the Rail intake area quieter: the new-group drop/intake zone now appears only when there is an active candidate selection; otherwise it shows a compact empty state.
