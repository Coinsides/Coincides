# V2.BN.8.7.6 Groups Rail OpenDesign Shell Parity Patch Note

Date: 2026-06-22

Status: completed and verified.

## Summary

8.7.6 把 note 右侧 Groups Rail 从旧的浮动操作面板，改成接近 OpenDesign `groups-rail.html` 的右侧 collect rail。这个版本只处理 Rail 的壳体、密度、第一屏交互骨架和现有工作流闭环，不把 Rail 扩展成完整 Gallery，也不引入 CanvasObject / projection / Graph runtime。

核心产品边界保持不变：

```text
Rail = collect
Gallery = organize
Single Editor = refine
```

## Completed

- 新增 `contentGroupRailShellModel.ts`，集中处理 Rail 行展示模型：title、topic、role、status、member preview、folder path、selection label。
- 新增 `check:groups-rail-shell`，固定 Rail 的 collect surface anchors、OpenDesign anatomy CSS anchors，并阻止本版本误引入后续系统。
- 重构 `ContentGroupPanel.tsx`：
  - Header 改为 active dot + `Groups` + open Gallery + close。
  - 增加 folder path bar 和轻量 folder selector。
  - 增加 New group、Search、local view controls 工具行。
  - 增加 `Folder / Topic / Role / All` Rail-local tabs。
  - 增加可展开 search row。
  - group row 改为 topic strip + title + role badge + status chip + chevron。
  - expanded group 区域显示 drop zone、`Open editor`、source/folder indicator、Add current item、Move here 和 delete。
  - 底部状态栏显示 group count 和 selection readiness。
- 重写 Rail 相关 CSS，让面板固定为右侧 360px rail，而不是旧的 420px 浮动卡片。
- 保留现有 create group、add current item、drag/drop add members、open Gallery、open Single Editor、soft delete、folder placement move 能力。

## Before Correction Visual Gap

- Shell shape: 旧实现是右上角浮动卡片，不是贴右侧的 full-height rail。
- Header/tool density: 旧实现把 `Groups / Collect`、scope、selection 状态都塞在 header，视觉噪音偏大。
- Folder path: 旧实现只有一行 folder label，没有 OpenDesign 的 path bar 心智。
- Drop zone: 旧实现的 create / drop / no-selection 区域更像表单控件，不像 collect rail。
- Group row anatomy: 旧实现是普通 list row，缺少 topic strip、role badge、status chip 和 resource row 密度。
- Expanded group: 旧实现展开后更像按钮堆和 member card list，不像 OpenDesign 的 drop zone + editor entry。
- Statusbar: 旧实现没有底部 rail 状态栏。

Fixed during comparison:

- Header action row 被旧 CSS specificity 压成竖排，已用更具体的 header selector 修正。
- Header 的 open Gallery 图标从 external-link 视觉改为 menu/list 视觉，更接近 OpenDesign 顶部操作。
- Rail 从 floating card 改为贴右侧 360px full-height panel。
- 第一屏补齐 folder path、tool row、view tabs、content groups section、status bar。
- group row 补齐 topic strip、role badge、status chip、chevron。
- expanded group 补齐 drop zone、Open editor、source indicator。
- 根据 Henry 的视觉反馈追加 density patch：把 ContentGroup row 从厚卡片压成更轻的 toggle list。
- 根据 Henry 的视觉反馈去掉 no-selection placeholder 对列表的垂直挤压；selection state 主要留给底栏和有真实 selection 时的 drop zone。
- 根据 Henry 的视觉反馈缩短 topic strip、压缩 row height、减弱 active 边框、移除默认 member preview 和无选区 disabled action。

Kept as necessary difference:

- 当前测试 note 的真实 folder path 是 `Note groups`，不是 OpenDesign 样板里的 `AMATH 231 / Power Series note / Chapter 1`。
- 没有当前选区时，Rail 顶部显示 quiet `No active selection.`，而不是强行显示 selected-ready drop state。
- Rail tabs 只做当前 note / current rail data 的轻量本地过滤和排序，不承担完整 Gallery 的跨 scope 浏览。
- Expanded group 里保留 `Add current item`、`Move here`、delete 等真实工作流入口，样板里只展示更简化的视觉形态。

Deferred:

- Richer folder selector：本版本只做轻量选择和打开 Gallery，不做完整 folder CRUD。
- 更完整的 drag/drop browser smoke：Browser Harness 可覆盖点击与路由，精确拖拽后续需要 richer seed。
- Mobile/narrow viewport Rail smoke。
- Single Editor OpenDesign shell 对齐，顺延到 8.7.7 / 8.8+。

Rejected as prototype-only:

- 不把 Rail 做成完整 Gallery。
- 不在 Rail 暴露 Reference / Duplicate / Fork / Materialize UI。
- 不在 Rail 引入 future graph scope / saved graph runtime。

## Not Included

- 不做 CanvasObject / ContentGroup projection / mini editor。
- 不做 GraphRAG / relation runtime。
- 不做 Reference / Duplicate / Fork / Materialize 的可见 UI。
- 不做 destructive source mutation。
- 不做 full folder manager。
- 不做 Single Editor workbench 视觉重构。

## Remaining Risks

- Rail view tabs are intentionally local lightweight modes. If Henry later wants them to feel like mini Gallery modes, that should be a separate product decision.
- Folder selector is deliberately shallow. Full folder management should remain in Gallery unless the Rail collect workflow clearly needs more.
- Expanded group still carries real action buttons, so it is denser than the static OpenDesign prototype. This is currently a necessary product difference.
- The app still has existing Vite chunk-size / dynamic-import warnings unrelated to 8.7.6.
