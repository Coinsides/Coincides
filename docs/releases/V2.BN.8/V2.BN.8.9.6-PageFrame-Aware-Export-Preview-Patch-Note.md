# V2.BN.8.9.6 PageFrame-aware Export Preview Patch Note

Date: 2026-06-26

Status: implemented

## Why

Before 8.9.6, Export Preview could count included / excluded / AI visible / AI hidden blocks, but it did not understand PageFrame as a first-class export context. That was enough for a single-page seed, but it became too weak after multi-PageFrame, PageFrame affiliation, slots, and template state landed.

This patch makes Export Preview PageFrame-aware without turning it into the final PDF/export engine.

## What Changed

- Extended `client/src/pages/Notes/canvasEngine/exportPreviewService.ts`.
- Added `PageFrameExportPreview`.
- Added `BuildExportPreviewModelOptions`.
- `ExportPreviewModel` now includes:
  - `pageFrames`
  - `crossingObjects`
  - `workspaceOnlyObjects`
- `buildExportPreviewModel` can now receive:
  - `pageFrames`
  - `blockPlacements`
  - `primaryPageFrameId`
- Export Preview now uses geometry-derived PageFrame affiliation to classify rows.
- Blocks are still not owned by PageFrame. PageFrame grouping is derived preview/readability state.
- `useNoteCanvasLayoutModel.ts` now passes runtime PageFrame context into Export Preview.
- `ExportPreviewLayer.tsx` now renders:
  - PageFrame groups
  - crossing-boundary group
  - workspace-only group
  - existing included / excluded / AI visible / AI hidden quick groups
- Added stable DOM markers:
  - `data-export-preview-page-frame`
  - `data-export-preview-page-frame-role`
  - `data-export-preview-crossing`
  - `data-export-preview-workspace-only`
- Added compact styles for PageFrame-aware preview groups.

## Not Included

- No final PDF export engine.
- No crossing-object export policy.
- No clipping policy.
- No manual export decision UI.
- No PageFrame reorder/export sequencing UI.
- No ContentGroup projection.
- No Relation runtime.
- No Agent write path.
