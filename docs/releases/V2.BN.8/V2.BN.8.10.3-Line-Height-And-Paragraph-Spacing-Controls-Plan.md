# V2.BN.8.10.3 Line Height And Paragraph Spacing Controls Lab Plan

> For agentic workers: Execute this plan after V2.BN.8.10.2. Keep the work scoped to note-level line height and paragraph spacing controls. Do not start typography measurement hardening, auto-pagination, export, rich text spans, or per-block style controls in this lab.

## 1. Goal

V2.BN.8.10.3 completes the first document-level typography control surface by adding:

- line height;
- paragraph spacing.

These controls must use the same note-level typography profile created in V2.BN.8.10.1 and exposed in V2.BN.8.10.2.

## 2. Current Ground

Already available:

- `DocumentTypographyProfile.lineHeightPx`
- `DocumentTypographyProfile.paragraphSpacingPx`
- `DOCUMENT_TYPOGRAPHY_LIMITS`
- `patchDocumentTypographyProfile(...)`
- `documentTypographyToCssVars(...)`
- `--document-line-height`
- `--document-paragraph-spacing`
- `NoteChromeLayer` typography section in More
- `saveDocumentTypographyProfile(...)` wired into Chrome

Missing:

- UI controls for line height and paragraph spacing.
- Runtime boundary checks for those controls.
- Visible paragraph spacing application on document text.

## 3. Scope

### Must Do

- Add line-height numeric control to the existing Typography section.
- Add paragraph-spacing numeric control to the existing Typography section.
- Save both values through `patchDocumentTypographyProfile(...)`.
- Keep line height clamped to the existing service rule: at least `fontSizePx + 2`.
- Keep paragraph spacing clamped to `0..32`.
- Apply paragraph spacing to document text blocks through CSS variables.
- Add model and runtime boundary checks.
- Add a V2.BN.8.10.3 patch note.
- Run browser/manual smoke.

### Must Not Do

- Do not introduce per-block typography.
- Do not implement rich text span styling.
- Do not add role-specific typography.
- Do not implement typography measurement service yet. That belongs to V2.BN.8.10.4.
- Do not implement auto-pagination or export.
- Do not mutate TextFlow content.

## 4. Implementation Steps

### Step 1 - Red Checks

Update `client/scripts/canvasEngineModelContractCheck.ts`:

- `patchDocumentTypographyProfile(default, { lineHeightPx: 24 })` preserves `24`.
- `patchDocumentTypographyProfile(default, { lineHeightPx: 3 })` clamps up to at least `fontSizePx + 2`.
- `patchDocumentTypographyProfile(default, { paragraphSpacingPx: 12 })` preserves `12`.
- paragraph spacing below `0` clamps to `0`.
- paragraph spacing above `32` clamps to `32`.
- writing typography metadata does not mutate TextFlow text.

Update `client/scripts/canvasRuntimeBoundaryCheck.mjs`:

- `NoteChromeLayer.tsx` contains `data-typography-line-height`.
- `NoteChromeLayer.tsx` contains `data-typography-paragraph-spacing`.
- `NoteDetail.module.css` contains `--document-paragraph-spacing` in a document text selector.

Run:

```bash
npm run smoke:canvas-engine-model-contract
npm run check:canvas-runtime-boundary
```

Expected first result: fail for missing controls / markers.

### Step 2 - UI Controls

Modify `NoteChromeLayer.tsx`.

Add handlers:

```ts
const handleTypographyLineHeightChange = useCallback((event: ChangeEvent<HTMLInputElement>) => {
  const nextProfile = patchDocumentTypographyProfile(documentTypographyProfile, {
    lineHeightPx: Number(event.target.value),
  });
  void onSaveDocumentTypographyProfile(nextProfile);
}, [documentTypographyProfile, onSaveDocumentTypographyProfile]);

const handleTypographyParagraphSpacingChange = useCallback((event: ChangeEvent<HTMLInputElement>) => {
  const nextProfile = patchDocumentTypographyProfile(documentTypographyProfile, {
    paragraphSpacingPx: Number(event.target.value),
  });
  void onSaveDocumentTypographyProfile(nextProfile);
}, [documentTypographyProfile, onSaveDocumentTypographyProfile]);
```

Add two compact numeric rows below `Size`:

```tsx
<label className={styles.typographyControlRow}>
  <span>Line</span>
  <input
    className={styles.typographyNumberInput}
    type="number"
    min={Math.max(documentTypographyProfile.fontSizePx + 2, DOCUMENT_TYPOGRAPHY_LIMITS.minLineHeightPx)}
    max={DOCUMENT_TYPOGRAPHY_LIMITS.maxLineHeightPx}
    step={1}
    value={documentTypographyProfile.lineHeightPx}
    onChange={handleTypographyLineHeightChange}
    data-typography-line-height="true"
  />
</label>
```

```tsx
<label className={styles.typographyControlRow}>
  <span>Spacing</span>
  <input
    className={styles.typographyNumberInput}
    type="number"
    min={DOCUMENT_TYPOGRAPHY_LIMITS.minParagraphSpacingPx}
    max={DOCUMENT_TYPOGRAPHY_LIMITS.maxParagraphSpacingPx}
    step={1}
    value={documentTypographyProfile.paragraphSpacingPx}
    onChange={handleTypographyParagraphSpacingChange}
    data-typography-paragraph-spacing="true"
  />
</label>
```

## 5. Paragraph Spacing CSS

Modify `NoteDetail.module.css`.

Use the smallest document-text selector that affects note writing content.

Preferred:

```css
.blockBox {
  margin-block-end: var(--document-paragraph-spacing, 0px);
}
```

If `.blockBox` affects too much layout chrome, use `.pageTextArea` or a text-content wrapper instead. The important rule is that spacing comes from `--document-paragraph-spacing`, not hard-coded block layout constants.
