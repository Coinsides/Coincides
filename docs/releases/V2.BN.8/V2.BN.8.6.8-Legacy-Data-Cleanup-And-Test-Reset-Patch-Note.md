# V2.BN.8.6.8 Legacy Data Cleanup And Test Reset Patch Note

status: implemented and verified

## Scope

V2.BN.8.6.8 retires the prototype surfaces that conflicted with the TextFlow-first / ContentGroup-first direction, then resets all prototype user data so the next subversions can build on a quiet schema.

This patch intentionally does not preserve existing user accounts or note data. Coincides has not entered production use, and every existing account in this branch was treated as disposable test data.

## Implemented

- Removed `AnnotationSet` from active runtime and active persistence surfaces.
- Retired `TextUnitGroup` from active writing UI/runtime behavior.
- Removed the old `DefinitionBlockProjection` path.
- Removed old structured block-template families from the active system template seed:
  - definition
  - theorem
  - proof
  - example
  - exercise
  - answer
  - heading
  - sidenote / warning / source quote style role templates
- Kept only active standalone block families that still have layout or rendering value:
  - paragraph/text
  - formula
  - code
- Hid the normal Advanced Insert entrance. Fixed role-shaped block insertion should not be the main path after TextFlow and ContentGroup become the product truth.
- Updated material-library and template-migration server tests so they expect the post-retreat `text.paragraph` seed instead of retired role templates.
- Reset the local prototype database and uploads after creating a backup.
- Created one clean reusable local test account for the continuing 8.6.9 / 8.6.10 work.
