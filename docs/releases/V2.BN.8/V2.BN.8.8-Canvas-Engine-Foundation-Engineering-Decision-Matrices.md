# V2.BN.8.8 Canvas Engine Foundation - Engineering Decision Matrices

> 目的：把第三阶段调研收束成 V2.BN.8.8 开工前必须补齐的工程决策表。它不是新一轮发散 brainstorm，而是正式 plan 的前置决策包。

## 0. 固定前提

V2.BN.8.8 的目标不是完整无限画布产品版，而是 Canvas Engine Foundation。

固定三条真相：

```text
TextFlow     = 内容真相
ContentGroup = 知识结构真相
Canvas       = 空间 / 布局真相
```

固定路线：

```text
Self-owned Minimal Hybrid NoteCanvas Engine
```

固定边界：

- 8.8 做有限可扩展 world，不做完整无限画布。
- 8.8 做 Canvas AI Tree read-only snapshot，不做真正 Agent 写入。
- 8.8 做 visual connector，不把普通箭头自动解释成 Relation。
- 8.8 做 PageFrame v1，不做完整 page template / export system。
- 8.8 做 object contract 和 runtime kernel，不追求完整 Object Family。

## 1. Data Lifecycle Matrix

### 1.1 目标

明确每类对象在创建、移动、复制、删除、刷新、导出、迁移时谁被改、谁不能被改。

### 1.2 核心实体生命周期

| Entity | Create | Move / Resize | Style | Delete | Duplicate | Refresh / Rebuild | Export |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `NoteCanvas` | note 首次进入 canvas runtime 时创建或读取 | 不移动 | 不直接承载 style | note 删除时删除 | note duplicate 时复制 | 可由 noteId 重建 shell | 不直接导出 |
| `CanvasObject` | 创建 PageFrame / block projection / shape / connector 时创建 | 不保存位置 | 不保存具体外观 | 删除对象时删除或 archive | 复制对象身份 | 可从 placement/mount 重建索引 | 作为 export inclusion 候选 |
| `CanvasPlacement` | 每次对象进入 canvas 时创建 | 移动/resize 的主要写入目标 | 不保存 style | object 删除时删除 | duplicate 时复制并偏移 | runtime 可重新索引 | 提供 export bbox |
| `ContentMount` | block-backed / projection-backed object 创建时创建 | 不变 | 不变 | detach 或 object 删除时删除 | 按 duplicate/fork/materialize 策略处理 | 目标缺失时进入 broken/degraded | 提供内容来源 |
| `PageFrameExtension` | PageFrame 创建时创建 | 尺寸可能随 placement 变化 | 保存 page-level template refs | PageFrame 删除时删除 | duplicate frame 时复制 | 可用 default template 重建部分字段 | 提供 page size / content rect |
| `VisualStyle` | pure shape / styled block 创建时创建 | 不保存位置 | style 的主要写入目标 | object 删除时删除 | duplicate 时复制 | 可 fallback 到 default style | 提供视觉样式 |
| `VisualConnector` | 用户画普通箭头/线时创建 | endpoint/object move 后重算几何或绑定 | line style 写这里或 style record | connector 删除时删除 | duplicate 时复制 | broken binding 可降级为 free connector | 可作为 visual element 导出 |
| `CanvasAIReadableSnapshot` | 由 runtime 派生 | 不直接写 | 不直接写 | 不需要删除真相 | 不复制 | 每次场景变化后重建/刷新 | 可作为 export/AI辅助输入 |
| `CanvasProposal` | AI / user batch draft 创建 | draft 状态可改 | draft 状态可改 | 可丢弃 | 可复制为新 proposal | 不是真相，可失效 | 不导出为正式内容 |
| `CanvasCommand` | 用户确认操作或 proposal apply 时创建 | command 记录变化 | command 记录变化 | command 记录变化 | command 记录变化 | 可用于 undo/replay | 可进入 audit package |

### 1.3 典型动作生命周期

| 用户动作 | 必须创建/修改 | 不能改 | 8.8 处理 |
| --- | --- | --- | --- |
| 创建 PageFrame | `CanvasObject(page_frame)`、`CanvasPlacement`、`PageFrameExtension` | TextFlow / ContentGroup | 必做 |
| 设置 primary PageFrame | `NoteCanvas.primaryFrameId` | PageFrame 内容 | 必做 |
| 创建 paragraph block | `NoteBlock`、`CanvasObject`、`CanvasPlacement`、`ContentMount(note_block)` | 其他 block | 必做 |
| 移动 block | `CanvasPlacement` | `NoteBlock.content_json` / TextFlow | 必做 |
| resize block | `CanvasPlacement.width/height`，必要时 measurement cache | TextFlow 内容 | 必做 |
| 给 block 加背景/边框 | `VisualStyle` | TextFlow | P1 |
| 创建 pure shape | `CanvasObject(shape)`、`CanvasPlacement`、`VisualStyle` | NoteBlock | P1 |
| shape 填文字 | `NoteBlock(paragraph)`、`ContentMount`，object 变 block-backed | shape placement | P1 |
| 清空 shape 文字 | 删除空 `NoteBlock` 与 `ContentMount`，保留 shape | shape object / placement / style | P1 |
| 创建 visual arrow | `VisualConnector`，可选 object binding | `KnowledgeRelation` | P1 |
| 删除 CanvasObject | 删除 object 及 placement/mount/style/connector binding | 被引用的源 ContentGroup / source text | P1 |
| duplicate object | 复制 object/placement/style，mount 按策略复制 | 源内容默认不 fork | P2 |
| materialize ContentGroup | 生成新 NoteBlocks / placements | 不移动原 ContentGroup / source | 8.10+ |
| AI 生成布局 | `CanvasProposal` | durable truth | 8.8 只留 contract |

### 1.4 删除策略

8.8 第一轮建议：

- 测试数据不做长期兼容。
- pure CanvasObject 删除走硬删。
- block-backed CanvasObject 删除时，若 NoteBlock 只被该 object 拥有，可一并删除；若 NoteBlock 是引用/复用，需要先进入 open decision。
- PageFrame 删除必须维护 primary frame 兜底规则。
- CanvasAIReadableSnapshot 是派生物，不做软删除。

## 2. Performance / Rendering Matrix

### 2.1 目标

明确什么走 DOM、什么走 SVG、什么走 overlay，哪些东西会触发测量、重绘、snapshot 刷新。

### 2.2 Render Layer Matrix

| Layer | 内容 | 技术形态 | 触发刷新 | 8.8 要求 |
| --- | --- | --- | --- | --- |
| BackgroundLayer | grid / workspace background | CSS / DOM | viewport zoom/pan | 简化实现 |
| PageFrameLayer | PageFrame outer/content rect | DOM | placement/frame config | 必做 |
| BlockLayer | paragraph block / existing block editor | DOM / React | TextFlow、placement、measurement | 必做 |
| CanvasObjectLayer | shape / image shell / table shell | DOM/SVG | object/style/placement | P1 |
| ConnectorLayer | visual connector / arrow | SVG | connector geometry、object move | P1 |
| OverlayLayer | selection handles / toolbar / context menu | DOM portal | selection/tool state | 必做 |
| DebugLayer | bbox / ai tree / coordinates | DOM/SVG | dev-only | P1 |

### 2.3 Object Rendering Matrix

| Object | 第一渲染方式 | 远距离 zoom 策略 | Measurement | Virtualization 需要 |
| --- | --- | --- | --- | --- |
| PageFrame | DOM | 保留 page outline / title | fixed + content rect | 多 frame 后需要 |
| paragraph block | DOM editor | 降级为 text preview / skeleton | 必须测量 auto-height | 大 note 后需要 |
| pure shape | SVG/DOM | 保留简化图形 | bbox fixed | 中等 |
| block-backed shape | DOM + shape shell | 降级为 shape + text preview | 必须测量文本 | 中等 |
| visual arrow | SVG | 可降级为简线 | geometry | 高连接数后需要 |
| image shell | DOM img | thumbnail / placeholder | natural size cache | asset 多时需要 |
| table shell | DOM table / structured renderer | skeleton | cell/viewport later | 后续 |
| ContentGroup projection | DOM card/tile | icon + label | fixed/card | 后续 |

### 2.4 Snapshot / Measurement Matrix

| 事件 | 需要重新测量 | 需要刷新 AI snapshot | 说明 |
| --- | --- | --- | --- |
| TextFlow 内容改变 | 是 | 是 | bbox/text 都可能变 |
| object move | 否 | 是 | bbox 位置变化 |
| object resize | 是 | 是 | text reflow |
| style 改变 | 视情况 | 是 | border/padding 可能影响 bbox |
| viewport pan | 否 | 可局部刷新 viewport context | durable layout 不变 |
| viewport zoom | 否 | 可刷新 visible state | world bbox 不变 |
| selection 改变 | 否 | 是 | selected context 改变 |
| PageFrame primary 改变 | 否 | 是 | page mode context 改变 |
| connector endpoint move | 否 | 是 | connector geometry 改 |

### 2.5 无限画布路线

| 阶段 | 能力 | 版本建议 |
| --- | --- | --- |
| 有限可扩展 world | world 有固定尺寸，允许手动或边缘扩展 | 8.8 |
| 自动边缘扩展 | 拖到边缘或创建越界对象时扩容 | 8.9 / 8.10 |
| render window | 只渲染视野附近对象 | 8.9+ |
| spatial index | 按 bbox / chunk 查询对象 | 8.10+ |
| tile/chunk virtualization | 区块化渲染，远距离降级 | later |

## 3. Migration / Cleanup Matrix

### 3.1 目标

明确现有 canvas seed 类型如何拆到新合同里，以及哪些旧测试数据不再兼容。

### 3.2 当前类型到新合同

| Current / Seed | 新合同 | 迁移策略 | 8.8 |
| --- | --- | --- | --- |
| `CanvasWorldModel` | `NoteCanvas.world` | 字段吸收 | 必做 |
| `CanvasViewport` | runtime viewport state | 保留为运行时/用户偏好，不当内容 truth | 必做 |
| `PageFrameModel` | `CanvasObject(page_frame)` + `CanvasPlacement` + `PageFrameExtension` | 拆分 | 必做 |
| `BlockPlacementModel` | `CanvasObject(paragraph_block_projection)` + `CanvasPlacement` + `ContentMount(note_block)` | 拆分 | 必做 |
| `CanvasObjectReserve` | `CanvasObject` | 从 reserve 升级成正式对象 | 必做 |
| `RelationEndpointReserve` | later Relation / ContentGroup Mode reserve | 保留概念，不接普通 arrow | 延后 |
| `better_notebook_layout` | import/reference only | 不写长期 converter | 只保留短期导入或清理 |
| note metadata canvas payload | entity-backed canvas tables / services | 未投产可清理测试数据 | 必做决策 |

### 3.3 清理原则

Henry 已明确：当前产品未投产，所有账号数据均为测试数据。不要为了短期测试数据背长期兼容债。

因此：

- 不为了旧 metadata payload 写永久兼容。
- 不为了旧 PageFrame / placement seed 写长期 converter。
- 允许清理测试账号数据后用新账号重建数据。
- 需要保留的只是开发证据、patch note、plan、contract，而不是旧测试数据。

### 3.4 迁移最小路径

1. 先定义新合同。
2. 写 read-side adapter：如果存在新实体，读新实体。
3. 对旧 seed 只提供一次性 import 或 dev reset。
4. import 成功后允许 strip legacy metadata。
5. 之后只维护新实体路径。

### 3.5 不做

- 不做生产级用户数据迁移。
- 不做跨版本永久兼容层。
- 不做 GraphRAG/source/relation 数据迁移。
- 不做完整 CanvasObject reuse 迁移。

## 4. Validation / Acceptance Matrix

### 4.1 目标

每个 sub-plan 必须知道如何验收，不能只靠“看起来能用”。

### 4.2 验证矩阵

| Sub-plan | Model / Contract | Browser / Manual | Build / Static | 通过标准 |
| --- | --- | --- | --- | --- |
| 8.8.1 Data Contract | canvas entity contract check | 不必须 | typecheck/build | 新合同能表达 PageFrame/block/shape/connector |
| 8.8.2 Runtime Kernel | coordinate / viewport unit check | pan/zoom smoke | build | world/screen 转换稳定 |
| 8.8.3 PageFrame v1 | primary frame invariant check | 创建/切换/刷新 PageFrame | build | Page Mode 聚焦 primary |
| 8.8.4 Block Projection | mount/placement integrity check | 创建 block、移动、刷新 | build | TextFlow 不被 placement 污染 |
| 8.8.5 Shape/Connector | pure vs backed object check | shape 填文字、清空、箭头 | build | pure shape 不产生 block；arrow 不产生 Relation |
| 8.8.6 Command/History Seed | command delta check | move/resize undo seed | build | 关键写入不绕过 command |
| 8.8.7 Canvas AI Tree | snapshot schema check | debug snapshot inspect | build | bbox/frameId/zIndex/selected context 可读 |
| 8.8.8 Experience Gate | integrated smoke | 新笔记全流程 | build + diff check | 体验闭环，风险记录清楚 |

### 4.3 必跑命令建议

```text

```

```text

```

```text

```

3. Page Mode 聚焦 primary PageFrame。
4. 切 Canvas Mode。
5. 创建 paragraph block。
6. 移动 block 到 PageFrame 外。
7. 创建 shape。
8. shape 填文字。

10. 创建 visual arrow。

## 5. Open Decision / Risk Register

### 5.1 必须在 8.8 开始前确认

| 决策 | 默认建议 | 风险 | 状态 |
| --- | --- | --- | --- |
| 8.8 是否做完整无限画布 | 不做；做有限可扩展 world | 过早做会拖垮坐标/渲染 | 建议固定 |
| 8.8 是否做 image/table | image shell/table shell 可选，不做成熟对象 | Object Family 膨胀 | 待 Henry 拍板 |
| 8.8 是否启用 rotate UI | 字段预留，UI 延后 | 文本编辑和 bbox 复杂 | 建议延后 |
| 8.8 history 做多深 | command/delta seed，undo 可最小 | 不做会影响后续 Agent | 建议做 seed |
| PageFrame 删除策略 | 维护 primary 兜底，最后一个 frame 自动 primary | 删除导致 note 打开错乱 | 建议固定 |
| crossing object 导出策略 | 8.8 只标记 crossing，不做完整导出 | 导出规则不清 | 8.9 再做 |
| visual arrow 是否绑定 Relation | 不绑定 | 污染 Relation / GraphRAG | 必须固定 |
| Agent 是否能写 Canvas | 不能；只 proposal | AI 黑箱改数据 | 必须固定 |
| 是否保留旧 test data | 不保留长期兼容 | dev 数据丢失 | 已接受 |

### 5.2 主要风险

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| TextFlow editor 在 transformed canvas 中光标/selection 异常 | 直接影响写作 | 先做有限 zoom、严控 DOM transform 层级 |
| measurement 不稳定 | block overlap / AI bbox 错 | 建 MeasurementService 和 invalidation |
| PageFrame 与 workspace 边界混乱 | 用户心智混乱 | inside/outside/crossing 明确入合同 |
| command 绕过 | undo/Agent/proposal 后续难做 | 关键写入走 command dispatcher |
| Object Family 膨胀 | 8.8 失控 | image/table/diagram/chart 全部以 shell/defer 处理 |
| AI snapshot 成第二真相 | 数据污染 | snapshot 派生、可丢弃、可重建 |

## 6. 结论

这五张表补齐后，V2.BN.8.8 可以进入正式 plan。

正式 plan 应从以下顺序开工：

1. Data Contract。
2. Runtime Kernel。
3. PageFrame v1。
4. Block Projection v1。
5. Shape / Connector v1。
6. Command / History Seed。
7. Canvas AI Tree v1。
8. Experience Gate。
