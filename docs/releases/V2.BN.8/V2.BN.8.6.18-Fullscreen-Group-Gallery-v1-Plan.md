# V2.BN.8.6.18 Fullscreen Group Gallery v1 Plan

> **For agentic workers:** Follow this plan exactly. Use `superpowers:executing-plans` when implementing. Gallery must be a full page, not a floating bubble panel.

**Goal:** 建立全屏 Group Gallery 第一版：左侧全局导航入口，资源管理器式 folder tree，右侧 ContentGroup 浏览区。
**Experience Test Policy:** 默认不使用 browser harness。体验测试优先 browser-use / in-app browser。
**Stop Point:** 用户能从左侧导航进入 Group Gallery，并按 folder / topic / role 三种视角浏览 ContentGroup。

---

## 0. 版本定位

8.6.18 是 ContentGroup Editor 的第一个真正完整页面。它与 Page / Canvas 平行，不是覆盖在当前笔记上的气泡窗。

## 1. 不做什么

- 不做 Single Group 细编辑。
- 不做 Petal 内容分配。
- 不做复杂搜索。
- 不做 relation graph。
- 不做 AI 生成临时 folder。

## 2. 预计触点

- 应用路由入口，实施时定位 `client/src` 中现有 route / navigation 文件。
- `D:/Coinsides/v2.x/Coincides/client/src/pages/Notes/canvasEngine/groupFolderService.ts`
- `D:/Coinsides/v2.x/Coincides/client/src/pages/Notes/canvasEngine/contentGroupService.ts`
- 可新增 `client/src/pages/GroupGallery/GroupGalleryPage.tsx` 或项目现有结构下的等价页面。
- 侧边导航组件。

## 3. 实施任务

### Task 1: 左侧导航入口

- [ ] 在左侧导航加入 `Group Gallery`。
- [ ] 入口与 Home / Projects / Source Library / Template Studio / Settings 平行。
- [ ] 点击进入全屏页面。
- [ ] 不通过 note 内气泡窗进入。

### Task 2: 页面框架

- [ ] 页面左侧是 folder tree。
- [ ] 页面右侧是 group list / cards。
- [ ] 顶部有当前路径 breadcrumb。
- [ ] 支持从 Gallery 返回关联 project / note。

### Task 3: Folder view

- [ ] 默认进入 folder view。
- [ ] folder 优先显示。
- [ ] ContentGroup 在 folder 后显示。
- [ ] ContentGroup 默认按 `updated_at` 倒序，若无则按 `created_at` 倒序。

### Task 4: Topic view

- [ ] 增加 `Topic` 切换。
- [ ] Folder 仍作为当前位置/路径存在，不被 topic 分组吞掉。
- [ ] Groups 按 topic 聚合。
- [ ] 无 topic 的 group 放入 `Untitled topic` 或等价空态。

### Task 5: Role view

- [ ] 增加 `Role` 切换。
- [ ] Groups 按 role 聚合。
- [ ] 无 role 的 group 放入 `No role` 或等价空态。
- [ ] role 只是局部说明，不预设 canonical role。

### Task 6: 打开 Single Group

- [ ] 点击 group card / row 进入 Single ContentGroup Editor。
- [ ] 若 8.6.19 尚未实现，可先进入占位页。
- [ ] 入口必须是明确页面切换，不是小弹窗。

## 4. 合格标准

- 左侧导航能进入 Group Gallery。
- Gallery 是全屏页面。
- Folder tree 能浏览 workspace / project / note root。
- 能按 folder / topic / role 三种视图切换。
- 点击 group 有通往细编辑页面的路径。
