# V2.BN.8.9.9 PageFrame Command Surface And Creation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give users natural PageFrame / PageStack creation entry points through a minimal command surface, toolbar action, and blank Canvas context menu.

**Architecture:** Reuse the existing PageFrame collection persistence and command menu foundation. Add a small PageFrame command vocabulary that both toolbar and context menu can call, so future toolbar, shortcut, right-click, and Agent proposal paths do not grow separate behavior.

**Tech Stack:** React + TypeScript, Vite, lucide-react icons, existing `ContextMenuLayer`, `commandSurfaceService`, `pageFrameCollectionService`, `useRuntimePresentationController`, `NoteChromeLayer`, `NoteWritingSurfaceLayer`, and V2.BN.8 model/boundary smoke scripts.

---

## 0. Scope Lock

### This version does

- Add PageFrame command surface seed.
- Add toolbar entry for creating a PageFrame / PageStack.
- Add blank Canvas context menu entry for creating a PageFrame / PageStack.
- Route both entries through existing PageFrame collection persistence.
- Keep 8.9.9 focused on creation and minimum object operation entry.

### This version does not do

- Full context menu system for every Canvas object.
- PageFrame drag/move/resize/configure maturity.
- Continuous PageStack v1.
- PageSlice extraction / merge / split.
- TextFlow typography maturity.
- ContentGroup projection.

- [x] **Step 2: Implement creation handler**

In `useRuntimePresentationController`, create a handler:

```ts
const handleCreatePageFrame = useCallback(() => {
  const afterFrameId = currentPageFrameCollection.selectedFrameId
    || currentPageFrameCollection.primaryFrameId
    || currentPageFrameCollection.pageFrames[currentPageFrameCollection.pageFrames.length - 1]?.id
    || null;
  if (!afterFrameId) return;
  void options.onSavePageFrameCollection(insertPageFrameAfter(currentPageFrameCollection, afterFrameId));
}, [currentPageFrameCollection, options]);
```

If the note has zero PageFrames, stop and record an open issue rather than inventing a new creation path in this version.

- [x] **Step 3: Pass it to UI layers**

Pass `onCreatePageFrame` into `NoteChromeLayer` and `NoteWritingSurfaceLayer`.
