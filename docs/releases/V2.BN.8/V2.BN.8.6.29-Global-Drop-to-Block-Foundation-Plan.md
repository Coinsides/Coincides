# V2.BN.8.6.29 Global Drop-to-Block Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 Draft Range / Label / Block 的拖拽不再只服务于 ContentGroup intake，而是能在 Page / Canvas 空白区域生成新的可见 block。

**Architecture:** 本版本把 drop target 分成两类：drop into ContentGroup 仍然创建引用，不移动原文；drop into document / canvas 才创建可见内容。第一版默认使用 copy / projection 语义，避免破坏原文；真正拖入正文改变位置留给 8.6.30。

**Tech Stack:** React, TypeScript, Vite, Canvas Engine, TextFlow service, draft block creation flow, HTML Drag and Drop / pointer drop layer.

---

## 1. 本版本边界

本版本只做：

```text
Draft Range / Label -> PageFrame 空白处 -> 新 TextBlock
Draft Range / Label -> Canvas scratch 空白处 -> 新自由 block
Block -> Page / Canvas -> 复用现有 block placement / copy 语义
```

本版本不做：

- 同一个 TextBlock 内部文字重排；
- 跨 TextBlock 精确插入；
- 拖进某个已有段落中间；
- table / image / canvas object item；
- 高级 drag undo；
- relation / source snapshot 新能力。

## 3. Drop 语义

必须明确两条路：

```text
Drop into ContentGroup
  -> add ContentGroupMember reference
  -> source text stays where it is

Drop into Page / Canvas
  -> create visible block
  -> source text also stays where it is
  -> first version is copy/projection
```

Invalid drop 必须有反馈：

```text
不支持的位置:
  不创建 block
  不删除原文
  显示轻量提示或保持 no-op
```

## 4. Task 1: Payload 转可见文本

**Files:**

- Modify: `client/src/pages/Notes/canvasEngine/contentGroupDragService.ts`
- Modify: `client/src/pages/Notes/canvasEngine/textFlowService.ts`

- [ ] **Step 1: 增加 payload -> plain text helper**

在 `contentGroupDragService.ts` 增加：

```ts
export function plainTextFromContentGroupDragPayload(payload: ContentGroupDragPayload): string {
  if (payload.kind === 'draft_range' || payload.kind === 'draft_ranges') {
    return payload.ranges
      .map((range) => range.range_text_cache?.trim())
      .filter((text): text is string => Boolean(text))
      .join('\n');
  }
  if (payload.kind === 'label') {
    const rangeText = payload.ranges
      ?.map((range) => range.range_text_cache?.trim())
      .filter((text): text is string => Boolean(text))
      .join('\n');
    return rangeText || payload.text_preview || payload.label || '';
  }
  if (payload.kind === 'block') return payload.text_preview || payload.label || '';
  return '';
}
```

验收：multi-range payload 生成多行文本；空文本 payload 不创建 block。

- [ ] **Step 2: 增加 payload -> TextFlow helper**

在 `textFlowService.ts` 使用现有 `createTextBlockContentV1`：

```ts
export function createTextFlowFromDroppedText(text: string): TextBlockContentV1 {
  return createTextBlockContentV1(text.trimEnd(), 'paragraph', {
    projection_source: 'drag_drop_projection',
  });
}
```

验收：新 block 的内容进入 TextFlow，而不是只写 `body` 字段。
