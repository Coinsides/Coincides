## 4. Current Doctrine

The current Better Notebook model is:

```text
Raw Source
  original evidence truth

TextFlow
  Coincides-owned content truth for natural writing

ContentRange
  address / location truth

SelectionDraft
  temporary user selection before an action commits

Label / AnnotationTruth
  visible marker and reusable range package

ContentGroup
  serious content package made from traceable members

Petal
  local role inside one ContentGroup

GroupFolder
  resource manager, browsing path, Gallery boundary, and future local graph scope

Relation
  later logical relationship between meaningful packages or local parts
```

Short rule:

```text
TextFlow is content truth.
Label is a visible mark.
ContentGroup is the serious package.
Petal is the local part.
GroupFolder decides where groups live.
Relation comes later.
```

## 5. User Experience Target

Better Notebook should stay natural first.

The user flow should feel like:

```text
write naturally
  -> mark useful ranges with labels
  -> collect fragments into ContentGroups
  -> organize groups through GroupFolders and Gallery
  -> refine one group into Petals
  -> later build relation / AI-reading views
```

The ordinary note must still feel like a note, not a pile of engineering structures.

The ContentGroup system has three surfaces:

```text
Groups Rail
  quick collection in the current scope

Group Gallery
  full-page resource manager and browsing surface

Single ContentGroup Editor
  focused refinement surface for one group and its Petals
```

Negative prompt:

- Do not turn Group Gallery into a local bubble panel.
- Do not stack rounded bubble forms endlessly.
- Do not show every action as a visible button.
- Do not show Petal as a naked label in source text.
- Do not shrink the main reading width with permanent gutters.
