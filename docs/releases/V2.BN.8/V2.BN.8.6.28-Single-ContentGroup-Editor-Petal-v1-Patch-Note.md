# V2.BN.8.6.28 Single ContentGroup Editor Petal v1 Patch Note

## What Changed

- Added `docs/contracts/Petal-Contract.md`.
- `Petal` now has an explicit fragment-first boundary inside `ContentGroup`.
- Annotation members preserve their source ranges in metadata so multi-range labels can be unfolded later.
- Added service helpers:
  - `createContentGroupFragmentFromMember`
  - `addMemberFragmentToPetal`
  - `removeContentGroupPetalFragment`
- Single ContentGroup Editor can show assignable member pieces and assign them to existing Petals.
- Petal rows now display fragment label, fragment preview, and source member context.

## Safety Boundary

Deleting or removing a Petal fragment does not delete:

- source text;
- Label / AnnotationTruth;
- top-level ContentGroup members;
- other Petals that may reference the same source member.

## Deferred

- Petal drag sorting.
- AI-created Petals.
- Table/image/canvas-object internal fragments.
- OpenDesign visual parity.
- Relation truth.
