# V2.BN.8.11.5 Object-Style Preset And Sticky Note Patch Note

> **Status:** implemented
> **Date:** 2026-06-29
> **Scope:** Structured Object Family / object-style preset / sticky note v1

## 1. 本次完成了什么

8.11.5 把 sticky note 定义为一种 **CanvasObject presentation**，而不是新的内容类型。

现在 sticky note 的底层结构是：

```text
CanvasObject.kind = shape
CanvasObject.backing = note_block
CanvasObject.objectClass = block_backed
CanvasObject.metadata.object_style.preset_id = shape.sticky_note
ContentMount.targetKind = note_block
backing block = paragraph block / TextFlow truth
```

这意味着：用户看到的是便签，但内容真相仍然是 paragraph block / TextFlow。

## 2. 工程改动

- 新增 `objectStyleService.ts`，集中管理 object-style preset 的读写、规范化、sticky 判定、CSS 解析和 AI presentation ref。
- `shapeSavePayload()` 现在会保留并规范化 `metadata.object_style`，移动、缩放、保存 shape 时不再丢失样式。
- 后端 shape validator 现在允许 `shape.default` / `shape.sticky_note`，并拒绝 pure shape 携带 sticky preset。
- Shape 渲染层读取 `object_style`，并暴露 `data-canvas-object-style-preset` 与 `data-canvas-object-presentation`。
- AI-readable layout 节点新增 `presentationRef`，AI 可以知道对象是 default shape 还是 sticky note，但正文仍从 `contentRef` / backing block 读取。
- Canvas/PageFrame 右键菜单新增 `Sticky note` 创建入口。
- Block-backed shape 右键菜单支持在 plain shape style 与 sticky note style 之间切换。

## 3. 没做什么

- 没有新增 `canvas_object_styles` 数据表。
- 没有做用户自定义样式库。
- 没有做完整 style inspector / top bar / ribbon。
- 没有把 sticky note 做成新的 `block_type`。
- 没有做 rich text span 样式。
- 没有做 image / table / visual connector。

## 5. Browser Smoke

- Confirmed Canvas surface context menu exposes `Sticky note`.
- Confirmed created sticky note persists as `CanvasObject.kind = shape`, `backing = note_block`, `object_style.preset_id = shape.sticky_note`.
- Confirmed DOM exposes `data-canvas-object-style-preset="shape.sticky_note"` and `data-canvas-object-presentation="sticky_note"`.
- Confirmed backing paragraph text survives reload.
- Confirmed style can switch `shape.sticky_note -> shape.default -> shape.sticky_note` without losing backing text.
- Note: `browser-harness type_text()` did not reliably trigger React textarea input in this surface; the smoke used native textarea value setter plus `input/change` events to verify the app save path. This is treated as a test-tool limitation, not a product bug.

## 6. 剩余风险

- 视觉样式只是 v1，可用但不是最终审美。
- object-style 目前仍存放在 `canvas_objects.metadata.object_style`；等用户自定义样式库或跨对象复用样式成熟后，再考虑独立表。
- 移动/缩放通过同一 `shapeSavePayload()` 保存路径保留 style metadata；本轮浏览器 smoke 未做脆弱拖拽自动化，后续人工测试仍可以继续覆盖真实拖拽体验。
