# V2.BN.8.9.17 PageSlice Snapshot And Reference v1 Plan

## 目标

让 PageStack 中的某一张物理页可以被系统理解为一个 `PageSlice`：它可以生成整页快照，可以形成引用描述，也可以成为 ContentGroup member 的候选对象。

这个版本只做整页粒度，不做页内细范围选择，不做真实导出/PDF，不做 PageSlice 的大 UI。核心是把语义和模型边界先打稳。

## 范围

- PageSlice 来自 PageStack 内的一个 PageFrame。
- PageSlice 记录 `noteId`、`pageStackId`、`pageFrameId`、页序号、页总数、页面外框、正文区域、整页 block id 列表、快照文本、快照 hash。
- PageSlice reference 只记录可回到原始页的目标，不复制整页内容。
- PageSlice snapshot 可以生成 `kind = page_slice` 的 ContentGroup member candidate。
- `page_slice` 是 snapshot-first member，不会自动写回 PageFrame，也不会重排 TextFlow。

## 不做

- 不做页内局部 range 的 PageSlice。
- 不做 PageSlice 的图片/PDF渲染。
- 不做 PageSlice detach / split / merge 操作。
- 不做 PageSlice Gallery 或大型 UI。
- 不做自动分页和跨页 block split materialization。

## 实施步骤

### 1. 先加失败的模型契约

在 `client/scripts/canvasEngineModelContractCheck.ts` 增加 `PageSlice snapshot and reference v1`：

- 两页 PageStack 中第二页能生成 PageSlice snapshot。
- snapshot 必须记录 PageStack、PageFrame、页序号、页总数、open-original target。
- reference descriptor 只保留引用语义和预览，不变成第二份页面真相。
- ContentGroup member candidate 必须是 `page_slice`，并保留 snapshot metadata。
- 缺失 PageFrame 时必须返回 `null`。

### 2. 增加 PageSlice 类型和服务

在 `types.ts` 增加：

- `PageSliceSnapshotV1`
- `PageSliceReferenceDescriptor`
- `PageSliceOpenOriginalTarget`

新增 `pageSliceService.ts`：

- `createPageSliceSnapshot(...)`
- `createPageSliceReferenceDescriptor(...)`

### 3. 接入 ContentGroup member 边界

更新：

- `runtimeDataTypes.ts`
- `contentGroupService.ts`
- `server/src/services/contentGroups.ts`

要求：

- `ContentGroupMemberKind` 支持 `page_slice`。
- `createContentGroupMemberFromPageSliceSnapshot(...)` 生成 snapshot-first member。
- `source_ref.metadata` 保留 PageSlice 的来源信息。

### 4. 加 runtime boundary

更新 `canvasRuntimeBoundaryCheck.mjs`：

- 保护 `pageSliceService.ts`。
- 保护 runtime types 中的 PageSlice contracts。
- 保护 client/server `page_slice` kind。

### 5. 验证

必须运行：

```text
npm run smoke:canvas-engine-model-contract
npm run check:canvas-runtime-boundary
npm run build:client
git diff --check
npm run check:changed-file-secrets
```

## 验收标准

- PageSlice 是 PageStack/PageFrame 的整页快照语义，不是新的页面真相。
- AI 和后续 ContentGroup 能稳定读到它来自哪一页。
- 引用语义能回到原始 PageStack/PageFrame。
- ContentGroup member 记录的是快照，避免原文变化污染 member。
- 8.9.18 可以基于这个能力做收口评估。
