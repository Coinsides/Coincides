# V2.BN.8.8.4 Block Projection v1 Foundation Patch Note

Date: 2026-06-25

Status: completed scoped engineering pass and verified.

## Summary

8.8.4 把 paragraph block 正式推进为 TextFlow-backed CanvasObject projection 的第一版服务边界。

这一步的重点不是可见 UI，而是把未来创建 / 移动 / 缩放 / 样式化 block 时必须遵守的底层规则立住：

```text
TextFlow = content truth
CanvasObject / Placement / VisualStyle = layout and presentation truth
ContentMount = bridge
```

## Completed

- Added `blockProjectionService.ts`.
- Added `createParagraphBlockProjection`:
  - creates a paragraph `NoteBlock`;
  - attaches `TextBlockContentV1` under `TEXT_FLOW_CONTENT_KEY`;
  - writes layout metadata through `writeLayoutOverride`;
  - derives `BlockPlacementModel`;
  - derives `paragraph_block_projection` CanvasObject;
  - derives `ContentMount`;
  - optionally derives `VisualStyle`.
- Added placement-only block projection helpers:
  - `moveBlockProjectionPlacement`;
  - `resizeBlockProjectionPlacement`.
- Added `restoreBlockProjectionLayout` so refresh can recover placement from stored layout metadata.
- Added `Block Projection v1 foundation` model contract group.
- Updated runtime boundary check so the Block Projection service is protected.
- Exported the service from the canvasEngine index.
- Updated `V2.BN.8.8-Canvas-Engine-Implementation-Checklist.md`.

## Engineering Boundary

This patch keeps block projection service-level only.

Important boundaries:

- Moving or resizing a projection changes placement data, not TextFlow content.
- Visual style attaches to CanvasObject, not the paragraph text.
- PageFrame block and workspace block are both supported at the service layer.
- Workspace block projections are not forced into PageFrame.
- Stored layout metadata remains the current compatibility bridge until durable CanvasObject storage arrives.

## Not Included

- No visible block creation UI rewrite.
- No drag / resize UI migration to `blockProjectionService`.
- No command dispatcher integration for create / move / resize.
- No durable CanvasObject database migration.
- No block-backed shape promotion / demotion.
- No table / image / formula projection redesign.
- No ContentGroup projection, Relation runtime, Agent write path, or GraphRAG.

## Remaining Risks

- Existing visible block operations are not yet wired through the new service.
- Command / history integration is still partial; 8.8.2 only introduced the move delta seed.
