# V2.BN.8.10.2 Font Family And Font Size Controls Patch Note

## Completed

- Added `DOCUMENT_FONT_FAMILY_OPTIONS` as the shared font-family option source for typography normalization and UI controls.
- Reused the typography service allowlist from the exported font-family options to prevent UI/service drift.
- Wired `saveDocumentTypographyProfile` from the note data adapter into runtime presentation and `NoteChromeLayer`.
- Added a compact document typography section inside the existing More panel.
- Added document-level font family, font size, and reset controls.
- Kept typography changes on the note-level profile path: UI -> `patchDocumentTypographyProfile(...)` -> `saveDocumentTypographyProfile(...)`.
- Added boundary and model checks for the new controls.

## Not Included

- No line-height control.
- No paragraph-spacing control.
- No per-block typography.
- No rich text spans.
- No auto-pagination.
- No export/PDF implementation.
- No CanvasObject or CanvasPlacement persistence migration.

## Manual Experience Check

Passed with Browser Harness on `http://localhost:5173/#/notes/7454b392-85b5-4c28-9b60-289ce88a38f7`.

Checked:

- More panel exposes `data-typography-controls="document"`.
- Font family control reads the default System Sans profile.
- Changing font family to `Georgia, serif` updates the runtime CSS variable.
- Changing font size to `18` updates `data-document-font-size="18"` and `--document-font-size: 18px`.
- Reloading the note preserves `Georgia, serif` and `18`.
- Reset restores the default font family and `15px`.
- Toggling Page -> Canvas -> Page does not mutate saved font size.
