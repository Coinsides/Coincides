Date: 2026-06-25

## Purpose

这份文档不是 Canvas 能力总目录，也不是设计愿景清单。它是 V2.BN.8.8+ Canvas Engine 的工程进度账本，用来回答：

```text
当前已经做了什么？
做到什么程度？
在哪个小版本完成？
用什么检查保护？
还差什么？
```

原始 research / inventory list 继续承担“能力地图”的职责；本文件只记录工程落地状态。

## Status Vocabulary

| Status | Meaning |
| --- | --- |
| `done` | 当前版本范围内已完成并有验证保护。 |
| `partial` | 底座或 seed 已完成，但完整体验/持久化/集成仍在后续版本。 |
| `planned` | 已进入 8.8+ 计划，但尚未实现。 |
| `deferred` | 有价值，但明确顺延到 8.9+ / 8.10+ / 9.x。 |
| `blocked` | 需要产品判断、架构判断或外部条件。 |
| `out_of_scope` | 当前 Canvas Foundation 不做。 |

## Maintenance Rule

Every V2.BN.8.8+ Canvas small version must update this checklist before final handoff:

1. Mark newly completed capabilities with `done` or `partial`.
2. Add evidence paths and verification commands.
3. Mark intentionally skipped work as `planned`, `deferred`, `blocked`, or `out_of_scope`.
4. Keep this file as a progress ledger, not a design essay.
