# V2.BN.8.7.8 Single Editor Refine Shell And Logic Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 Single ContentGroup Editor 从“表单 + 卡片堆”推进成一个清楚的 `Single Editor = refine` 表面，同时不实现真正的 Canvas/workbench。

**Architecture:** 8.7.8 只做非 Canvas 的 refine shell：顶部 identity/title/status、summary bar、member/material shelf、Petal dock、source/status drawer、契约检查和浏览器截图验收。真正的自由画布、material free placement、CanvasObject projection、source text projection、Relation runtime 全部继续顺延到 8.8+。

**Tech Stack:** React 18 + TypeScript + CSS Module + Vite；现有 ContentGroup / GroupFolder / Member / Petal entity-backed DTO；Node shell contract check；Browser Harness 视觉 smoke。

## Scope Lock

### In Scope

- 让 Single Editor 页面明确承担 `refine`，不是 collect，也不是 organize。
- 增加 Single Editor 专用 display model，集中计算 title、topic、role、status、folder path、member count、Petal count、source/status 文案。
- 把当前 title/topic/role/summary/status 操作收进更接近 OpenDesign `single-contentgroup-editor.html` 的 topbar + summary bar。
- 把 member 区从普通卡片堆调整为 `material shelf`：用户看到的是可被 Petal 消化的材料包，而不是原文被移动。
- 把 Petal 区调整为 `petal dock`：强调 Petal 是 ContentGroup 内部结构，支持现有创建、重命名、删除、排序、fragment assignment。
- 把 source/status 说明收成底部或侧边 `source drawer`：清楚说明 source truth 不被 Single Editor 编辑。
- 增加 `check:single-editor-shell`，固定 8.7.8 的非 Canvas 边界和关键 UI anchor。
- 8.7.8 patch note / CHANGELOG / Experience Review / Open Issues 同步。

### Out Of Scope

- 不做真正自由画布。
- 不做 OpenDesign 原型里的 `data-od-id="single-group-workbench"` 自由工作台。
- 不做 material 自由拖动、缩放、绝对坐标布局。
- 不做 CanvasObject / ContentGroup projection / mini editor。
- 不做 source text 上的 Petal projection。
- 不做 Reference / Duplicate / Fork / Materialize UI。
- 不做 Relation runtime / GraphRAG。
- 不做 SourceArtifact / SourceAnchor 完整迁移。
- 不做 destructive source mutation、true reorder、offset rebase。

- [ ] **Step 1: Create the model file**

Create a display-model layer that only formats existing truth:

```typescript
import {
  summarizeContentGroupStability,
} from '@/pages/Notes/canvasEngine/contentGroupService';
import type {
  ContentGroupV1,
  GroupFolderV1,
  Note,
} from '@/pages/Notes/canvasEngine/runtimeDataTypes';
import {
  cleanLabel,
  folderPathText,
  memberLabel,
  memberPreview,
} from './groupGalleryData';

export interface SingleEditorShellView {
  title: string;
  statusLabel: string;
  statusKind: string;
  topicLabel: string;
  roleLabel: string;
  summaryPreview: string;
  sourceNoteTitle: string;
  folderPath: string;
  memberCountLabel: string;
  petalCountLabel: string;
  stabilityLabel: string;
  stabilityReason: string;
  canAccept: boolean;
  acceptReason: string | null;
}

export function buildSingleEditorShellView(input: {
  group: ContentGroupV1;
  note: Note;
  folders: GroupFolderV1[];
  folder: GroupFolderV1 | null;
}): SingleEditorShellView {
  const stability = summarizeContentGroupStability({
    group: input.group,
    folder: input.folder,
  });
  const activePetals = input.group.petals.filter((petal) => petal.status !== 'deleted');
  const statusKind = input.group.identity.status === 'none' ? 'draft' : input.group.identity.status;

  return {
    title: cleanLabel(input.group.title, 'Untitled group'),
    statusLabel: statusKind,
    statusKind,
    topicLabel: cleanLabel(input.group.identity.topic, 'No topic'),
    roleLabel: cleanLabel(input.group.identity.role, 'No role'),
    summaryPreview: cleanLabel(input.group.identity.summary, 'No summary yet.'),
    sourceNoteTitle: cleanLabel(input.note.title, 'Untitled note'),
    folderPath: folderPathText(input.folders, input.group.folder_id || input.group.placements?.[0]?.folder_id || null),
    memberCountLabel: `${input.group.members.length} members`,
    petalCountLabel: `${activePetals.length} petals`,
    stabilityLabel: stability.label,
    stabilityReason: stability.reason,
    canAccept: !stability.accept_disabled_reason,
    acceptReason: stability.accept_disabled_reason,
  };
}

export function buildSingleEditorMemberHint(group: ContentGroupV1, memberId: string): string {
  const member = group.members.find((item) => item.id === memberId);
  if (!member) return 'Source member missing';
  return `${memberLabel(member)} / ${memberPreview(member)}`;
}
```

import { existsSync, readFileSync } from 'node:fs';
import { resolve } from 'node:path';

const root = process.cwd();

function readProjectFile(path) {
  const fullPath = resolve(root, path);
  if (!existsSync(fullPath)) throw new Error(`Missing required file: ${path}`);
  return readFileSync(fullPath, 'utf8');
}

function assertContainsAll(name, text, tokens) {
  const missing = tokens.filter((token) => !text.includes(token));
  if (missing.length > 0) throw new Error(`${name}: Missing ${missing.join(', ')}`);
}

function assertContainsNone(name, text, tokens) {
  const found = tokens.filter((token) => text.includes(token));
  if (found.length > 0) throw new Error(`${name}: Forbidden ${found.join(', ')}`);
}

const editor = readProjectFile('src/pages/GroupGallery/SingleContentGroupEditor.tsx');
const model = readProjectFile('src/pages/GroupGallery/singleContentGroupEditorShellModel.ts');
const css = readProjectFile('src/pages/GroupGallery/GroupGallery.module.css');

assertContainsAll('Single Editor keeps refine surface role', editor, [
  'CONTENT_GROUP_SURFACE_ROLES.editor',
  'data-content-group-surface',
  'data-content-group-role',
]);

assertContainsAll('Single Editor exposes non-canvas refine anchors', editor + model + css, [
