# V2.BN.8.7.3 ContentGroupMember Entity Cutover Patch Note

status: implemented and verified
date: 2026-06-22

## Implemented

- Added `content_group_members` as the active persistence table for `ContentGroupMember`.
- Moved active member persistence out of `content_groups.members_json`.
- Kept `ContentGroupV1.members[]` as the stable client API shape for Rail, Gallery, Single Editor, and reuse services.
- Added hard-delete behavior for members.
- Added hard cascade pruning for dependent embedded Petals and fragments.
- Added a focused member delete service and route through the ContentGroup service boundary.
- Added runtime boundary coverage so ContentGroup repository saves entity groups and does not write note metadata as a second member truth.

## Notes

- `ContentGroupMember` is now a group-owned child entity, not a standalone product surface.
- `ContentGroupPetal` and fragment records remain embedded until V2.BN.8.7.4.
- Member deletion does not create archived/deleted member rows.
- Member deletion does not mutate source text, source ranges, labels, note blocks, or source artifacts.
