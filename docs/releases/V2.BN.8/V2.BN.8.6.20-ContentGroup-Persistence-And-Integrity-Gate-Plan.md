# V2.BN.8.6.20 ContentGroup Persistence And Integrity Gate Plan

> **For agentic workers:** Follow this plan exactly. Use `superpowers:executing-plans` when implementing. This is a gate version: prioritize correctness over new UI.

**Goal:** 对 ContentGroup / GroupFolder / Member / Petal 做持久化与完整性检查，确认刷新、重开、删除、移动后数据不乱。
**Experience Test Policy:** 默认不使用 browser harness。体验测试优先 browser-use / in-app browser。
**Stop Point:** 数据层足够稳定，可以进入视觉和交互瘦身。

---

## 0. 版本定位

8.6.20 不是加功能，而是堵漏。ContentGroup 是未来 relation 的地基之一，不能出现 member 丢定位、folder 丢路径、Petal 丢归属这类问题。

## 1. 不做什么

- 不做新视觉。
- 不做 AI 功能。
- 不做 Gallery 新功能。
- 不做 relation graph。
- 不写旧数据 adapter。

## 3. 实施任务

### Task 1: 完整性扫描 helper

- [ ] 新增或整理 `validateContentGroupGraph()`。
- [ ] 检查 group 必须有 folder。
- [ ] 检查 folder parent 链不能循环。
- [ ] 检查 system root 必须存在。
- [ ] 检查 member 必须有 source locator。
- [ ] 检查 Petal 的 member 引用必须指向同 group 内 member。

### Task 2: 保存和刷新

- [ ] 新建 folder 后刷新不丢。
- [ ] 新建 group 后刷新不丢。
- [ ] 修改 group 字段后刷新不丢。
- [ ] 新增 member 后刷新不丢。
- [ ] 新增 Petal 后刷新不丢。
- [ ] 分配 member 到 Petal 后刷新不丢。

### Task 3: 删除语义

- [ ] 删除 ContentGroup 不删除原文。
- [ ] 删除 member 不删除原文。
- [ ] 删除 Petal 不删除 member，除非明确提供 remove assignment。
- [ ] 删除普通 folder 时必须处理内部 groups 和子 folder：第一版可拒绝非空删除。
- [ ] 系统 root folder 永远不能删。

### Task 4: 源文本变动同步

- [ ] 源文本修改后 member preview 可刷新。
- [ ] 源文本删除或 locator 失效时，member 显示 stale 状态。
- [ ] stale member 不能悄悄变成空字符串。
- [ ] range rebase 能处理基本文本插入/删除。

### Task 5: Gate 报告

- [ ] 写一个简短 patch note，列出通过的完整性项。
- [ ] 若发现已知不足，记录到 Open Issue 或后续 plan。

## 4. 合格标准

- 基础 CRUD 刷新后不丢。
- GroupFolder 不出现孤儿根或循环。
- Member 定位不丢。
- Petal 归属不乱。
- 删除不会误删原文。
- 失效来源有可见 stale 状态。
