# V2.BN.8.9.16 Cross-page Block Fragment v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让一个逻辑 paragraph block 在 PageStack 中跨越多个 PageFrame 时，先获得稳定的视觉分片提示和机器可读分片投影。TextFlow / NoteBlock 仍然只有一份真相，不在本版本自动拆分内容。

**Status:** Completed first implementation pass on 2026-06-27. See `V2.BN.8.9.16-Cross-page-Block-Fragment-v1-Patch-Note.md`.

**Architecture:** 新增一个纯模型服务，把 `PageFrameCollection + block layout` 编译成 `PageStackBlockFragmentProjection[]`。运行时把这些 projection 挂到 Canvas runtime、AI-readable snapshot 和 Block 外壳 DOM 上。UI 只展示“上接 / 下续”提示，不做行级分页、不做 Word-like 自动排版、不 materialize 新 block。

**Tech Stack:** React + TypeScript, existing Canvas Engine model services, `canvasEngineModelContractCheck.ts`, `canvasRuntimeBoundaryCheck.mjs`, Vite client build.

---

## 边界

本版本做：

- 检测一个 Block 的几何占地区域是否与同一个 PageStack 中多个 PageFrame 的内容区相交。
- 为跨页 Block 生成稳定 fragment projection：
  - `blockId`
  - `pageStackId`
  - `pageFrameId`
  - `pageIndex / pageTotal`
  - `fragmentIndex / fragmentTotal`
  - `role: single | start | middle | end`
  - `visibleRect`
  - `clippedTop / clippedBottom`
- Runtime 暴露 `blockFragmentProjections`。
- Canvas AI-readable snapshot 能读到 Block 的跨页 fragment metadata。
- Block 外壳 DOM 带稳定 marker，用户能看到轻量“上接 / 下续”提示。

本版本不做：

- 不做真实行级分页。
- 不把一个 NoteBlock 自动拆成多个 NoteBlock。
- 不改 TextFlow 内容真相。
- 不做 PageSlice snapshot/reference。
- 不做用户确认后的 split/materialize 流程。
- 不做 PDF/export 级别的分页裁切。
