# V2.BN.8.9.13 Continuous PageStack v1 Patch Note

Date: 2026-06-27

## Scope

This patch introduces `PageStack` as the explicit continuity relation for PageFrames.

Completed:

- Added `PageStackModel` and extended `PageFrameCollectionModel` with `pageStacks`, `primaryStackId`, and `selectedStackId`.
- Added `pageStackCollectionService.ts` for PageStack normalization, single-frame stack creation, add-page-below, detach, merge, collapse/expand, and stack-local numbering.
- Updated PageFrame collection metadata to `V2.BN.8.9.13` while keeping old metadata without `pageStacks` independent.
- Updated new PageFrame collection seed so A4-style note creation starts with one explicit primary PageStack.
- Updated the Project Detail `New Note` path so it writes PageFrameCollection seed metadata at note creation time instead of relying on runtime fallback.
- Routed New PageStack, Add page below, Detach from PageStack, and Collapse/Expand PageStack through runtime persistence.
- Added PageStack identity, local page index, total page count, collapse state, and local number label to runtime PageFrame extensions.
- Added PageStack container nodes and page-frame reference children to the Canvas AI-readable snapshot.
- Added PageStack grouping metadata to Export Preview without changing actual export behavior.
- Updated Canvas Mode PageFrame DOM markers and Layout panel grouping for PageStack vs independent PageFrames.
- Added model-contract and runtime-boundary coverage for PageStack service, runtime context, command surface, Project Detail New Note seed, DOM markers, AI Tree, and Export Preview metadata.

Product boundary:

- PageStack is layout continuity truth, not TextFlow truth and not Block ownership.
- Independent PageFrames stay independent unless a user command explicitly creates or attaches a stack.
- PageFrame move / resize still changes geometry only; stack membership remains explicit.
- Collapse hides pages from Canvas view only; it does not delete pages and does not hide the stack from AI-readable layout.

## Product Decision

The settled v1 model is:

```text
PageFrame = one physical page slice.
PageStack = ordered continuity relation among PageFrames.
Independent PageFrame = PageFrame with no PageStack membership.
```

This avoids splitting the product into `fixed PageFrame` and `continuous PageFrame` modes. A one-page document is simply a one-frame PageStack; a standalone canvas page is an independent PageFrame.
