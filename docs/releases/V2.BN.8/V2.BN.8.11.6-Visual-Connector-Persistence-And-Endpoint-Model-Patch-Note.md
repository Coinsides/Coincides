# V2.BN.8.11.6 Visual Connector Persistence And Endpoint Model Patch Note

> **Status:** implemented
> **Date:** 2026-06-29
> **Scope:** Structured Object Family / visual connector / visual-only endpoint model

## 1. 本次完成了什么

8.11.6 把 `visual_connector` 从 8.8 时代的 runtime seed 推进成了真正可持久化、可读回、可渲染、可进入 AI-readable layout 的普通 CanvasObject。

它的边界被明确钉住：

```text
CanvasObject.kind = visual_connector
CanvasObject.backing = none
CanvasObject.objectClass = pure
VisualConnector.relationKind = visual_only
```

这条线只表达画布上的视觉连接和布局提示，不是 Relation，不是 KnowledgeRelation，不复用 RelationEndpointReserve，也不承担 ContentGroup / Petal 的语义关系。

## 2. 工程改动

- 新增 `visual_connector_extensions` 服务端表，保存 visual-only 端点、锚点、线型、颜色、箭头和 metadata。
- 服务端 `saveCanvasObject` kind handler 新增 `visual_connector`，并拒绝 content-backed / semantic relation payload。
- `getSavedCanvasObject()` 和 `getNoteCanvasPersistence()` 现在会返回 `visualConnector` / `visualConnectors`。
- 删除 endpoint object 时，服务端会先硬删除引用它的 visual connector object，避免孤儿线。
- 客户端 persistence normalizer 新增 `visualConnectors` hydrate。
- Runtime model 现在从 persisted connector 生成 `visualConnectors`，并根据 endpoint object placement 重新计算 start / end 和 connector bbox。
- AI-readable tree 的 connector node 现在包含 `connectorRef`，并暴露 `startKind/endKind`、endpoint object、anchor、world points 和 `relationKind = visual_only`。
- 新增 `visualConnectorService.ts`，集中处理 endpoint anchor 计算、connector bbox 和 save payload。
- 新增 `VisualConnectorLayer.tsx`，用最小 SVG layer 渲染 visual-only arrow line。
- Shape 右键菜单新增最小连接流程：从一个 shape 开始连接，再在另一个 shape 上完成连接。
- Visual connector 本体支持右键删除；删除被连接的 shape 时，客户端运行时也会同步移除相关 connector。

## 3. 没有做什么

- 没有做 Relation runtime。
- 没有做 KnowledgeRelation / GraphEdge。
- 没有做 connector label、关系名、关系描述、权重、证据字段。
- 没有做复杂自动布线、折线/曲线编辑器、避让逻辑。
- 没有做完整 connector anchor editor。
- 没有做 flowchart / diagram mode。
- 没有做 ContentGroup projection。
- 没有做 image / table / asset-backed object。

## 5. 剩余风险

- Browser smoke 过程中发现并修复了客户端 `line_style='straight'` 与服务端 validator `solid/dashed/dotted` 不一致的问题；v1 统一为线条样式 `solid`，后续 diagram routing 的 straight/elbow/curve 不在本字段内提前表达。
- 当前交互是 v1：右键开始、右键完成，够用但不优雅；后续可以做拖拽手柄和 hover endpoint。
- 当前 connector 只支持最小直线箭头渲染；复杂折线、曲线、避让属于后续 diagram family。
- 当前 anchor 默认为 center，数据模型已经留出 north/east/south/west/auto，但 UI 还没有开放。
- 连接线视觉样式只是工程默认值，后续需要和 object-style / toolbar 体系一起打磨。
