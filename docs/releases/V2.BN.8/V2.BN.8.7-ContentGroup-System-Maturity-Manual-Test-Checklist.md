## Scope

This checklist verifies the ContentGroup System before the next CanvasObject / Canvas projection track resumes.

8.7 scope:

- Rail = collect.
- Gallery = organize.
- Single Editor = refine.
- ContentGroupMember = group-local content truth.
- ContentRange / SourceAnchor = source location truth.
- Petal = ContentGroup internal structure.
- Reference / Duplicate / Fork / Materialize / Open original semantics remain service-bound.

Out of scope:

- destructive source mutation;
- true reorder / offset rebase;
- relation runtime;
- GraphRAG;
- full database migration;
- CanvasObject reuse / projection.
