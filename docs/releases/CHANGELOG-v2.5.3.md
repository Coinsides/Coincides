# CHANGELOG v2.5.3

## Summary

v2.5.3 adds the first DomainBlockSet and PackageManifest runtime foundation.

- Added `PackageManifest` and `DomainBlockSet` runtime tables.
- Added membership tables linking domain sets to runtime templates and composition templates.
- Added system package seed `coincides.core.domain-seeds@0.1.0`.
- Added starter domain sets for math learning, research evidence, and briefing workflows.
- Added package preview/validation and domain compatibility report APIs.
- Added Template Studio lightweight Domain Packages section.

## Changed

- Updated the AI operating manual with package/domain safety rules.
- Updated v2.x continuity with v2.5.3 graph-native migration evidence.

## Deferred

- Full Package Studio, package import/export, template migration proposals, marketplace, and graph database migration remain deferred.
