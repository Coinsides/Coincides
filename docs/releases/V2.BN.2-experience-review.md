# V2.BN.2 Experience Review - Natural Page Writing

## Status

Implemented; Henry acceptance pending.

## Experience Questions

V2.BN.2 should be accepted only if the first writing action feels like a notebook:

- Does a blank note invite writing without exposing Add Block first?
- Does the user understand where typing will go?
- Does the page feel calmer than the old engineering card stack?
- Is slash command discoverable enough without dominating the page?
- Does conversion feel safe and reversible enough for a first seed?
- Do existing source-backed blocks still give useful provenance signals?

## Browser Smoke Notes

Browser smoke was completed against the running local app.

Observed:

- The blank note now opens as a quiet document page instead of an engineering Add Block form.
- First click creates an editable draft area with a clear caret and lightweight hint.
- The old Add Block form is still available under `Advanced block form`, which is good for fallback but no longer dominates the page.
- The hover/active block controls are less visually noisy than the old always-on card toolbar.
- `/definition` on an existing paragraph opens a conversion preview before mutating metadata, which feels safer than direct conversion.
- Formula/image/code are only first-pass command seeds; image remains disabled until the media data contract exists.

Impeccable review lens:

- This moves the note page closer to the product purpose: human-readable refined information, not an internal object editor.
- The page now has one obvious primary action: write.
- The implementation avoids turning draft state into canonical truth.

Taste review lens:

- The page is calmer, darker/white-mode compatible, and less glass-heavy.
- The content column is still simple and linear; true block resize, side-by-side layout, and A4 page affordances remain future work.
- The toolbar behavior is acceptable for a seed, but V2.BN.3 should make selection, resize handles, and layout mode more deliberate.
