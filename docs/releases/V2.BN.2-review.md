# V2.BN.2 Review - Natural Page Writing

## Status

Implemented; Henry acceptance pending.

## Quality Review

Findings:

- No blocking code issue found in the implemented V2.BN.2 path.
- The first implementation attempt exposed a payload contract bug: `POST /api/notes/:id/blocks` accepts omitted `title`, but rejects `title: null`. The client now omits the title for new blocks.
- Draft caret state stays local until blur, `Ctrl+Enter`, or slash command confirmation. This differs slightly from the early "first meaningful input immediately persists" wording, but better protects the database from partial/empty rows.
- Slash command `Image` is intentionally disabled because media/image blocks need the future media and data contract work.
- Delete behavior still uses the existing move-to-trash path. True delete-with-undo remains deferred and should be handled with the broader Better Notebook delete/undo design.

Implemented:

- Blank note page surface with click-to-write behavior.
- Existing blocks now read more like note content, with controls appearing on hover/active state.
- Runtime template options are used for new block metadata.
- Slash command seed supports grouped commands for text, heading, quote, definition, formula, code, and planned image.
- Paragraph-to-definition and paragraph-to-formula conversion now use deterministic preview plus user confirmation.
- Source badges and source jump behavior remain wired into the block editor.

## Graph-Native / Adapter Evidence

- `NoteBlock` remains canonical content truth.
- Draft caret state is UI-only and should not become graph truth.
- Slash command selection strengthens future `(:NoteBlock)-[:USES_TEMPLATE]->(:TemplateDefinition)` evidence because new blocks still write runtime template metadata.
- Structured conversion stores `structured_fields` seed metadata for definition/formula, which is useful future graph-label evidence, but V2.BN.2 does not create graph truth or graph edges.
- No GraphRAG adapter, source adapter, relation adapter, or external editor adapter was touched.
