## Interaction Findings

Status: `PASS_WITH_FOLLOWUP`

Expected interaction:

```text
Course Detail
  -> Reconcile
  -> Review candidate groups
  -> Mark reviewed or Discard
```

Important interaction promise:

- `Mark reviewed` does not merge, delete, hide, or rewrite source material.

## Workflow Findings

Status: `PASS_WITH_FOLLOWUP`

The workflow should feel like a first reconciliation audit pass, not a final merge tool.

The proposal must show:

- candidate group kind;
- evidence count;
- confidence;
- warnings;
- explicit review-only language.

Browser smoke remains pending for Henry local validation because Codex could not launch a temporary background server in this environment.
