## Code Review

v2.4.1 upgraded the static v2.4.0 A4 preview into a local interactive canvas surface.

Implemented:

- local React/CSS canvas fallback;
- pan and zoom;
- node selection;
- node move and resize;
- Canvas Document promoted out of the Course Material right rail into a top-level course workspace;
- focus mode for a larger canvas workspace;
- selected object scope display;
- layout persistence through existing `canvas_nodes`;
- viewport persistence through existing `canvas_viewport_states`;
- existing open/jump and archive actions retained.

No tldraw dependency was added. The tldraw gate remains documented for a later adapter spike.

## Graph-native Migration Notes

v2.4.1 strengthens the future graph-native boundary:

- `CanvasNode` is still projection, not knowledge truth.
- selected object scope should become a future bridge from human interaction to graph/AI operations.
- layout records are useful graph context but should not become semantic relation truth by themselves.
- future `ObjectRelation` should be separate from visual node placement.
