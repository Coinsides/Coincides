**Created**: 2026-05-23
**Updated**: 2026-05-23
**Branch**: `feat/v2.0-noteblock`
**Status**: Implemented

---

## 1. Version Boundary

v2.4.1 upgrades the v2.4.0 Learning Canvas seed into a basic interactive canvas editor.

The implementation uses a local React/CSS fallback canvas. `tldraw` remains the preferred future mature engine candidate, but it is not adopted in this patch because it requires a dependency and license/key decision that should be handled as a separate adapter spike.

---

## 2. Engine Ownership

Canonical state:

- `learning_canvases`
- `canvas_nodes`
- `canvas_viewport_states`

Adapter state:

- local pointer/zoom/selection UI state;
- future tldraw shape/editor state if adopted.

The adapter may render, select, move, resize, and zoom. It must not own NoteBlock/source/evidence/proposal truth.

---

## 3. API Contracts

v2.4.1 reuses existing routes:

```text
GET /api/canvases/:id
PUT /api/canvas-nodes/:id
PUT /api/canvases/:id/viewport
GET /api/canvas-nodes/:id/jump-target
POST /api/canvas-nodes/:id/archive
POST /api/canvases/:id/seed-from-source-board
```

Node layout persistence payload:

```json
{
  "x": 120,
  "y": 240,
  "width": 320,
  "height": 180
}
```

Viewport persistence payload:

```json
{
  "viewport_x": 40,
  "viewport_y": 24,
  "zoom": 0.85
}
```

No new migration is required.

---

## 4. Frontend Contract

The Course Detail `Canvas Document` panel renders an interactive surface:

- pan by dragging empty canvas space;
- zoom with wheel or toolbar controls;
- reset view;
- select a node;
- drag a node by its body/header;
- resize from bottom-right handle;
- open source-backed node target;
- archive node;
- show selected object scope.

Selected object scope shape:

```json
{
  "canvas_id": "canvas-id",
  "canvas_node_id": "canvas-node-id",
  "node_type": "source_board_node",
  "target_type": "source_board_node",
  "target_id": "target-id"
}
```

---

## 5. Safety Rules

- Canvas movement updates only layout records.
- Viewport changes update only session records.
- Open/jump delegates to existing source jump-target behavior.
- Canvas must remain usable without any external engine snapshot.
- Future tldraw shape ids must be treated as adapter ids, not domain ids.
