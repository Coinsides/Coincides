# v2.3.1 Engineering Spec - Source Anchor + Jump Back

**Created**: 2026-05-22
**Updated**: 2026-05-22
**Status**: Implemented

---

## 1. Implementation Boundary

v2.3.1 adds a stable SourceAnchor pointer layer on top of existing source snapshots.

It implements:

- additive SourceAnchor tables;
- idempotent anchor generation from NoteBlock source references and EvidenceItems;
- source anchor list/detail/jump/refresh APIs;
- Note editor `View source` jump-back;
- Source Snapshot panel focused page display.

It does not implement range selection, Source Board, annotation editing, PDF rendering, or Canvas.

---

## 3. Generation Behavior

Inputs:

```text
note_block_sources
evidence_items
source_snapshots
source_snapshot_pages
```

Rules:

- `note_block_sources` generate anchors linked to `note_block_source` and `note_block`.
- `evidence_items` generate anchors linked to `evidence_item` and `evidence_set`.
- Anchor matching uses document, chunk, source material, fragment, segment, and page range metadata.
- If no snapshot or page can be found, generation returns a warning and skips that source row.
- Re-running generation must not duplicate equivalent anchors or links.
- Existing notes, evidence, source material, and snapshot content must not be rewritten.

---

## 4. API Behavior

Routes:

```text
GET /api/source-anchors?course_id=...&target_type=...&target_id=...
POST /api/source-anchors/generate
GET /api/source-anchors/:id
GET /api/source-anchors/:id/jump-target
POST /api/source-anchors/:id/refresh
```

Responses must be user-scoped.

`GET /api/source-anchors/:id/jump-target` returns:

```json
{
  "anchor": {},
  "snapshot": {},
  "page": {},
  "focus": {
    "page_start": 1,
    "page_end": 1,
    "text_start_offset": null,
    "text_end_offset": null
  },
  "warnings": []
}
```

---

## 5. UI Behavior

- Note detail fetches anchors for visible NoteBlock ids.
- Existing source reference rows show `View source` when a matching anchor exists.
- Clicking `View source` opens the source snapshot panel for the anchor jump target.
- Focused source pages receive a visible highlight style.
- If a jump target cannot be resolved, show a warning toast.
