# v2.5.0 Engineering Spec - Template Definition Runtime

**Status**: implemented

## Summary

v2.5.0 introduces a persistent `TemplateDefinition` runtime while keeping the v2.1.1 static registry as seed/fallback input. Runtime templates become the source for new NoteBlock metadata, while old NoteBlocks continue to resolve softly through compatibility logic.

## Runtime Service

Implemented in:

```text
server/src/services/templateDefinitions.ts
```

Core functions:

- `seedSystemTemplateDefinitions`
- `listTemplateDefinitions`
- `getTemplateDefinition`
- `mergeRuntimeNoteBlockTemplateMetadata`
- `getTemplateCompatibilityReport`
- `legacyBlockTypeForRuntimeTemplate`

Resolver order:

1. `metadata.template_definition_id`
2. `metadata.template_key` + `metadata.template_version`
3. legacy `metadata.template_id`
4. legacy `block_type`
5. fallback `text.paragraph`

Strictness:

- manual/canvas creation rejects explicitly unknown templates;
- proposal generation may fallback and warn;
- old blocks are read softly and reported.

## Existing Flow Integration

Manual NoteBlock create/update:

- route-level metadata merge now uses runtime resolver.
- unknown explicit template references fail on create.
- unknown legacy metadata is preserved unless a user explicitly changes template metadata.

Organized note proposals:

- deterministic fallback now uses runtime metadata.
- AI output uses runtime resolver.
- unknown AI template output falls back with warnings.
- apply writes runtime metadata into real NoteBlocks.

Canvas-created NoteBlocks:

- `createCanvasNoteBlock` resolves runtime template before creating NoteBlock.
- resulting CanvasNode remains projection only.

## Graph-Native Migration Evidence

`TemplateDefinition` has stable identity and should be treated as a future graph-adjacent capability node candidate.

Likely v3.x mapping:

```text
(:NoteBlock)-[:USES_TEMPLATE]->(:TemplateDefinition)
```

For now:

- behavior fields are JSON properties;
- render hints are projection metadata;
- compatibility states are migration evidence;
- template seeding is runtime infrastructure, not package import.
