# V2.BN.7 Existing Research Intake

> 本文是 V2.BN.7 的旧调研 intake。目的不是重写 PI-046 或 Better Notebook Research，而是判断哪些结论可以直接支撑 V2.BN.8 Canvas Engine Foundation，哪些结论需要在 Canvas Engine clean branch 前补调研或技术 spike。

## 1. 总结

已有调研已经足够支持一个方向判断：

```text
Coincides 应继续保持自己的 truth layer。
AFFiNE / BlockSuite 可以作为成熟体验和工程架构参考。
当前 branch 的 NoteDetail runtime 只能作为 prototype evidence，不应继续作为长期 Canvas Engine 地基。
V2.BN.8 应进入 Canvas Engine Foundation，并预留 V2.BN.8.x 反复打磨。
```

但已有调研还不足以直接开写完整 Canvas Engine。缺口主要集中在：

- canvas-native coordinate model；
- pan / zoom 下的文本编辑和 selection；
- transformed canvas 下的 popover / toolbar / inspector 定位；
- large note / multi-frame / relation-heavy 性能预算；
- frame export 和 page boundary 的工程实现；
- relation path / connector endpoint 的预留方式；
- 是否借鉴 BlockSuite Edgeless 的内部结构，而不是只借鉴视觉效果。

## 4. 已经足够确定的方向

### 4.1 Truth Layer 不交给外部 runtime

无论 V2.BN.8 选择自研 Canvas Engine，还是后续重新评估 AFFiNE / BlockSuite，以下边界都不应改变：

- NoteBlock content truth 属于 Coincides Core；
- BlockBox / placement / layout truth 属于 Coincides Core；
- source provenance 属于 Coincides Core；
- ObjectRelation 属于 Coincides Core；
- TemplateDefinition / field schema / field value 属于 Coincides Core；
- editor runtime 只负责 projection、interaction、temporary state、view rebuild。

### 4.2 AFFiNE / BlockSuite 是参考，不是答案

AFFiNE 的价值主要在三处：

- 证明 page 与 edgeless 可以并存；
- 提供 mature notebook / canvas UX benchmark；
- 提供 frame、connector、toolbar、selection、zoom、bottom tool palette 的工程参考。

它不能直接解决：

- Coincides 的 source chain；
- internal source / external source versioning；
- ObjectRelation 与 CanvasEdge 的分离；
- TemplateDefinition / structured field truth；
- GraphRAG sidecar boundary；
- proposal-first mutation。

### 4.3 当前 branch 应收口为实验场

V2.BN.1 到 V2.BN.6 的 self-owned prototype 证明了很多体验规则，但也证明了旧 runtime 不应无限补丁化。它应该成为：

- experiment branch；
- fallback branch；
- UX reference branch；
- Canvas Engine anti-pattern library。

## 6. 对 V2.BN.8 的直接影响

V2.BN.8 不应直接追求完整无限画布宇宙。第一版 Canvas Engine Foundation 应先证明：

- 有统一 NoteCanvas；
- 有正式 PageFrame；
- PageFrame 外有 FrameOutsideWorkspace；
- pan / zoom / viewport persistence 能跑；
- selection / hit-testing / placement / resize 能跑；
- overlay / popover 不再跟 block 视觉层打架；
- block measurement / auto-height 不再靠临时补丁；
- relation connector endpoint 至少有预留；
- 可以设置 V2.BN.8.x 的可靠性打磨空间。

## 7. Intake 结论

已有调研给出的不是“直接实现方案”，而是“不要走错方向”的护栏。

V2.BN.7 接下来要做的，是把当前 self-owned prototype 的真实经验接到这些护栏上：

```text
旧调研
  -> 证明方向和边界

当前 prototype
  -> 证明体验价值和工程风险

V2.BN.7 autopsy / closure / gate
  -> 把方向、经验、风险变成 V2.BN.8 Canvas Engine 的开工条件
```
