# V2.BN.7 Canvas Engine Route Decision Draft

> 本文给出 V2.BN.8 的默认路线建议。它是 draft，最终仍需要 Henry 拍板。

## 1. 推荐结论

默认路线：

```text
self-owned Canvas Engine on clean branch
```

同时保留两条后备：

```text
hybrid route with selected external ideas
AFFiNE / BlockSuite-first fallback if self-owned engine fails
```

这不是因为自研最轻松，而是因为 Coincides 的核心能力太依赖自己的 truth layer：

- SourceReference；
- internal/external provenance chain；
- ObjectRelation；
- structured NoteBlock FieldValue；
- TemplateDefinition；
- proposal-first mutation；
- future GraphRAG adapter boundary。

这些都不能被外部 editor runtime 反向定义。

## 2. 路线一：Self-Owned Canvas Engine

### 优点

- 数据主权最清晰；
- NoteBlock / placement / source / relation / template 可以完全按 Coincides 需要定义；
- 可以直接继承 V2.BN.1-V2.BN.6 的产品经验；
- 可以保留当前 branch 作为 fallback；
- 不被 AFFiNE / BlockSuite release、license、internal API 绑架；
- 更适合未来 Source Library、Relation Runtime、Template Studio、GraphRAG adapter。

### 风险

- pan/zoom、selection、text editing、measurement、overlay 都是硬问题；
- 性能需要自己压；
- 需要 V2.BN.8.x 反复打磨；
- 初期速度可能慢于直接套成熟 editor runtime。

### 适用条件

- Henry 接受 clean branch；
- 接受实验性 layout data clean reset；
- 接受 V2.BN.8.x 打磨空间；
- 接受先做 engine reliability，再做更上层功能。

## 3. 路线二：Hybrid Route With Selected External Ideas

### 含义

不直接采用 AFFiNE / BlockSuite runtime，但学习它们的：

- frame；
- connector；
- bottom toolbar；
- overlay；
- selection；
- viewport；
- LOD；
- export frame。

### 优点

- 保留 Coincides truth layer；
- 可以吸收成熟产品经验；
- 不承担 full fork 或 deep adapter 的成本；
- 和 self-owned Canvas Engine 可并行。

### 风险

- 学 UI 容易，学 runtime 结构难；
- 如果只模仿视觉，仍可能复刻旧 runtime 的脆弱性；
- 需要定期对照 AFFiNE / BlockSuite 的真实行为，不要凭截图猜。

### 适用条件

这是当前推荐路线的自然组成部分：self-owned engine + external ideas。

## 4. 路线三：AFFiNE / BlockSuite-first

### 优点

- Edgeless、frame、connector、viewport、selection 可能已有成熟实现；
- 大量 canvas 问题可能已有工程解法；
- 体验上有现成 benchmark。

### 风险

- full AFFiNE fork 成本高；
- BlockSuite internal model 未必贴合 Coincides；
- frame / connector 可能是几何 projection，不是 Coincides semantic truth；
- sidecar identity map 必不可少；
- source/relation/template/proposal-first 都要写 adapter；
- 未来升级成本不可控。

### 适用条件

只有在 self-owned Canvas Engine 明显失败时，才建议重新评估：

- text editing under transform 长期不稳定；
- 1000 blocks benchmark 无法过；
- relation path layer 工程成本过高；
- overlay / selection 复杂度持续失控；
- 自研速度明显拖垮整个 Better Notebook。

## 5. 路线比较

| 维度 | Self-Owned | Hybrid Ideas | AFFiNE / BlockSuite-first |
| --- | --- | --- | --- |
| 数据主权 | 最强 | 最强 | 需要 sidecar 强约束 |
| 开发速度 | 中慢 | 中 | 可能快，也可能被 adapter 拖慢 |
| 长期可控性 | 最强 | 最强 | 中低 |
| 工程风险 | 高 | 中高 | 中高 |
| UX benchmark | 需要自己磨 | 可借鉴 | 成熟 |
| Source/Relation/Template 适配 | 最自然 | 最自然 | 需要大量桥接 |
| fallback 成本 | 可保留当前 branch | 可保留当前 branch | 迁移/桥接成本高 |

## 6. 推荐路线

推荐：

```text
V2.BN.8 使用 self-owned Canvas Engine clean branch。
V2.BN.8.x 预留反复打磨空间。
AFFiNE / BlockSuite 作为体验和工程参考，不作为默认 substrate。
当前 branch 保留为 fallback/reference。
```

## 7. 必须设置的失败阈值

自研 Canvas Engine 不是信仰。必须允许失败。

如果出现以下情况，应启动路线复盘：

- 1000 blocks 基础场景无法达到可接受交互；
- pan/zoom 下文本编辑反复不稳定；
- measurement service 无法压住 overlap；
- overlay portal 持续混乱；
- relation connector reserve 与 block placement 冲突严重；
- V2.BN.8.x 打磨后仍达不到 V2.BN.1-V2.BN.5 的自然写作体验；
- 工程复杂度明显超过当前团队承受范围。

## 8. 决策草案

建议 Henry 批准：

```text
V2.BN.8 = Canvas Engine Foundation
default route = self-owned clean branch
external route = reference / fallback
current branch = experiment / fallback / reference
no long-term migration from experimental better_notebook_layout unless real user data appears
V2.BN.8.x reserved for reliability and UX polish
```
