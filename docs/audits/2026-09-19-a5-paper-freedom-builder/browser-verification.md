# 隔离浏览器验证

使用真实 Chrome、现役前端与后端，端口 5105/4105；创建独立临时数据库及本地测试账户。只操作本次夹具，未使用用户数据。完整观察、夹具修正过程见 [browser-smoke.md](../../../.codex-tmp/a5-paper/browser-smoke.md)。以下是人工操作与 DOM/AX 观察，不混入单元测试计数。

| 操作 | 观察结果 |
|---|---|
| 正常阅读打开外观浮卡 | 八种纸型预设，无单页尺寸输入/拖调手柄 |
| A4→A5 纵向→A3 横向 | 读数依次 14.8×21cm、42×29.7cm，纸面及阅读比例随之改变 |
| 进入 Layout，单位改 mm，宽度输入400并提交 | 整本默认420×297mm保持，当前页400×297mm且标为异形 |
| 恢复默认，再 Ctrl+Z | 默认标签恢复，随后撤销回40×29.7cm异形页 |
| 刷新页面 | A3横向默认及单页40×29.7cm覆写均保留 |
| 实际拖动页角 | 40.00×29.70cm→42.04×30.92cm；Ctrl+Z/ Ctrl+Shift+Z 在两者之间恢复，确认已经提交历史而非仅有预览 |
| 既有 Web 长页夹具 | 浮卡只显示“Web 长页随内容生长。”；整本纸型选择器0个、页角拖调手柄0个 |

浏览器发现并修复了新旧浮卡内容重复 React key；独立复核发现的预览回流导致拖调未保存问题也在修复后通过上述真实拖动验证。数值与撤销检查覆盖正常保存和重载；A1 多页、装订/封面拓扑、失败/导航代次保护由对应自动回归覆盖，不把本次空白浏览器夹具说成多页端到端验收。

夹具初始化先遇到空库默认 v1 坐标设置及 raw notes API 未附带 Web 集合的问题；按现役 v2 元数据和 B1c 集合补齐后验证。没有修改产品 schema、坐标契约或用户数据库。测试结束已关闭本次 Chrome 标签页及两个临时服务。
