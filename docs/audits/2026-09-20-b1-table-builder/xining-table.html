青苗法青黄不接时向农户贷钱或谷物，随夏秋税归还。缓解农户周转困难，抑制高利贷。
免役法按户等交纳免役钱，由官府募人承担差役。减轻轮差对生产的干扰。
农田水利法鼓励地方兴修水利，按受益范围分担费用。改善灌溉与防洪，扩大耕地。
方田均税法丈量土地，按土质与肥瘠分等计税。清查隐田，使田赋负担较为均平。
市易法设市易机构收购滞销货物，并向商户提供信贷。调节供需，限制大商人垄断。
均输法统筹东南财赋采购，因地择便、视价调运。降低采购与运输成本。
保甲法编组乡村居民，组织巡查并训练保丁。加强地方治安，补充兵源。
保马法由民户养育官马，按规定给予便利。增加战马供给，减少官养费用。
将兵法以将为单位整编军队，选任将官专责训练。加强训练与指挥，提高战斗力。
