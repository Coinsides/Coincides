# V13.2 单 4b · 合成例外行翻旗停线核对单

**结论：施工前停线。** 单 4b §一.2b 要求不满足双尺不变量的行原样保留；§一.2e 要求例外不阻塞 v2 翻旗，并以“4a 读法安全解释”为前提。现物对有帧的 `page_frame_local` 行在 v2 无条件叠加内容原点，原有合成样本已能推翻此前提。没有执行迁移、备份、翻旗或回滚。

## 现物证据

- `client/src/pages/Notes/canvasEngine/placementContractService.ts:44`：`resolveWorldRect` 的 v1 返回原 y；`:54` 仅在缺帧、非 local 标签或 tray 时返回原几何；`:58` 对其余 local 行返回 `y + origin.y`。没有例外行的 v1 兼容分支。
- 同文件 `:62`：`resolveScreenRect` 在 v2 使用上述 world y，因此差异也进入屏显坐标，并非只有 census 的解释不同。
- `client/src/pages/Notes/canvasEngine/placementService.ts:212` 的现役 hydration 已一起调用验证；两个契约下，这些 local 样本的 y 都保持原值，不能在翻旗前后抵消差异。
- `server/scripts/wildernessShadow/synthetic.ts:83`、`:84`、`:85`、`:99`：直接复用单 3 的 `local`、`mixed`、`second`、`cross-note` 四个现成样本，没有改写 fixture 或另造语义函数。

## 实跑采样

以下 world rect 均以 `(x,y,width,height)` 记。探针给 `pageOffsetX=O.x`，只为对齐横轴、隔离纵轴反例；**不是宣布实际 UI 的 pageOffsetX 应取该值**。纵轴差异与 pageOffsetX 无关。所有输入均为 formal page、`page_frame_local`。

| 合成行 | O=(Ox,Oy) | 原始 (x,y) | 冻结规则候选 (x,y) | v1 world | 候选 v2 world | 原行不动后的 v2 world |
| --- | --- | --- | --- | --- | --- | --- |
| local | (110,220) | (10,10) | (10,10) | (120,10,20,20) | (120,230,20,20) | (120,230,20,20) |
| mixed | (110,220) | (10,230) | (10,10) | (120,230,20,20) | (120,230,20,20) | (120,450,20,20) |
| second | (110,520) | (10,530) | (10,10) | (120,530,20,20) | (120,530,20,20) | (120,1050,20,20) |
| cross-note | (1010,2020) | (10,10) | (10,10) | (1020,10,20,20) | (1020,2030,20,20) | (1020,2030,20,20) |

`local` 的 `10 - 220 = -210 < -0.5`，按冻结规则判已 local、候选 y 保留 10；双尺不等，所以必须入例外并原样不动。翻旗后 world 与 hydration 后 screen 的 y 都从 10 变为 230，位移 **+220**。`cross-note` 同理位移 **+2020**。这两个反例即足以阻止无条件翻旗。

`mixed` 与 `second` 是归一成功的正对照：候选经过双尺严格全等。表中最后一列对这两个正对照只说明“若不归一”的读法，不声称它们应被列为例外。

复用了单 3 的 `readShadowReport`：合成数据 **8 notes、24 项三表预计守恒全等**。这只证明影子计划保全行身份，不能证明翻旗后的坐标不变，也不是迁移后实测。探针还断言只读连接与序列化前后完全相等。

```javascript
import Database from 'better-sqlite3';
import assert from 'node:assert/strict';
import { createSyntheticBuffer } from './scripts/wildernessShadow/synthetic.ts';
import { readShadowReport } from './scripts/wildernessShadow/census.ts';
import { resolveWorldRect, resolveScreenRect } from '../client/src/pages/Notes/canvasEngine/placementContractService.ts';
import { reconcileHydratedBlockLayoutSurfaceAuthority } from '../client/src/pages/Notes/canvasEngine/placementService.ts';
const db = new Database(createSyntheticBuffer(), { readonly: true });
try {
  const before = db.serialize();
  const report = readShadowReport(db, 's0-user', 'synthetic');
  assert.equal(report.evidence.readonlyConnection, true);
  assert.equal(report.shadow.conservationOk, true);
  assert.equal(report.shadow.conservation.length, 24);
  for (const id of ['local', 'mixed', 'second', 'cross-note']) {
    const row = db.prepare('SELECT id,note_id,x,y,width,height,frame_id,surface,boundary_role,metadata FROM canvas_placements WHERE id=?').get(id);
    const f = db.prepare('SELECT e.frame_id,p.x,p.y,p.width,p.height,e.content_inset_json FROM page_frame_extensions e JOIN canvas_placements p ON p.object_id=e.object_id AND p.note_id=e.note_id WHERE e.note_id=? AND e.frame_id=?').get(row.note_id,row.frame_id);
    const frame = { id:f.frame_id,x:f.x,y:f.y,width:f.width,height:f.height,contentInset:JSON.parse(f.content_inset_json),role:'primary_page_frame',exportable:true };
    const layout = {...row,coordinate_space:JSON.parse(row.metadata).layout_policy.coordinate_space};
    const origin = { x:frame.x+frame.contentInset.left,y:frame.y+frame.contentInset.top };
    const candidate = {...layout,y:row.y-origin.y>=-0.5?row.y-origin.y:row.y,coordinate_space:'page_frame_local'};
    const v1 = resolveWorldRect(layout,frame,'v1',origin.x);
    const v2Candidate = resolveWorldRect(candidate,frame,'v2',origin.x);
    const v2Unchanged = resolveWorldRect(layout,frame,'v2',origin.x);
    const beforeHydrated = reconcileHydratedBlockLayoutSurfaceAuthority(layout,[frame],'v1');
    const afterHydrated = reconcileHydratedBlockLayoutSurfaceAuthority(layout,[frame],'v2');
    assert.equal(beforeHydrated.y,row.y);
    assert.equal(afterHydrated.y,row.y);
    const screenBefore = resolveScreenRect(beforeHydrated,frame,'v1',origin.x);
    const screenAfterUnchanged = resolveScreenRect(afterHydrated,frame,'v2',origin.x);
    if (id === 'local' || id === 'cross-note') {
      assert.notDeepEqual(v1,v2Candidate);
      assert.equal(v2Unchanged.y-v1.y,origin.y);
      assert.equal(screenAfterUnchanged.y-screenBefore.y,origin.y);
    } else {
      assert.deepEqual(v1,v2Candidate);
    }
    console.log(JSON.stringify({synthetic:true,id,origin,input:{x:row.x,y:row.y},candidate:{x:candidate.x,y:candidate.y},v1,v2Candidate,v2Unchanged,screenBefore,screenAfterUnchanged}));
  }
  assert.deepEqual(db.serialize(),before);
  console.log(JSON.stringify({synthetic:true,conservation:report.shadow.conservationOk,checks:report.shadow.conservation.length,readonly:true,bytesUnchanged:true,result:'EXCEPTION_DRIFT_REPRODUCED'}));
} finally { db.close(); }
```
