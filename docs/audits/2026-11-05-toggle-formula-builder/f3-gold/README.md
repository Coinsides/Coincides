上一轮「65 式字符守恒」没有挡住错误公式，因为字符确实没丢。这里比的是**意思**。

| 文件 | 内容 |
|---|---|
| `F3-复核样本.docx` | 压平和其他写错的样本：argmin、argmax、定义等号、iid、limsup、带标签下括号、`w:sym`、公式内修订、式内换行、方程组对齐、斜分式、线性分式，以及 OLE 公式和脚注 |
| `F1-全结构.docx` | F1 用过的全结构样本 |

## 第二语料（防过拟合，builder 没见过）

`check_second_corpus.mjs` 自带样本定义，每次运行重新生成 `F3-新样本.docx`，种子是 `seed.docx`。判定同下。`baseline-second-corpus-F3.txt` 是 F3 首版的结果，46 对、18 降级、1 EYE、16 错。

这 16 条里有 6 条反驳后**不算缺陷**，F3b 不必让它们变绿：`修订在rPr`、`分母修订rPr`、`结构标记删除`（`w:rPr` 里放 `w:del`，没有真实生产者）；`根号隐藏次数`、`求和隐藏上限有内容`（隐藏标记配有内容的槽）；`Symbol字体文本`。`箭头标注` 的 EYE 我核过，`pos=top` 确实是箭头在上，产物对，是我金标准写反了。

## 怎么跑

```bash
cd <repo>/server
node --import tsx ../docs/audits/2026-11-05-toggle-formula-builder/f3-gold/check_gold.mjs <repo>
```

脚本同时认 `\(…\)` 和 `$…$`，修前修后都能跑。解析器模块从第二个参数指的仓库导入。

## 判定

| 判定 | 含义 | 过关？ |
|---|---|---|
| `ok` | 与某个金标准读法语义相同。多余花括号、数学或文本模式、`\left` 与普通定界符不算差别 | 过 |
| `degraded` | 诚实降级：没有定界符段，有「未能转换」字样，且横幅响 | 过 |
| `EYE` | 结构和字符都对得上，顺序或嵌套不同，要人看 | 我逐条看 |
| `WRONG` | 其他一切。包括写了「未能转换」但横幅不响 | 不过 |
| `INVALID` | KaTeX 解析失败 | 不过 |
| `MISSING` | 找不到这一段 | 不过 |

这对应单面「语义正确或走诚实降级，没有第三种」。

## 限定

- **没有 MS Word。** 样本是照 Word 的 OMML 写法手造的。真实文档可能有这里没有的结构，所以 F3 的兜底（说转不了）和这张表同样重要。
- **语义比对有上限**。它比的是 KaTeX 解析树的规范形，不懂数学等价：`a+b` 和 `b+a` 算不同，这是有意的。
- 金标准里有多个读法的条目，是我认为都不改变意思的写法。builder 觉得还有别的合理写法，可以提出来，由 Main_Designer 判，不要直接改 `gold.json`。
- 占位符的正则是 `未能转换|could not be converted`。builder 用别的措辞的话，改脚本里 `DEGRADED` 一处，并在回执写明。
