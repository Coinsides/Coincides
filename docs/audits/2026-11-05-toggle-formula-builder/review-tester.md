### 小尾巴（都不挡上线）

1. **网格预览多出 `$`**：formula 卡如果存的就是 `\(…\)`，预览会显示 `$` 公式 `$`。原因是 `client/src/pages/Decks/components/types.ts:30` 的 `getContentPreview` 在外面再包了一层 `$`，这个文件不在 F3b 清单里。Agent 建卡时服务端已经把定界符剥掉了，所以只有手工存进去的才会这样，Henry 目前 0 张卡。一行可修。
2. **编辑弹窗预览报错**：卡片编辑弹窗的公式预览写的是 `` `$$${formula}$$` ``，遇到带 `\(…\)` 的公式字段会报错。同一类问题，同样少见。
3. **KaTeX 字体覆盖**：`\mathbb` 用在数字和小写字母上，`\mathcal` 用在小写字母上，KaTeX 字体里没有这些字形，所以 `𝟙` 会显示成普通的 `1`。存下的 LaTeX 是对的，只是显示受限。
4. **卡片里的美元金额**：「售价 $100，每年付 $5」两边都把两个 `$` 之间的部分当成公式。这是卡片沿用 `$` 语义造成的，既有问题，与 F3b 无关，记录在案。
