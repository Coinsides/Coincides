# 说明书「已知」一节素材:留字框(builder 2026-11-08,对象 r2.3c;取代 r2.3 包里那份)

> 供 Main_Designer 收割时写进 `app-operating-manual.md`。对象:编辑器组 r2.3c(主 JS `index-BVrO4Ql1.js`)。只写人看得见的行为,不写实现。

## 什么时候会出现留字框

- 你在标题后面接着打字时,应用正在把标题和正文分成两块。这时如果有几个字一时放不进笔记(保存很慢、建块失败、你那一刻离开了这篇笔记),这些字不会丢。
- 它们留在一个小框里,框上写着「Not in the note yet」;同时存在这台浏览器里,下次打开这篇笔记还在。

## 字会自己回去吗

- **多半会**。保存恢复了,或者你重新打开这篇笔记,框里的字会自己落回原处,框随之消失。
- **你正在框里打字时,它们不会落回。** 光标一离开框(点回笔记或别处),下一次才落回去。你在框里打的字也算在里面。
- **落回去以后,标题和后面的正文可能还在同一块里。** 这不影响内容。你下次在那一块里编辑时,它们会自动分成两块。
- 字自己落回时,不会把光标从你正在写的地方拿走。
- 少数情况它们回不去:原来那一行没了,或者认不准该放哪。字就一直留在框里,等你处理。

## 框在哪里

- **平时**:框正好盖在那几个字原来所在的那一行上,和那一行一样高。字多时在框里上下滚动,不会盖住下一行。页面上方出现横幅、滚动、改窗口大小,框都跟着那一行走。
- **那一行找不到了**(被移走、删掉,或者框会挡住别的行):框挪到正文栏外面,先右边,右边不够就左边;一侧至少要 200 像素宽才放。停在那里的框最高 160 像素,字多时在框里滚动。
- **两边都放不下**(窗口很窄):框收成一条提示,只剩「Not in the note yet」和按钮。点「Show words」字就出来,点「Hide words」再收起。
- **有好几个留字框时**:它们依次往下排,互不重叠。每个框的 Discard 只删它自己那几个字。
- **窗口窄到连提示条都找不到空地方时**:提示条停在窗口右上角,可能压住一点别的东西。这是已知限制。

## 你能做什么

- **什么都不做**:多数时候字会自己回去。
- **复制**:字没回去、你又要用,就选中框里的字复制,粘到想放的地方。**粘进去之后再点 Discard 把框关掉**,否则框里的字以后可能还会自己回去,笔记里就有两份。
- **Discard**:删掉这个框里的字,包括存在浏览器里的那一份。删了就找不回来。
- 除了你自己点 Discard,框和它的字不会被别的操作删掉。

## 已知、不算故障

- 字落回以后,标题和正文可能暂时同在一块,编辑那一块时才分开。
- 你一直把光标留在框里,字就一直不落回。
- 框挪到栏外以后,只有原来那一行又出现在屏幕上,它才会回去。
- 很窄的窗口(手机宽)下,收起的提示条可能停在右上角。
- 极少数情况下(同一块里恰好新建了一行编号相同、类型相同、又是空的),框里的字可能落进那一新行。已记录,另行处理。
