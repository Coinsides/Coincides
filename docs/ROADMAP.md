## 3. V2.BN.12「外骨骼与地板」

> 权威定义见宪章 §13 + 拍板记录 待拍-8。本节是执行视图，不是定义源。

### 3.1 必修五件

| # | 内容 | 备注 |
|---|---|---|
| ① | **MCP 工具面** —— 操作暴露为工具 + 守卫 + 收据 | 头号前置；**末端执行器首次实体化**。架构落点需在 `ARCHITECTURE.md` 新增边界章节 |
| ② | **流式装配面 + 地板组件** | 一维组件流成为默认写作面；生而结构化的落点 |
| ③ | **选区收据系统** | 一切手势归一为 `{对象 IDs, 文字范围, 几何, 时刻}`；**选区收据＝还没保存的锚** |
| ④ | **层0/层1 + 抽取矩阵** | 原件观看 + 区域锚；**解析按需，不入库即解析**。⚠️ **层0 schema 与窄腰契约本版定死**；层2 VLM 本体归 Agent 版 |
| ⑤ | **token 预设 v0 + root-cause 并案修理** | 「只修活的」—— 噪声随面死，机件随面活 |

### 3.2 随行三线

摄入收据埋线 · 数据隔离与备份纪律 · AI-readable tree 对齐 DOM（修画布双盲，a11y + agent 可操作性一石二鸟）。

### 3.3 明确不带（勿自行扩范围）

知识图谱（按证据入场）· Relation 消费面 + 评估执行器（地板睡觉零成本）· 订单规格细做 · 产房沙盒 · 意图路由器 · 阅卷 · homing projection · 墙 register。

### 3.4 两条边界（宪章已拍，施工必守）

- **canvas 减负（待拍-1）**：保留＝写作顺手 / 装配 / 圈选锚 / 打散重排；释放＝无尽打磨 / Figma 级 / 炫技。这是**范围收缩，不是 ADR-0001 路线推翻**。
- **page frame 退役（待拍-2）**：Note ＝ 唯一文档单位，page frame 降为「导出取景框」。⚠️ **V12 期间机器不物理拆** —— 新流面**绕开**而非拆除，物理清场另立专项。

## 4. 长青参考（**经分诊筛过**）

> ⚠️ **重要：不能整段照搬旧路线图的「长青参考」。**
> 旧件的阅读指南自称「§1–§5 长青参考（不随版本过时）」，**这句话已不成立**：
> - 旧 **§2 产品北极星** 把定位写作 `page-first, canvas-backed, **block-based**` —— `block-first` 早在 **2026-06-20** 就被 `TextFlow-first / ContentGroup-aware` 取代（见 `PRODUCT.md` 06-20 教义），`page-first / canvas-backed` 又被待拍-1/2 取代。**这一节被「长青」标签保护着错了两个月。**
> - 旧 **§3.3「Page-first, Canvas-backed」** 整节被待拍-2 与宪章 §4 表面重划取代。
>
> 教训记档：**「长青」不是可以自我声明的属性**。下面每条都注明了它凭什么还活着。

| 原节 | 判定 | 凭什么 |
|---|---|---|
| §3.1 点击，然后书写 | ✅ 存活并**加强** | 与宪章 §4「流式装配面＝默认面」同向；空白页应邀请写作，用户不必先理解对象模型 |
| §3.2 内容 / 排版分离 | ✅ 存活（**词汇需更新**） | 原则＝分离真相，是全项目唯一的结构律；但 `NoteBlock / BlockBox` 是 block-first 残留词汇，现行表述见 `PRODUCT.md` 原则 4 与 06-29 设计语法 |
| §3.3 Page-first, Canvas-backed | ❌ **被取代** | 待拍-1 + 待拍-2 + 宪章 §4 |
| §3.4 工程 metadata 退到幕后 | ✅ 存活 | 与 `PRODUCT.md` 原则 10「界面默认安静」同源，未被任何拍板触及 |
| §3.5 AI 站在成熟的人类表面之后 | ✅ 存活并**加强** | V12 的整个存在理由就是这条：先建 agent 进来之前必须存在的东西。可靠性顺序「工程可靠 → 用户可靠 → 人机协作可靠」不变 |
| §1 路线图职责 | 🔶 部分 | 「旧地基不废掉，换重心」的框架仍对；但「新重心＝收进成熟笔记产品」的表述早于本次转向 |
| §2 产品北极星 | 🔶 **部分被取代** | `block-based` / `page-first` / `canvas-backed` 三个词已死（见上方说明）。**但北极星本身仍是「信息处理中台」** —— 2026-08-20 Henry 亲裁：**保留更宽的定位，学习是当前阶段焦点不是天花板**，宪章 §1「学习主力工具」的范围部分随之降级为阶段焦点。本体论（长着投影的收据数据库）不受影响。权威表述见 `PRODUCT.md`「Product Purpose」 |
| §4 学习模板与产品参考 | ✅ 存活 | Notion / AFFiNE / Word / tldraw / Obsidian 的对照分析仍是参考材料，不随版本过时 |
| §5 必读调研索引 | 🔶 部分 | 索引结构有用，但所列 active reference 多已降级（`PRD.md` / `Reality-Check` / `Relation-Product-Design` 均已标脱节或 superseded）；**新时代的调研索引见下方 §5** |

### 仍然生效的三条硬边界（跨时代不变）

1. **Agent 移出 BN 版本线** —— Agent 是之后单独接入的**操作者**，不是 BN 的依赖。（2026-07-01 拍定，V12 承接：本版建的是它要插进来的插座）
2. **完工判据：用户可靠 ＝ Henry 可靠** —— DoD ＝ 真实旅程无死路，不是功能清单打勾。
3. **红线不变式** —— Agent 能做的，人类必须 100% 能做；同门同钥无后门；大动作全收据可撤销。

## 7. 版本纪律

### 7.1 命名

`V2.BN.x` / `V2.BN.x.y`。

### 7.2 每个 12.x plan 必带（2026-07-15 §十 新增）

- **触及面申报** —— 声明碰 / 不许碰哪几层地板。横切版本的炸伤半径靠这个划界。
